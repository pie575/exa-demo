Deep Search는 Search API의 리서치 모드입니다. 동일한 `/search` 엔드포인트를 사용하지만, 검색 과정에서 여러 차례 search를 수행하고 evidence를 검토한 뒤 접근 방식을 개선해 근거 기반 결과를 synthesis할 수 있습니다.

잘 정리된 질의에 대해 순위가 매겨진 페이지가 필요할 때는 standard Search를 사용하세요. 답을 찾는 데 리서치가 필요할 때는 Deep을 사용하세요.

<div id="how-deep-search-works">
  ## Deep Search 작동 방식
</div>

Deep Search는 최종 response 이전에 리서치 loop를 추가합니다:

<Steps>
  <Step title="search 계획 수립">
    Exa는 사용자의 `query`에서 시작해, 요청의 여러 측면을 포괄하도록 이를 여러 searches로 확장할 수 있습니다.
    `additionalQueries`로 출발점이 될 변형 질의를 직접 제공할 수도 있습니다.
  </Step>

  <Step title="search 및 검토">
    Deep은 evidence를 찾아 요청과 대조하고, 무엇이 뒷받침되는지, 무엇이 아직 부족한지 판단합니다.
  </Step>

  <Step title="정교화">
    evidence가 불완전하거나 서로 모순될 경우, Deep은 처음 발견한 그럴듯한 페이지를 그대로 반환하지 않고
    더 정밀하게 겨냥한 search를 수행할 수 있습니다.
  </Step>

  <Step title="선별 및 synthesis">
    Deep은 유용한 결과를 선별한 뒤, 다른 search types와 동일한 synthesis path를 사용합니다.
    `outputSchema`를 제공하면 response에 구조화된 `output.content`와
    `output.grounding`의 field 단위 citations가 포함됩니다.
  </Step>
</Steps>

이 과정은 목록과 structured outputs에 특히 유용합니다. 요청한 항목마다 서로 다른 search가 필요할 수 있는데, Deep은 최종 구조를 생성하기 전에 그 결과들을 모아 검증할 수 있습니다.

<div id="choose-a-deep-mode">
  ## Deep 모드 선택하기
</div>

| 유형               | 사용 시점                                                |
| ---------------- | ---------------------------------------------------- |
| `deep-lite`      | 가벼운 질의 확장과 synthesis가 필요할 때                          |
| `deep`           | 반복적인 search, evidence 수집 또는 여러 개의 구조화된 항목이 필요한 작업일 때 |
| `deep-reasoning` | 어렵거나 서로 상충하는 evidence에 대해 더 신중한 추론이 필요한 작업일 때        |

리서치 워크플로우라면 `deep`으로 시작하세요. 작업이 더 단순하고 latency가 중요하다면 `deep-lite`로 전환하세요.

<Tip>
  장시간 실행되는 리서치, 리스트 빌딩, 멀티홉 enrichment에는 `deep-reasoning` 대신 [Exa Agent](/ko/docs/agent/quickstart)를 사용하세요. Agent는 실행당 더 많은 연산을 사용하며 근거 기반의 구조화된 결과를 반환합니다.
</Tip>

현재 비용 및 latency 관련 안내는 [Pricing](/ko/docs/admin/pricing#deep-search)을 참고하세요.

<div id="make-a-deep-request">
  ## Deep 요청 보내기
</div>

일반 Search API 요청에 `type`을 설정하세요:

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()

  result = exa.search(
      "Compare how major database vendors support vector, keyword, and hybrid retrieval",
      type="deep",
      contents={"highlights": True},
  )
  ```

  ```javascript JavaScript theme={null}
  import Exa from "exa-js";

  const exa = new Exa();

  const result = await exa.search(
    "Compare how major database vendors support vector, keyword, and hybrid retrieval",
    {
      type: "deep",
      contents: { highlights: true }
    }
  );
  ```

  ```bash cURL theme={null}
  curl -s -X POST "https://api.exa.ai/search" \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer $EXA_API_KEY" \
    -d '{
      "query": "Compare how major database vendors support vector, keyword, and hybrid retrieval",
      "type": "deep",
      "contents": { "highlights": true }
    }'
  ```
</CodeGroup>

Deep는 선별된 검색 결과를 `results`에 담아 반환합니다. 종합된 답변이나 구조화된 데이터셋까지 받으려면 `outputSchema`를 추가하세요.

<div id="provide-starting-queries">
  ## 시작 질의 제공하기
</div>

Deep은 보통 어떤 검색을 수행할지 스스로 결정합니다. 리서치에서 반드시 다뤄야 할 특정 용어나 관점, 하위 문제를 이미 알고 있다면 `additionalQueries`를 사용하세요:

<CodeGroup>
  ```python Python theme={null}
  result = exa.search(
      "Compare current approaches to inference-time scaling",
      additional_queries=[
          "inference-time compute scaling benchmark",
          "test-time reasoning methods survey",
          "adaptive compute language models",
      ],
      type="deep",
      contents={"highlights": True},
  )
  ```

  ```javascript JavaScript theme={null}
  const result = await exa.search(
    "Compare current approaches to inference-time scaling",
    {
      additionalQueries: [
        "inference-time compute scaling benchmark",
        "test-time reasoning methods survey",
        "adaptive compute language models"
      ],
      type: "deep",
      contents: { highlights: true }
    }
  );
  ```

  ```bash cURL theme={null}
  curl -s -X POST "https://api.exa.ai/search" \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer $EXA_API_KEY" \
    -d '{
      "query": "Compare current approaches to inference-time scaling",
      "additionalQueries": [
        "inference-time compute scaling benchmark",
        "test-time reasoning methods survey",
        "adaptive compute language models"
      ],
      "type": "deep",
      "contents": { "highlights": true }
    }'
  ```
</CodeGroup>

기본 `query`는 항상 포함됩니다. 추가 질의는 최대 10개까지 지정할 수 있으며, 이 목록은 Deep search types에서만 사용할 수 있습니다.

검색량을 늘리려는 목적으로 표현만 조금 바꾼 질의는 넣지 마세요. 각 질의가 의미 있게 다른 검색 방향을 더할 때만 추가하세요.

<div id="guide-behavior-and-output-separately">
  ## 동작과 output을 따로 제어하기
</div>

`systemPrompt`와 `outputSchema`는 요청에서 서로 다른 부분에 영향을 줍니다.

* `systemPrompt`는 소스 선호도, 최신성, 중복 제거, Deep의 리서치 동작을 안내합니다.
* `outputSchema`는 최종 형태를 정의하고 synthesis를 트리거합니다.

질의에는 무엇을 리서치할지를, 시스템 prompt에는 그 리서치를 어떻게 수행하고 제시할지를 담아야 합니다.

<CodeGroup>
  ```python Python theme={null}
  result = exa.search(
      "Find AI infrastructure companies that announced Series A or B funding in the last six months",
      type="deep",
      system_prompt="Prefer company announcements and investor portfolio pages. Exclude duplicate rounds.",
      output_schema={
          "type": "object",
          "required": ["companies"],
          "properties": {
              "companies": {
                  "type": "array",
                  "maxItems": 8,
                  "items": {
                      "type": "object",
                      "required": ["name", "round", "amount"],
                      "properties": {
                          "name": {"type": "string"},
                          "round": {"type": "string"},
                          "amount": {"type": "string"},
                      },
                  },
              }
          },
      },
  )
  ```

  ```javascript JavaScript theme={null}
  const result = await exa.search(
    "Find AI infrastructure companies that announced Series A or B funding in the last six months",
    {
      type: "deep",
      systemPrompt:
        "Prefer company announcements and investor portfolio pages. Exclude duplicate rounds.",
      outputSchema: {
        type: "object",
        required: ["companies"],
        properties: {
          companies: {
            type: "array",
            maxItems: 8,
            items: {
              type: "object",
              required: ["name", "round", "amount"],
              properties: {
                name: { type: "string" },
                round: { type: "string" },
                amount: { type: "string" }
              }
            }
          }
        }
      }
    }
  );
  ```

  ```bash cURL theme={null}
  curl -s -X POST "https://api.exa.ai/search" \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer $EXA_API_KEY" \
    -d '{
      "query": "Find AI infrastructure companies that announced Series A or B funding in the last six months",
      "type": "deep",
      "systemPrompt": "Prefer company announcements and investor portfolio pages. Exclude duplicate rounds.",
      "outputSchema": {
        "type": "object",
        "required": ["companies"],
        "properties": {
          "companies": {
            "type": "array",
            "maxItems": 8,
            "items": {
              "type": "object",
              "required": ["name", "round", "amount"],
              "properties": {
                "name": { "type": "string" },
                "round": { "type": "string" },
                "amount": { "type": "string" }
              }
            }
          }
        }
      }
    }'
  ```
</CodeGroup>

구조화된 항목이 세 개 이상 필요하거나 각 항목이 여러 요구 사항을 충족해야 한다면 Deep을 사용하세요. 표준 search type도 동일한 synthesis 경로를 사용하지만, synthesis 이전에 이와 같은 반복적 리서치는 수행하지 않습니다.

<div id="read-the-grounded-response">
  ## 근거 기반 response 읽기
</div>

구조화된 response는 생성된 값과 그 값의 evidence를 분리해서 보여줍니다:

```json theme={null}
{
  "results": [
    {
      "title": "Acme AI raises $30M Series B",
      "url": "https://acme.example/news/series-b"
    }
  ],
  "output": {
    "content": {
      "companies": [
        {
          "name": "Acme AI",
          "round": "Series B",
          "amount": "$30M"
        }
      ]
    },
    "grounding": [
      {
        "field": "companies[0].amount",
        "citations": [
          {
            "title": "Acme AI raises $30M Series B",
            "url": "https://acme.example/news/series-b"
          }
        ],
        "confidence": "high"
      }
    ]
  }
}
```

`output.content`는 생성된 result로 사용하고, `output.grounding`은 각 field를 뒷받침하는 소스를 보여주거나 검증하는 데 사용하세요. 직접 정의한 schema에 인용이나 confidence field를 추가할 필요는 없습니다. Exa가 자동으로 반환합니다.

`numResults`는 `results`에 반환되는 페이지 수를 제어합니다. Deep이 수행하는 searches의 횟수를 설정하는 값은 아닙니다.

<div id="stream-the-synthesis">
  ## synthesis 스트리밍
</div>

`outputSchema`와 함께 `stream: true`를 설정하면 synthesis된 output을 server-sent events로 받을 수 있습니다:

<CodeGroup>
  ```python Python theme={null}
  import os
  import requests

  response = requests.post(
      "https://api.exa.ai/search",
      headers={"Authorization": f"Bearer {os.environ['EXA_API_KEY']}"},
      json={
          "query": "Explain the competing technical approaches to long-context retrieval",
          "type": "deep",
          "stream": True,
          "outputSchema": {
              "type": "text",
              "description": "A grounded comparison organized by approach",
          },
      },
      stream=True,
  )
  response.raise_for_status()

  for line in response.iter_lines(decode_unicode=True):
      if line:
          print(line)
  ```

  ```javascript JavaScript theme={null}
  const response = await fetch("https://api.exa.ai/search", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      Authorization: `Bearer ${process.env.EXA_API_KEY}`
    },
    body: JSON.stringify({
      query: "Explain the competing technical approaches to long-context retrieval",
      type: "deep",
      stream: true,
      outputSchema: {
        type: "text",
        description: "A grounded comparison organized by approach"
      }
    })
  });

  if (!response.ok || !response.body) {
    throw new Error(`Search failed: ${response.status}`);
  }

  const decoder = new TextDecoder();
  for await (const chunk of response.body) {
    process.stdout.write(decoder.decode(chunk, { stream: true }));
  }
  ```

  ```bash cURL theme={null}
  curl -N -X POST "https://api.exa.ai/search" \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer $EXA_API_KEY" \
    -d '{
      "query": "Explain the competing technical approaches to long-context retrieval",
      "type": "deep",
      "stream": true,
      "outputSchema": {
        "type": "text",
        "description": "A grounded comparison organized by approach"
      }
    }'
  ```
</CodeGroup>

`done`이 나올 때까지 타입이 지정된 이벤트를 처리하세요. 마지막 이벤트에는 완료된 output과 search 소요 시간이 담기며, 비용 정보가 있는 경우 함께 제공됩니다.

<div id="when-to-stay-with-standard-search">
  ## standard Search를 그대로 쓰는 것이 좋은 경우
</div>

한 번의 검색으로 요청을 충족할 수 있다면 Deep은 필요하지 않습니다:

* 리서치를 거친 결론이 아니라 관련 페이지가 필요한 경우
* 질의가 이미 특정 소스나 좁은 주제를 지정하고 있는 경우
* 애플리케이션이 자체적으로 추론을 수행하며 검색만 필요한 경우
* 요청이 대화형, 자동 완성, 음성 경로에서 처리되는 경우

기본적인 품질과 속도의 균형이 필요하면 `auto`를, latency 요구사항이 엄격하다면 `fast`나 `instant`를 사용하세요.
