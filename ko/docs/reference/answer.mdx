description: "Exa search 결과를 바탕으로 질문에 대한 LLM 답변을 받습니다. `/answer`는 Exa search를
  수행한 뒤 LLM을 사용해 다음 중 하나를 생성합니다:

  1. 명확한 질의에 대한 직접적인 답변 (예: \"프랑스의 수도는 어디인가요?\"에는 \"파리\"를 반환)

  2. 개방형 질의에 대한 citations가 포함된 상세한 summary (예: \"의료 분야의 AI 현황은 어떤가요?\"에는 관련 출처의
  citations가 포함된 summary를 반환)


  응답에는 생성된 답변과 답변 작성에 사용된 출처가 함께 포함됩니다. 이 endpoint는 Streaming(`stream=True`)도
  지원하며, 이 경우 토큰이 생성되는 대로 반환합니다.


  또는 OpenAI 호환 [chat completions 인터페이스](/docs/integrations/openai-sdk#answer)를
  사용할 수도 있습니다.\n"
