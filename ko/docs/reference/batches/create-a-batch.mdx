`requests`의 각 항목은 batch 내에서 고유한 `customId`를 가진 `/search` 또는 `/agent/runs`에 대한 `POST` 요청입니다. 결과 파일에도 동일한 `customId`가 반환되므로 output 행을 입력 데이터와 대응시킬 수 있습니다. 전체 워크플로우는 [Batch API 가이드](/ko/docs/batch/quickstart)를 참고하세요.
