<Info>
  Team Management API는 team 단위로 활성화됩니다. 인증에는 서비스 계정 API key를 사용하며, 이 key는 해당 기능이 team에 활성화된 뒤 [API keys 페이지](https://dashboard.exa.ai/api-keys)의 **Service keys** 탭에서 생성할 수 있습니다. 접근 권한이 필요하면 [support@exa.ai](mailto:support@exa.ai)로 문의하세요.
</Info>

<div id="overview">
  ## 개요
</div>

Get API Key endpoint를 사용하면 고유 식별자로 특정 API key의 상세 정보를 조회할 수 있습니다.

<div id="path-parameters">
  ## 경로 매개변수
</div>

* **id**: 조회할 API key의 고유 식별자

<div id="response">
  ## 응답
</div>

다음을 포함한 API key의 상세 정보를 반환합니다:

* **id**: 고유 식별자
* **name**: 식별용 이름
* **rateLimit**: 분당 요청 수 기준 rate limit (설정된 경우)
* **teamId**: 이 key가 속한 team ID
* **createdAt**: key 생성 시각
