## 개요 {#overview}

Get API Key 엔드포인트를 사용하면 고유 식별자로 특정 API 키의 상세 정보를 조회할 수 있습니다.

## Path Parameters {#path-parameters}

* **id**: 조회할 API 키의 고유 식별자

## Response {#response}

다음을 포함한 API 키의 상세 정보를 반환합니다:

* **id**: 고유 식별자
* **name**: 설명용 이름
* **rateLimit**: 분당 요청 수 기준 속도 제한(설정된 경우)
* **teamId**: 이 키가 속한 team ID
* **createdAt**: 키가 생성된 시각
