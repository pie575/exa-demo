<div id="overview">
  ## 개요
</div>

Get API Key Usage endpoint를 사용하면 특정 API key의 지정된 기간에 대한 상세 billing 및 usage 분석 데이터를 조회할 수 있습니다. 이 endpoint는 Exa의 billing 시스템에서 가져온 cost 데이터를 반환하므로, 해당 API key에 실제로 청구되는 내용을 정확하게 파악할 수 있습니다.

<div id="path-parameters">
  ## Path Parameters
</div>

* **id**: 사용량을 조회할 API key의 고유 식별자

<div id="query-parameters">
  ## 쿼리 파라미터
</div>

* **start&#95;date** (선택): 사용량 집계 기간의 시작 날짜로, ISO 8601 형식입니다(예: `2025-01-01T00:00:00Z` 또는 `2025-01-01`). 기본값은 30일 전입니다. 최근 6개월(180일) 이내여야 합니다.
* **end&#95;date** (선택): 사용량 집계 기간의 종료 날짜로, ISO 8601 형식입니다. 기본값은 현재 시각입니다.
* **group&#95;by** (선택): 결과를 그룹화할 시간 단위입니다(`hour`, `day`, `month`). 현재는 향후 기능 확장을 위해 예약된 값으로, 응답 형태에는 영향을 주지 않습니다. 기본값은 `day`입니다.

<div id="response">
  ## 응답
</div>

다음을 포함한 상세 usage 및 billing 정보를 반환합니다:

* **id**: API key의 고유 식별자
* **api&#95;key&#95;id**: API key의 고유 식별자
* **api&#95;key&#95;name**: API key의 설명용 이름(설정된 경우)
* **team&#95;id**: 해당 key가 속한 Team ID
* **period**: usage 기간의 시작일과 종료일이 담긴 객체
* **total&#95;cost&#95;usd**: 지정한 기간의 총 cost(USD)
* **cost&#95;breakdown**: 가격 유형별 cost 내역 배열로, 각 항목은 다음을 포함합니다:
  * **price&#95;id**: 가격의 고유 식별자
  * **price&#95;name**: 가격 이름(예: &quot;Neural Search&quot;, &quot;Content Retrieval&quot;)
  * **quantity**: 소비된 총 수량
  * **amount&#95;usd**: 해당 가격 유형의 cost(USD)
* **metadata**: 보고서 생성 timestamp가 담긴 객체

<div id="important-notes">
  ## 중요 참고 사항
</div>

* **6개월 조회 제한**: billing 시스템에는 6개월(180일) 조회 제한이 있습니다. `start_date`가 180일 이전인 요청은 400 오류를 반환합니다.
* **usage 없음**: 요청한 기간에 해당 API key의 usage가 없으면 `total_cost_usd`는 0이 되고 `cost_breakdown`은 비어 있을 수 있습니다.
* **Team 소유권**: 인증에 사용하는 서비스 API key는 조회 대상 API key와 동일한 team에 속해야 합니다. team 간 접근은 허용되지 않습니다.
* **날짜 형식**: 날짜는 시간 정보를 포함하거나 생략한 ISO 8601 형식으로 지정할 수 있습니다(예: `2025-01-01` 또는 `2025-01-01T00:00:00Z`).

<div id="use-cases">
  ## 활용 사례
</div>

이 endpoint는 다음과 같은 경우에 유용합니다:

* API key 단위의 billing dashboard 구축
* 특정 API key의 usage 및 cost 모니터링
* usage 임계값 기반 자동 알림 설정
* 내부 비용 배분을 위한 usage 리포트 생성
* 특정 API key의 billing 관련 문의 디버깅
