<div id="overview">
  ## 개요
</div>

Delete API Key endpoint는 team에서 API key를 영구적으로 삭제합니다.

<div id="path-parameters">
  ## 경로 매개변수
</div>

* **id**: 삭제할 API key의 고유 식별자입니다.
