---
title: "실행 중지"
description: "진행 중인 Agent 실행을 안전하게 중지하고 지금까지 수집한 결과를 유지합니다."
openapi: "/ko/docs/exa-spec.yaml POST /agent/runs/{id}/stop"
timestamp: false
---

실행이 아직 활성 상태라면 agent가 작업을 마무리하고 지금까지 수집한 결과와 함께 실행을 조기에 완료합니다. 실행은 상태 `completed`, `stopReason: stopped`로 종료됩니다. 중지 이전까지 누적된 사용량에 대해서는 요금이 청구됩니다. 실행이 이미 종료 상태(completed, failed, cancelled)에 도달했다면 엔드포인트는 기존 실행을 변경 없이 반환합니다.

결과를 반환하지 않고 실행을 즉시 종료하려면 [cancel](/ko/docs/reference/agent-api/cancel-a-run)을 사용하세요.

<Note>
  `max` effort 실행에서만 지원됩니다. `Exa-Beta: agent-max-effort-2026-07-27`을 요청 header로
  전달해야 합니다. 이 header에는 쉼표로 구분된 베타 토큰 목록을 지정할 수 있습니다.
</Note>
