자연어 `query`로 실행을 생성하세요. 검증된 구조화 JSON이 필요하면 `outputSchema`를, 처리할 행이 있으면 `input.data`를, 제외할 레코드나 엔터티가 있으면 `input.exclusion`을, 완료된 실행에 이어서 진행하려면 `previousRunId`를 추가하세요.

`Accept: text/event-stream`을 설정하면 실행이 생성, 시작, 완료되는 과정을 실행 이벤트로 스트리밍할 수 있습니다.

<Note>
  **Connect:** `dataSources`를 전달하면 실행 중에 agent가 서드파티 data provider에 접근할 수 있습니다. 자세한 내용은 [Connect 가이드](/ko/docs/agent/quickstart#connect-data-sources)를 참고하세요.
</Note>
