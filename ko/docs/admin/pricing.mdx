## Search, Contents, Answer, Monitors {#search-contents-answer-and-monitors}

각 엔드포인트에는 최대 10개의 result가 포함된 요청당 기본 가격이 책정되어 있습니다. 10개를 초과하는 result와 Exa가 생성한 페이지 summary는 추가로 과금됩니다.

| 엔드포인트       | 기본 가격<br />(최대 10개 result) | 10개 초과 result당    | AI 페이지 요약    |
| ----------- | -------------------------- | ----------------- | ------------ |
| `/search`   | 1,000회 요청당 $7              | 1,000개 result당 $1 | 1,000페이지당 $1 |
| `/answer`   | 1,000회 요청당 $5              | —                 | —            |
| `/monitors` | 1,000회 요청당 $15             | 1,000개 result당 $1 | 1,000페이지당 $1 |
| `/contents` | content type별 1,000페이지당 $1 | —                 | 1,000페이지당 $1 |

## Agent {#agent}

[Agent](/ko/docs/agent/quickstart)에 `effort`를 고정값으로 설정하면 요청당 가격을 예측할 수 있습니다. `auto`는 기본 종량제 모드이며, 베타인 `max` 역시 종량제로 동일한 사용량 요금이 적용됩니다:

| Effort    | 가격          |
| --------- | ----------- |
| `minimal` | $0.012 / 요청 |
| `low`     | $0.025 / 요청 |
| `medium`  | $0.10 / 요청  |
| `high`    | $0.50 / 요청  |
| `xhigh`   | $1.00 / 요청  |

종량제 실행은 실행당 상한 내에서 실제 사용량만큼 청구됩니다. `auto`의 기본 상한은 $5, 베타인 `max`의 기본 상한은 $20입니다:

| 사용량 항목                 | 가격              |
| ---------------------- | --------------- |
| Agent Compute Unit     | $0.10 / ACU     |
| Search 도구 call         | $0.005 / search |
| 이메일 contact enrichment | $0.02 / 이메일     |
| 전화 contact enrichment  | $0.07 / 전화번호    |

## Deep Search {#deep-search}

[`/search`](/ko/docs/search/deep-search)에서 `type`으로 설정합니다. 추가 result와 AI 페이지 요약 비용은 standard search와 동일합니다.

| Type             | 기본 가격<br />(result 10개까지) | Latency | 적합한 용도                        |
| ---------------- | ------------------------- | ------- | ----------------------------- |
| `deep-lite`      | 1천 요청당 $12                | 약 4초    | 가벼운 synthesis                 |
| `deep`           | 1천 요청당 $12                | 4~15초   | structured output을 활용한 다단계 추론 |
| `deep-reasoning` | 1천 요청당 $15                | 12~40초  | 난도 높은 리서치 작업                  |

## 비용 용어집 {#cost-glossary}

<AccordionGroup>
  <Accordion title="요청">
    엔드포인트에 대한 API 호출 1회입니다. 가격은 요청 1,000건 기준으로 표시되므로, $7 / 1k 요율은 호출당 $0.007입니다.
  </Accordion>

  <Accordion title="result">
    response로 반환되는 search result 1건입니다. 기본 가격에는 요청당 처음 10건의 result가 포함되며, 10건을 초과하는 result에는 result 1,000건당 $1가 추가됩니다. 따라서 `numResults: 20`을 요청하면 기본 가격에 추가 result 10건 비용이 더해집니다.
  </Accordion>

  <Accordion title="페이지 및 content type">
    페이지는 Exa가 콘텐츠를 반환하는 URL 1개를 말합니다. content type은 해당 페이지를 보는 하나의 방식으로, `text`, `highlights`, `summary`가 있습니다. `/contents`는 content type별로 각각 과금하므로, `text`와 `highlights`를 함께 요청한 페이지 1개는 2건으로 계산됩니다.
  </Accordion>

  <Accordion title="AI page summary">
    Exa가 생성한 페이지 summary로, Exa 측에서 추가 LLM 호출을 거쳐 만들어집니다. 이를 반환하는 모든 엔드포인트에서 페이지 1,000건당 $1로 과금됩니다.
  </Accordion>

  <Accordion title="Agent Compute Unit (ACU)">
    Agent 실행이 소비하는 모델 연산 단위이며, `usage.agentComputeUnits`로 보고됩니다. 실행이 길수록, `input.data`가 클수록, 추론 단계가 많을수록 더 많은 ACU를 소비합니다.
  </Accordion>

  <Accordion title="Effort">
    비용 및 latency와 철저함 사이의 균형을 조절하는 Agent 매개변수입니다. `auto`는 기본 상한 $5까지 소비량(ACU와 도구 call) 기준으로 과금되고, 베타 단계인 `max`는 동일한 사용량 요율로 기본 상한 $20까지 과금됩니다. 고정 effort는 요청당 정액으로 과금됩니다. [Agent effort 모드](/ko/docs/agent/quickstart#effort)를 참고하세요.
  </Accordion>

  <Accordion title="Contact enrichment">
    사람 또는 회사의 이메일 주소나 전화번호를 반환하는 Agent 조회입니다. 해당 실행의 다른 비용에 더해, 찾아낸 연락처 건당 과금됩니다.
  </Accordion>

  <Accordion title="Credits">
    계정에 선불로 충전된 달러 잔액입니다. 사용량에 따라 위 요율대로 credits에서 차감됩니다.
  </Accordion>
</AccordionGroup>
