<div id="search-contents-answer-and-monitors">
  ## Search, Contents, Answer, Monitors
</div>

각 endpoint에는 결과 10개까지 포함하는 요청당 기본 가격이 있습니다. 10개를 초과하는 결과와 Exa가 생성한 페이지 summaries는 별도로 과금됩니다.

| Endpoint    | 기본 가격<br />(결과 10개까지)      | 10개 초과 결과당  | AI 페이지 summaries |
| ----------- | -------------------------- | ----------- | ---------------- |
| `/search`   | 요청 1천 건당 $7                | 결과 1천 건당 $1 | 페이지 1천 건당 $1     |
| `/answer`   | 요청 1천 건당 $5                | —           | —                |
| `/monitors` | 요청 1천 건당 $15               | 결과 1천 건당 $1 | 페이지 1천 건당 $1     |
| `/contents` | content type별 페이지 1천 건당 $1 | —           | 페이지 1천 건당 $1     |

<div id="agent">
  ## Agent
</div>

[Agent](/ko/docs/agent/quickstart)에 고정 `effort`를 설정하면 요청당 가격을 예측할 수 있습니다. `auto`가 기본 종량제 모드이며, 베타 `max`도 종량제로 동일한 사용량 요금이 적용됩니다:

| Effort    | 가격         |
| --------- | ---------- |
| `minimal` | 요청당 $0.012 |
| `low`     | 요청당 $0.025 |
| `medium`  | 요청당 $0.10  |
| `high`    | 요청당 $0.50  |
| `xhigh`   | 요청당 $1.00  |

종량제 실행은 실행당 상한까지 실제 사용량만큼 청구됩니다. `auto`의 기본 상한은 $5, 베타 `max`의 기본 상한은 $20입니다:

| 사용량 항목                  | 가격             |
| ----------------------- | -------------- |
| Agent Compute Unit      | ACU당 $0.10     |
| search 도구 call          | search당 $0.005 |
| 이메일 contact enrichment  | 이메일당 $0.02     |
| 전화번호 contact enrichment | 전화번호당 $0.07    |

<div id="deep-search">
  ## Deep Search
</div>

[`/search`](/ko/docs/search/deep-search)에서 `type`으로 설정합니다. 추가 결과와 AI summary은 표준 search와 동일한 비용이 청구됩니다.

| 유형               | 기본 가격<br />(최대 10개 결과) | 지연 시간  | 적합한 용도                        |
| ---------------- | ---------------------- | ------ | ----------------------------- |
| `deep-lite`      | $12 / 요청 1,000회        | 약 4초   | 가벼운 synthesis                 |
| `deep`           | $12 / 요청 1,000회        | 4~15초  | structured output을 활용한 다단계 추론 |
| `deep-reasoning` | $15 / 요청 1,000회        | 12~40초 | 난도 높은 리서치 작업                  |

<div id="cost-glossary">
  ## 비용 용어집
</div>

<AccordionGroup>
  <Accordion title="요청">
    endpoint에 대한 API call 1회입니다. 가격은 요청 1,000건 단위로 표시되므로, $7 / 1k 요금은 call당 $0.007입니다.
  </Accordion>

  <Accordion title="결과">
    응답으로 반환되는 search 결과 1건입니다. 기본 가격에는 요청당 처음 10건의 결과가 포함되며, 10건을 초과하는 결과에는 결과 1,000건당 $1가 추가됩니다. 따라서 `numResults: 20`을 요청하면 기본 가격에 추가 결과 10건의 비용이 더해집니다.
  </Accordion>

  <Accordion title="페이지 및 content type">
    페이지는 Exa가 contents를 반환하는 URL 하나를 의미합니다. content type은 해당 페이지를 보여주는 하나의 형태로, `text`, `highlights`, `summary`가 있습니다. `/contents`는 content type별로 각각 과금하므로, `text`와 `highlights`를 함께 요청한 페이지 하나는 2건으로 계산됩니다.
  </Accordion>

  <Accordion title="AI 페이지 summary">
    Exa가 생성한 페이지 summary로, Exa 측에서 추가 LLM call을 실행해 만들어집니다. summary를 반환하는 모든 endpoint에서 페이지 1,000건당 $1로 과금됩니다.
  </Accordion>

  <Accordion title="Agent Compute Unit (ACU)">
    Agent 실행이 소비하는 모델 연산의 단위로, `usage.agentComputeUnits`로 보고됩니다. 실행이 길수록, `input.data`가 클수록, 추론 단계가 많을수록 더 많은 ACU를 소비합니다.
  </Accordion>

  <Accordion title="Effort">
    비용 및 지연 시간과 철저함 사이의 균형을 조정하는 Agent 매개변수입니다. `auto`는 소비량(ACU 및 도구 call)에 따라 과금되며 기본 상한은 $5입니다. 베타인 `max`는 동일한 사용 요금을 적용하되 기본 상한이 $20입니다. 고정 effort는 요청당 정액으로 과금됩니다. [Agent effort 모드](/ko/docs/agent/quickstart#effort)를 참고하세요.
  </Accordion>

  <Accordion title="Contact enrichment">
    사람 또는 회사의 이메일 주소나 전화번호를 반환하는 Agent 조회입니다. 해당 실행의 다른 비용에 더해, 찾아낸 연락처 건당 과금됩니다.
  </Accordion>

  <Accordion title="Credits">
    계정에 선불로 충전된 달러 잔액입니다. 위 요금에 따라 사용한 만큼 credits가 차감됩니다.
  </Accordion>
</AccordionGroup>
