Exa는 계정 usage와 유료 기능 이용 권한을 &#39;Team&#39; 단위로 관리합니다:

계정을 생성하면 &#39;Personal&#39; Team에 속하게 됩니다. 아래에 표시된 Exa dashboard 왼쪽 상단의 드롭다운에서 새 Team을 생성하거나 보유 중인 다른 Team으로 전환할 수 있습니다. Team은 원하는 만큼 만들 수 있습니다.

<div id="inviting-people-to-your-team">
  ## 팀에 사람 초대하기
</div>

team 관리자는 team settings의 Invite 기능으로 멤버를 추가할 수 있습니다.

<img src="/docs/images/admin/team-management/dashboard_invite.png" alt="team settings에서 멤버 초대하기" width="2954" height="1916" data-path="images/admin/team-management/dashboard_invite.png" />

팀 멤버를 초대하면 팀 관리 메뉴에서 해당 멤버의 상태가 &#39;Pending&#39;으로 표시됩니다.

<img src="/docs/images/admin/team-management/dashboard_invite_pending.png" alt="team 멤버가 Pending 초대 상태로 표시됨" width="2954" height="1916" data-path="images/admin/team-management/dashboard_invite_pending.png" />

초대받은 사람에게는 팀 참여를 안내하는 이메일이 전송됩니다.

<img src="/docs/images/admin/team-management/dashboard_invite_email.png" alt="team 초대 이메일" width="1094" height="1082" data-path="images/admin/team-management/dashboard_invite_email.png" />

초대를 수락하면 두 멤버 모두 &#39;Accepted&#39;로 표시됩니다. 모든 team 멤버는 해당 team 플랜의 usage limits와 기능을 함께 사용합니다.

<img src="/docs/images/admin/team-management/dashboard_invite_accepted.png" alt="Accepted 상태를 보여주는 team 멤버 목록" width="2954" height="1916" data-path="images/admin/team-management/dashboard_invite_accepted.png" />

<div id="team-management-api">
  ## Team Management API
</div>

[Team Management API](/ko/docs/reference/team-management/create-api-key)를 사용하면 API key를 프로그래밍 방식으로 생성하고 관리할 수 있습니다.

<Info>
  Team Management API는 team 단위로 활성화됩니다. 인증에는 서비스 계정 API key를 사용하며, 해당 기능이 team에 활성화되면 [API keys 페이지](https://dashboard.exa.ai/api-keys)의 **Service keys** 탭에서 key를 생성할 수 있습니다. 접근 권한을 요청하려면 [support@exa.ai](mailto:support@exa.ai)로 문의하세요.
</Info>
