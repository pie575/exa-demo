<Note>
  원본 OpenAPI 명세가 요청 및 응답 schema의 기준입니다. 자동 생성된
  레퍼런스 페이지에는 레시피, 마이그레이션 참고 사항, 권장 기본값이 빠져 있을 수 있으므로 `type: "auto"`, highlights,
  freshness 설정 등 최신 연동 지침은 가이드와 예제를 참고하세요. 이 링크들은 항상 현재 문서 배포본에서
  제공하는 명세를 가리킵니다.
</Note>
