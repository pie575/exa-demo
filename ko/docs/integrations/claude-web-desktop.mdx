<div id="work-with-whats-on-the-web-right-now">
  ## 지금 웹에 있는 정보로 작업하세요
</div>

Claude Code에서 Exa는 리포지토리 작업 중에도 최신 문서, 이슈, 변경 로그, 실제 사용 예제를 검색할 수 있습니다. 같은 연동으로 Claude Web, Desktop, Cowork에서도 최신 뉴스, 리서치, 회사 정보, 제품 세부 정보 등 아직 컨텍스트에 없는 소스를 활용할 수 있습니다.

```text theme={null}
우리는 Tailwind v3를 쓰고 있어. Exa로 공식 Tailwind v4 업그레이드 가이드를
찾아 읽고, 이 프로젝트를 v4로 마이그레이션해줘.
```

Claude Code는 찾아낸 내용을 바탕으로 코드베이스를 직접 수정할 수 있습니다. 다른 Claude 클라이언트에서는 동일한 소스를 답변, 아티팩트, Cowork 작업에 활용할 수 있습니다.

답변이 최신 정보나 특정 웹 소스에 좌우되는 경우라면 언제든 같은 패턴을 적용할 수 있습니다.

* &quot;이 의존성의 최신 릴리스 노트를 찾아서 호환성이 깨지는 변경 사항을 요약해 줘.&quot;
* &quot;추론 시점 스케일링에 관한 최근 1차 연구를 검색해서 방법론을 비교해 줘.&quot;
* &quot;현재 Stripe 웹훅 문서를 읽고 권장되는 재시도 동작을 설명해 줘.&quot;
* &quot;이 제품들의 공식 가격 페이지를 찾아서 입문용 플랜을 비교해 줘.&quot;

<div id="search-read-and-research">
  ## 검색, 읽기, 리서치
</div>

Exa 연동은 Claude에 웹을 검색하고 읽는 도구를 제공하며, Claude는 이를 조합해 장기간에 걸친 리서치 작업을 수행할 수 있습니다.

  <Card title="검색" icon="search">

  </Card>

  <Card title="읽기" icon="file-text">

  </Card>

  <Card title="리서치" icon="compass">
    여러 번 검색을 수행하고 유용한 페이지를 살펴본 뒤, evidence를 종합해 소스가 명시된 response를 만듭니다.
  </Card>
</Columns>

<div id="research-without-leaving-claude">
  ## Claude를 벗어나지 않고 리서치하기
</div>

원하는 결과를 요청하고, 어떤 종류의 소스가 중요한지 Claude에게 알려주세요:

```text theme={null}
주요 오픈 소스 벡터 데이터베이스의 매니지드 서비스, 라이선스, 가격을
비교해 줘. 최신 1차 소스를 사용하고 출처를 인용해 줘.
```

Claude는 대화 전반에 걸쳐 Exa를 사용해 작업에 필요한 소스를 찾고 읽을 수 있습니다. 기술 리서치, 경쟁사 분석, 시장 지형 파악, 기업 조사처럼 답이 웹 곳곳에 흩어져 있는 질문에 활용하세요.

<div id="use-exa-in-cowork">
  ## Cowork에서 Exa 사용하기
</div>

동일한 커넥터를 Cowork에서도 사용할 수 있습니다. 외부 정보가 필요한 작업을 Claude에게 맡기면, 사용자의 파일 및 연결된 다른 도구를 함께 활용하면서 웹을 검색하거나 페이지를 읽을 수 있습니다.

```text theme={null}
이 경쟁사 분석 자료를 검토하고, Exa로 현재 벤더 페이지와 대조해 모든 가격 관련 내용을
확인한 뒤, 출처를 달아 문서를 업데이트해 줘.
```

<div id="prefer-mcp-directly">
  ## MCP를 직접 사용하고 싶으신가요?
</div>

Claude를 수동으로 설정하거나 다른 MCP 클라이언트를 사용한다면, Exa가 호스팅하는 MCP 서버에 직접 연결할 수 있습니다:

```bash theme={null}
claude mcp add --transport http exa https://mcp.exa.ai/mcp
```

다른 client, 구성 옵션, 사용 가능한 도구에 대해서는 [Exa MCP](/ko/docs/get-started/exa-mcp)를 참고하세요.
