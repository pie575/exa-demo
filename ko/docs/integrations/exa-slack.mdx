팀의 Slack에서 Exa를 사용해 보세요. 어느 채널이나 thread에서든 **@Exa**를 태그하고 리서치 질문, 리스트 빌딩 작업, enrichment 요청을 남기면 됩니다. Exa가 웹을 search하고 소스를 읽은 뒤, 출처가 표기된 답변을 thread에 바로 달아 줍니다.

## 시작하기 {#get-started}

### 설치 {#installation}

1. [Dashboard &gt; Management &gt; Exa in Slack](https://dashboard.exa.ai/integrations/slack)로 이동한 다음 **Install**을 클릭합니다.

<img src="/docs/images/integrations/exa-slack/dashboard-install.png" alt="Install 버튼이 있는 Exa dashboard의 Exa in Slack 페이지" width="3414" height="900" data-path="images/integrations/exa-slack/dashboard-install.png" />

2. Slack의 OAuth 흐름이 열립니다. Exa를 추가할 워크스페이스를 선택한 다음 **Allow**를 클릭합니다.

<img src="/docs/images/integrations/exa-slack/oauth-approval.png" alt="Exa app에 대한 Slack의 OAuth 승인 화면으로, &#x22;App is not approved by Slack&#x22; 안내, 워크스페이스 선택기, 요청된 권한, Allow 버튼이 표시됨" width="1820" height="1180" data-path="images/integrations/exa-slack/oauth-approval.png" />

<Note>
  빨간색 **&quot;App is not approved by Slack&quot;** 안내는 정상이며 무시해도 됩니다. Exa가 공개 Slack
  마켓플레이스에 등록되어 있지 않다는 의미일 뿐, 문제가 있는 것은 아닙니다.
</Note>

3. 설치가 끝나면 채널에 @Exa를 초대하거나 직접 DM을 보내 질문을 시작하세요.

## Slack에서 Exa 사용하기 {#how-to-use-exa-from-slack}

Exa가 추가된 채널이라면 어디서든 @Exa를 mention하고 질문을 입력하세요:

```text theme={null}
@Exa find all Series A fintech startups in SF
```

Exa가 thread 안에서 질문에 답변합니다.

### Follow-ups {#follow-ups}

Exa가 thread에서 답변한 뒤에는 해당 thread에 답글만 달면 대화를 계속 이어갈 수 있습니다. @Exa를 다시 mention하지 않아도 됩니다. Exa가 대화 내용을 기억하기 때문에 follow-up은 이전 답변을 바탕으로 이어집니다. 해당 thread에 있는 누구나 follow-up을 보낼 수 있습니다.

### Direct messages {#direct-messages}

DM으로 Exa에게 직접 메시지를 보낼 수도 있습니다. 이때는 mention이 전혀 필요하지 않습니다. 메시지를 보낼 때마다 새로운 요청이 시작되고, 해당 메시지 아래 thread에 답변이 달립니다. 대화를 이어가려면 그 thread에 답글을 남기세요.

### 실행 취소하기 {#cancelling-a-run}

실행이 진행 중일 때 thread에 답글을 달아 Exa에게 실행을 중단해 달라고 요청하세요. mention은 필요하지 않습니다.

```text theme={null}
현재 실행 중지
```

### Exa Connect 제공업체 {#exa-connect-providers}

Exa는 질문과 관련이 있는 경우 [Exa Connect](/ko/docs/agent/connect/overview) 데이터 제공업체를 자동으로 포함합니다. 특정 제공업체를 사용하려면 메시지에서 해당 제공업체를 mention하세요:

```text theme={null}
@Exa find me all AI infrastructure startups that raised funding this quarter using Fiber.ai
```

사용 가능한 전체 데이터 제공업체 목록은 Exa에 물어보면 됩니다.

## Keywords {#keywords}

Exa가 참여 중인 thread에서 사용하세요. 명령어는 `@Exa` mention 뒤에 이어 쓰거나 메시지 맨 앞에 바로 쓸 수 있습니다:

| Keyword           | 기능                                                                    |
| ----------------- | --------------------------------------------------------------------- |
| `!max <message>`  | 이 요청을 max effort로 실행합니다. 매우 큰 목록을 만들 때 적합합니다.                         |
| `mute`            | thread에서 mention 없는 답글에는 Exa가 응답하지 않습니다. 명시적인 @Exa mention은 계속 동작합니다. |
| `unmute`          | `mute` 이후 thread follow-ups를 다시 시작합니다.                                |
| `sleep`           | 해당 thread에서 Exa의 동작을 완전히 중단합니다. @Exa를 mention하면 다시 깨어납니다.             |
| `aside <message>` | Exa가 무시하는 부가 코멘트를 남깁니다. Exa가 지켜보고 있는 thread에서 동료와 대화할 때 유용합니다.        |
| `help`            | 사용 방법을 보여줍니다.                                                         |

## 권한 {#permissions}

Slack용 Exa app은 다음 scope를 요청합니다:

| 권한                     | Slack 접근 범위                  | Exa에 필요한 이유                                                |
| ---------------------- | ---------------------------- | ---------------------------------------------------------- |
| `app_mentions:read`    | @Exa를 직접 mention한 메시지 조회     | 채널이나 thread에서 누군가 Exa를 mention하면 요청 시작                     |
| `assistant:write`      | Slack에서 App Agent로 동작        | Slack의 agent 환경을 활용해 DM과 채널 thread로 답변 스트리밍                |
| `channels:history`     | Exa가 추가된 공개 채널의 메시지 조회       | 공개 채널 thread 답글을 수신해 다시 mention하지 않아도 follow-ups가 작동하도록 함  |
| `channels:read`        | 공개 채널의 기본 정보 조회              | 웹 세션을 동기화할 위치를 선택할 때 Exa가 이미 추가된 공개 채널 찾기                  |
| `chat:write`           | Exa app 명의로 메시지 전송           | thread 시작 메시지, 답변, 진행 상황 업데이트, 확인 메시지, 웹 동기화 메시지 게시        |
| `chat:write.customize` | app이 작성한 메시지의 이름과 아바타 사용자 지정 | 웹 앱에서 동기화된 메시지에 웹 참여자의 이름과 프로필 이미지 표시                      |
| `files:read`           | Exa가 추가된 대화에서 공유된 파일 조회      | 질문에 첨부된 파일 읽기                                              |
| `files:write`          | Exa app 명의로 파일 업로드, 편집, 삭제   | 내보낸 표와 같은 result 파일을 답변에 첨부                                |
| `groups:history`       | Exa가 추가된 비공개 채널의 메시지 조회      | 비공개 채널 thread 답글을 수신해 다시 mention하지 않아도 follow-ups가 작동하도록 함 |
| `groups:read`          | Exa가 추가된 비공개 채널의 기본 정보 조회    | 웹 세션 동기화 대상을 선택할 때 사용 가능한 비공개 채널을 찾고 멤버십 확인                |
| `im:history`           | Exa와 주고받은 direct messages 조회 | DM 요청과 follow-up 답글 수신                                     |
| `im:write`             | direct messages 시작           | 인증된 사용자가 웹 세션 동기화 대상으로 선택했을 때 해당 사용자의 Exa DM 열기            |
| `users:read`           | 사용자와 기본 Slack 프로필 조회         | mention을 이름으로 변환하고 동기화된 메시지에 웹 참여자의 Slack 프로필 이미지 사용       |
| `users:read.email`     | 워크스페이스 member의 이메일 주소 조회     | team 귀속 및 맞춤형 웹 메시지 프로필 이미지를 위해 Slack 계정과 Exa 계정 매칭        |

<Note>
  `channels:read`, `groups:read`, `im:write`는 웹에서 Slack으로 동기화할 때 대상 discovery를 가능하게 합니다.
  기존 설치 환경은 이러한 scope 없이도 현재 Slack thread를 계속 사용할 수 있지만,
  해당 대상을 사용하려면 먼저 다시 연결해야 합니다. `chat:write.customize`는 런타임에서 선택 사항입니다.
  이 권한이 없으면 웹 동기화 메시지는 기본 Exa app 신원을 그대로 유지하며 메시지 본문에 참여자의 이름을 포함합니다.
</Note>

Exa는 명시적으로 초대된 채널과 자체 DM에서만 메시지를 수신합니다.
