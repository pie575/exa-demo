***

LangChain은 LLM을 데이터, API 및 기타 도구와 결합하는 애플리케이션을 만들기 위한 프레임워크입니다. Exa의 LangChain 연동으로 RAG를 구현해 보세요:

1. Exa의 LangChain 연동을 설정하고 Exa로 관련 content를 가져옵니다
2. 이 content를 OpenAI LLM으로 생성을 수행하는 툴체인에 연결합니다

<Info> LangChain 팀이 만든, 이와 매우 유사한 구성의 YouTube 튜토리얼은 [여기](https://www.youtube.com/watch?v=dA1cHGACXCo)에서 확인하세요. </Info>

<Info> LangChain의 전체 reference는 [여기](https://python.langchain.com/docs/integrations/providers/exa%5Fsearch/)에서 확인하세요. </Info>

***

## 시작하기 {#get-started}

<Steps>
  <Step title="사전 요구 사항 및 설치">
    핵심 OpenAI 및 Exa LangChain 라이브러리를 설치합니다

    ```Bash Bash theme={null}
    pip install langchain-openai langchain-exa
    ```

    <Note> API 키가 올바르게 초기화되었는지 확인하세요. LangChain 라이브러리의 경우 OpenAI 키와 Exa 키의 환경 변수 이름은 각각 `OPENAI_API_KEY`와 `EXA_API_KEY`입니다. </Note>

    <Card title="Exa API key 발급받기" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      dashboard에서 키를 생성하세요. 신규 계정에는 무료 credits이 제공됩니다.
    </Card>
  </Step>

  <Step title="Exa Search를 LangChain 도구로 사용하기">
    `ExaSearchRetriever`를 사용해 Retriever 도구를 설정합니다. Exa Search에 연결하여 의미 기반 검색으로 관련 문서를 찾아주는 retriever입니다. 먼저 필요한 라이브러리를 import하고 ExaSearchRetriever를 인스턴스화합니다.

    ```Python Python theme={null}
    # 환경 변수 로드
    import os
    from dotenv import load_dotenv
    load_dotenv()
    from langchain_exa import ExaSearchRetriever
    from langchain_core.prompts import PromptTemplate
    from langchain_core.runnables import RunnableLambda

    # Exa Search를 사용하는 retriever 정의: 결과 3개를 가져와 각 결과에서 highlights를 파싱
    retriever = ExaSearchRetriever(api_key=os.getenv("EXA_API_KEY"), k=3, highlights=True)
    ```
  </Step>

  <Step title="prompt 템플릿 만들기(선택 사항)">
    LangChain의 [PromptTemplate](https://python.langchain.com/v0.1/docs/modules/model%5Fio/prompts/quick%5Fstart/#prompttemplate)을 사용해 Exa retriever에서 URL과 highlights를 추출하는 플레이스홀더 템플릿을 정의합니다.

    ```Python Python theme={null}
    # XML 형식의 태그를 사용해 문서 prompt 템플릿을 정의합니다
    document_prompt = PromptTemplate.from_template("""
    <source>
        <url>{url}</url>
        <highlights>{highlights}</highlights>
    </source>
    """)
    ```
  </Step>

  <Step title="Exa 결과에서 URL과 콘텐츠 파싱하기">
    [Runnable Lambda](https://api.python.langchain.com/en/latest/runnables/langchain%5Fcore.runnables.base.RunnableLambda.html)를 사용해 Exa Search 결과에서 URL과 Highlights 속성을 추출한 뒤, 이를 위의 prompt 템플릿에 전달합니다

    ```Python Python theme={null}
    # retriever에서 highlights와 URL 속성을 파싱한 뒤 위에서 만든 문서 prompt로 전달하는 Runnable Lambda 생성
    document_chain = RunnableLambda(
        lambda document: {
            "highlights": document.metadata["highlights"],
            "url": document.metadata["url"]
        }
    ) | document_prompt
    ```
  </Step>

  <Step title="검색을 위해 Exa 결과와 콘텐츠 결합하기">
    Exa retriever와 parser, 그리고 짧은 람다 함수를 이어 붙여 검색 체인을 완성합니다. 이 과정은 다음 단계에서 결과를 LLM의 컨텍스트로 쓸 단일 문자열 형태로 전달하기 위해 반드시 필요합니다.

    ```Python Python theme={null}
    # 검색 체인 정의 - Exa search 결과 => 속성을 추출해 XML로 파싱 => 다음 단계에서 컨텍스트로 전달하기 위해 하나의 문자열로 결합
    retrieval_chain = retriever | document_chain.map() | (lambda docs: "\n".join([i.text for i in docs]))
    ```
  </Step>

  <Step title="생성에 사용할 OpenAI를 비롯한 나머지 도구 모음을 설정합니다">
    이 단계에서는 각각 사용자와 Exa Search에서 가져올 Query와 Context 템플릿 입력을 포함하는 system prompt를 정의합니다. 먼저, LangChain 라이브러리에서 관련 라이브러리와 컴포넌트를 다시 한 번 import 합니다

    ```Python Python theme={null}
    from langchain_core.runnables import RunnablePassthrough, RunnableParallel
    from langchain_core.prompts import ChatPromptTemplate
    from langchain_openai import ChatOpenAI
    from langchain_core.output_parsers import StrOutputParser
    ```

    그런 다음 생성용 prompt를 정의합니다. 이는 Exa에서 가져온 컨텍스트와 함께 RAG를 수행하는 데 사용되는 prompt 템플릿입니다.

    ```Python Python theme={null}
    # 핵심 prompt 템플릿 정의
    generation_prompt = ChatPromptTemplate.from_messages([
        ("system", "You are an expert research assistant. You use xml-formatted context to research people's questions."),
        ("human", """
    Please answer the following query based on the provided context. Please cite your sources at the end of your response.:

    Query: {query}
    ---
    <context>
    {context}
    </context>
    """)
    ])
    ```

    생성용 [LLM을 OpenAI로](https://python.langchain.com/v0.1/docs/integrations/chat/openai/) 설정한 다음, [RunnableParallel](https://python.langchain.com/v0.1/docs/expression%5Flanguage/primitives/parallel/) 병렬 연결로 모든 요소를 연결합니다. 질의와 컨텍스트가 담긴 생성 prompt는 LLM으로 전달되고, [output을 더 보기 좋게 표현하기 위해 파싱됩니다](https://api.python.langchain.com/en/latest/output%5Fparsers/langchain%5Fcore.output%5Fparsers.string.StrOutputParser.html).

    ```Python Python theme={null}
    # 생성에는 OpenAI 사용
    llm = ChatOpenAI(api_key=os.getenv("OPENAI_API_KEY"))

    # output을 위한 간단한 문자열 파싱
    output_parser = StrOutputParser()

    # 사용자의 질의와 2단계 Exa retriever 체인의 컨텍스트를 병렬로 연결해 체인 구성
    chain = RunnableParallel({
        "query": RunnablePassthrough(),
        "context": retrieval_chain,
    }) | generation_prompt | llm | output_parser
    ```
  </Step>

  <Step title="전체 RAG 도구 체인 실행하기">
    이제 체인을 [invoke](https://python.langchain.com/v0.1/docs/expression%5Flanguage/interface/#invoke)해 봅시다:

    ```Python Python theme={null}
    result = chain.invoke("Latest research on climate change innovation")

    print(result)
    ```

    그리고 output을 확인해 보세요(줄바꿈이 처리된 상태):

    ```Stdout Stdout theme={null}
    '제공된 컨텍스트를 바탕으로, 기후변화 혁신에 관한 최신 리서치는 다음과 같은 몇 가지 중요한 사실을 보여줍니다:
    1. 기후변화에 대응하는 혁신: 한 연구는 70개국의 패널 데이터를 분석해 혁신이 기후변화에 어떻게 반응하는지 살펴보았습니다. 이 연구에 따르면 기후변화 관련 혁신의 수는 주로 천연가스와 석유에서 비롯되는 기체 및 액체 연료의 이산화탄소 배출량 증가와 양의 상관관계를 보였습니다. 반면 주로 석탄에서 비롯되는 고체 연료 소비의 이산화탄소 배출량 증가 및 기타 온실가스 배출량과는 음의 상관관계를 나타냈습니다. 또한 정부 투자가 기후 기술을 개발하고 특허를 출원하려는 결정에 항상 영향을 미치지는 않는다는 점도 강조했습니다. 이 연구는 주요 기후변화 요인의 변화에 혁신이 어떻게 반응하는지에 대한 통찰을 제공함으로써 환경 혁신 문헌에 기여합니다.
    2. 기후 기술 자금 조달과 관심: 2010년부터 2022년까지 미국, 중국, EU, 인도를 제외한 나머지 지역이 차지한 기후 벤처캐피털 활동은 전체의 8%에 불과했습니다. 이처럼 자금과 관심이 특정 지역에 집중되면서, 이미 기후변화의 영향을 체감하고 있지만 이를 효과적으로 해결할 자원이 부족한 저소득 지역사회와 개발도상국에 기후 기술 솔루션이 도달하는 데 걸림돌이 되고 있을 수 있습니다.
    3. 연구 자금 배분: University of Sussex Business School의 한 연구는 1990년부터 2020년까지의 기후 및 에너지 연구 자금을 분석했습니다. 그 결과 자금의 36%는 기후 적응에, 28%는 에너지 시스템을 청정화하는 방법에 관한 연구에 배분된 것으로 나타났습니다. 그 밖에 교통 및 이동성(13%), 지구공학(12%), 산업 탈탄소화(11%)에도 상당한 비중이 배분되었습니다. 자금의 대부분은 부유한 서구 국가의 연구자들에게 돌아갔는데, 이들 국가는 기후변화의 직접적인 영향에 가장 취약한 곳이 아닐 수 있습니다.
    소스:
    1. 기후변화에 대한 혁신의 반응에 관한 연구: https://www.sciencedirect.com/science/article/pii/S0040162516302542
    2. 기후 기술 자금 조달과 관심: https://www.sbs.ox.ac.uk/oxford-answers/climate-tech-opportunity-save-planet
    3. 기후 및 에너지 연구의 연구 자금 배분: https://www.protocol.com/bulletins/climate-research-funding-adaptation'
    ```
  </Step>

  <Step title="필요에 따라 체인의 output을 스트리밍합니다">
    필요하다면 체인의 output을 스트리밍할 수도 있습니다.

    ```Python Python theme={null}
    for chunk in chain.stream("Latest research on climate change innovation"):
      print(chunk, end="|", flush=True)

    # 또는 비동기로
    async def run_async():
      async for chunk in chain.astream("Latest research on climate change innovation"):
        print(chunk, end="|", flush=True)

    import asyncio
    asyncio.run(run_async())
    ```

    스트리밍으로 output을 반환합니다. 청크 처리와 output 파싱을 비롯한 `.stream` 메서드에 대해 [자세히 알아보기](https://python.langchain.com/v0.1/docs/expression%5Flanguage/streaming/).
  </Step>
</Steps>
