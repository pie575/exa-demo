Exa는 [Grok Build](https://docs.x.ai/build/overview) 마켓플레이스에서 플러그인으로 제공됩니다. 이를 통해 Grok에 실시간 web search, 페이지 읽기, 딥 리서치 skill을 추가할 수 있습니다.

## 설치 {#installation}

<Steps>
  <Step title="Grok Build 설치">
    Grok CLI를 설치합니다(자세한 내용은 [Grok Build 문서](https://docs.x.ai/build/overview) 참조):

    ```bash theme={null}
    curl -fsSL https://x.ai/cli/install.sh | bash
    ```

    그런 다음 xAI 계정으로 sign-in합니다:

    ```bash theme={null}
    grok login
    ```
  </Step>

  <Step title="마켓플레이스 열기">
    `grok`을 실행해 Grok Build를 시작한 뒤 마켓플레이스를 엽니다:

    ```text theme={null}
    /marketplace
    ```
  </Step>

  <Step title="Exa 플러그인 설치">
    목록에서 **exa**를 찾아 `i`를 눌러 설치합니다.
  </Step>

  <Step title="Exa에 sign-in">
    `/mcp`로 MCP 서버 탭을 열고 **exa**를 선택한 뒤 `i`를 눌러 sign-in합니다. 브라우저에서 Exa sign-in 페이지가 열립니다. 신규 계정은 가입 시 무료 credits를 받습니다.
  </Step>
</Steps>

exa가 **ready**로 표시되면, 웹 검색이 필요한 무엇이든 Grok에게 물어보세요.

## 제공 기능 {#what-you-get}

* **web&#95;search&#95;exa**: 실시간 web search. 자연어 쿼리와 함께 뉴스, 기업, 인물, 논문, GitHub 등의 카테고리 필터를 지원합니다.
* **web&#95;fetch&#95;exa**: 임의의 URL을 읽어 페이지 콘텐츠를 깔끔한 마크다운으로 반환합니다.
* **exa-search skill**: 딥 리서치 skill입니다. Grok에게 특정 주제를 심층적으로 분석해 달라고 요청하면 여러 차례 search를 수행하고, 가장 적합한 소스를 읽은 뒤 citations와 함께 답변합니다.
