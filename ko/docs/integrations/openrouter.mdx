Exa는 [OpenRouter](https://openrouter.ai)의 web search를 구동하는 검색 엔진입니다. OpenRouter는 수백 개의 모델을 하나의 API로 제공하고, Exa는 이 모델들에 실시간 웹 접근을 제공합니다. 자체 search 기능이 없는 모델은 기본적으로 Exa를 통해 grounding되며, 어떤 모델이든 Exa를 사용하도록 명시적으로 지정할 수 있습니다. Exa API key는 필요하지 않습니다. OpenRouter가 서버 측에서 searches를 실행하고 OpenRouter credits에서 비용을 차감합니다.

<div id="use-the-web-search-server-tool">
  ## web search 서버 도구 사용하기
</div>

`tools` 배열에 `openrouter:web_search`를 추가하면 모델이 언제 검색할지, 무엇을 검색할지, 같은 요청 안에서 다시 검색할지를 스스로 판단합니다. [서버 도구](https://openrouter.ai/docs/guides/features/server-tools/web-search)는 OpenRouter에서 베타 단계이며, 지원이 중단된 `web` 플러그인과 `:online` 모델 변형을 대체합니다. 둘 중 하나를 사용 중이라면 OpenRouter의 [마이그레이션 가이드](https://openrouter.ai/docs/guides/features/server-tools/web-search#migrating-from-the-web-search-plugin)를 참고하세요.

<CodeGroup>
  ```javascript JavaScript theme={null}
  const response = await fetch("https://openrouter.ai/api/v1/chat/completions", {
    method: "POST",
    headers: {
      Authorization: "Bearer <OPENROUTER_API_KEY>",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "openai/gpt-5.2",
      messages: [
        { role: "user", content: "What were the major AI announcements this week?" },
      ],
      tools: [{ type: "openrouter:web_search" }],
    }),
  });

  const data = await response.json();
  console.log(data.choices[0].message.content);
  ```

  ```python Python theme={null}
  import requests

  response = requests.post(
      "https://openrouter.ai/api/v1/chat/completions",
      headers={
          "Authorization": "Bearer <OPENROUTER_API_KEY>",
          "Content-Type": "application/json",
      },
      json={
          "model": "openai/gpt-5.2",
          "messages": [
              {"role": "user", "content": "What were the major AI announcements this week?"}
          ],
          "tools": [{"type": "openrouter:web_search"}],
      },
  )

  print(response.json()["choices"][0]["message"]["content"])
  ```

  ```bash cURL theme={null}
  curl https://openrouter.ai/api/v1/chat/completions \
    -H "Authorization: Bearer <OPENROUTER_API_KEY>" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "openai/gpt-5.2",
      "messages": [
        { "role": "user", "content": "What were the major AI announcements this week?" }
      ],
      "tools": [{ "type": "openrouter:web_search" }]
    }'
  ```
</CodeGroup>

기본값인 `engine: "auto"`에서는 OpenRouter가 자체 검색 기능을 갖춘 모델에는 해당 provider의 네이티브 검색을, 그 외의 모델에는 Exa를 사용합니다. 모든 모델에서 검색 동작을 동일하게 유지하려면 `engine: "exa"`로 설정하세요:

```json theme={null}
{
  "type": "openrouter:web_search",
  "parameters": {
    "engine": "exa",
    "mode": "auto",
    "max_results": 5,
    "max_total_results": 20,
    "allowed_domains": ["arxiv.org"],
    "excluded_domains": ["reddit.com"]
  }
}
```

| 파라미터                                  | 용도                                                                                                                                                  |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `mode`                                | 지연 시간과 깊이를 절충합니다: `instant`, `fast`, `auto`(기본값), `deep-lite`, `deep`, `deep-reasoning`. 각 모드는 Exa의 [search types](/ko/docs/search/quickstart)에 대응합니다. |
| `max_results`                         | search 호출당 결과 수 제한(기본값 5)                                                                                                                           |
| `max_uses`                            | 한 요청에서 모델이 search할 수 있는 횟수 제한                                                                                                                       |
| `max_total_results`                   | 한 요청의 모든 searches에 걸친 누적 결과 수 제한                                                                                                                    |
| `max_characters`                      | highlights에 적용할 결과당 정확한 character budget 설정                                                                                                         |
| `search_context_size`                 | 대신 사전 설정된 예산 사용: `low`, `medium`, `high`                                                                                                            |
| `allowed_domains`, `excluded_domains` | 결과 도메인을 필터링합니다. Exa는 한 요청에서 두 필터를 동시에 지원합니다.                                                                                                        |

<div id="how-results-come-back">
  ## 결과가 반환되는 방식
</div>

OpenRouter는 각 결과에 대해 전체 페이지 텍스트 대신 [Exa highlights](/ko/docs/search/highlights)를 요청합니다. 즉, `max_characters`나 `search_context_size`를 설정하지 않으면 결과당 보통 2,000~4,000자 범위에서 길이가 자동 조정된 추출형 excerpt를 받게 됩니다. 모델은 이 excerpt를 읽고, API 호출자는 응답 메시지에 표준화된 `url_citation` 어노테이션 형태로 이를 전달받습니다. 하나의 결과 안에서는 `[...]` 표시가 페이지의 서로 다른 부분에서 가져온 excerpt를 구분해 줍니다.

<div id="pricing">
  ## 가격
</div>

Exa search는 결과를 읽는 데 드는 모델의 토큰 비용과 별도로 OpenRouter credits에서 차감됩니다. `instant`, `fast`, `auto` 모드는 search당 $0.007, `deep-lite`와 `deep`은 $0.012, `deep-reasoning`은 $0.015입니다. 각 search에는 최대 10개의 결과가 포함되며, 그 이상의 결과는 개당 $0.001입니다. 최신 요금은 [OpenRouter의 web search 문서](https://openrouter.ai/docs/guides/features/server-tools/web-search)를 참고하세요.

응답의 `usage` 객체는 모델이 실행한 search 횟수를 `server_tool_use.web_search_requests`에 보고합니다.
