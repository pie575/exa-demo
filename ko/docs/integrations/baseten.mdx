Exa는 [Baseten Hosted Tools](https://www.baseten.co/blog/introducing-baseten-hosted-tools/)의 web search provider입니다. Baseten Model APIs는 오픈소스 모델을 서빙하며, Hosted Tools를 사용하면 도구 루프를 직접 구성하지 않아도 이 모델들이 웹을 검색할 수 있습니다. 표준 요청에 Exa 도구 셀렉터를 추가하기만 하면, Baseten이 모델과 Exa search를 서버 측 루프에서 함께 실행하고 그 결과로 grounded answer를 동일한 응답에 담아 돌려줍니다. Exa API key는 필요하지 않습니다. Baseten은 Exa의 cost를 별도의 마진 없이 Baseten 청구서에 그대로 반영합니다.

<div id="use-the-exa-web-search-tools">
  ## Exa web search 도구 사용하기
</div>

`x-baseten-server-tools: true` header를 설정하고 `tools` 배열에 Exa 선택자를 하나 이상 추가하세요. `type`만 지정하면 되며, 나머지 도구 schema는 Baseten이 자동으로 확장합니다. 언제 search할지, 무엇을 search할지, 어떤 페이지를 읽을지는 모델이 스스로 판단합니다. server-side tools는 Baseten의 [Chat Completions](https://docs.baseten.co/reference/inference-api/chat-completions), [Messages](https://docs.baseten.co/reference/inference-api/messages), Responses endpoint에서 버퍼링 방식과 streaming 방식 모두 동작합니다.

<CodeGroup>
  ```python Python theme={null}
  from openai import OpenAI

  client = OpenAI(
      api_key="<BASETEN_API_KEY>",
      base_url="https://inference.baseten.co/v1",
      default_headers={"x-baseten-server-tools": "true"},
  )

  response = client.chat.completions.create(
      model="zai-org/GLM-5.3-Fast",
      messages=[
          {"role": "user", "content": "What were the major AI announcements this week?"}
      ],
      tools=[
          {"type": "baseten__exa__web_search_exa"},
          {"type": "baseten__exa__web_fetch_exa"},
      ],
      extra_body={"baseten": {"tool_settings": {"max_react_iterations": 5}}},
  )

  print(response.choices[0].message.content)
  ```

  ```javascript JavaScript theme={null}
  import OpenAI from "openai";

  const client = new OpenAI({
    apiKey: "<BASETEN_API_KEY>",
    baseURL: "https://inference.baseten.co/v1",
    defaultHeaders: { "x-baseten-server-tools": "true" },
  });

  const response = await client.chat.completions.create({
    model: "zai-org/GLM-5.3-Fast",
    messages: [
      { role: "user", content: "What were the major AI announcements this week?" },
    ],
    tools: [
      { type: "baseten__exa__web_search_exa" },
      { type: "baseten__exa__web_fetch_exa" },
    ],
    baseten: { tool_settings: { max_react_iterations: 5 } },
  });

  console.log(response.choices[0].message.content);
  ```

  ```bash cURL theme={null}
  curl https://inference.baseten.co/v1/chat/completions \
    -H "Authorization: Bearer <BASETEN_API_KEY>" \
    -H "Content-Type: application/json" \
    -H "x-baseten-server-tools: true" \
    -d '{
      "model": "zai-org/GLM-5.3-Fast",
      "messages": [
        { "role": "user", "content": "What were the major AI announcements this week?" }
      ],
      "tools": [
        { "type": "baseten__exa__web_search_exa" },
        { "type": "baseten__exa__web_fetch_exa" }
      ],
      "baseten": { "tool_settings": { "max_react_iterations": 5 } }
    }'
  ```
</CodeGroup>

Exa 도구는 세 가지가 제공됩니다. 모델이 출처를 찾은 뒤 직접 고른 페이지를 읽게 하려면 search와 fetch를 함께 제공하세요.

| 선택자                                     | 모델이 얻는 기능                                                         |
| --------------------------------------- | ----------------------------------------------------------------- |
| `baseten__exa__web_search_exa`          | [Exa search](/ko/docs/search/quickstart): 질의에 대한 관련 결과와 page content |
| `baseten__exa__web_search_advanced_exa` | 도메인 필터, 하위 페이지 크롤링, 결과별 선택적 summary를 지원하는 search                  |
| `baseten__exa__web_fetch_exa`           | 모델이 이미 확보한 URL의 [전체 page contents](/ko/docs/contents/quickstart)     |

선택자에는 추가 필드가 필요 없으며, 도구 인자는 모델이 Exa의 schema를 바탕으로 채웁니다. 언제 search할지, 1차 출처를 fetch할지, 어떻게 인용할지 같은 search 정책은 system prompt로 조정하세요. 루프의 상한은 `baseten.tool_settings`로 지정합니다.

| 설정                             | 용도                                                                                              |
| ------------------------------ | ----------------------------------------------------------------------------------------------- |
| `max_react_iterations`         | 요청당 모델 반복 횟수를 제한합니다(기본값 12, 범위 2~20). 마지막 반복은 답변용으로 예약되므로, `N`을 지정하면 도구 call은 `N - 1`회까지 수행됩니다. |
| `max_tool_calls_per_iteration` | 한 번의 반복에서 수행할 server-side tools call 횟수를 제한합니다(기본값 10, 범위 1~10)                                 |

<div id="how-results-come-back">
  ## 결과가 반환되는 방식
</div>

최종 답변은 endpoint의 일반 필드를 통해 전달됩니다. 완료된 Exa call은 프로토콜별로 기록됩니다. Messages에서는 `tool_use` 및 `tool_result` 블록, Responses에서는 `mcp_call` 항목, Chat Completions에서는 `baseten.iterations[].continuation_messages`에 기록됩니다. 스트리밍 요청의 경우 루프가 실행되는 동안 각 search call과 그 결과를 server-sent events로 받게 되므로, 답변이 도착하기 전에 진행 상황을 표시할 수 있습니다. `baseten.request.server_tool_calls[]` 배열은 해당 요청에서 수행된 모든 Exa call의 결과를 알려줍니다.

<div id="pricing">
  ## 가격
</div>

Exa call은 모델의 토큰 비용에 더해, 마크업 없이 Exa의 요율 그대로 Baseten 계정에 청구됩니다. search당 약 $0.007, 가져온 URL당 약 $0.001 수준입니다. Exa는 각 call의 요금을 실행 시점에 보고하므로 개별 call은 이 수치와 다를 수 있습니다. 청구된 도구 call은 Baseten 워크스페이스 설정의 Billing → Usage에서 provider별로 묶여 표시됩니다. 현재 요율은 [Baseten의 가격표](https://docs.baseten.co/inference/model-apis/web-search#pricing)를 참고하세요.

Hosted Tools는 Baseten에서 얼리 액세스 단계이며, Organization당 분당 25건의 요청 limit이 적용됩니다. [Baseten 플레이그라운드](https://app.baseten.co/model-apis/zai-org/GLM-5.3-Fast/playground)에서 Exa search를 사용해 보거나, 프로덕션 워크로드를 위해 limit 상향이 필요하면 Baseten에 문의하세요.
