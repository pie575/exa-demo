[Hermes Agent](https://github.com/NousResearch/hermes-agent)는 모델이 호출할 수 있는 `web_search` 및 `web_extract` 도구의 네이티브 백엔드로 Exa를 기본 지원합니다. 두 기능 모두에 Exa를 사용하거나, 다른 Hermes 웹 provider와 함께 사용할 수 있습니다.

<div id="connect-your-exa-account">
  ## Exa 계정 연결하기
</div>

<Steps>
  <Step title="Exa API 키 발급받기">
    <Card title="Exa API 키 발급받기" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      대시보드에서 키를 생성하세요. 신규 계정에는 무료 크레딧이 제공됩니다.
    </Card>
  </Step>

  <Step title="Hermes에서 Exa 선택하기">
    도구 설정 마법사를 실행하세요:

    ```bash theme={null}
    hermes tools
    ```

    **Web Search &amp; Extract**를 열고 Exa를 선택한 뒤, API 키 기반 옵션을 선택하세요. 입력하라는 메시지가 나타나면 Exa API 키를 입력합니다. Hermes는 시크릿을 `~/.hermes/.env`에, provider 선택 정보를 `~/.hermes/config.yaml`에 저장합니다.
  </Step>

  <Step title="웹 접근 테스트하기">
    Hermes를 실행한 뒤 검색을 요청하고, 결과 중 하나를 읽도록 해보세요:

    ```text theme={null}
    Search the web for the latest Exa product updates, then read the most relevant result.
    ```

    Hermes가 `web_search`를 호출하고, 페이지 내용이 필요할 때는 이어서 `web_extract`를 호출해야 합니다.
  </Step>
</Steps>

<div id="configure-manually">
  ## 직접 설정하기
</div>

Hermes 환경 파일에 key를 추가하세요:

```bash ~/.hermes/.env theme={null}
EXA_API_KEY=your-exa-api-key
```

그런 다음 두 가지 웹 기능 모두에서 Exa를 선택하세요:

```yaml ~/.hermes/config.yaml theme={null}
web:
  search_backend: "exa"
  extract_backend: "exa"
```

대신 공유 폴백을 사용할 수 있습니다:

```yaml ~/.hermes/config.yaml theme={null}
web:
  backend: "exa"
```

기능별 설정은 `web.backend`보다 우선 적용됩니다. 따라서 여러 provider를 조합할 때 Exa를 search에만, 또는 extraction에만 사용할 수 있습니다.

<div id="tools-hermes-gets">
  ## Hermes가 사용할 수 있는 도구
</div>

| 도구            | Exa 동작                                                   |
| ------------- | -------------------------------------------------------- |
| `web_search`  | Exa로 search를 수행하고 제목, URL, 텍스트 스니펫이 포함된 순위화된 페이지를 반환합니다. |
| `web_extract` | Exa Contents를 통해 하나 이상의 URL에서 읽을 수 있는 콘텐츠를 가져옵니다.        |

Hermes는 추출된 페이지가 길 경우 설정된 character budget에 맞춰 잘라내고, 전체 텍스트는 디스크에 저장합니다. 기본값은 `web.extract_char_limit`으로 변경하거나, agent가 개별 call마다 더 큰 `char_limit`을 요청하도록 할 수 있습니다.

<Note>
  Hermes는 API 키 없이도 키가 필요 없는 무료 provider 풀을 통해 Exa를 사용할 수 있습니다. 이 풀은 요청 수가 제한되며 여러 provider 사이에서 전환될 수 있습니다. 요청이 항상 사용자의 Exa 계정을 사용하도록 하려면 `EXA_API_KEY`를 설정하고 API 키 기반 Exa 옵션을 선택하세요.
</Note>

<div id="troubleshooting">
  ## 문제 해결
</div>

<AccordionGroup>
  <Accordion title="Hermes가 Exa를 선택하지 않는 경우">
    `hermes tools`를 실행한 뒤 Exa를 명시적으로 선택하세요. 파일을 직접 설정하는 경우에는 `web.search_backend`, `web.extract_backend` 또는 `web.backend`가 `exa`로 지정되어 있는지 확인하세요.
  </Accordion>

  <Accordion title="Hermes가 EXA_API_KEY가 없다고 알리는 경우">
    `~/.hermes/.env`에 키를 추가한 다음, Hermes를 재시작해 환경 변수를 다시 불러오게 하세요.
  </Accordion>

  <Accordion title="search는 동작하지만 extraction은 다른 provider를 사용하는 경우">
    Hermes는 search와 extraction을 각각 독립적으로 설정할 수 있습니다. `web.search_backend`와 `web.extract_backend`를 모두 `exa`로 설정하세요.
  </Accordion>
</AccordionGroup>
