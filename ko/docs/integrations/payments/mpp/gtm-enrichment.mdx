이 쿡북을 활용해 Exa의 `/search` 및 `/contents` 엔드포인트 위에 GTM enrichment agent 또는 파이프라인을 구축하고, Machine Payments Protocol(MPP)을 통해 요청 건당 비용을 지불하세요. MPP는 여러 결제 수단을 지원하며, 이 문서의 예제에서는 [Tempo](https://tempo.xyz) 기반 스테이블코인을 사용합니다. 월 구독도, API 키도, 좌석 기반 가격도 없습니다. wallet에 USDC.e를 충전한 뒤 리드나 기업을 enrich하는 만큼만 지불하면 됩니다.

<Info>
  MPP는 현재 Exa의 `/search` 및 `/contents` 엔드포인트에서만 지원됩니다.
  Agent API(`/agent/runs`)와 `/answer`는 Exa API key가 필요하며 표준 API 키 청구 흐름을 따릅니다.
</Info>

## 구축할 내용 {#what-youll-build}

회사 이름 목록이나 대상 설명을 입력받아 동작하는 가벼운 enrichment 파이프라인입니다.

1. Exa `/search`에 `type: "deep"`과 `outputSchema`를 지정해 공식 회사 페이지를 찾고 핵심 metadata를 추출합니다.
2. 반환된 result에 `contents.highlights`를 사용해 투자 유치, 본사, 직원 수, 제품에 관한 소스 스니펫을 가져옵니다.
3. 입력마다 CSV 또는 JSON enrichment 레코드를 생성합니다.

이 패턴은 리드 목록 enrichment, 어카운트 리서치, 아웃바운드 개인화에 적합합니다. 개별적인 `/search` + `/contents` call로 구성되어 있으므로 모든 단계를 MPP로 결제할 수 있습니다.

## 사전 준비 사항 {#prerequisites}

* Tempo mainnet에서 **USDC.e**가 충전된 Tempo 호환 wallet.
* 런타임에 wallet private key를 안전하게 불러오는 방법(아래 참고. private key를 커밋하거나 소스 코드에 노출하지 마세요).
* `mppx`(TypeScript) 또는 `pympp`(Python) 설치.

<Info>
  raw private key 없이 명령줄에서 설정하려면 [Tempo Wallet CLI](/ko/docs/integrations/payments/mpp/quickstart#pay-from-the-command-line)를 사용하세요. `tempo wallet login`은 wallet을 생성하거나 연결하며, 신규 가입자에게는 무료 MPP Credits이 제공될 수 있습니다.
</Info>

### 유료 search 요청 보내기 {#make-a-paid-search-request}

<CodeGroup>
  ```typescript TypeScript theme={null}
  import { Mppx, tempo } from "mppx/client";
  import { privateKeyToAccount } from "viem/accounts";

  // 프로덕션에서는 secret 관리 도구에서 불러오세요. 원본 값을 절대 커밋하지 마세요.
  const account = privateKeyToAccount(process.env.WALLET_PRIVATE_KEY as `0x${string}`);
  const mppx = Mppx.create({
    methods: [tempo.charge({ account })],
  });

  const response = await mppx.fetch("https://api.exa.ai/search", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      query: "Series A fintech companies with 50-200 employees",
      numResults: 5,
      contents: { highlights: true },
    }),
  });

  const data = (await response.json()) as { results: { title: string; url: string }[] };
  console.log(data.results);
  console.log("Payment receipt:", response.headers.get("Payment-Receipt"));
  ```

  ```python Python theme={null}
  import asyncio
  import os

  from mpp.client import Client
  from mpp.methods.tempo import ChargeIntent, TempoAccount, tempo


  async def main() -> None:
      # 프로덕션에서는 secret 관리 도구에서 불러오세요. 원본 값을 절대 커밋하지 마세요.
      account = TempoAccount.from_key(os.environ["WALLET_PRIVATE_KEY"])
      method = tempo(
          account=account,
          chain_id=4217,
          intents={"charge": ChargeIntent()},
      )

      async with Client(methods=[method]) as client:
          response = await client.post(
              "https://api.exa.ai/search",
              json={
                  "query": "Series A fintech companies with 50-200 employees",
                  "numResults": 5,
                  "contents": {"highlights": True},
              },
          )

      data = response.json()
      for result in data["results"]:
          print(result["url"], result["title"])
      print("Payment receipt:", response.headers.get("Payment-Receipt"))


  asyncio.run(main())
  ```
</CodeGroup>

요청이 성공하면 Exa 결과와 함께 on-chain 트랜잭션 해시가 담긴 `Payment-Receipt` header가 반환됩니다.

## GTM enrichment 레시피 {#gtm-enrichment-recipe}

### 회사 목록 enrich하기 {#enrich-a-list-of-companies}

회사 이름 목록을 받아 각 회사의 페이지를 검색하고 구조화된 세부 정보를
추출합니다.

<CodeGroup>
  ```typescript TypeScript theme={null}
  interface CompanyEnrichment {
    name: string;
    url: string;
    title: string;
    industry?: string;
    headquarters?: string;
    funding?: string;
    summary?: string;
    highlights: string[];
  }

  async function enrichCompanies(names: string[]): Promise<CompanyEnrichment[]> {
    const enriched: CompanyEnrichment[] = [];

    for (const name of names) {
      const response = await mppx.fetch("https://api.exa.ai/search", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          query: `${name} official company`,
          type: "deep",
          numResults: 1,
          contents: {
            highlights: { query: "funding, headquarters, employees, product" },
          },
          outputSchema: {
            type: "object",
            properties: {
              company: {
                type: "object",
                properties: {
                  name: { type: "string" },
                  url: { type: "string" },
                  industry: { type: "string" },
                  headquarters: { type: "string" },
                  funding: { type: "string" },
                  summary: { type: "string" },
                },
                required: ["name", "url"],
              },
            },
            required: ["company"],
          },
        }),
      });

      const data = (await response.json()) as {
        output?: { company?: CompanyEnrichment & { summary?: string } };
        results?: { highlights?: string[] }[];
      };
      const company = data.output?.company;
      const highlights = data.results?.[0]?.highlights?.slice(0, 3) ?? [];
      if (!company) continue;

      enriched.push({
        ...company,
        title: company.name,
        highlights,
      });
    }

    return enriched;
  }
  ```

  ```python Python theme={null}
  async def enrich_companies(names):
      enriched = []
      for name in names:
          response = await client.post(
              "https://api.exa.ai/search",
              json={
                  "query": f"{name} official company",
                  "type": "deep",
                  "numResults": 1,
                  "contents": {
                      "highlights": {"query": "funding, headquarters, employees, product"}
                  },
                  "outputSchema": {
                      "type": "object",
                      "properties": {
                          "company": {
                              "type": "object",
                              "properties": {
                                  "name": {"type": "string"},
                                  "url": {"type": "string"},
                                  "industry": {"type": "string"},
                                  "headquarters": {"type": "string"},
                                  "funding": {"type": "string"},
                                  "summary": {"type": "string"},
                              },
                              "required": ["name", "url"],
                          }
                      },
                      "required": ["company"],
                  },
              },
          )
          data = response.json()
          company = data.get("output", {}).get("company")
          highlights = []
          if data.get("results"):
              highlights = data["results"][0].get("highlights", [])[:3]
          if not company:
              continue

          enriched.append({
              "name": company["name"],
              "url": company["url"],
              "title": company["name"],
              "industry": company.get("industry"),
              "headquarters": company.get("headquarters"),
              "funding": company.get("funding"),
              "summary": company.get("summary"),
              "highlights": highlights,
          })
      return enriched
  ```
</CodeGroup>

### 인물 프로필 enrich하기 {#enrich-a-person-profile}

이 레시피는 `type: "deep"`, `contents.highlights`, `outputSchema`를 사용해
인물을 리서치하고 구조화된 프로필을 반환합니다.

<CodeGroup>
  ```typescript TypeScript theme={null}
  const response = await mppx.fetch("https://api.exa.ai/search", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      query: "Exa Labs founders contact and background",
      type: "deep",
      numResults: 5,
      contents: {
        highlights: { query: "email, title, education, work history, LinkedIn" },
      },
      outputSchema: {
        type: "object",
        properties: {
          people: {
            type: "array",
            items: {
              type: "object",
              properties: {
                name: { type: "string" },
                title: { type: "string" },
                company: { type: "string" },
                email: { type: "string" },
                linkedInUrl: { type: "string" },
                summary: { type: "string" },
              },
              required: ["name"],
            },
          },
        },
        required: ["people"],
      },
    }),
  });

  const data = (await response.json()) as {
    output?: { people: { name: string; title?: string; company?: string }[] };
  };
  console.log(data.output?.people);
  ```

  ```python Python theme={null}

      json={
          "query": "Exa Labs founders contact and background",
          "type": "deep",
          "numResults": 5,
          "contents": {
              "highlights": {"query": "email, title, education, work history, LinkedIn"}
          },
          "outputSchema": {
              "type": "object",
              "properties": {
                  "people": {
                      "type": "array",
                      "items": {
                          "type": "object",
                          "properties": {
                              "name": {"type": "string"},
                              "title": {"type": "string"},
                              "company": {"type": "string"},
                              "email": {"type": "string"},
                              "linkedInUrl": {"type": "string"},
                              "summary": {"type": "string"},
                          },

          },

  print(response.json().get("output", {}).get("people"))
  ```

<Note>
  여기서는 더 풍부한 추론을 위해 `type: "deep"`을, response 형태를 지정하기 위해
  `outputSchema`를 사용합니다. Deep search는 요청당 $0.012이며,
  `contents.highlights`는 result당 $0.001이 추가됩니다.
</Note>

### Structured output {#structured-output}

원문 텍스트 대신 JSON field를 받고 싶다면 search 요청에 `outputSchema`를 지정하세요.
Exa는 지정한 schema 형태에 맞춘 `output` 객체를 반환합니다.

<CodeGroup>
  ```python Python theme={null}
  response = await client.post(
      "https://api.exa.ai/search",
      json={
          "query": "Series A fintech companies with 50-200 employees",
          "type": "deep-lite",
          "numResults": 5,
          "outputSchema": {
              "type": "object",
              "properties": {
                  "companies": {
                      "type": "array",
                      "items": {
                          "type": "object",
                          "properties": {
                              "name": {"type": "string"},
                              "headcount": {"type": "string"},
                              "headquarters": {"type": "string"},
                              "fundingStage": {"type": "string"},
                          },
                          "required": ["name"],
                      },
                  }
              },
              "required": ["companies"],
          },
      },
  )
  ```

  ```javascript JavaScript theme={null}
  const response = await mppx.fetch("https://api.exa.ai/search", {
    method: "POST",

      type: "deep-lite",

        type: "object",

            type: "array",

              type: "object",

                name: { type: "string" },
                headcount: { type: "string" },
  ```

<Note>
  `outputSchema`는 `deep-lite` 또는 `deep` search type과 함께 사용할 때 가장 효과적입니다. Exa 측에서
  LLM call이 추가로 발생하므로 `deep-lite`/`deep` 요금이 적용됩니다.
</Note>

## Pricing 및 limits {#pricing-and-limits}

MPP는 API 키 청구와 동일한 요청당 가격을 사용합니다. MPP search 요청은
최대 10개의 결과로 제한됩니다.

| 작업                                              | 가격          |
| ----------------------------------------------- | ----------- |
| `type`이 `instant`, `auto`, 또는 `fast`인 `/search` | 요청당 $0.007  |
| `type`이 `deep-lite` 또는 `deep`인 `/search`        | 요청당 $0.012  |
| `type`이 `deep-reasoning`인 `/search`             | 요청당 $0.015  |
| `contents.text`                                 | URL당 $0.001 |
| `contents.highlights`                           | URL당 $0.001 |
| `contents.summary`                              | 결과당 $0.001  |

속도 제한, 네트워크 세부 정보, payment header 등 전체 reference는 [Pay with MPP (Tempo)](/ko/docs/integrations/payments/mpp/quickstart)를 참고하세요.

## 프로덕션 팁 {#production-tips}

* **wallet에는 USDC.e만 충전하세요.** Exa가 Tempo 네트워크 수수료를 부담하므로
  wallet에 별도의 가스 토큰을 보유할 필요가 없습니다.
* **`402` response를 처리하세요.** MPP SDK는 자동으로 재시도하지만, 커스텀
  client를 사용한다면 `WWW-Authenticate: Payment` challenge를 이용해 `402`에 대해 직접 재시도해야 합니다.
* **`/contents` result를 캐시하세요.** Contents는 URL 단위로 과금됩니다. 같은 회사 페이지에
  두 번 비용을 내지 않도록 URL 기준으로 캐시하세요.
* **result 10개 제한에 유의하세요.** MPP search는 `numResults`를 최대 10으로 제한합니다.
* **private key는 절대 커밋하지 마세요.** `WALLET_PRIVATE_KEY`는 소스 관리 시스템이 아닌
  secret 관리 도구에서 불러오세요.

## FAQ {#faq}

<AccordionGroup>
  <Accordion title="Exa Agent API에서 MPP를 사용할 수 있나요?">
    아니요. Exa 코드베이스에서 MPP는 `/search`와 `/contents`에만 연결되어 있습니다.
    `/agent/runs`와 `/answer`는 Exa API key가 필요하며 표준 API 키 청구을
    사용합니다.
  </Accordion>

  <Accordion title="같은 요청에서 MPP와 Exa API key를 함께 사용할 수 있나요?">
    아니요. 요청에 `x-api-key` 또는 `Authorization: Bearer`가 포함되어 있으면 API
    키 방식이 우선하며 MPP는 건너뜁니다.
  </Accordion>

  <Accordion title="MPP settlement가 실패하면 어떻게 되나요?">
    Exa는 새로운 `WWW-Authenticate: Payment` challenge와 함께 `402`를 반환하며
    결과는 제공하지 않습니다. client는 새 payment로 재시도할 수 있습니다. settlement가
    성공하기 전까지는 결과가 반환되지 않습니다.
  </Accordion>

  <Accordion title="환경별로 별도의 Tempo wallet이 필요한가요?">
    동일한 wallet을 재사용해도 되지만, 개발과 프로덕션에는 별도의 wallet을
    사용하는 것을 권장합니다. wallet당 QPS는 해당 wallet에서 오는 모든 요청을
    합쳐 초당 10건입니다.
  </Accordion>
</AccordionGroup>
