agent는 [Nevermined](https://nevermined.ai)의 [x402 card-delegation](https://nevermined.ai/docs/specs/x402-card-delegation) 방식을 사용해 신용카드로 Exa에 결제합니다. **$7을 구매**할 때마다 **$7의 Exa credits**가 담긴 Exa API key가 반환됩니다.

<Info>
  다음 Nevermined plan ID를 사용하세요:<br />`27800462147494506865542649899724877617306579171265399959488097895839186996870`<br />이 plan은 Nevermined의 라이브 환경(live 접두사가 붙은 API 키)에서 동작합니다. 이 구매는 단일 search 요청이 아니라 API credits에 대한 결제입니다.
</Info>

Nevermined로 처음 결제하는 payer라면 `POST /team-management/nevermined/purchase-key`가 새 Exa API key를 발급하고 $7의 credits를 추가합니다. 키의 잔액이 모두 소진되면 동일한 delegation으로 새 x402 토큰을 mint한 뒤 같은 엔드포인트를 다시 call하세요. Exa는 동일한 API key에 $7의 credits를 추가해 반환합니다.

## 키 구매하기 {#buy-a-key}

```bash theme={null}
POST https://admin-api.exa.ai/team-management/nevermined/purchase-key
payment-signature: <x402-token>
```

* **비용:** 구매당 $7이며, x402 토큰이 참조하는 delegation에 연결된 카드로 청구됩니다.
* **Response (신규 payer):** `{ status: "ok", apiKey: "…", expiresAt: null }` — $7 상당의 credits이 포함된 새 Exa API key입니다.
* **Response (기존 payer):** `{ status: "ok", apiKey: "…", expiresAt: null }` — 기존과 동일한 Exa API key에 $7 상당의 credits이 추가됩니다.
* **Response (replay된 토큰):** 캐시된 결과가 반환되며, 추가 청구는 없습니다.
* **signature 누락/유효하지 않음:** `402 Payment Required`와 함께 결제 요구 사항이 body에 담겨 반환됩니다.

## 작동 방식 {#how-it-works}

결제는 Nevermined가 처리하며, Exa는 서명된 x402 토큰만 확인합니다.

1. **최초 설정(카드 소유자가 수행):** [nevermined.app](https://nevermined.app)에서 카드를 등록하고, 해당 카드에 **delegation**(지출 권한: 소유자가 limit과 기간을 설정하며 특정 API 키로 scope를 한정할 수 있음)을 생성한 뒤, agent용 Nevermined API 키를 발급합니다.
2. **agent가 자신의 delegation을 찾습니다.** Nevermined SDK를 사용하면 agent가 자신의 키로 지출할 수 있는 delegation을 discovery하고 남은 예산이 충분한(최소 $7) 것을 선택할 수 있습니다. 해당하는 delegation이 없으면 소유자가 dashboard에서 생성하거나, 완전 자율 agent가 카드의 limits 범위 내에서 SDK를 통해 직접 생성할 수 있습니다.
3. **agent가 x402 access 토큰을 mint합니다.** 위의 plan ID에 대해 card-delegation 스킴으로 mint하며, delegation은 ID로 참조합니다. mint 전에 delegation이 미리 존재해야 하며, 토큰이 delegation을 즉석에서 생성할 수는 없습니다.
4. **agent가 위 엔드포인트로 토큰을 POST합니다.** `payment-signature` header에 담아 전송하고, response에서 Exa API key를 받습니다.
5. **키는 즉시 사용할 수 있습니다.** 표준 [Exa Search API](/ko/docs/search/quickstart)에 바로 사용 가능합니다.

agent가 바로 활용할 수 있는 전체 안내(SDK 메서드, parameters, delegation discovery 및 생성, 문제 해결)는 Nevermined의 Exa 연동 가이드를 참고하세요: [nevermined.ai/docs/integrations/exa](https://nevermined.ai/docs/integrations/exa) (agent의 경우: [nevermined.ai/docs/integrations/exa.md](https://nevermined.ai/docs/integrations/exa.md) 가져오기).

Credits는 표준 Exa API 가격에 따라 차감됩니다. 현재 요금 기준으로 $7의 credits로 대략 다음 정도를 이용할 수 있습니다:

| --------------------------------------------- | ---------------------------: | -------------: |
| 최대 10개 결과의 Search (`instant`, `fast`, `auto`) |               $7 / 1,000회 요청 |      1,000회 요청 |
| Deep-Lite Search                              |              $10 / 1,000회 요청 |        700회 요청 |
| Deep Search                                   |              $12 / 1,000회 요청 |       ~583회 요청 |

| Search 또는 Contents의 AI 페이지 요약                 |               $1 / 1,000 페이지 | 7,000개 summary |
| 처음 10개를 초과하는 추가 결과                            |               $1 / 1,000개 결과 |   7,000개 추가 결과 |

Search 요청에는 최대 10개 결과에 대한 text와 highlights가 포함됩니다. 10개를 초과하는 추가 결과와 AI summary는 별도로 청구됩니다.<br />
전체 가격 정보는 [Exa 가격](https://exa.ai/pricing)을 참고하세요.

## 키의 credits가 소진되면 {#when-the-key-runs-out}

API 키의 credits가 모두 소진되면 Exa는 일반 API 엔드포인트에서 **`HTTP 402`**를 반환합니다:

```json theme={null}
{
  "requestId": "...",
  "error": "You have exceeded your credits limit. Please top up to keep using Exa at dashboard.exa.ai",
  "tag": "NO_MORE_CREDITS"
}
```

동일한 plan ID와 delegation으로 새 x402 토큰을 mint한 다음, 같은 `/purchase-key` 엔드포인트로 다시 POST하세요. 그러면 Exa가 동일한 API 키에 $7 상당의 credits를 추가로 적립합니다.
