description: "Websets를 최신 데이터로 지속적으로 유지해 주는 새로운 `Monitor`를 생성합니다.


  Monitor는 정의한 일정에 따라 자동으로 실행되므로, 수동 개입 없이도 Websets를 항상 최신 상태로 유지할 수 있습니다:


  - **새로운 content 찾기**: `search` 작업을 실행해 criteria에 부합하는 새로운 item을 발견합니다

  - **기존 content 업데이트**: `refresh` 작업을 실행해 item의 contents와 enrichments를 업데이트합니다

  - **자동 일정 관리**: `cron` 표현식과 `timezone`을 설정해 일정을 정밀하게 제어합니다"
