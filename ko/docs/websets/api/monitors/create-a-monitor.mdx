description: "Websets를 항상 최신 데이터로 유지하는 새로운 `Monitor`를 생성합니다.


  Monitor는 지정한 일정에 따라 자동으로 실행되어, 수동 개입 없이도 Websets를 최신 상태로 유지합니다:


  - **새 콘텐츠 찾기**: `search` 작업을 실행해 criteria에 맞는 새로운 item을 찾습니다

  - **기존 콘텐츠 업데이트**: `refresh` 작업을 실행해 item의 contents와 enrichment를 갱신합니다

  - **자동 스케줄링**: `cron` 표현식과 `timezone`을 설정해 일정을 정밀하게 제어합니다"
