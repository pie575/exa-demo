  response에는 deliveries 검증에 사용하는 서명용 `secret`이 포함되며, 이 값은 생성 시에만 반환됩니다."
---

<Warning>
  **리디렉션은 따라가지 않습니다.** 웹훅 deliveries는 등록된 URL로 직접 전송됩니다. 엔드포인트가 3xx 리디렉션으로
  응답하면 해당 delivery는 실패로 처리됩니다. 항상 최종 목적지 URL을 등록하세요.
</Warning>
