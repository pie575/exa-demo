<Warning>
  **리디렉션은 따라가지 않습니다.** webhook 전달은 등록된 URL로 직접 전송됩니다. endpoint가 3xx 리디렉션으로 응답하면 해당 전달은 실패로 처리됩니다. 항상 최종 목적지 URL을 등록하세요.
</Warning>
