## 개요 {#overview}

Exclude Results 기능을 사용하면 새로운 search를 생성할 때 중복된 result를 받지 않습니다. 이전 Websets나 업로드한 CSV 파일을 기준으로 제외할 URL을 지정하면, 기존 데이터를 보완하는 새롭고 고유한 result를 발견하는 데 집중할 수 있습니다.

<br />

## 작동 방식 {#how-it-works}

<img src="/docs/images/websets/exclude-flow.png" alt="Webset 생성 시 결과 제외 옵션" width="1466" height="857" data-path="images/websets/exclude-flow.png" />

1. 새 Webset 생성을 시작합니다
2. 사이드 패널의 criteria 아래에서 &quot;Exclude&quot;를 클릭합니다
3. 이전에 만든 Webset을 선택하거나 제외할 URL이 담긴 CSV를 업로드합니다. 여러 소스를 선택해 제외할 수 있습니다.
4. search를 시작하면 제외 대상에 해당하지 않는 새로운 result만 표시됩니다

제외할 수 있는 result의 최대 개수는 plan에 따라 결정됩니다.

<br />

## exclusions를 사용하는 경우 {#when-to-use-exclusions}

* CRM에 아직 없는 리드 찾기
* 이전 search를 더 정교한 criteria로 이어서 진행하기
* 이미 알고 있는 result 제외하기
