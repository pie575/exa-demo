이미 URL 목록(회사, 인물, 제품 등)을 가지고 있다면 이를 Webset으로 **import**할 수 있습니다. Webset을 어떻게 설정하느냐에 따라 가져온 item을 enrich하거나, criteria에 따라 평가하거나, Web Discovery 결과와 결합할 수 있습니다.

이 가이드에서는 복사해서 바로 쓸 수 있는 API 호출과 함께 모든 configuration을 하나씩 살펴봅니다. `$EXA_API_KEY`만 여러분의 API key로 바꿔주세요.

<div id="our-example-5-it-consulting-suppliers">
  ## 예시: IT 컨설팅 공급업체 5곳
</div>

이 가이드 전반에서 동일한 5개 기업 목록을 import로 사용합니다:

| 회사           | URL                              | 비고                          |
| ------------ | -------------------------------- | --------------------------- |
| Accenture    | `https://www.accenture.com`      | 글로벌 IT 컨설팅, 미국 본사           |
| Infosys      | `https://www.infosys.com`        | IT 서비스, 미국 내 대규모 입지         |
| Wipro        | `https://www.wipro.com`          | IT 서비스, 미국 내 사무소 보유         |
| EPAM Systems | `https://www.epam.com`           | 소프트웨어 엔지니어링, 미국 상장          |
| Persol Group | `https://www.persol-group.co.jp` | 인력 파견 회사, 일본 중심, 미국 내 입지 미미 |

이 목록을 고른 이유는 5곳 중 4곳이 전형적인 IT 컨설팅 criteria(미국 사무소, IT 서비스)에 명확히 부합하기 때문입니다. **Persol Group**만 예외인데, 미국 내 입지가 거의 없는 일본계 인력 파견 회사이므로 미국 중심 criteria는 충족하지 못해야 합니다.

아래 예시에서 사용할 criteria는 다음과 같습니다:

1. &quot;회사가 미국에 사무소를 두고 있다&quot;
2. &quot;회사가 IT 컨설팅 또는 인력 보강 서비스를 제공한다&quot;

<div id="config-1-import-only-enrich-without-filtering">
  ## 구성 1: Import Only -- 필터링 없이 Enrich하기
</div>

<Note>
  **실제 예시:** [dashboard에서 이 webset 보기](https://websets.exa.ai/websets/webset_01kmnrshyh3bdart13q1ehdtdj)
</Note>

**사용 시점:** URL 목록을 가지고 있고 이를 enrich하기만 하면 될 때. 점수 매기기도 필터링도 없이 모든 item이 그대로 유지됩니다.

<div id="api-calls">
  ### API 호출
</div>

```bash theme={null}
# 1단계: 공급업체 URL이 담긴 CSV import 생성
curl -s -X POST "https://api.exa.ai/websets/v0/imports" \
  -H "Authorization: Bearer $EXA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "format": "csv",
    "count": 5,
    "size": 128,
    "entity": { "type": "company" },
    "title": "IT Consulting Suppliers"
  }'
# 응답에는 `uploadUrl`과 import `id`가 포함됩니다

# 2단계: 1단계에서 받은 사전 서명된 URL로 CSV 업로드
curl -X PUT "<UPLOAD_URL>" \
  -H "Content-Type: text/csv" \
  --data-binary @suppliers.csv
# suppliers.csv 내용: url\nhttps://www.accenture.com\nhttps://www.infosys.com\n...

# 3단계: 이 import를 사용하는 Webset 생성 (enrichment만 사용, search/criteria 없음)
# Webset을 생성하면 해당 import의 처리가 자동으로 예약됩니다.
curl -s -X POST "https://api.exa.ai/websets/v0/websets" \
  -H "Authorization: Bearer $EXA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "import": [
      { "source": "import", "id": "<IMPORT_ID>" }
    ],
    "enrichments": [
      { "description": "What services does this company provide?", "format": "text" },
      { "description": "Number of employees", "format": "number" }
    ]
  }'
```

**item 5개**가 모두 Webset에 표시됩니다. criteria가 없으므로 필터링이 일어나지 않습니다.

| 공급업체         | Webset 포함 여부 | Source   | 평가 | Enrichment | 이유                            |
| ------------ | ------------ | -------- | -- | ---------- | ----------------------------- |
| Accenture    | **예**        | `import` | 0  | 2          | import된 항목이며, 평가할 criteria 없음 |
| Infosys      | **예**        | `import` | 0  | 2          | import된 항목이며, 평가할 criteria 없음 |
| Wipro        | **예**        | `import` | 0  | 2          | import된 항목이며, 평가할 criteria 없음 |
| EPAM Systems | **예**        | `import` | 0  | 2          | import된 항목이며, 평가할 criteria 없음 |
| Persol Group | **예**        | `import` | 0  | 2          | import된 항목이며, 평가할 criteria 없음 |

모든 item의 `source`는 `"import"`이고 `evaluations`는 `[]`입니다. 이 설정에는 criteria가 없으므로, criteria 통과 여부와 관계없이 5개 모두 유지되고 enrich됩니다.

<Note>
  Persol Group의 URL(`persol-group.co.jp`)은 엔티티 데이터에서 &quot;PERSOL Vietnam Japan Desk&quot;로 확인되었습니다 -- 그래도 시스템은 이를 그대로 import하고 enrich하며, 단지 지역 자회사 페이지로 연결되었을 뿐입니다.
</Note>

<div id="config-4-scoped-search-web-discovery-score-your-list-and-find-new-matches">
  ## 구성 4: Scoped Search + Web Discovery -- 내 목록 평가와 새로운 매칭 항목 발굴을 동시에
</div>

<Note>
  **실제 예시:** [dashboard에서 이 webset 보기](https://websets.exa.ai/websets/webset_01kmpbj5wjcsh1yqn2cfhx2v7h)
</Note>

**사용 시점:** 보유한 공급업체 목록을 criteria에 따라 평가하면서, 동일한 criteria에 부합하는 기업을 웹에서 추가로 발굴하고 싶을 때 사용합니다. 두 단계로 진행됩니다. 먼저 Scoped Search로 webset을 생성한 뒤, 같은 webset에 일반 web search를 추가합니다.

<div id="api-calls-3">
  ### API 호출
</div>

<CodeGroup>
  ```python Python theme={null}
  import os
  import requests

  # Config 1과 같이 CSV import를 생성해 업로드한 뒤, 그 ID를 여기에 사용하세요.
  headers = {"Authorization": f"Bearer {os.environ['EXA_API_KEY']}"}
  webset_response = requests.post(
      "https://api.exa.ai/websets/v0/websets",
      headers=headers,
      json={
          "search": {
              "query": "IT consulting and staff augmentation companies",
              "entity": {"type": "company"},
              "criteria": [
                  {"description": "The company has an office in the United States"},
                  {
                      "description": "The company provides IT consulting or staff augmentation services"
                  },
              ],
              "count": 25,
              "scope": [
                  {"source": "import", "id": "<IMPORT_ID>"},
              ],
          },
          "enrichments": [
              {
                  "description": "What services does this company provide?",
                  "format": "text",
              },
              {"description": "Number of employees", "format": "number"},
          ],
      },
  )
  webset_response.raise_for_status()
  webset_id = webset_response.json()["id"]

  search_response = requests.post(
      f"https://api.exa.ai/websets/v0/websets/{webset_id}/searches",
      headers=headers,
      json={
          "query": "IT consulting and staff augmentation companies",
          "entity": {"type": "company"},
          "criteria": [
              {"description": "The company has an office in the United States"},
              {
                  "description": "The company provides IT consulting or staff augmentation services"
              },
          ],
          "count": 25,
          "behavior": "append",
      },
  )
  search_response.raise_for_status()
  ```

  ```javascript JavaScript theme={null}

            { description: "The company has an office in the United States" },
            {

            }

            { source: "import", id: "<IMPORT_ID>" }
          ]

          {
            description: "What services does this company provide?",
            format: "text"
          },
          { description: "Number of employees", format: "number" }
        ]
      })
    }
  );

  if (!websetResponse.ok) {
    throw new Error(`Webset creation failed: ${websetResponse.status}`);

  const webset = await websetResponse.json();

  const searchResponse = await fetch(
  ```
