[Financial Datasets](https://financialdatasets.ai)는 AI agents가 바로 처리할 수 있는 형태의
기업 및 시장 데이터를 제공합니다.
[Exa Connect](/ko/docs/agent/connect/overview)를 통해 agent는 실시간 및 과거 가격, 기업 정보,
재무제표와 밸류에이션 지표, 실적, insider 및 institutional ownership, SEC filings와
filing 섹션, 기업 뉴스를 조회하고, 펀더멘털 기준으로 미국 시장을 스크리닝할 수 있습니다.

[Exa Agent](/ko/docs/agent/quickstart) 실행에 `financial_datasets`를 attach하면,
agent가 Exa web search와 함께 Financial Datasets에 질의합니다.

<div id="use-it-for">
  ## 활용 사례
</div>

* 구조화된 기업 리서치 스냅샷 구축
* 재무 성과, 밸류에이션, 과거 추세 분석
* SEC filings 읽기 및 위험 요인, MD&amp;A 등의 섹션 추출
* insider 거래 및 institutional ownership 조사
* 펀더멘털 기준 기반 미국 시장 스크리닝
* 기업 뉴스 및 주요 동향 모니터링

<div id="data-available">
  ## 사용 가능한 데이터
</div>

다음 데이터셋은 모두 `financial_datasets` provider에서 제공되며, agent가 작업에 맞는 것을 선택합니다:

| 데이터셋                    | 반환 내용                                                                |
| ----------------------- | -------------------------------------------------------------------- |
| 실질 소유권                  | Schedule 13D/13G에 보고된 5% 이상 실질 소유주(행동주의 지분 및 수동적 지분 포함).             |
| 기업 정보                   | 상호, 섹터, 산업, 거래소, 소재지, SEC CIK, SIC 분류.                               |
| 기업 뉴스                   | 특정 ticker에 대한 최신 뉴스 기사.                                              |
| 실적                      | 분기 매출 및 EPS, 전년 동기 대비 변동, 예상치 상회/하회 서프라이즈.                           |
| 재무 지표                   | 시가총액, EV, P/E, P/B, P/S, EV/EBITDA, PEG, 마진, ROE/ROA/ROIC, 성장률, EPS. |
| 재무제표                    | SEC filings 기반 손익계산서, 재무상태표, 현금흐름표.                                  |
| 과거 주가                   | 지정 기간의 OHLCV 데이터(일/주/월/년 단위).                                        |
| 인덱스 펀드 보유 종목            | 비중별 ETF/인덱스 펀드 구성 종목, 또는 특정 증권을 보유한 펀드 목록.                           |
| Insider 보유 지분           | SEC Form 3 및 5 기반 insider 보유 현황(임원, 이사, 10% 이상 주주의 보유 주식 수).         |
| Insider 거래              | SEC Form 4 insider 거래 내역(성명, 직위, 거래 유형, 주식 수, 금액).                   |
| Institutional ownership | 13F 기관 투자자, 보유 주식 수, 보고 가치.                                          |
| 금리                      | 중앙은행의 현재 및 과거 정책 금리(Fed, ECB, BOJ 등).                                |
| SEC 공시 항목               | 10-K/10-Q/8-K의 특정 항목 추출 텍스트(예: 위험 요인, MD&amp;A).                     |
| SEC filings             | 공시 메타데이터 및 EDGAR 직접 링크, 양식 유형별 필터링 가능.                               |
| 부문별 재무 정보               | 제품, 사업 부문, 지역별로 구분한 매출, 영업이익 및 기타 항목.                                |
| 주가 스냅샷                  | 현재 실시간 가격, 당일 변동폭, 호가 시각.                                            |
| 종목 스크리너                 | 펀더멘털 필터 criteria에 부합하는 기업.                                           |
