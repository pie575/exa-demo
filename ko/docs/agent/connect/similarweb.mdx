[Similarweb](https://www.similarweb.com)는 디지털 시장 인텔리전스 분야의 대표적인
데이터 소스입니다. 수백만 개의 웹사이트와 앱의 트래픽 및 사용자 참여도를 모델링하여
추정 방문 수, 트래픽 소스, 방문자 인구 통계는 물론 특정 도메인을 둘러싼
경쟁 그룹까지 다룹니다.

[Exa Connect](/ko/docs/agent/connect/overview)를 통해 `similarweb`을
[Exa Agent](/ko/docs/agent/quickstart) 실행에 연결하면, agent가 Exa web search와
함께 Similarweb을 조회합니다.

<div id="use-it-for">
  ## 활용 사례
</div>

* 동종 업계 대비 특정 기업의 웹 트래픽과 사용자 참여도 벤치마킹
* 도메인의 경쟁사 및 방문자가 겹치는 사이트 매핑
* 디지털 발자국을 기준으로 시장 규모 산정 및 기업 선별
* 실제 행동 데이터로 기업 및 카테고리 리서치 보강(enrich)

<div id="pricing">
  ## 요금
</div>

Similarweb는 데이터 credit 단위로 `$0.30 / credit`을 청구하며, 각 call에는 Similarweb가 해당 call에 대해 보고한 credit이 부과됩니다. credit은 반환되는 데이터 양에 비례해 늘어나며, 대략 데이터 포인트(지표 × 행 × 월)당 1 credit입니다. 따라서 call의 가격은 해당 call의 파라미터에 따라 결정됩니다:

| 도구           | Credit                                     |
| ------------ | ------------------------------------------ |
| 트래픽 및 순위     | 요청한 월당 최대 7 (1~2개월)                        |
| 유사 사이트       | 반환된 사이트당 3 (1~5개 사이트)                      |
| 트래픽 소스       | 10                                         |
| 상위 리퍼러       | 반환된 리퍼러당 3 (1~5)                           |
| 상위 국가        | 반환된 국가당 3 (1~5)                            |
| 상위 페이지       | 반환된 페이지당 2 (1~7)                           |
| 상위 키워드       | 1~10 (키워드 데이터 포인트 100개당 약 1; 키워드 50개는 약 7) |
| 키워드 개요       | 1~2                                        |
| 방문자 인구통계     | 8                                          |
| 방문자 중복       | 도메인 조합당 2 (도메인 2~~3개: 6~~14)               |
| 기술           | 10                                         |
| 카테고리별 상위 사이트 | 반환된 사이트당 1 (1~10)                          |

데이터를 반환하지 않는 call(알 수 없거나 트래픽이 적은 도메인, 검색량이 없는 키워드)은 무료입니다. `numResults`와 `months`가 비용을 지불할 데이터 포인트 수를 결정하므로, 작업에 필요한 최소한의 값으로 설정하세요.

<div id="example">
  ## 예시
</div>

빠르게 성장하는 B2B SaaS 기업 10곳과 각 기업의 추정 웹 트래픽을 찾아봅니다.

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="Find 10 fast-growing B2B SaaS companies and their estimated web traffic.",
      data_sources=[{"provider": "similarweb"}],
      output_schema={
          "type": "object",
          "required": ["companies"],
          "properties": {
              "companies": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["name", "domain", "monthlyVisits"],
                      "properties": {
                          "name": {"type": "string"},
                          "domain": {"type": "string"},
                          "monthlyVisits": {"type": "number", "description": "from Similarweb"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

  ```javascript JavaScript theme={null}
  import Exa from "exa-js";

  const exa = new Exa();
  const run = await exa.agent.runs.create({
    query: "Find 10 fast-growing B2B SaaS companies and their estimated web traffic.",
    dataSources: [{ provider: "similarweb" }],
    outputSchema: {
      type: "object",
      required: ["companies"],
      properties: {
        companies: {
          type: "array",
          maxItems: 10,
          items: {
            type: "object",
            required: ["name", "domain", "monthlyVisits"],
            properties: {
              name: { type: "string" },
              domain: { type: "string" },
              monthlyVisits: { type: "number", description: "from Similarweb" },
            },
          },
        },
      },
    },
  });
  ```
