Exa Connect는 프리미엄 data partners를 Exa Agent 루프에 통합합니다. 실행에 provider를
attach하면 Exa Agent가 web search와 함께 해당 partner의 데이터베이스를 조회한 뒤,
그 결과를 근거에 기반한 하나의 구조화된 답변으로 결합합니다.

agent 실행이 처음이신가요? [Exa Agent 가이드](/ko/docs/agent/quickstart)로 시작한 다음
다시 돌아와 data partners를 attach하세요.

<Tip>
  Exa Agent는 이미 전체 [data index](/ko/docs/search/data/overview), 즉 Search API와 동일한
  뉴스, 코드, 기업, 인물 소스를 검색합니다. Exa Connect는 그 위에 프리미엄 partner 데이터베이스를
  더해 줍니다.
</Tip>

<Tip>
  MCP를 선호하시나요? Exa Agent와 [Exa Connect](/ko/docs/agent/connect/overview)는 [Exa MCP](/ko/docs/get-started/exa-mcp#exa-agent)에서 사용할 수 있습니다. `tools=agent_run`을 활성화하면 Claude, Cursor를 비롯한 MCP 클라이언트에서 다단계 리서치, 리스트 빌딩, enrichment, structured output을 실행할 수 있습니다.
</Tip>

<div id="why-exa-connect">
  ## Exa Connect를 사용해야 하는 이유
</div>

* **별도의 통합 작업 없이 프리미엄 데이터 사용.** 계약을 체결하거나 SDK를 연동하지 않고도 partner 데이터를 사용할 수 있습니다. Exa API 하나만 호출하면 됩니다.
* **복잡한 연결 작업은 Exa가 처리합니다.** provider 인증, 도구 선택, 재시도, 결과 랭킹은 Exa가 알아서 관리합니다.
* **Exa Agent가 소스를 선택합니다.** `outputSchema`에서 &quot;Similarweb 기준 월간 방문 수&quot;나 &quot;검증된 임원 정보&quot;를 요청하면, Exa Agent는 웹 페이지에서 추측하는 대신 이에 맞는 partner 도구를 호출합니다.
* **하나의 실행에서 인덱스와 partner 데이터를 함께 활용합니다.** Connect는 Exa 인덱스 위에서 동작합니다. Exa Agent는 각 소스를 가장 강점이 있는 영역에 활용하고 그 결과를 인용합니다.

<div id="how-it-works">
  ## 작동 방식
</div>

1. [`POST /agent/runs`](/ko/docs/reference/agent-api/create-a-run)의 `dataSources` 배열을 통해 하나 이상의 provider를 **attach**합니다.
2. Exa Agent가 질의와 `outputSchema`를 바탕으로 각 단계에 맞는 **도구를 선택**합니다. partner 데이터 또는 Exa web search 중에서 선택합니다.
3. partner 결과는 **웹 리서치와 융합**되어 출처가 함께 첨부된 structured output으로 반환됩니다.

<div id="pricing">
  ## 가격
</div>

<Note>
  Exa Connect 가격은 표준 [Agent 실행 가격](/ko/docs/agent/quickstart#pricing)에 더해 추가로 부과됩니다.
  기존 Agent 컴퓨트 및 search 비용에 더해, Exa Connect 도구 호출마다 provider call 요금이 부과됩니다.
</Note>

| Provider                                             | 가격                                            |
| ---------------------------------------------------- | --------------------------------------------- |
| [Fiber.ai](/ko/docs/agent/connect/fiber#pricing)        | `$0.02 / credit`                              |
| [Similarweb](/ko/docs/agent/connect/similarweb#pricing) | `$0.30 / credit`                              |
| [Baselayer](/ko/docs/agent/connect/baselayer#pricing)   | `$0.10 – $4.00 / order (varies by operation)` |
| [Polymarket](/ko/docs/agent/connect/polymarket#pricing) | `Free`                                        |
| Affiliate.com                                        | `$0.015 / call`                               |
| Particle                                             | `$0.015 / call`                               |
| Financial Datasets                                   | `$0.01 / call`                                |
| Jinko                                                | `$0.005 / call`                               |

Fiber.ai는 call마다 자체 요금이 달라지기 때문에 call 단위가 아니라 credit 단위로
과금합니다. search는 2 credit에 반환된 결과당 1 credit이 추가되고, 회사 또는 인물
조회는 반환된 후보당 과금되며(따라서 이름이 모호해 이를 구분하려고 회사 조회의
`numResults`를 높이면 비용이 더 듭니다), 연락처 조회는 work email, personal email,
전화번호 중 무엇을 요청하는지에 따라 2~5 credit입니다. 각 call에 대해 Fiber가
보고한 credit만큼 과금되며, 일치하는 결과가 없는 call은 무료입니다. [Fiber.ai 가격](/ko/docs/agent/connect/fiber#pricing)을 참고하세요.

Similarweb은 데이터 credit 단위로 과금하며(대략 지표 × 행 × 월당 1 credit), 따라서
call 가격은 `numResults`/`months`에 따라 call당 1~15 credit으로 정해집니다. 각 call에 대해
Similarweb이 보고한 credit만큼 과금되며, 데이터를 반환하지 않는 call은 무료입니다.
[Similarweb 가격](/ko/docs/agent/connect/similarweb#pricing)을 참고하세요.

Baselayer는 order 단위로 과금하며, 요율은 operation에 따라 달라집니다. KYB 사업자
search는 $1.00, UCC 담보권 search는 조회한 주(state)당 $2.00, 소송/파산 사건기록
search는 카테고리당 $1.00, watchlist 스크리닝은 요청한 목록당 $0.10~$0.25, 산업
분류와 웹사이트 분석은 각각 $0.35, 웹 존재감 분석은 선택한 분석 항목의 합계(항목당
$0.15~$0.35), 해외 사업자 search는 $4.00입니다. 이전 사업자 search 결과에 대한 후속
조회(사업자 조회, 임원, 등록 정보, 임원 역방향 조회)는 무료입니다.
[Baselayer 가격](/ko/docs/agent/connect/baselayer#pricing)을 참고하세요.

<div id="combining-providers">
  ### provider 조합하기
</div>

작업에 필요한 만큼 partner를 attach하세요. Exa Agent는 각 partner를 가장 강점을 발휘하는 영역에서 호출하고, 그 결과를 web search 결과와 함께 하나의 구조화된 답변으로 통합합니다:

```json theme={null}
{
  "dataSources": [
    { "provider": "similarweb" },
    { "provider": "fiber" },
    { "provider": "harmonic" }
  ]
}
```

모든 partner가 호출되도록 질의와 `outputSchema`를 구성하는 방법을 포함한 전체 과정은 [Combining providers](/ko/docs/agent/connect/combining-providers)를 참고하세요.
