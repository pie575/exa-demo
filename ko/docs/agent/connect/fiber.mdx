[Fiber.ai](https://fiber.ai)는 4,000만 개 이상의 기업, 8억 5,000만 명 이상의 인물,
3,000만 개 이상의 채용 공고에 대한 최신 데이터를 보유한 B2B 데이터 플랫폼입니다. 실시간 기업, 인물,
채용 데이터를 검색하고, 누락된 정보가 있는 records를 work email, 개인 이메일, 전화번호로
enrich할 수 있습니다.

[Exa Connect](/ko/docs/agent/connect/overview)를 통해 [Exa Agent](/ko/docs/agent/quickstart) 실행에
`fiber`를 attach하면, agent가 Exa web search와 함께
Fiber.ai에도 쿼리를 보냅니다.

<div id="use-it-for">
  ## 활용 사례
</div>

* work email이나 개인 이메일을 역으로 조회해 인물을 찾거나, 일부만 채워진 회사/인물
  레코드를 enrich해 CRM을 정리할 때.
* 이직, 승진, 신규 입사, 인원 변동, 자금 조달 등 실시간 LinkedIn 시그널을 추적할 때.
* LinkedIn, X, Instagram, TikTok, Reddit, YouTube 전반에서 관련 게시물을 찾아
  댓글과 반응을 수집한 뒤, 작성자의 연락처 정보를 enrich할 때.
* 4,000만 개 이상의 회사와 8억 5,000만 명 이상의 인물을 검색하고, 잠재 고객에
  work email, 개인 이메일, 전화번호를 enrich할 때.

<div id="provider-id">
  ## 제공업체 ID
</div>

`dataSources`에 다음 값을 사용하세요:

```text theme={null}
fiber
```

<div id="pricing">
  ## Pricing
</div>

Fiber.ai는 `$0.02 / credit` 요율로 credits를 청구하며, 각 call에는 Fiber가 해당 call에 대해 보고한 credits가 부과됩니다:

| 작업              | Credits                   |
| --------------- | ------------------------- |
| search          | 2 + 반환된 result당 1         |
| 회사 조회           | 반환된 후보당 ~2                |
| 인물 조회 / 이메일 역조회 | 2                         |
| 연락처 공개          | 2 (work email) – 5 (전화번호) |

일치 항목이 없는 call(또는 Fiber가 요금을 환불하는 call)은 무료입니다. 매개변수 선택에 따라 가격이 달라집니다. 회사 조회의 `numResults`는 비용을 지불할 후보 수를 결정하며, search는 result 수가 비용의 대부분을 좌우합니다.

<div id="example">
  ## 예시
</div>

뉴욕에 위치한 직원 수 50~200명 규모의 시리즈 A 핀테크 기업으로 B2B 잠재 고객 목록을 만들어 보겠습니다.

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="I'm building a B2B sales prospecting list using a B2B company database. Find Series A fintech companies in New York with 50-200 employees, and for each return the company's LinkedIn profile, domain, employee count, and funding stage.",
      data_sources=[{"provider": "fiber"}],
      output_schema={
          "type": "object",
          "required": ["companies"],
          "properties": {
              "companies": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["name", "domain", "employeeCount", "fundingStage"],
                      "properties": {
                          "name": {"type": "string"},
                          "domain": {"type": "string"},
                          "employeeCount": {"type": "number"},
                          "fundingStage": {"type": "string"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

  ```javascript JavaScript theme={null}
  import Exa from "exa-js";

  const exa = new Exa();

    dataSources: [{ provider: "fiber" }],

      type: "object",

      properties: {
        companies: {
          type: "array",

              fundingStage: { type: "string" },
            },
          },
        },
      },
    },
  });
  ```
