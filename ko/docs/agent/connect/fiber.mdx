[Fiber.ai](https://fiber.ai)는 4,000만 개 이상의 기업, 8억 5,000만 명 이상의 인물,
3,000만 건 이상의 채용 공고에 대한 최신 데이터를 보유한 B2B 데이터 플랫폼입니다.
실시간 기업, 인물, 채용 데이터를 검색하고, 불완전한 레코드에 업무용 이메일,
개인 이메일, 전화번호를 enrich할 수 있습니다.

[Exa Connect](/ko/docs/agent/connect/overview)를 통해 [Exa Agent](/ko/docs/agent/quickstart)
실행에 `fiber`를 연결하면, agent가 Exa web search와 함께 Fiber.ai에 질의합니다.

<div id="use-it-for">
  ## 활용 사례
</div>

* work email이나 개인 이메일을 역조회해 인물을 찾아내거나, 불완전한 회사/인물
  레코드를 enrich하여 CRM을 정리할 수 있습니다.
* 이직, 승진, 신규 입사, 인원 변동, 자금 조달 등 실시간 LinkedIn 신호를 추적할 수 있습니다.
* LinkedIn, X, Instagram, TikTok, Reddit, YouTube 전반에서 관련 게시물을 찾아
  댓글과 반응을 수집한 뒤, 작성자의 연락처 정보를 enrich할 수 있습니다.
* 4,000만 개 이상의 기업과 8억 5,000만 명 이상의 인물을 search하고, prospect에
  work email, 개인 이메일, 전화번호를 더해 enrich할 수 있습니다.

<div id="pricing">
  ## 가격
</div>

Fiber.ai는 `$0.02 / credit` 기준으로 credits를 청구하며, 각 call마다 Fiber가 보고한
credits만큼 요금이 부과됩니다:

| 작업                 | Credits                   |
| ------------------ | ------------------------- |
| search             | 2 + 반환된 결과당 1             |
| 회사 조회              | 반환된 후보당 ~2                |
| 인물 조회 / 이메일 역방향 조회 | 2                         |
| 연락처 공개             | 2 (work email) – 5 (전화번호) |

일치하는 결과가 없는 call(또는 Fiber가 요금을 환불하는 call)은 무료입니다. 매개변수
선택에 따라 가격이 달라집니다. 회사 조회에서는 `numResults`가 요금이 부과되는 후보 수를
결정하며, search에서는 결과 수가 cost의 대부분을 좌우합니다.

<div id="example">
  ## 예시
</div>

뉴욕에 있는 직원 50~200명 규모의 시리즈 A 핀테크 기업으로 B2B 잠재 고객 리스트를 만들어 봅니다.

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="I'm building a B2B sales prospecting list using a B2B company database. Find Series A fintech companies in New York with 50-200 employees, and for each return the company's LinkedIn profile, domain, employee count, and funding stage.",
      data_sources=[{"provider": "fiber"}],
      output_schema={
          "type": "object",
          "required": ["companies"],
          "properties": {
              "companies": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["name", "domain", "employeeCount", "fundingStage"],
                      "properties": {
                          "name": {"type": "string"},
                          "domain": {"type": "string"},
                          "employeeCount": {"type": "number"},
                          "fundingStage": {"type": "string"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

  ```javascript JavaScript theme={null}

  const exa = new Exa();

    dataSources: [{ provider: "fiber" }],

          },

      },
    },
  });
  ```
