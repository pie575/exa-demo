## 프로덕션 체크리스트 {#production-checklist}

* Agent에 작업 단위와 원하는 소스 품질을 명시한 구체적인 `query`를 제공하세요.
* 이미 알고 있는 records는 prompt에 행으로 넣지 말고 `input.data`로 전달하세요.
* 다시 반환되지 않아야 할 records에는 `input.exclusion`을 사용하세요.
* 후속 코드에서 결과를 사용하는 경우에는 반드시 `outputSchema`를 추가하세요.
* 범위와 비용을 예측 가능하게 관리하려면 배열에 `maxItems`를 사용하세요.
* 반환된 실행 `id`를 저장해 두면 나중에 폴링하거나, 이벤트를 replay하거나, 비용을 확인하거나, 해당 실행을 이어서 진행할 수 있습니다.
