Exa skill은 coding agent에 Exa API로 search하고, 콘텐츠를 가져오고, 애플리케이션을 구축하는 방법을 알려줍니다. 오픈소스 [exa-labs/agent-skills](https://github.com/exa-labs/agent-skills) repository에서 확인할 수 있습니다.

각 skill은 개방형 [Agent Skills](https://agentskills.io) 표준을 따르는 마크다운 파일로 구성되어 있어, 동일한 파일을 호환되는 모든 agent에 그대로 설치할 수 있습니다.

<div id="install">
  ## 설치
</div>

모든 Exa skill을 한 번에 설치하려면:

```bash theme={null}
npx skills add exa-labs/agent-skills
```

<Card title="Exa API key 발급받기" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  대시보드에서 key를 생성하세요. 신규 계정에는 무료 크레딧이 제공됩니다.
</Card>

<Note>
  agent 환경에서 key를 `EXA_API_KEY`로 설정하세요.
</Note>

또는 아래 skill 페이지를 열어 해당 setup prompt를 복사한 뒤 agent에 붙여넣으세요. 이 prompt는 해당 skill을 설치하고, API key를 출력하지 않고 검증합니다.
