  # Zero Data Retention
</div>

> Exa 제품별 Zero Data Retention 지원 현황입니다.

Zero Data Retention(ZDR)은 Enterprise 플랜에서 제공되며, team 단위로 활성화됩니다. 자세한 내용은 [sales@exa.ai](mailto:sales@exa.ai)로 문의해 주세요.

| 제품       | ZDR 지원 여부 |
| -------- | --------- |
| Search   | 지원        |
| Contents | 지원        |
| Agent    | 지원        |
| Answer   | 현재 미지원    |
| Websets  | 현재 미지원    |
