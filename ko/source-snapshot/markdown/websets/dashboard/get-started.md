# 시작하기 {#get-started}

> Websets Dashboard에 오신 것을 환영합니다! 아무리 복잡한 조건이라도 웹에서 원하는 것을 무엇이든 찾아보세요.

<br />

## 1. 가입하기 {#1-sign-up}

Websets가 이제 [https://websets.exa.ai/](https://websets.exa.ai/)에서 정식 출시되었습니다!

궁금한 점이 있으시면 [여기에서 미팅을 예약하세요](https://scheduler.default.com/exa/websets-intro/30min).

<br />

## 2. Get started {#2-get-started}

Websets는 사용법이 아주 간단합니다.

<img src="https://mintcdn.com/exa-52/tmzyKnsgpKLGddKC/images/websets/websets-landing.png?fit=max&auto=format&n=tmzyKnsgpKLGddKC&q=85&s=8573cf90a9e9f98c757ac0fa56c8a64d" alt="Websets 랜딩 페이지" width="2870" height="1726" data-path="images/websets/websets-landing.png" />

1. 원하는 것을 일상적인 언어로 설명하세요. 얼마든지 복잡해도 괜찮습니다!

<img src="https://mintcdn.com/exa-52/tmzyKnsgpKLGddKC/images/websets/websets-preview.png?fit=max&auto=format&n=tmzyKnsgpKLGddKC&q=85&s=15c47c556750ad0f1cebfb78b1ea52aa" alt="생성된 criteria의 Webset 미리보기" width="2870" height="1726" data-path="images/websets/websets-preview.png" />

2. criteria와 데이터 카테고리가 적절한지 확인하세요.

3. 원하는 result 개수를 확인한 뒤 search를 시작하세요.

<br />

## 3. Webset 내부 살펴보기 {#3-inside-your-webset}

간단히 말해 Websets는 다음과 같이 동작합니다:

1. 요청한 내용을 세분화합니다

2. 요청을 충족할 만한 유망한 데이터를 찾습니다

3. AI agent와 병렬 소스 탐색을 활용해 모든 criteria를 검증합니다

4. agent에 제공한 피드백을 바탕으로 search를 조정합니다

<Info>
  처음 나온 결과가 만족스럽지 않다면 &quot;Edit criteria&quot;나 채팅에서 criteria를
  다듬어 보세요.
</Info>

<br />

## 4. Webset 다루기 {#4-interacting-with-your-webset}

Webset이 완성되면 각 구성 요소를 직접 살펴보고 조작할 수 있습니다!

result를 클릭하면 다음을 확인할 수 있습니다:

<img src="https://mintcdn.com/exa-52/tmzyKnsgpKLGddKC/images/websets/websets-result.png?fit=max&auto=format&n=tmzyKnsgpKLGddKC&q=85&s=793c040207129ee6c2efc1c8d922d6fe" alt="AI summary, 충족한 criteria, 소스가 표시된 Webset result 상세 화면" width="2870" height="1734" data-path="images/websets/websets-result.png" />

1. AI가 생성한 summary

2. Webset에 포함되기 위해 충족한 criteria

3. 매칭 판단의 근거가 된 소스 (여기에서 소스를 클릭해 바로 이동할 수 있습니다)

result를 수동으로 삭제해 export하기 전에 Webset을 정리할 수도 있습니다.

<br />

## 5. result criteria와 사용자 지정 열 추가하기 {#5-add-more-result-criteria-and-custom-columns}

<img src="https://mintcdn.com/exa-52/tmzyKnsgpKLGddKC/images/websets/add-enrichment.png?fit=max&auto=format&n=tmzyKnsgpKLGddKC&q=85&s=5d94338cdb1931e9afced3c196acf075" alt="enrichment 열 추가하기" width="2870" height="1734" data-path="images/websets/add-enrichment.png" />

1. **enrichment 추가:** 원하는 정보를 무엇이든 요청하는 사용자 지정 enrichment 열을 만들 수 있습니다. 연락처 정보(이메일 및 전화번호), 매출, 직원 수, 감성 분석, 논문 summary 등을 떠올려 보세요. 다음 항목을 입력합니다:

* 열 이름(예: &#39;Revenue&#39;)

* 열 유형(예: &#39;Number&#39;)

* Websets가 데이터를 찾는 데 사용할 지침(예: &#39;회사의 연간 매출을 찾으세요&#39;)

* 또는 &quot;fill in for me&quot;를 클릭하면 Exa의 agent가 지침을 자동으로 생성합니다

<br />

## 6. Webset 공유 및 내보내기 {#6-share-and-export-your-webset}

1. export를 클릭하여 Webset을 CSV 파일로 다운로드합니다.

2. share를 클릭하여 Webset 공유 링크를 받습니다.

<br />

## 7. 검색 기록 {#7-search-history}

왼쪽 상단의 sidebar 아이콘을 클릭하면 왼쪽 패널에서 지금까지 만든 모든 Websets을 포함한 전체 기록을 확인할 수 있습니다.
