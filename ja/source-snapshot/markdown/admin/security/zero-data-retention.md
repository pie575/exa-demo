  # Zero Data Retention
</div>

> Exa の各製品における Zero Data Retention の対応状況です。

Zero Data Retention (ZDR) は Enterprise プランで利用可能で、チーム単位で有効化されます。詳細については [sales@exa.ai](mailto:sales@exa.ai) までお問い合わせください。

| 製品       | ZDR の対応状況 |
| -------- | --------- |
| Search   | 対応        |
| Contents | 対応        |
| Agent    | 対応        |
| Answer   | 現在非対応     |
| Websets  | 現在非対応     |
