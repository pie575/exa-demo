<div id="blind-visual-review">
  ## ブラインド目視レビュー
</div>

[159ページのA/B比較ギャラリーを開く](blind/index.html)。各ページの2枚の
スクリーンショットは、ページごとに独立してシャッフルされます。A/B/引き分けの選択結果は
ブラウザに保存されます。代表的なデスクトップ/モバイルの4ペアについても、
識別キーを参照せずにレビューを実施しました ([最終レビュー](blind/final-review.md)) 。
それ以前の独立したレビューと対応するスクリーンショットは
`blind/review-round-2/` にアーカイブされています。

最終的な代表レビューでは、どちらのバージョンにも見た目の面で有意な優位性は
見られませんでした。最終代表ペアのうち2組はビットマップが完全に一致し、残りの
2組も記録されたしきい値での差異はそれぞれ8ピクセルと1ピクセルのみでした
 ([ピクセル測定結果](representative-pixel-comparison.json)) 。これらはキャプチャした
ビューポートを対象としたチェックであり、あらゆる条件でのピクセル単位の一致や
ホスト型サービスとしての同等性を保証するものではありません。全159ページ中158ページで
本文テキストが一致しており、残る1ページの差異はライブのステータスページに表示されるチェックのタイムスタンプです。

<div id="fidelity-details">
  ## 再現性の詳細
</div>

インポートでは、本番環境のテーマ、ナビゲーション、カスタムスタイルと
スクリプト、フォント、ページのメタデータ、API 仕様、元の MDX コンポーネントがそのまま保持されます。
また、Markdown エクスポートでは欠落していた Agent Examples スプレッドシートと、
ローカルレンダラーでは表示されなかった公開済みの 85 件の変更ラベルも復元されます。
元のレスポンスとチェックサムは `source-snapshot/` に保存されています。

Exa のホスト型 AI アシスタントは、Mintlify のローカルプレビューでは利用できません。ローカルでは、
アシスタントのコントロールを操作すると、代わりに実際に動作するドキュメント検索が開きます。外部のダッシュボードや
API プレイグラウンドへのリンクは、引き続き外部サイトを参照します。Markdown とスキーマのダウンロード URL は、
ネイティブの開発サーバーがこれらのファイル拡張子を直接配信できないため、
内容が同一の `.txt` ペイロードにリダイレクトされます。ライブステータスのタイムスタンプや
アニメーションメディアは、取得時点によって異なる場合があります。

<div id="reproduce">
  ## 再現手順
</div>

```sh
pnpm validate
pnpm check:links
pnpm audit:content
pnpm dev
# プレビューを起動したまま、別のターミナルで次を実行します:
python3 verification/audit-content.py --url http://localhost:3000 --output verification/route-audit.json
python3 verification/check-exports.py
node verification/audit-interactions.mjs
node verification/audit-api-content.mjs
node verification/compare-all.mjs
node verification/mobile-theme-check.mjs
node verification/build-blind-gallery.mjs
```

ブラウザチェックには Google Chrome が必要です。また、インストール済みの Playwright パッケージを使用します。
全ページのスクリーンショットはローカルで生成される成果物で、Git の管理対象から除外されています。
新しくチェックアウトした環境でギャラリーを使う前に、スクリーンショットを再生成してください。
