title: "モニターを作成"
description: "スケジュールに従って Exa 検索を定期的に実行する新しいモニターを作成します。


  モニターは、設定したスケジュールで検索クエリを自動的に繰り返し実行し、 重複を自動的に除外したうえで結果を webhook エンドポイントに配信します。


  - **日付ベースのフィルタリング**: 前回の実行以降のコンテンツのみを取得します


  - **セマンティック重複排除**: 過去の出力を追跡し、新しい動向のみを 抽出します


  レスポンスには `webhookSecret` が含まれますが、これは作成時に一度だけ 返されます。webhook
  の署名検証に使用するため、安全に保管してください。"
