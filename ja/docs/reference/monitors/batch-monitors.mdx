title: "モニターの一括操作"
description: "指定したフィルターに一致するモニターに対して一括操作を実行します。


  サポートされている操作:

  - **delete**: 一致するモニターを完全に削除します

  - **pause**: 一致するモニターを一時停止します

  - **unpause**: 一致するモニターの一時停止を解除します


  `dry_run: true`（デフォルト）を指定すると、操作を実行する前に対象となるモニターをプレビューできます。 結果は `limit`
  パラメーターによってページ分割されます。 一致するすべてのモニターを処理するには、`has_more` が `false`
  になるまで繰り返しリクエストしてください。"
