実行は新しい順に返されます。ページサイズは `limit` で指定します。次のページを取得するには、前回のレスポンスに含まれる `nextCursor` の値を `cursor` に指定してください。

<Card title="Exa API キーを取得" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  ダッシュボードでキーを作成してください。新規アカウントには無料クレジットが付与されます。
</Card>
