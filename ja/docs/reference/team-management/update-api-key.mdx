## 概要 {#overview}

Update API Key エンドポイントを使用すると、既存の API キーを変更できます

## パスパラメーター {#path-parameters}

* **id**: 更新対象の API キーの一意の識別子。

## 任意のパラメーター {#optional-parameters}

* **name**: API キーの新しい名前(用途がわかる名前)
* **rateLimit**: 新しいレート制限(1 分あたりのリクエスト数)
