## 概要 {#overview}

Get API Key エンドポイントでは、一意の識別子を指定して、特定の API キーの詳細情報を取得できます。

## パスパラメーター {#path-parameters}

* **id**: 取得するAPIキーの一意の識別子

## レスポンス {#response}

API キーの詳細情報を返します。含まれる項目は次のとおりです。

* **id**: 一意の識別子
* **name**: 識別用の名前
* **rateLimit**: レート制限 (1 分あたりのリクエスト数、設定されている場合)
* **teamId**: このキーが属するチームの ID
* **createdAt**: キーの作成日時
