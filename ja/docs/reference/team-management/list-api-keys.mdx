<div id="overview">
  ## 概要
</div>

List API Keys エンドポイントは、チームに関連付けられたすべての API キーを返します。レスポンスには、各キーのキー ID、名前、レート制限、作成タイムスタンプが含まれます。

<div id="response-format">
  ## レスポンス形式
</div>

レスポンスには、以下の情報を持つ API キーオブジェクトの配列が含まれます。

* **id**: API キーの一意の識別子
* **name**: 人が読める形式の名前 (作成時に指定した場合)
* **rateLimit**: 1 分あたりのリクエスト数で表したレート制限 (設定されている場合)
* **createdAt**: キーの作成日時を示す ISO 8601 形式のタイムスタンプ
