openapi: "/ja/docs/exa-spec.yaml POST /v0/webhooks"
timestamp: false
description: "選択したイベントが発生するたびに、指定したURLへ配信するWebhookを作成します。


  レスポンスには、配信の検証に使用する署名用の `secret` が含まれます。この値は作成時にのみ返されます。"
---

<Warning>
  **リダイレクトには追従しません。** Webhookの配信は、登録されたURLに直接送信されます。
  エンドポイントが3xxリダイレクトを返した場合、その配信は失敗として扱われます。
  必ずリダイレクト先の最終的なURLを登録してください。
</Warning>
