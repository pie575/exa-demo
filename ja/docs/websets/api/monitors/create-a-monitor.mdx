description: "新しい `Monitor` を作成し、Websets を常に最新のデータに保ちます。


  モニターは指定したスケジュールで自動的に実行されるため、手動で操作しなくても Websets を最新の状態に維持できます。


  - **新しいコンテンツの発見**: `search` 操作を実行し、条件に一致する新しい item を検出します

  - **既存コンテンツの更新**: `refresh` 操作を実行し、item のコンテンツとエンリッチメントを更新します

  - **自動スケジューリング**: `cron` 式と `timezone` を設定し、スケジュールを細かく制御します"
