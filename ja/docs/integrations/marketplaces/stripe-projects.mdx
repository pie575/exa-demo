[Stripe Projects](https://projects.dev) を使えば、開発者自身やコーディングエージェントがターミナルから直接サードパーティサービスをプロビジョニングできます。ダッシュボードでの操作も、キーのコピー&amp;ペーストも必要ありません。コマンドを 1 つ実行するだけで Exa アカウントが作成され、API キーがプロジェクトに同期されます。

<div id="prerequisites">
  ## 前提条件
</div>

Stripe CLI と Projects プラグインをインストールしてください。

```bash theme={null}
brew install stripe/stripe-cli/stripe && stripe plugin install projects
```

その他のプラットフォームや CLI のセットアップ手順の詳細については、[Stripe Projects](https://projects.dev) を参照してください。

<div id="get-started">
  ## はじめに
</div>

プロジェクトディレクトリで次のコマンドを実行し、プロジェクトの初期化、Exa の追加、認証情報の取得を行います。

```bash theme={null}
stripe projects init
stripe projects add exa/api
stripe projects env --pull
```

`.env` に `EXA_API_KEY` が追加されました。[Exa SDK](/ja/docs/sdks/quickstart) と [クイックスタート](/ja/docs/search/quickstart) はこの変数を自動的に読み込むため、コードを変更せずにそのまま動作します。

<Info>
  このキーは、お客様が所有する Exa アカウントでプロビジョニングされています。使用量、キー、課金はいつでも [Exa Dashboard](https://dashboard.exa.ai) から管理できます。
</Info>

<div id="link-an-existing-exa-team">
  ## 既存の Exa チームをリンクする
</div>

すでに Exa アカウントをお持ちの場合は、先にアカウントを接続してください。これにより、API キーが既存のチームにプロビジョニングされます。

```bash theme={null}
stripe projects link exa
stripe projects add exa/api
```

`stripe projects link` を実行すると Exa が開き、認証を行ってチームを Stripe アカウントに関連付けられます。連携済みの Exa Dashboard は、`stripe projects open exa` でいつでも開けます。

<div id="provision-from-your-coding-agent">
  ## コーディングエージェントからプロビジョニングする
</div>

`stripe projects init` を実行すると、Stripe Projects の [Agent Skill](https://projects.dev) がプロジェクトに追加されます。これにより、エージェント (Claude Code、Cursor、Codex など) にこの手順を任せることができます：

```text theme={null}
Stripe Projects を使って Exa を追加し、API キーを設定してください。
```
