Exa は [Baseten Hosted Tools](https://www.baseten.co/blog/introducing-baseten-hosted-tools/) のウェブ検索プロバイダーです。Baseten Model APIs はオープンソースモデルを提供しており、Hosted Tools を使えば、ツールループを自前で組まなくてもそれらのモデルがウェブを検索できます。標準のリクエストに Exa のツールセレクターを追加するだけで、Baseten がサーバー側のループ内でモデルの実行と Exa の検索をまとめて処理し、検索結果に基づいた回答が同じレスポンスで返されます。Exa API キーは不要です。Exa の費用は上乗せなしでそのまま Baseten の請求に含まれます。

## Exa のウェブ検索ツールを使用する {#use-the-exa-web-search-tools}

`x-baseten-server-tools: true` ヘッダーを設定し、`tools` 配列に 1 つ以上の Exa セレクターを追加します。指定が必要なのは `type` のみです。ツールスキーマは Baseten が自動的に展開し、いつ検索するか、何を検索するか、どのページを読むかはモデルが判断します。サーバーサイドツールは、Baseten の [Chat Completions](https://docs.baseten.co/reference/inference-api/chat-completions)、[Messages](https://docs.baseten.co/reference/inference-api/messages)、Responses の各エンドポイントで利用でき、バッファリングとストリーミングのどちらにも対応しています。

<CodeGroup>
  ```python Python theme={null}
  from openai import OpenAI

  client = OpenAI(
      api_key="<BASETEN_API_KEY>",
      base_url="https://inference.baseten.co/v1",
      default_headers={"x-baseten-server-tools": "true"},
  )

  response = client.chat.completions.create(
      model="zai-org/GLM-5.3-Fast",
      messages=[
          {"role": "user", "content": "What were the major AI announcements this week?"}
      ],
      tools=[
          {"type": "baseten__exa__web_search_exa"},
          {"type": "baseten__exa__web_fetch_exa"},
      ],
      extra_body={"baseten": {"tool_settings": {"max_react_iterations": 5}}},
  )

  print(response.choices[0].message.content)
  ```

  ```javascript JavaScript theme={null}
  import OpenAI from "openai";

  const client = new OpenAI({
    apiKey: "<BASETEN_API_KEY>",
    baseURL: "https://inference.baseten.co/v1",
    defaultHeaders: { "x-baseten-server-tools": "true" },
  });

  const response = await client.chat.completions.create({
    model: "zai-org/GLM-5.3-Fast",
    messages: [
      { role: "user", content: "What were the major AI announcements this week?" },
    ],
    tools: [
      { type: "baseten__exa__web_search_exa" },
      { type: "baseten__exa__web_fetch_exa" },
    ],
    baseten: { tool_settings: { max_react_iterations: 5 } },
  });

  console.log(response.choices[0].message.content);
  ```

  ```bash cURL theme={null}
  curl https://inference.baseten.co/v1/chat/completions \
    -H "Authorization: Bearer <BASETEN_API_KEY>" \
    -H "Content-Type: application/json" \

        { "type": "baseten__exa__web_search_exa" },
        { "type": "baseten__exa__web_fetch_exa" }
      ],
      "baseten": { "tool_settings": { "max_react_iterations": 5 } }
    }'
  ```
</CodeGroup>

利用できる Exa ツールは 3 つです。モデルにソースを探させ、その中から選んだページを読ませたい場合は、検索とフェッチの両方を指定してください。

| セレクター                                   | モデルが得られるもの                                              |
| --------------------------------------- | ------------------------------------------------------- |
| `baseten__exa__web_search_exa`          | [Exa 検索](/ja/docs/search/quickstart)：クエリに関連する結果とそのページコンテンツ |
| `baseten__exa__web_search_advanced_exa` | ドメインフィルター、サブページのクロール、結果ごとの要約 (オプション) に対応した検索            |
| `baseten__exa__web_fetch_exa`           | モデルがすでに把握している URL の[ページ全文](/ja/docs/contents/quickstart)   |

セレクターに追加のフィールドは不要です。ツールの引数は、モデルが Exa のスキーマに従って入力します。いつ検索するか、一次情報源をフェッチするかどうか、どのように引用するかといった検索方針は、システムプロンプトで指示してください。ループの上限は `baseten.tool_settings` で設定します。

| 設定                             | 用途                                                                                                     |
| ------------------------------ | ------------------------------------------------------------------------------------------------------ |
| `max_react_iterations`         | リクエストあたりのモデルの反復回数の上限 (デフォルトは 12、範囲は 2～20) 。最後の反復は回答用に確保されるため、`N` を指定した場合、ツール呼び出しは最大 `N - 1` ラウンドとなります。 |
| `max_tool_calls_per_iteration` | 1 回の反復あたりのサーバーサイドツール呼び出し数の上限 (デフォルトは 10、範囲は 1～10)                                                      |

## 結果の返却方法 {#how-results-come-back}

最終的な回答は、エンドポイントの通常のフィールドで返されます。完了した Exa の呼び出しは、プロトコルごとに次の形式で記録されます。Messages では `tool_use` および `tool_result` ブロック、Responses では `mcp_call` アイテム、Chat Completions では `baseten.iterations[].continuation_messages` です。ストリーミングリクエストでは、ループの実行中に各検索呼び出しとその結果が server-sent events として順次送信されます。そのため、回答が届く前から進捗を表示できます。`baseten.request.server_tool_calls[]` 配列には、リクエスト内のすべての Exa 呼び出しの結果が含まれます。

## 料金 {#pricing}

Exa の呼び出しは、モデルのトークンコストとは別に、Exa の料金のまま (上乗せなし) Baseten アカウントに請求されます。目安は検索 1 回あたり約 $0.007、取得した URL 1 件あたり $0.001 です。各呼び出しの料金は Exa が実行時に報告するため、呼び出しによってはこれらの金額と異なる場合があります。請求対象のツール呼び出しは、Baseten のワークスペース設定の Billing → Usage に、プロバイダー別に表示されます。最新の料金については [Baseten の料金表](https://docs.baseten.co/inference/model-apis/web-search#pricing)を参照してください。

Hosted Tools は Baseten で早期アクセスとして提供されており、組織あたり 1 分間に 25 リクエストまでの上限があります。[Baseten playground](https://app.baseten.co/model-apis/zai-org/GLM-5.3-Fast/playground) で Exa 検索をお試しください。本番ワークロード向けに上限を引き上げたい場合は、Baseten にお問い合わせください。
