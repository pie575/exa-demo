[Baselayer](https://baselayer.com) は、信頼性の高い登記データとリスクデータをもとに米国の事業体を検証する
Know Your Business (KYB) プラットフォームです。
企業名と住所から事業体を特定し、役員、
州の登記情報、事業体の構成、検証ステータスを含む完全なプロファイルを返します。

[Exa Connect](/ja/docs/agent/connect/overview) を通じて `baselayer` を [Exa Agent](/ja/docs/agent/quickstart) の実行にアタッチすると、
エージェントは Exa のウェブ検索と並行して
Baselayer にもクエリを実行します。

## 主な用途 {#use-it-for}

* KYB オンボーディング、およびベンダーや顧客の本人確認。
* 役員、登記情報、事業体の構成に関するデューデリジェンス。
* 企業のリスク評価やウォッチリスト該当の有無を確認するスクリーニング。

## プロバイダー ID {#provider-id}

`dataSources` には次の値を指定します。

```text theme={null}
baselayer
```

## 料金 {#pricing}

Baselayer は注文単位で課金され、金額は操作とそのパラメーターによって異なります。

| 操作                           | 料金                                          |
| ---------------------------- | ------------------------------------------- |
| 企業検索                         | `$1.00 / search`                            |
| 企業ルックアップ / 役員 / 登記情報 / 役員逆引き | 無料 (過去の検索結果の読み取り)                           |
| 先取特権検索                       | `$2.00 / state searched`                    |
| 訴訟検索                         | `$1.00 / category (litigation, bankruptcy)` |
| ウォッチリストスクリーニング               | `$0.10 – $0.25 / list requested`            |
| 業種分類                         | `$0.35 / call`                              |
| Web サイト分析                    | `$0.35 / call`                              |
| Web プレゼンス                    | `$0.15 – $0.35 / selected analysis`         |
| 海外企業検索                       | `$4.00 / search`                            |

料金はパラメーターの選択によって変わります。たとえば、2 つの州を対象とする先取特権検索は $4.00、サポート対象の 6 つのリストすべてを対象とするウォッチリストスクリーニングは $1.35 です。Web プレゼンスの呼び出しは、選択した分析の合計額になります (何も選択しない場合は、Baselayer のデフォルトセット — NAICS 予測と Web サイト分析 — の合計額) 。

## 相性の良いサービス {#pairs-well-with}

* [Fiber.ai](/ja/docs/agent/connect/fiber): 検証済みの企業情報を、企業属性データ、従業員数、連絡先情報で補完します。
* [Financial Datasets](/ja/docs/agent/connect/financialdatasets): 上場企業に関する最新のニュース報道を追加します。
* [Similarweb](/ja/docs/agent/connect/similarweb): 検証済み企業のウェブトラフィックや競合企業をベンチマーク分析します。
