[Particle](https://particle.news) の Podcast Intelligence は、100,000 以上の番組をインデックス化しています。
各番組は配信から数分以内に全編が文字起こしされ、話者分離、話者の特定、ラベル付け、メタデータの補完が行われるため、
音声での会話を検索できます。各結果は、タイムスタンプと話者情報が付与された
文字起こしの一区間です。

[Exa Connect](/ja/docs/agent/connect/overview) を通じて `particle` を [Exa Agent](/ja/docs/agent/quickstart) の実行にアタッチすると、
エージェントは Exa のウェブ検索と並行して
Particle にもクエリを送信します。

## 主な用途 {#use-it-for}

* 専門家のコメントや引用に適した発言の発見
* メディアおよびブランドのモニタリング
* ナラティブやセンチメントのリサーチ
* ポッドキャストの発見と最新情報の把握

## プロバイダーID {#provider-id}

`dataSources` には次の値を指定します。

```text theme={null}
particle
```

## 例 {#example}

AI規制についてポッドキャストのホストたちがどのような発言をしているかを調べます。

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="What are prominent podcast hosts and guests saying about AI regulation in 2025?",
      data_sources=[{"provider": "particle"}],
      output_schema={
          "type": "object",
          "required": ["mentions"],
          "properties": {
              "mentions": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["podcast", "episode", "speaker", "quote", "stance"],
                      "properties": {
                          "podcast": {"type": "string"},
                          "episode": {"type": "string"},
                          "speaker": {"type": "string"},
                          "quote": {"type": "string"},
                          "stance": {"type": "string", "description": "pro-regulation, anti-regulation, or nuanced"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

  ```javascript JavaScript theme={null}

  });
  ```
