[Fiber.ai](https://fiber.ai) は、4,000 万社以上の企業、8 億 5,000 万人以上の人物、3,000 万件以上の求人について最新データを提供する B2B データプラットフォームです。企業、人物、求人のリアルタイムデータを検索できるほか、不完全なレコードを勤務先メールアドレス、個人用メールアドレス、電話番号で補完できます。

[Exa Connect](/ja/docs/agent/connect/overview) を使って `fiber` を [Exa Agent](/ja/docs/agent/quickstart) の実行にアタッチすると、エージェントは Exa のウェブ検索に加えて Fiber.ai にもクエリを実行します。

## 主な用途 {#use-it-for}

* 勤務先メールアドレスや個人用メールアドレスから人物を逆引きしたり、
  不完全な企業/人物のレコードを補完したりして、CRM のデータを整理する。
* 転職、昇進、新しい職への就任、従業員数の変化、資金調達といった
  LinkedIn のシグナルをリアルタイムで追跡する。
* LinkedIn、X、Instagram、TikTok、Reddit、YouTube から関連する投稿を見つけ、
  コメントやリアクションを取得したうえで、投稿者の
  連絡先情報を補完する。
* 4,000 万社以上の企業と 8 億 5,000 万人以上の人物を横断して検索し、見込み客の
  勤務先メールアドレス、個人用メールアドレス、電話番号を補完する。

## プロバイダー ID {#provider-id}

`dataSources` には次の値を指定します。

```text theme={null}
fiber
```

## 料金 {#pricing}

Fiber.ai はクレジット制で課金され、単価は `$0.02 / credit` です。各呼び出しには、Fiber がその呼び出しについて報告したクレジット数が課金されます。

| 操作                 | クレジット                     |
| ------------------ | ------------------------- |
| 検索                 | 2 + 返された結果 1 件につき 1       |
| 企業検索               | 返された候補 1 件につき約 2          |
| 人物検索 / メールアドレスの逆引き | 2                         |
| 連絡先の開示             | 2 (勤務先メールアドレス) – 5 (電話番号) |

一致するデータがなかった呼び出し (または Fiber が課金を返金した呼び出し) は無料です。料金はパラメーターの指定によって変わります。企業検索では `numResults` によって課金対象となる候補数が決まり、検索では結果の件数がコストの大半を占めます。

## 例 {#example}

ニューヨークを拠点とする従業員数50〜200名のシリーズAフィンテック企業について、B2B向けの見込み顧客リストを作成します。

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="I'm building a B2B sales prospecting list using a B2B company database. Find Series A fintech companies in New York with 50-200 employees, and for each return the company's LinkedIn profile, domain, employee count, and funding stage.",
      data_sources=[{"provider": "fiber"}],
      output_schema={
          "type": "object",
          "required": ["companies"],
          "properties": {
              "companies": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["name", "domain", "employeeCount", "fundingStage"],
                      "properties": {
                          "name": {"type": "string"},
                          "domain": {"type": "string"},
                          "employeeCount": {"type": "number"},
                          "fundingStage": {"type": "string"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

## 組み合わせて使えるサービス {#pairs-well-with}

* [Similarweb](/ja/docs/agent/connect/similarweb): 見込み客のウェブ上での存在感や競合状況を把握します。
* [Baselayer](/ja/docs/agent/connect/baselayer): 候補として絞り込んだ米国企業の役員情報や登記情報を検証します。
* [Particle](/ja/docs/agent/connect/particle): 企業や経営幹部についてポッドキャストでどのように語られているかを調べます。
