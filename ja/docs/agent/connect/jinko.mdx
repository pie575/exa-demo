[Jinko](https://gojinko.com) は、リアルタイム料金に対応したフライト・
ホテル検索を提供する旅行検索プラットフォームです。路線と日付を指定して最新のフライトオファーを検索できるほか、
目的地や特定の施設を指定してホテルの客室と料金を比較したり、
出発空港から行ける目的地を探したりできます。

[Exa Connect](/ja/docs/agent/connect/overview) を通じて `jinko` を [Exa Agent](/ja/docs/agent/quickstart) の実行に
アタッチすると、エージェントは Exa のウェブ検索と併せて
Jinko にもクエリを送信します。

<div id="use-it-for">
  ## 主な用途
</div>

* 指定した路線と日付で、運賃、手荷物、変更規定を含むリアルタイムのフライトオファーを検索する。
* 目的地のホテルをリアルタイムの客室料金付きで検索する、または特定のホテルの料金を再検索する。
* 日付範囲、座席クラス、予算を横断して、目的地や柔軟な日程を探す。

<div id="provider-id">
  ## Provider ID
</div>

`dataSources` にはこの値を指定してください:

```text theme={null}
jinko
```

<div id="example">
  ## 例
</div>

3月にニューヨークから往復400ドル未満で行けるビーチリゾートを探します。

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="Find beach destinations reachable from New York for under $400 round-trip in March.",
      data_sources=[{"provider": "jinko"}],
      output_schema={
          "type": "object",
          "required": ["destinations"],
          "properties": {
              "destinations": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["city", "iataCode", "lowestFare"],
                      "properties": {
                          "city": {"type": "string"},
                          "iataCode": {"type": "string"},
                          "lowestFare": {"type": "number", "description": "round-trip fare in USD"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

  ```javascript JavaScript theme={null}
  import Exa from "exa-js";

  const exa = new Exa();
  const run = await exa.agent.runs.create({
    query: "Find beach destinations reachable from New York for under $400 round-trip in March.",
    dataSources: [{ provider: "jinko" }],
    outputSchema: {
      type: "object",
      required: ["destinations"],
      properties: {
        destinations: {
          type: "array",
          maxItems: 10,
          items: {
            type: "object",
            required: ["city", "iataCode", "lowestFare"],
            properties: {
              city: { type: "string" },
              iataCode: { type: "string" },
              lowestFare: { type: "number", description: "round-trip fare in USD" },
            },
          },
        },
      },
    },
  });
  ```
