[Similarweb](https://www.similarweb.com) は、デジタルマーケットインテリジェンスを提供する
代表的な情報源です。数百万のウェブサイトやアプリのトラフィックとエンゲージメントをモデル化しており、
推定訪問数、トラフィックソース、オーディエンス属性に加え、任意のドメインの
競合サイト群を網羅しています。

[Exa Connect](/ja/docs/agent/connect/overview) を介して `similarweb` を [Exa Agent](/ja/docs/agent/quickstart) の実行にアタッチすると、
エージェントは Exa のウェブ検索と併せて
Similarweb にもクエリを実行します。

## 主な用途 {#use-it-for}

* 企業のウェブトラフィックとエンゲージメントを同業他社とベンチマーク比較する。
* ドメインの競合企業や、オーディエンスが重複するサイトを洗い出す。
* デジタルフットプリントをもとに市場規模を推定し、企業をスクリーニングする。
* 実際の行動データで、企業やカテゴリのリサーチを補完する。

## プロバイダー ID {#provider-id}

`dataSources` には次の値を指定します。

```text theme={null}
similarweb
```

## 料金 {#pricing}

Similarweb はデータクレジット単位で `$0.30 / credit` の料金を請求し、各呼び出しには
Similarweb がその呼び出しに対して報告したクレジット数が課金されます。クレジットは返されるデータ量に応じて増減し、
おおよそ 1 データポイント (指標 × 行 × 月) あたり 1 クレジットです。そのため、呼び出しの料金は
パラメーターによって決まります。

| ツール        | クレジット                                         |
| ---------- | --------------------------------------------- |
| トラフィックとランク | リクエストした月 1 か月あたり最大 7 (1〜2 か月)                 |
| 類似サイト      | 返されたサイト 1 件あたり 3 (1〜5 サイト)                    |
| トラフィックソース  | 10                                            |
| 上位リファラー    | 返されたリファラー 1 件あたり 3 (1〜5)                      |
| 上位国        | 返された国 1 件あたり 3 (1〜5)                          |
| 上位ページ      | 返されたページ 1 件あたり 2 (1〜7)                        |
| 上位キーワード    | 1〜10 (キーワードデータポイント約 100 件あたり 1、50 キーワードで約 7)  |
| キーワード概要    | 1〜2                                           |
| オーディエンス属性  | 8                                             |
| オーディエンスの重複 | ドメインの組み合わせ 1 つあたり 2 (2〜3 ドメインで 6〜14)          |
| テクノロジー     | 10                                            |
| カテゴリ別上位サイト | 返されたサイト 1 件あたり 1 (1〜10)                       |

データが返されない呼び出し (不明なドメインやトラフィックの少ないドメイン、検索ボリュームのないキーワードなど) は
無料です。`numResults` と `months` によって課金対象となるデータポイント数が決まるため、タスクに必要な最小限の値に設定してください。

## 例 {#example}

急成長中の B2B SaaS 企業を 10 社探し、各社の推定ウェブトラフィックを取得します。

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="Find 10 fast-growing B2B SaaS companies and their estimated web traffic.",
      data_sources=[{"provider": "similarweb"}],
      output_schema={
          "type": "object",
          "required": ["companies"],
          "properties": {
              "companies": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["name", "domain", "monthlyVisits"],
                      "properties": {
                          "name": {"type": "string"},
                          "domain": {"type": "string"},
                          "monthlyVisits": {"type": "number", "description": "from Similarweb"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

  ```javascript JavaScript theme={null}
  import Exa from "exa-js";

  const exa = new Exa();
  const run = await exa.agent.runs.create({
    query: "Find 10 fast-growing B2B SaaS companies and their estimated web traffic.",
    dataSources: [{ provider: "similarweb" }],
    outputSchema: {
      type: "object",
      required: ["companies"],
      properties: {
        companies: {
          type: "array",
          maxItems: 10,
          items: {
            type: "object",
            required: ["name", "domain", "monthlyVisits"],
            properties: {
              name: { type: "string" },
              domain: { type: "string" },
              monthlyVisits: { type: "number", description: "from Similarweb" },
            },
          },
        },
      },
    },
  });
  ```

