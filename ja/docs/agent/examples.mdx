<div id="production-checklist">
  ## 本番環境向けチェックリスト
</div>

* Agent には、作業単位と求めるソースの品質を明示した具体的な `query` を指定してください。
* 既知のレコードは、プロンプトに行を埋め込まず、`input.data` で渡してください。
* 再度返す必要のないレコードは `input.exclusion` で指定してください。
* 下流のコードで結果を利用する場合は、必ず `outputSchema` を追加してください。
* スコープとコストを予測可能な範囲に収めたい場合は、配列に `maxItems` を指定してください。
* 返された実行の `id` を保存しておけば、後からポーリング、イベントのリプレイ、コストの確認、実行の継続を行えます。
