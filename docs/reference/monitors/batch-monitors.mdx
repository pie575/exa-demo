title: "Batch action on monitors"
description: "Perform a batch action on monitors matching the provided filters.


  Supported actions:

  - **delete**: Permanently remove matching monitors

  - **pause**: Pause matching monitors

  - **unpause**: Unpause matching monitors


  Use `dry_run: true` (the default) to preview which monitors would be affected
  before performing the action. Results are paginated via the `limit` parameter;
  loop until `has_more` is `false` to process all matching monitors."
