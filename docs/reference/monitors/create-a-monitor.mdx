title: "Create a monitor"
description: "Creates a new Monitor to run recurring Exa searches on a schedule.


  Monitors automatically execute your search query on a recurring schedule and
  deliver results to your webhook endpoint with automatic deduplication:


  - **Date-based filtering** only fetches content since the last run


  - **Semantic deduplication** tracks previous outputs to surface only new
  developments


  The response includes a `webhookSecret` that is only returned once at creation
  time. Store it securely for webhook signature verification."
