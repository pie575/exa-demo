---
title: "Update a webhook"
openapi: "/docs/exa-spec.yaml PATCH /v0/webhooks/{id}"
timestamp: false
description: "Updates the target URL, subscribed events, or metadata of a
  Webhook. Omitted fields are left unchanged."
---

<Warning>
  **Redirects are not followed.** If you update the URL, ensure it is the final
  destination. Endpoints that respond with a 3xx redirect will be treated as
  delivery failures.
</Warning>
