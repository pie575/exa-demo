  with fresh data.


  Monitors automatically run on your defined schedule to ensure your Websets
  stay current without manual intervention:

  matching your criteria

  - **Update existing content**: Run `refresh` operations to update items
  contents and enrichments

  - **Automated scheduling**: Configure `cron` expressions and `timezone` for
  precise scheduling control"
