# Zero Data Retention

> Zero Data Retention availability across Exa products.

Zero Data Retention (ZDR) is available on Enterprise plans and enabled per team. Contact [sales@exa.ai](mailto:sales@exa.ai) for details.

| Product  | ZDR availability        |
| -------- | ----------------------- |
| Search   | Available               |
| Contents | Available               |
| Agent    | Available               |
| Answer   | Not currently supported |
| Websets  | Not currently supported |
