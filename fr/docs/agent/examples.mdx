<div id="production-checklist">
  ## Liste de vérification avant la mise en production
</div>

* Donnez à l&#39;Agent une `query` précise qui nomme l&#39;unité de travail et la qualité de source attendue.
* Utilisez `input.data` pour les records connus plutôt que d&#39;intégrer les lignes dans le prompt.
* Utilisez `input.exclusion` pour les records qui ne doivent pas être renvoyés une nouvelle fois.
* Ajoutez `outputSchema` dès lors que du code en aval exploite le résultat.
* Utilisez `maxItems` sur les tableaux lorsque vous avez besoin d&#39;un scope et d&#39;un coût prévisibles.
* Conservez l&#39;`id` du run renvoyé afin de pouvoir poller, rejouer les événements, examiner les coûts ou reprendre le run ultérieurement.
