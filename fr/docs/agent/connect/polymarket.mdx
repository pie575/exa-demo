[Polymarket](https://polymarket.com) est une plateforme de marchés prédictifs où
les prix du marché reflètent la probabilité implicite, estimée collectivement, d&#39;événements
du monde réel. [Exa Connect](/fr/docs/agent/connect/overview) fournit
un accès en lecture seule aux données de marché publiques de Polymarket.

Attachez `polymarket` à un run [Exa Agent](/fr/docs/agent/quickstart) : l&#39;agent
interrogera alors Polymarket en parallèle d&#39;Exa web search.

<div id="use-it-for">
  ## À utiliser pour
</div>

* Trouver des marchés prédictifs et les market-implied odds actuelles sur un sujet.
* Comparer l&#39;évolution dans le temps de la probabilité implicite d&#39;un résultat.
* Examiner la liquidité d&#39;un marché, la profondeur du carnet d&#39;ordres (achat/vente) et les principaux détenteurs de positions.
* Consulter les positions actuelles d&#39;un trader et son activité on-chain récente.

<div id="provider-id">
  ## ID du fournisseur
</div>

Utilisez cette valeur dans `dataSources` :

```text theme={null}
polymarket
```

<div id="pricing">
  ## Tarification
</div>

Les API de lecture de Polymarket sont gratuites et ne nécessitent aucune authentification : les appels d&#39;outil Polymarket ne coûtent donc rien. Vous ne payez que la
[tarification standard des runs Agent](/fr/docs/agent/quickstart#pricing).

<div id="data-available">
  ## Données disponibles
</div>

| Donnée                | Description                                                                                                                             |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Marchés et événements | Marchés prédictifs et événements en cours, avec prix exprimés en probabilité implicite, volume et liquidité.                            |
| Historique des prix   | Évolution de la probabilité implicite d&#39;un résultat au fil du temps.                                                                |
| Carnets d&#39;ordres  | Profondeur et écart acheteur/vendeur en temps réel pour le résultat d&#39;un marché.                                                    |
| Détenteurs et traders | Principaux détenteurs de positions sur un marché, ainsi que les positions actuelles et l&#39;activité on-chain récente d&#39;un trader. |

<div id="example">
  ## Exemple
</div>

Obtenez les market-implied odds d&#39;une baisse des taux de la Fed ainsi que leur évolution au cours du mois écoulé.

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query=(
          "What are the current market-implied odds of a Fed rate cut at the "
          "next FOMC meeting, and how have they moved over the past month?"
      ),
      data_sources=[{"provider": "polymarket"}],
      output_schema={
          "type": "object",
          "required": ["market", "currentProbability", "trend"],
          "properties": {
              "market": {"type": "string", "description": "the market question"},
              "currentProbability": {"type": "number", "description": "between 0 and 1"},
              "trend": {"type": "string", "description": "how the implied probability moved over the past month"},
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

  ```typescript TypeScript theme={null}
  import Exa from "exa-js";

  const exa = new Exa();
  const run = await exa.agent.runs.create({
    query:
      "What are the current market-implied odds of a Fed rate cut at the next FOMC meeting, and how have they moved over the past month?",
    dataSources: [{ provider: "polymarket" }],
    outputSchema: {
      type: "object",
      required: ["market", "currentProbability", "trend"],
      properties: {
        market: { type: "string", description: "the market question" },
        currentProbability: { type: "number", description: "between 0 and 1" },
        trend: { type: "string", description: "how the implied probability moved over the past month" },
      },
    },
  });
  ```

