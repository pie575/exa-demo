Exa Connect intègre des partners de données premium dans le loop d&#39;Exa Agent. Attachez un
fournisseur à un run : Exa Agent interroge alors la base de données de ce partner en parallèle de la recherche
web, puis combine les résultats en une seule réponse structurée et fondée sur des preuves.

Vous débutez avec les agent runs ? Commencez par le [guide Exa Agent](/fr/docs/agent/quickstart),
puis revenez ici pour attacher des partners de données.

<Tip>
  Exa Agent interroge déjà l&#39;intégralité de l&#39;[index de données](/fr/docs/search/data/overview), soit les mêmes
  sources d&#39;actualités, de code, d&#39;entreprises et de personnes que la Search API. Exa Connect y ajoute
  des bases de données de partners premium.
</Tip>

<Tip>
  Vous préférez MCP ? Exa Agent et [Exa Connect](/fr/docs/agent/connect/overview) sont disponibles dans [Exa MCP](/fr/docs/get-started/exa-mcp#exa-agent). Activez `tools=agent_run` pour lancer des recherches multi-étapes, de la constitution de liste, de l&#39;enrichment et de la sortie structurée depuis Claude, Cursor et d&#39;autres clients MCP.
</Tip>

## Pourquoi Exa Connect {#why-exa-connect}

* **Des données premium sans intégrations distinctes.** Accédez aux données des partners sans
  signer de contrat ni intégrer de SDK. Vous appelez une seule API Exa.
* **Exa gère la plomberie.** Nous prenons en charge l&#39;authentification des fournisseurs, la sélection des outils,
  les nouvelles tentatives et le classement des résultats.
* **L&#39;Exa Agent choisit la source.** Lorsque votre `outputSchema` demande
  « les visites mensuelles depuis Similarweb » ou « les dirigeants vérifiés », l&#39;Exa Agent appelle l&#39;outil
  partner correspondant au lieu de deviner à partir d&#39;une page web.
* **Données de l&#39;index et des partners dans un même run.** Connect s&#39;appuie sur l&#39;index Exa.
  L&#39;Exa Agent utilise chaque source là où elle est la plus performante et cite les résultats.

## Fonctionnement {#how-it-works}

1. **Attachez** un ou plusieurs fournisseurs via le tableau `dataSources` sur
   [`POST /agent/runs`](/fr/docs/reference/agent-api/create-a-run).
2. L&#39;Exa Agent **sélectionne l&#39;outil adapté** à chaque étape en fonction de votre requête et
   de `outputSchema` : données du partner ou Exa web search.
3. Les résultats du partner sont **fusionnés avec la recherche web** dans votre sortie structurée,
   avec les sources associées.

## Tarification {#pricing}

<Note>
  La tarification d&#39;Exa Connect s&#39;ajoute à la [tarification standard des Agent runs](/fr/docs/agent/quickstart#pricing).
  Vous payez les coûts habituels de calcul et de search de l&#39;Agent, plus les frais d&#39;appel au fournisseur pour chaque appel d&#39;outil Exa Connect.
</Note>

Fiber.ai facture en crédits plutôt qu&#39;à l&#39;appel, car son propre tarif varie
d&#39;un appel à l&#39;autre : un search coûte 2 crédits plus 1 par result renvoyé, une
recherche d&#39;entreprise ou de personne est facturée par candidat renvoyé
(augmenter le `numResults` d&#39;une recherche d&#39;entreprise pour lever l&#39;ambiguïté
d&#39;un nom revient donc plus cher), et la révélation d&#39;un contact coûte de 2 à
5 crédits selon que vous demandez l&#39;e-mail professionnel, l&#39;e-mail personnel ou
le téléphone. Les crédits qui vous sont facturés sont ceux que Fiber déclare
pour chaque appel ; les appels sans correspondance sont gratuits. Voir
[la tarification Fiber.ai](/fr/docs/agent/connect/fiber#pricing).

Similarweb facture en crédits de données (environ un par métrique × ligne ×
mois) : le prix d&#39;un appel dépend donc de ses valeurs `numResults`/`months` — de 1 à
15 crédits par appel. Les crédits qui vous sont facturés sont ceux que Similarweb
déclare pour chaque appel ; les appels qui ne renvoient aucune donnée sont gratuits.
Voir [la tarification Similarweb](/fr/docs/agent/connect/similarweb#pricing).

Baselayer facture à la commande, et le tarif dépend de l&#39;opération : une
recherche d&#39;entreprise KYB coûte 1,00 $, une recherche de privilèges UCC
2,00 $ par state consulté, une recherche de dossiers de contentieux ou de
faillite 1,00 $ par catégorie, le screening de watchlist de 0,10 $ à 0,25 $
par liste demandée, la classification sectorielle et l&#39;analyse de site web
0,35 $ chacune, la présence web correspond à la somme des analyses
sélectionnées (de 0,15 $ à 0,35 $ chacune), et une recherche d&#39;entreprise
internationale 4,00 $. Les lectures de follow-up d&#39;une recherche d&#39;entreprise
antérieure (consultation d&#39;entreprise, dirigeants, immatriculations, recherche
inversée de dirigeant) sont gratuites. Voir
[la tarification Baselayer](/fr/docs/agent/connect/baselayer#pricing).

## Utilisation {#usage}

### Combiner les fournisseurs {#combining-providers}

Attachez autant de partners que votre tâche l&#39;exige. Exa Agent appelle chacun d&#39;eux là où il est
le plus performant et combine les résultats avec la recherche web en une seule réponse structurée :

```json theme={null}
{
  "dataSources": [
    { "provider": "similarweb" },
    { "provider": "fiber" },
    { "provider": "harmonic" }
  ]
}
```

Pour un guide complet, expliquant notamment comment structurer votre requête et votre `outputSchema` afin que chaque
partner soit sollicité, consultez [Combiner les fournisseurs](/fr/docs/agent/connect/combining-providers).
