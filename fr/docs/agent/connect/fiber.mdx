[Fiber.ai](https://fiber.ai) est une plateforme de données B2B qui propose des données fraîches sur plus de 40 M d&#39;entreprises, 850 M de personnes et 30 M d&#39;offres d&#39;emploi. Recherchez en temps réel des données sur les entreprises, les personnes et les emplois, et enrichissez les enregistrements incomplets avec des adresses e-mail professionnelles et personnelles ainsi que des numéros de téléphone.

Attachez `fiber` à un run d&#39;[Exa Agent](/fr/docs/agent/quickstart) via
[Exa Connect](/fr/docs/agent/connect/overview) : l&#39;agent interroge alors
Fiber.ai en parallèle d&#39;Exa web search.

<div id="use-it-for">
  ## Cas d&#39;usage
</div>

* Nettoyer un CRM en remontant d&#39;un e-mail professionnel ou personnel jusqu&#39;à une personne,
  ou enrichir une fiche entreprise/personne incomplète.
* Suivre en temps réel les signaux LinkedIn : changements de poste, promotions, nouveaux emplois,
  évolutions d&#39;effectifs et levées de fonds.
* Trouver les publications pertinentes sur LinkedIn, X, Instagram, TikTok, Reddit et
  YouTube, en récupérer les commentaires et réactions, puis enrichir les coordonnées
  de leurs auteurs.
* Rechercher parmi plus de 40 M d&#39;entreprises et 850 M de personnes, et enrichir les prospects avec
  leur e-mail professionnel, leur e-mail personnel et leurs numéros de téléphone.

<div id="provider-id">
  ## ID du provider
</div>

Utilisez cette valeur dans `dataSources` :

```text theme={null}
fiber
```

<div id="pricing">
  ## Tarification
</div>

Fiber.ai facture en credits au tarif de `$0.02 / credit`, et chaque call est facturé selon les credits que Fiber déclare pour celui-ci :

| Opération                                              | Credits                        |
| ------------------------------------------------------ | ------------------------------ |
| Search                                                 | 2 + 1 par résultat renvoyé     |
| Recherche d&#39;entreprise                             | ~2 par candidat renvoyé        |
| Recherche de personne / recherche inverse d&#39;e-mail | 2                              |
| Révélation de contact                                  | 2 (e-mail professionnel) – 5 (téléphone) |

Les calls qui ne renvoient aucune correspondance (ou dont Fiber rembourse le montant) sont gratuits. Le choix des parameters influe sur le prix : le `numResults` d&#39;une recherche d&#39;entreprise détermine le nombre de candidats facturés, et le nombre de résultats d&#39;un search constitue l&#39;essentiel de son cost.

<div id="example">
  ## Exemple
</div>

Constituez une liste de prospection B2B regroupant les entreprises fintech en série A situées à New York et comptant de 50 à 200 employés.

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="I'm building a B2B sales prospecting list using a B2B company database. Find Series A fintech companies in New York with 50-200 employees, and for each return the company's LinkedIn profile, domain, employee count, and funding stage.",
      data_sources=[{"provider": "fiber"}],
      output_schema={
          "type": "object",
          "required": ["companies"],
          "properties": {
              "companies": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["name", "domain", "employeeCount", "fundingStage"],
                      "properties": {
                          "name": {"type": "string"},
                          "domain": {"type": "string"},
                          "employeeCount": {"type": "number"},
                          "fundingStage": {"type": "string"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

  ```javascript JavaScript theme={null}

  const exa = new Exa();

      },
    },
  });
  ```
