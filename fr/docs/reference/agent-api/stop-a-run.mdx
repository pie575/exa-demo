---
title: "Arrêter un run"
description: "Arrêtez proprement un run Agent en cours et conservez les
  résultats déjà collectés."
openapi: "/fr/docs/exa-spec.yaml POST /agent/runs/{id}/stop"
timestamp: false
---

Si le run est encore actif, l&#39;agent finalise et termine le run de façon anticipée avec les résultats déjà collectés. Le run se termine avec le statut `completed` et `stopReason: stopped`. L&#39;utilisation accumulée avant l&#39;arrêt vous est facturée. Si le run a déjà atteint un statut terminal (completed, failed ou cancelled), l&#39;endpoint renvoie le run existant tel quel.

Pour interrompre immédiatement un run sans renvoyer de résultats, utilisez plutôt [cancel](/fr/docs/reference/agent-api/cancel-a-run).

<Note>
  Pris en charge uniquement sur les runs avec effort `max`. Le header `Exa-Beta: agent-max-effort-2026-07-27` doit
  être transmis dans la requête. Ce header accepte une liste de jetons bêta séparés par des virgules.
</Note>
