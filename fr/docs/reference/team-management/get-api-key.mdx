<div id="overview">
  ## Vue d&#39;ensemble
</div>

L&#39;endpoint Get API Key vous permet de récupérer des informations détaillées sur une API key spécifique à partir de son identifiant unique.

<div id="path-parameters">
  ## Paramètres de chemin
</div>

* **id** : L&#39;identifiant unique de l&#39;API key à récupérer

<div id="response">
  ## Réponse
</div>

Renvoie des informations détaillées sur l&#39;API key, notamment :

* **id** : identifiant unique
* **name** : nom descriptif
* **rateLimit** : limite de débit en requests par minute (si définie)
* **teamId** : ID de la Team à laquelle appartient cette clé
* **createdAt** : date de création de la clé
