<div id="overview">
  ## Aperçu
</div>

L&#39;endpoint List API Keys renvoie toutes les API keys associées à votre team. Pour chaque key, sont inclus l&#39;ID, le nom, la limite de débit et l&#39;horodatage de création.

<div id="response-format">
  ## Format de réponse
</div>

La réponse contient un tableau d&#39;objets API key comportant les informations suivantes :

* **id** : identifiant unique de l&#39;API key
* **name** : nom lisible (s&#39;il a été fourni lors de la création)
* **rateLimit** : limite de débit en requêtes par minute (si elle est définie)
* **createdAt** : horodatage ISO 8601 de la création de la clé
