openapi: "/fr/docs/exa-spec.yaml POST /batches"
timestamp: false
---

Chaque élément de `requests` est un `POST` vers `/search` ou `/agent/runs` accompagné d&#39;un `customId` unique au sein du batch. Ce même `customId` est renvoyé dans le fichier de résultats, ce qui vous permet de relier les lignes d&#39;output à vos données d&#39;entrée. Consultez le [guide de l&#39;API Batch](/fr/docs/batch/quickstart) pour le workflow de bout en bout.
