---
title: "Récupérer un batch"
description: "Récupérez un batch par son ID."
openapi: "/fr/docs/exa-spec.yaml GET /batches/{id}"
timestamp: false
---

Utilisez cet endpoint pour interroger un batch jusqu&#39;à ce qu&#39;il atteigne l&#39;état `completed`, `cancelled` ou `expired`. Une fois le batch terminé, `resultsUrl` contient une URL présignée de courte durée pointant vers le fichier de résultats JSONL ; récupérez à nouveau le batch pour obtenir une nouvelle URL.
