---
title: "Annuler un batch"
description: "Annulez un batch en cours."
openapi: "/fr/docs/exa-spec.yaml POST /batches/{id}/cancel"
timestamp: false
---

Le batch cesse de planifier de nouvelles requêtes et laisse se terminer les traitements en cours avant de passer à l&#39;état `cancelled`. Annuler un batch déjà `cancelling` ou `cancelled` le renvoie inchangé ; un batch `completed` ou `expired` ne peut pas être annulé.
