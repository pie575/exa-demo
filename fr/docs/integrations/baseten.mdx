Exa est un fournisseur de recherche web dans [Baseten Hosted Tools](https://www.baseten.co/blog/introducing-baseten-hosted-tools/). Les Model APIs de Baseten exposent des modèles open source, et les Hosted Tools permettent à ces modèles d&#39;effectuer des recherches sur le web sans que vous ayez à câbler une loop d&#39;outils : vous ajoutez un selector d&#39;outil Exa à une requête standard, Baseten exécute le modèle et les Exa searches conjointement dans une loop côté serveur, et vous obtenez une réponse fondée sur des preuves dans cette même réponse. Aucune API key Exa n&#39;est nécessaire. Baseten répercute le coût d&#39;Exa sur votre facture Baseten sans majoration.

## Utiliser les tools Exa web search {#use-the-exa-web-search-tools}

Définissez le header `x-baseten-server-tools: true` et ajoutez un ou plusieurs selectors Exa à votre array `tools`. Seul le `type` est nécessaire : Baseten développe automatiquement le schéma d&#39;outil, et le modèle décide quand chercher, quoi chercher et quelles pages lire. Les server-side tools fonctionnent avec les endpoints [Chat Completions](https://docs.baseten.co/reference/inference-api/chat-completions), [Messages](https://docs.baseten.co/reference/inference-api/messages) et Responses de Baseten, en mode bufferisé ou streaming.

<CodeGroup>
  ```python Python theme={null}
  from openai import OpenAI

  client = OpenAI(
      api_key="<BASETEN_API_KEY>",
      base_url="https://inference.baseten.co/v1",
      default_headers={"x-baseten-server-tools": "true"},
  )

  response = client.chat.completions.create(
      model="zai-org/GLM-5.3-Fast",
      messages=[
          {"role": "user", "content": "What were the major AI announcements this week?"}
      ],
      tools=[
          {"type": "baseten__exa__web_search_exa"},
          {"type": "baseten__exa__web_fetch_exa"},
      ],
      extra_body={"baseten": {"tool_settings": {"max_react_iterations": 5}}},
  )

  print(response.choices[0].message.content)
  ```

  ```javascript JavaScript theme={null}
  import OpenAI from "openai";

  const client = new OpenAI({
    apiKey: "<BASETEN_API_KEY>",
    baseURL: "https://inference.baseten.co/v1",
    defaultHeaders: { "x-baseten-server-tools": "true" },
  });

  const response = await client.chat.completions.create({
    model: "zai-org/GLM-5.3-Fast",
    messages: [
      { role: "user", content: "What were the major AI announcements this week?" },
    ],
    tools: [
      { type: "baseten__exa__web_search_exa" },
      { type: "baseten__exa__web_fetch_exa" },
    ],
    baseten: { tool_settings: { max_react_iterations: 5 } },
  });

  console.log(response.choices[0].message.content);
  ```

  ```bash cURL theme={null}
  curl https://inference.baseten.co/v1/chat/completions \
    -H "Authorization: Bearer <BASETEN_API_KEY>" \
    -H "Content-Type: application/json" \
    -H "x-baseten-server-tools: true" \
    -d '{
      "model": "zai-org/GLM-5.3-Fast",
      "messages": [
        { "role": "user", "content": "What were the major AI announcements this week?" }
      ],
      "tools": [
        { "type": "baseten__exa__web_search_exa" },
        { "type": "baseten__exa__web_fetch_exa" }
      ],
      "baseten": { "tool_settings": { "max_react_iterations": 5 } }
    }'
  ```
</CodeGroup>

Trois tools Exa sont disponibles. Donnez au modèle search et fetch lorsqu&#39;il doit découvrir des sources puis lire les pages qu&#39;il retient.

| Selector                                | Ce que reçoit le modèle                                                                            |
| --------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `baseten__exa__web_search_exa`          | [Exa search](/fr/docs/search/quickstart) : résultats pertinents avec le page content pour une requête |
| `baseten__exa__web_search_advanced_exa` | Search avec filtres de domaines, exploration des sous-pages et un résumé optionnel par résultat    |
| `baseten__exa__web_fetch_exa`           | [Page contents complets](/fr/docs/contents/quickstart) pour une URL dont le modèle dispose déjà       |

Les selectors ne prennent aucun field supplémentaire : le modèle renseigne les arguments de l&#39;outil à partir du schéma d&#39;Exa. Utilisez le system prompt pour orienter la stratégie de search, par exemple quand chercher, s&#39;il faut récupérer les primary sources et comment citer. Utilisez `baseten.tool_settings` pour borner la loop :

| Paramètre                      | À utiliser pour                                                                                                                                                                            |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `max_react_iterations`         | Limiter les itérations du modèle par requête (12 par défaut, plage de 2 à 20). La dernière itération est réservée à la réponse, donc `N` autorise `N - 1` séries d&#39;appels d&#39;outil. |
| `max_tool_calls_per_iteration` | Limiter les appels de server-side tools au sein d&#39;une itération (10 par défaut, plage de 1 à 10)                                                                                       |

## Réception des résultats {#how-results-come-back}

La réponse finale arrive via le field habituel de l&#39;endpoint. Les appels Exa terminés sont enregistrés selon le protocole : blocs `tool_use` et `tool_result` sur Messages, éléments `mcp_call` sur Responses, et `baseten.iterations[].continuation_messages` sur Chat Completions. Les requests en streaming reçoivent chaque appel de search et son résultat sous forme de server-sent events pendant l&#39;exécution de la loop, ce qui permet d&#39;afficher la progression avant l&#39;arrivée de la réponse. Le tableau `baseten.request.server_tool_calls[]` indique l&#39;issue de chaque appel Exa de la requête.

## Tarif {#pricing}

Les appels Exa sont facturés sur votre compte Baseten au tarif d&#39;Exa, sans marge, en plus des coûts de jetons du modèle : environ 0,007 $ par search et 0,001 $ par URL récupérée. Exa indique le montant de chaque appel à l&#39;exécution, si bien que les appels individuels peuvent s&#39;écarter de ces valeurs. Les appels d&#39;outils facturés apparaissent dans les paramètres de l&#39;espace de travail Baseten, sous Billing → Usage, regroupés par fournisseur. Consultez le [tableau de tarification de Baseten](https://docs.baseten.co/inference/model-apis/web-search#pricing) pour connaître les tarifs en vigueur.

Les Hosted Tools sont en accès anticipé sur Baseten, avec une limite de 25 requests par minute et par organization. Essayez Exa search dans le [playground Baseten](https://app.baseten.co/model-apis/zai-org/GLM-5.3-Fast/playground), ou contactez Baseten pour relever cette limite pour vos charges de travail en production.
