[Hermes Agent](https://github.com/NousResearch/hermes-agent) intègre Exa comme backend natif pour ses outils `web_search` et `web_extract` appelables par le modèle. Utilisez Exa pour ces deux capacités, ou associez-le à un autre fournisseur web de Hermes.

<div id="connect-your-exa-account">
  ## Connectez votre compte Exa
</div>

<Steps>
  <Step title="Obtenir une API key Exa">
    <Card title="Obtenez votre API key Exa" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      Créez une clé dans le dashboard. Les nouveaux comptes démarrent avec des crédits gratuits.
    </Card>
  </Step>

  <Step title="Sélectionner Exa dans Hermes">
    Lancez l&#39;assistant de configuration des outils :

    ```bash theme={null}
    hermes tools
    ```

    Ouvrez **Web Search &amp; Extract**, choisissez Exa, puis sélectionnez l&#39;option adossée à une API key. Lorsque vous y êtes invité, saisissez votre API key Exa. Hermes stocke les secrets dans `~/.hermes/.env` et la sélection du fournisseur dans `~/.hermes/config.yaml`.
  </Step>

  <Step title="Tester l'accès au web">
    Démarrez Hermes et demandez-lui de faire une recherche, puis de lire l&#39;un des résultats :

    ```text theme={null}
    Recherche sur le web les dernières nouveautés produit d'Exa, puis lis le résultat le plus pertinent.
    ```

    Hermes devrait appeler `web_search`, puis `web_extract` lorsqu&#39;il a besoin de la page elle-même.
  </Step>
</Steps>

<div id="configure-manually">
  ## Configuration manuelle
</div>

Ajoutez votre clé au fichier d&#39;environnement Hermes :

```bash ~/.hermes/.env theme={null}
EXA_API_KEY=your-exa-api-key
```

Sélectionnez ensuite Exa pour les deux capacités web :

```yaml ~/.hermes/config.yaml theme={null}
web:
  search_backend: "exa"
  extract_backend: "exa"
```

Vous pouvez utiliser le repli partagé à la place :

```yaml ~/.hermes/config.yaml theme={null}
web:
  backend: "exa"
```

Les paramètres propres à chaque capacité sont prioritaires sur `web.backend`. Cela vous permet d&#39;utiliser Exa uniquement pour la recherche ou uniquement pour l&#39;extraction lorsque vous combinez plusieurs providers.

<div id="tools-hermes-gets">
  ## Les tools dont dispose Hermes
</div>

| Tool          | Comportement d&#39;Exa                                                                                     |
| ------------- | ---------------------------------------------------------------------------------------------------------- |
| `web_search`  | Effectue une recherche avec Exa et renvoie des pages classées avec leurs titres, URL et extraits de texte. |
| `web_extract` | Récupère le contenu lisible d&#39;une ou plusieurs URL via Exa Contents.                                   |

Hermes tronque les pages extraites trop longues selon le character budget configuré et stocke le texte complet sur disque. Modifiez la valeur par défaut avec `web.extract_char_limit`, ou laissez l&#39;agent demander un `char_limit` plus élevé pour un appel donné.

<Note>
  Hermes peut utiliser Exa via son pool de fournisseurs gratuits, sans API key. Ce pool est soumis à une limitation de débit et peut alterner entre les fournisseurs. Configurez `EXA_API_KEY` et sélectionnez l&#39;option Exa adossée à une API key lorsque vous avez besoin que les requests passent systématiquement par votre compte Exa.
</Note>

<div id="troubleshooting">
  ## Dépannage
</div>

<AccordionGroup>
  <Accordion title="Hermes ne sélectionne pas Exa">
    Exécutez `hermes tools` et sélectionnez explicitement Exa. Si vous modifiez les fichiers de configuration manuellement, vérifiez que `web.search_backend`, `web.extract_backend` ou `web.backend` a pour valeur `exa`.
  </Accordion>

  <Accordion title="Hermes indique que EXA_API_KEY est manquante">
    Ajoutez la clé dans `~/.hermes/.env`, puis redémarrez Hermes pour qu&#39;il recharge l&#39;environnement.
  </Accordion>

  <Accordion title="La recherche fonctionne, mais l'extraction passe par un autre fournisseur">
    Hermes permet de configurer la recherche et l&#39;extraction indépendamment. Définissez `web.search_backend` et `web.extract_backend` sur `exa`.
  </Accordion>
</AccordionGroup>
