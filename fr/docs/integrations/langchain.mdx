LangChain est un framework permettant de créer des applications qui combinent des LLM avec des données, des API et d&#39;autres outils. Utilisez l&#39;intégration LangChain d&#39;Exa pour faire du RAG :

1. Configurez l&#39;intégration LangChain d&#39;Exa et utilisez Exa pour récupérer du contenu pertinent
2. Reliez ce contenu à une chaîne d&#39;outils qui s&#39;appuie sur le LLM d&#39;OpenAI pour la génération

<Info> Visionnez un tutoriel YouTube de l&#39;équipe LangChain présentant une configuration très similaire [ici](https://www.youtube.com/watch?v=dA1cHGACXCo). </Info>

<Info> Consultez la référence complète de LangChain [ici](https://python.langchain.com/docs/integrations/providers/exa%5Fsearch/). </Info>

<div id="get-started">
  ## Démarrer
</div>

<Steps>
  <Step title="Prérequis et installation">
    Installez les bibliothèques LangChain de base pour OpenAI et Exa

    ```Bash Bash theme={null}
    pip install langchain-openai langchain-exa
    ```

    <Note> Assurez-vous que les API keys sont correctement initialisées. Pour les bibliothèques LangChain, les noms des variables d&#39;environnement sont `OPENAI_API_KEY` et `EXA_API_KEY`, respectivement pour les clés OpenAI et Exa. </Note>

    <Card title="Obtenez votre Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      Créez une clé dans le dashboard. Les nouveaux comptes bénéficient de credits gratuits.
    </Card>
  </Step>

  <Step title="Utilisez Exa Search pour alimenter un outil LangChain">
    Configurez un outil Retriever à l&#39;aide de `ExaSearchRetriever`. Il s&#39;agit d&#39;un retriever qui se connecte à Exa Search pour trouver des documents pertinents grâce à la recherche sémantique. Commencez par importer les bibliothèques nécessaires, puis instanciez ExaSearchRetriever.

    ```Python Python theme={null}
    # charger les variables d'environnement
    import os
    from dotenv import load_dotenv
    load_dotenv()
    from langchain_exa import ExaSearchRetriever
    from langchain_core.prompts import PromptTemplate
    from langchain_core.runnables import RunnableLambda

    # Définir notre retriever pour qu'il utilise Exa Search, récupère 3 résultats et extraie les highlights de chacun
    retriever = ExaSearchRetriever(api_key=os.getenv("EXA_API_KEY"), k=3, highlights=True)
    ```
  </Step>

  <Step title="Créez un modèle de prompt (facultatif)">
    Nous utilisons un [PromptTemplate](https://python.langchain.com/v0.1/docs/modules/model%5Fio/prompts/quick%5Fstart/#prompttemplate) LangChain pour définir un template à espaces réservés qui extrait les URL et les highlights renvoyés par le retriever Exa.

    ```Python Python theme={null}
    # Définir un template de prompt de document à l'aide de balises de type XML
    document_prompt = PromptTemplate.from_template("""
    <source>
        <url>{url}</url>
        <highlights>{highlights}</highlights>
    </source>
    """)
    ```
  </Step>

  <Step title="Analysez l’URL et le contenu des résultats Exa">
    Nous utilisons une [Runnable Lambda](https://api.python.langchain.com/en/latest/runnables/langchain%5Fcore.runnables.base.RunnableLambda.html) pour extraire les attributs URL et Highlights des résultats d&#39;Exa Search, puis les transmettre au template de prompt ci-dessus

    ```Python Python theme={null}
    # Crée un Runnable Lambda qui extrait les attributs highlights et URL renvoyés par le retriever et les transmet au prompt de document défini ci-dessus
    document_chain = RunnableLambda(
        lambda document: {
            "highlights": document.metadata["highlights"],
            "url": document.metadata["url"]
        }
    ) | document_prompt
    ```
  </Step>

  <Step title="Combinez les résultats et le contenu d’Exa pour la récupération d’informations">
    Complétez la chaîne de retrieval en assemblant le retriever Exa, le parser et une courte fonction lambda — cette étape est essentielle pour transmettre le résultat sous forme d&#39;une chaîne unique servant de context au LLM à l&#39;étape suivante.

    ```Python Python theme={null}
    # Définir la chaîne de retrieval - résultats de recherche Exa => récupérer les attributs et les convertir en XML => concaténer en une seule chaîne à fournir comme context dans les étapes suivantes
    retrieval_chain = retriever | document_chain.map() | (lambda docs: "\n".join([i.text for i in docs]))
    ```
  </Step>

  <Step title="Configurez le reste de la chaîne d’outils, notamment OpenAI pour la génération">
    Dans cette étape, nous définissons le system prompt avec les entrées de template Query et Context, issues respectivement de l&#39;utilisateur et d&#39;Exa Search. Commencez par importer à nouveau les bibliothèques et composants nécessaires depuis les bibliothèques LangChain

    ```Python Python theme={null}
    from langchain_core.runnables import RunnablePassthrough, RunnableParallel
    from langchain_core.prompts import ChatPromptTemplate
    from langchain_openai import ChatOpenAI
    from langchain_core.output_parsers import StrOutputParser
    ```

    Nous définissons ensuite un prompt de génération — le template de prompt utilisé avec le contexte fourni par Exa pour effectuer du RAG.

    ```Python Python theme={null}
    # Définir le template de prompt principal
    generation_prompt = ChatPromptTemplate.from_messages([
        ("system", "You are an expert research assistant. You use xml-formatted context to research people's questions."),
        ("human", """
    Please answer the following query based on the provided context. Please cite your sources at the end of your response.:

    Query: {query}
    ---
    <context>
    {context}
    </context>
    """)
    ])
    ```

    Nous définissons le [LLM de génération sur OpenAI](https://python.langchain.com/v0.1/docs/integrations/chat/openai/), puis nous relions le tout via une connexion parallèle [RunnableParallel](https://python.langchain.com/v0.1/docs/expression%5Flanguage/primitives/parallel/). Le prompt de génération, qui contient la query et le context, est ensuite transmis au LLM, puis [analysé afin d&#39;obtenir une meilleure représentation de l&#39;output](https://api.python.langchain.com/en/latest/output%5Fparsers/langchain%5Fcore.output%5Fparsers.string.StrOutputParser.html).

    ```Python Python theme={null}
    # Utilisation d'OpenAI pour la génération
    llm = ChatOpenAI(api_key=os.getenv("OPENAI_API_KEY"))

    # Analyse simple de la chaîne pour l'output
    output_parser = StrOutputParser()

    # Connexion de la chaîne, avec une connexion parallèle pour la query de l'utilisateur et le context provenant de la chaîne de retriever Exa de l'étape 2.
    chain = RunnableParallel({
        "query": RunnablePassthrough(),
        "context": retrieval_chain,
    }) | generation_prompt | llm | output_parser
    ```
  </Step>

  <Step title="Exécuter l’ensemble de la chaîne d’outils RAG">
    [Invoquons](https://python.langchain.com/v0.1/docs/expression%5Flanguage/interface/#invoke) la chaîne :

    ```Python Python theme={null}
    result = chain.invoke("Latest research on climate change innovation")

    print(result)
    ```

    Et regardez le résultat (sauts de ligne interprétés) :

  </Step>

  <Step title="Diffusez éventuellement la sortie de la chaîne en flux continu">
    Vous pouvez aussi, si vous le souhaitez, diffuser en streaming la sortie de la chaîne.

    ```Python Python theme={null}
    for chunk in chain.stream("Latest research on climate change innovation"):
      print(chunk, end="|", flush=True)

    # Ou de façon asynchrone
    async def run_async():
      async for chunk in chain.astream("Latest research on climate change innovation"):
        print(chunk, end="|", flush=True)

    import asyncio
    asyncio.run(run_async())
    ```

    Produit l&#39;output en flux continu. [En savoir plus](https://python.langchain.com/v0.1/docs/expression%5Flanguage/streaming/) sur la méthode `.stream`, notamment sur la gestion des fragments et l&#39;analyse des outputs.
  </Step>
</Steps>
