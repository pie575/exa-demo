Installez Exa dans Claude Code ou connectez-le à Claude Web, Desktop et Cowork pour donner à Claude accès à des informations à jour issues du web. Claude peut lancer des recherches en langage naturel, lire les pages pertinentes et s&#39;appuyer sur ces sources au fil de son travail.

<div id="work-with-whats-on-the-web-right-now">
  ## Travaillez avec ce qui se trouve sur le web en temps réel
</div>

Dans Claude Code, Exa peut rechercher la documentation, les issues, les changelogs et des exemples concrets à jour pendant que vous travaillez dans votre repository. Cette même integration fournit à Claude Web, Desktop et Cowork l&#39;actualité, les travaux de recherche, les informations sur les entreprises, les détails produits et d&#39;autres sources qui ne figurent pas nécessairement déjà dans le context.

```text theme={null}
Nous sommes sur Tailwind v3. Utilise Exa pour trouver et lire le guide officiel
de migration vers Tailwind v4, puis migre ce projet vers la v4.
```

Claude Code peut utiliser ce qu&#39;il trouve pour effectuer la modification dans votre base de code. Dans les autres clients Claude, il peut exploiter les mêmes sources dans les réponses, les artefacts et les tâches Cowork.

Le même principe s&#39;applique dès que la réponse dépend de sources web actuelles ou précises :

* « Trouve les dernières notes de version de cette dépendance et résume les changements incompatibles. »
* « Cherche des travaux de recherche primaires récents sur la mise à l&#39;échelle au moment de l&#39;inférence et compare les méthodes. »
* « Lis la documentation actuelle des webhooks Stripe et explique le comportement de relance recommandé. »
* « Trouve les pages de tarifs officielles de ces produits et compare leurs formules d&#39;entrée de gamme. »

<div id="search-read-and-research">
  ## Rechercher, lire et recherche
</div>

L&#39;intégration Exa donne à Claude des outils pour rechercher et lire le web, qu&#39;il peut combiner au fil d&#39;une tâche de recherche plus longue.

<Columns cols={3}>
  <Card title="Rechercher" icon="search">

<div id="research-without-leaving-claude">
  ## Faire des recherches sans quitter Claude
</div>

Demandez le résultat souhaité et indiquez à Claude quels types de sources sont importants :

```text theme={null}
Compare les offres managées, les licences et les tarifs des principales
bases de données vectorielles open source. Appuie-toi sur des sources
primaires à jour et cite-les.
```

Claude peut faire appel à Exa tout au long de la conversation pour trouver et lire les sources nécessaires à la tâche. Utilisez cette approche pour la recherche technique, l&#39;analyse concurrentielle, la cartographie de marché, la recherche d&#39;entreprises ou toute question dont la réponse se trouve dispersée sur le web.

<div id="use-exa-in-cowork">
  ## Utiliser Exa dans Cowork
</div>

Le même connecteur est disponible dans Cowork. Confiez à Claude une tâche qui nécessite des informations externes : il pourra effectuer des recherches ou consulter des pages web tout en travaillant avec vos fichiers et les autres outils connectés.

```text theme={null}
Relis cette note de veille concurrentielle, vérifie chaque affirmation tarifaire
sur les pages actuelles des fournisseurs avec Exa, puis mets à jour le document avec les citations.
```

<div id="prefer-mcp-directly">
  ## Vous préférez MCP directement ?
</div>

Si vous configurez Claude manuellement ou si vous utilisez un autre client MCP, vous pouvez vous connecter directement au MCP server hébergé par Exa :

```bash theme={null}
claude mcp add --transport http exa https://mcp.exa.ai/mcp
```

Consultez [Exa MCP](/fr/docs/get-started/exa-mcp) pour découvrir les autres clients, les options de configuration et les tools disponibles.
