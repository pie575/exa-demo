[OpenHuman](https://tinyhumans.gitbook.io/openhuman) de TinyHumans est un assistant IA de bureau doté d&#39;un outil de recherche web natif que l&#39;agent appelle de lui-même. Exa est le provider de recherche derrière cet outil.

| Approche              | Configuration          | S&#39;exécute sur                                                                 |
| --------------------- | ---------------------- | --------------------------------------------------------------------------------- |
| **OpenHuman Managed** | Aucune                 | Le backend d&#39;OpenHuman, propulsé par Exa. Sans API key.                       |
| **Exa provider**      | Coller une API key Exa | Votre machine, directement vers `https://api.exa.ai` sur votre propre compte Exa. |

<div id="openhuman-managed">
  ## OpenHuman Managed
</div>

La recherche managée est l&#39;option par défaut. Choisissez **Simple** lors de la configuration initiale et l&#39;agent pourra immédiatement effectuer des recherches sur le web.

<Frame caption="Choisissez Simple lors de la configuration initiale pour une recherche managée propulsée par Exa">
  <img src="/docs/images/integrations/openhuman/onboarding-runtime-choice.png" alt="Configuration initiale d'OpenHuman demandant comment exécuter OpenHuman, avec l'option Simple sélectionnée" style={{width: "700px", height: "auto", margin: "0 auto"}} width="1180" height="700" data-path="images/integrations/openhuman/onboarding-runtime-choice.png" />
</Frame>

<Tip>
  **Le mode managé est le moyen le plus rapide d&#39;obtenir des résultats Exa.** Aucune clé à créer, stocker ou renouveler, aucun identifiant sur votre machine, et la recherche est facturée sur votre abonnement OpenHuman.
</Tip>

<div id="exa-provider">
  ## Exa provider
</div>

Configurez Exa directement pour exécuter les recherches sur votre propre compte Exa et fournir à l&#39;agent les tools search et contents d&#39;Exa.

<div id="get-your-exa-api-key">
  ### Obtenir votre API key Exa
</div>

<Card title="Obtenir votre API key Exa" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  Créez une key dans le dashboard. Les nouveaux comptes bénéficient de credits gratuits.
</Card>

<div id="add-exa-in-openhuman">
  ### Ajouter Exa dans OpenHuman
</div>

1. Ouvrez **Connections**, puis sélectionnez **Search engine** sous **API keys**.

<Frame caption="Connections → API keys → Search engine">
  <img src="/docs/images/integrations/openhuman/connections-search.png" alt="La page Connections d'OpenHuman avec Search engine sélectionné sous API keys, affichant la liste des moteurs de recherche avec OpenHuman Managed actif" style={{width: "800px", height: "auto", margin: "0 auto"}} width="1180" height="820" data-path="images/integrations/openhuman/connections-search.png" />
</Frame>

2. Sélectionnez **Exa**.

<Frame caption="Exa sélectionné, en attente d'une clé">
  <img src="/docs/images/integrations/openhuman/select-exa.png" alt="L'option de moteur Exa sélectionnée dans le panneau Search engine d'OpenHuman, affichant le badge Needs API key" style={{width: "800px", height: "auto", margin: "0 auto"}} width="1180" height="820" data-path="images/integrations/openhuman/select-exa.png" />

3. Collez votre clé dans **Exa API key**, puis sélectionnez **Save**.

<div id="configuration">
  ### Configuration
</div>

Le panneau écrit dans le fichier `config.toml` d&#39;OpenHuman. Vous pouvez également définir les mêmes valeurs directement dans le fichier ou via l&#39;environnement :

<Tabs>
  <Tab title="config.toml">
    ```toml config.toml theme={null}
    [search]
    engine = "exa"        # requis
    max_results = 5       # optionnel, 1-20
    timeout_secs = 15     # optionnel

    [search.exa]
    api_key = "your-exa-api-key"   # requis
    ```
  </Tab>

  <Tab title="Environnement">
    ```bash theme={null}
    OPENHUMAN_SEARCH_ENGINE=exa
    EXA_API_KEY=your-exa-api-key
    ```

    <Note>
      `EXA_API_KEY` et `OPENHUMAN_EXA_API_KEY` remplacent tous deux `search.exa.api_key`. Si les deux sont définies, `OPENHUMAN_EXA_API_KEY` est prioritaire.
    </Note>
  </Tab>
</Tabs>

<div id="tools-the-agent-gets">
  ### Les tools dont dispose l&#39;agent
</div>

| Tool               | Renvoie                                                                            |
| ------------------ | ---------------------------------------------------------------------------------- |
| `web_search_tool`  | Une recherche web, assurée par Exa.                                                |
| `exa_search`       | Des pages classées avec titres, URL, dates de publication et, en option, le texte. |
| `exa_get_contents` | Le contenu complet des URL fournies, avec summaries ou highlights en option.       |

L&#39;agent définit les [search parameters](/fr/docs/search/quickstart) d&#39;Exa à chaque appel : de simples instructions suffisent donc à orienter le search mode, les domaines, les dates et les catégories.

<div id="troubleshooting">
  ## Dépannage
</div>

<AccordionGroup>
  <Accordion title="Exa search indisponible : aucune API key configurée">
    OpenHuman n&#39;a trouvé aucune key dans le panneau **Search engine**, dans les variables `EXA_API_KEY` et `OPENHUMAN_EXA_API_KEY`, ni dans `search.exa.api_key`. Définissez-la à l&#39;un de ces emplacements, puis redémarrez OpenHuman si vous avez modifié `config.toml` pendant son exécution.
  </Accordion>

  <Accordion title="Exa a rejeté l'API key configurée (HTTP 401)">
    La key est invalide ou révoquée. Vérifiez-la dans le [dashboard Exa](https://dashboard.exa.ai/api-keys), puis utilisez **Clear** pour supprimer la key enregistrée et enregistrez la bonne. Attention aux espaces copiés par inadvertance.
  </Accordion>

  <Accordion title="Exa a renvoyé un statut non 2xx">
    `429` indique une rate limit atteinte ou un quota épuisé : vérifiez votre usage dans le [dashboard](https://dashboard.exa.ai). Pour les `5xx`, réessayez, puis consultez les [error codes](/fr/docs/admin/error-codes).
  </Accordion>

  <Accordion title="OpenHuman Managed n'apparaît pas dans la liste des moteurs">
    Les sessions purement locales ne peuvent pas utiliser la recherche managée. Configurez le Exa provider avec votre propre key.
  </Accordion>
</AccordionGroup>
