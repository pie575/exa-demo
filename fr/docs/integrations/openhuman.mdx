[OpenHuman](https://tinyhumans.gitbook.io/openhuman) de TinyHumans est un assistant IA de bureau doté d&#39;un outil de recherche web natif que l&#39;agent appelle de lui-même. Exa est le fournisseur de recherche derrière cet outil.

| Approche              | Configuration          | S&#39;exécute sur                                                                 |
| --------------------- | ---------------------- | --------------------------------------------------------------------------------- |
| **OpenHuman Managed** | Aucune                 | Le backend d&#39;OpenHuman, propulsé par Exa. Sans API key.                       |
| **Exa provider**      | Collez une API key Exa | Votre machine, directement vers `https://api.exa.ai` sur votre propre compte Exa. |

<div id="openhuman-managed">
  ## OpenHuman Managed
</div>

La recherche managée est l&#39;option par défaut. Choisissez **Simple** lors de la configuration initiale et l&#39;agent pourra immédiatement lancer des recherches sur le web.

<Frame caption="Choisissez Simple lors de la configuration initiale pour une recherche managée propulsée par Exa">
  <img src="/docs/images/integrations/openhuman/onboarding-runtime-choice.png" alt="Configuration initiale d'OpenHuman demandant comment exécuter OpenHuman, avec l'option Simple sélectionnée" style={{width: "700px", height: "auto", margin: "0 auto"}} width="1180" height="700" data-path="images/integrations/openhuman/onboarding-runtime-choice.png" />
</Frame>

<Tip>
  **L&#39;option managée est le moyen le plus rapide d&#39;obtenir des résultats Exa.** Aucune clé à créer, stocker ou renouveler, aucune information d&#39;authentification sur votre machine, et la recherche est facturée sur votre abonnement OpenHuman.
</Tip>

<div id="exa-provider">
  ## Exa provider
</div>

Configurez Exa directement pour exécuter la search sur votre propre compte Exa et fournir à l&#39;agent les tools de search et de contenu de page d&#39;Exa.

<div id="get-your-exa-api-key">
  ### Obtenir votre API key Exa
</div>

<Card title="Obtenir votre API key Exa" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  Créez une clé dans le tableau de bord. Les nouveaux comptes bénéficient de crédits gratuits.
</Card>

<div id="add-exa-in-openhuman">
  ### Ajouter Exa dans OpenHuman
</div>

1. Ouvrez **Connections**, puis sélectionnez **Search engine** sous **API keys**.

<Frame caption="Exa sélectionné, en attente d'une clé">

<div id="configuration">
  ### Configuration
</div>

Le panneau écrit dans le fichier `config.toml` d&#39;OpenHuman. Vous pouvez aussi définir les mêmes valeurs directement dans le fichier ou dans l&#39;environnement :

<Tabs>
  <Tab title="config.toml">
    ```toml config.toml theme={null}
    [search]
    engine = "exa"        # requis
    max_results = 5       # optionnel, 1-20
    timeout_secs = 15     # optionnel

    [search.exa]
    api_key = "your-exa-api-key"   # requis
    ```
  </Tab>

  <Tab title="Environnement">
    ```bash theme={null}
    OPENHUMAN_SEARCH_ENGINE=exa
    EXA_API_KEY=your-exa-api-key
    ```

    <Note>
      `EXA_API_KEY` et `OPENHUMAN_EXA_API_KEY` remplacent toutes deux `search.exa.api_key`. Si les deux sont définies, `OPENHUMAN_EXA_API_KEY` est prioritaire.
    </Note>
  </Tab>
</Tabs>

<div id="tools-the-agent-gets">
  ### Les tools dont dispose l&#39;agent
</div>

| Tool               | Retourne                                                                   |
| ------------------ | -------------------------------------------------------------------------- |
| `web_search_tool`  | Recherche web, assurée par Exa.                                            |
| `exa_search`       | Pages classées avec titres, URL, dates de publication et texte facultatif. |
| `exa_get_contents` | Contenu complet des URL fournies, avec résumés ou highlights en option.    |

L&#39;agent définit les [paramètres de recherche](/fr/docs/search/quickstart) d&#39;Exa à chaque appel : de simples instructions suffisent donc à orienter le mode de recherche, les domaines, les dates et les catégories.

<div id="troubleshooting">
  ## Dépannage
</div>

<AccordionGroup>
  <Accordion title="Exa search indisponible : aucune API key configurée">
    OpenHuman n&#39;a trouvé aucune clé dans le panneau **Search engine**, dans les variables `EXA_API_KEY` et `OPENHUMAN_EXA_API_KEY`, ni dans `search.exa.api_key`. Définissez-la à l&#39;un de ces emplacements, puis redémarrez OpenHuman si vous avez modifié `config.toml` pendant son exécution.
  </Accordion>

  <Accordion title="Exa a rejeté l'API key configurée (HTTP 401)">
    La clé est invalide ou révoquée. Vérifiez-la dans le [tableau de bord Exa](https://dashboard.exa.ai/api-keys), puis utilisez **Clear** pour effacer la clé enregistrée et enregistrez la bonne. Attention aux espaces indésirables lors du copier-coller.
  </Accordion>

  <Accordion title="Exa a renvoyé un statut non 2xx">
    `429` indique une limite de débit atteinte ou un quota épuisé : vérifiez votre utilisation dans le [tableau de bord](https://dashboard.exa.ai). Pour les `5xx`, réessayez, puis consultez les [codes d&#39;erreur](/fr/docs/admin/error-codes).
  </Accordion>

  <Accordion title="OpenHuman Managed est absent de la liste des moteurs">
    Les sessions purement locales ne peuvent pas utiliser la recherche managée. Configurez le Exa provider avec votre propre clé.
  </Accordion>
</AccordionGroup>
