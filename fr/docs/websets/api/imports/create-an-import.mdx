title: "Créer un import"
openapi: "/fr/docs/exa-spec.yaml POST /v0/imports"
timestamp: false
description: "Crée un nouvel import pour téléverser vos données dans Websets.
  Les imports peuvent servir à :


  - **Enrich** : enrichir vos données avec des informations supplémentaires
  grâce à notre moteur d'enrichment propulsé par l'IA

  - **Search** : interroger vos données via la recherche agentique de Websets,
  avec des filtres en langage naturel

  - **Exclude** : éviter que des résultats en doublon ou déjà connus
  n'apparaissent dans vos searches


  Une fois l'import créé, vous pouvez téléverser vos données vers l'`uploadUrl`
  renvoyée jusqu'à `uploadValidUntil` (1 heure par défaut)."
