description: "Prévisualisez la façon dont une requête de recherche sera
  décomposée avant de créer un webset. Cet endpoint effectue la même analyse de
  requête que celle réalisée lors de la création d'un webset, ce qui vous permet
  de voir à l'avance le type d'entité détecté, les critères de recherche générés
  et les colonnes d'enrichment disponibles.


  Utilisez-le pour aider les utilisateurs à comprendre comment leur recherche
  sera interprétée avant de créer un webset complet."
