<div id="get-started">
  # Get started
</div>

> Bienvenue dans le Dashboard Websets ! Trouvez tout ce que vous cherchez sur le web, aussi complexe soit-il.

<br />

<div id="1-sign-up">
  ## 1. Inscription
</div>

Websets est désormais disponible pour tous sur [https://websets.exa.ai/](https://websets.exa.ai/) !

Si vous avez des questions, [réservez un appel ici](https://scheduler.default.com/exa/websets-intro/30min).

<br />

<div id="2-get-started">
  ## 2. Get started
</div>

Websets est très simple à utiliser.

<img src="https://mintcdn.com/exa-52/tmzyKnsgpKLGddKC/images/websets/websets-landing.png?fit=max&auto=format&n=tmzyKnsgpKLGddKC&q=85&s=8573cf90a9e9f98c757ac0fa56c8a64d" alt="Page d'accueil de Websets" width="2870" height="1726" data-path="images/websets/websets-landing.png" />

1. Décrivez ce que vous cherchez en langage naturel — votre demande peut être aussi complexe que vous le souhaitez !

<img src="https://mintcdn.com/exa-52/tmzyKnsgpKLGddKC/images/websets/websets-preview.png?fit=max&auto=format&n=tmzyKnsgpKLGddKC&q=85&s=15c47c556750ad0f1cebfb78b1ea52aa" alt="Aperçu du Webset avec les critères générés" width="2870" height="1726" data-path="images/websets/websets-preview.png" />

2. Vérifiez que vos critères et votre catégorie de données vous conviennent.

3. Indiquez le nombre de résultats souhaité, puis lancez votre search.

<br />

<div id="3-inside-your-webset">
  ## 3. Au cœur de votre Webset
</div>

En résumé, Websets procède ainsi :

1. Décomposer votre demande

2. Trouver des données prometteuses susceptibles d&#39;y répondre

3. Vérifier tous les critères à l&#39;aide d&#39;agents IA et de sources parallèles

4. Ajuster la search en fonction des retours que vous transmettez à notre agent

<Info>
  Si les premiers résultats ne vous satisfont pas, affinez les critères via
  « Edit critères » ou directement dans le chat.
</Info>

<br />

<div id="4-interacting-with-your-webset">
  ## 4. Interagir avec votre Webset
</div>

Une fois le Webset terminé, vous pouvez interagir avec ses différents éléments !

Cliquez sur un résultat pour voir :

<img src="https://mintcdn.com/exa-52/tmzyKnsgpKLGddKC/images/websets/websets-result.png?fit=max&auto=format&n=tmzyKnsgpKLGddKC&q=85&s=793c040207129ee6c2efc1c8d922d6fe" alt="Détail d'un résultat de Webset avec résumé IA, critères satisfaits et sources" width="2870" height="1734" data-path="images/websets/websets-result.png" />

1. Son résumé généré par IA

2. Les critères qu&#39;il remplit pour figurer dans le Webset

3. Les sources ayant établi la correspondance (vous pouvez les consulter directement ici)

Vous pouvez supprimer manuellement des résultats afin de nettoyer votre Webset avant de l&#39;exporter.

<br />

<div id="5-add-more-result-criteria-and-custom-columns">
  ## 5. Ajouter d&#39;autres critères de résultat et colonnes personnalisées
</div>

<img src="https://mintcdn.com/exa-52/tmzyKnsgpKLGddKC/images/websets/add-enrichment.png?fit=max&auto=format&n=tmzyKnsgpKLGddKC&q=85&s=5d94338cdb1931e9afced3c196acf075" alt="Ajout d'une colonne d'enrichment" width="2870" height="1734" data-path="images/websets/add-enrichment.png" />

1. **Ajouter des enrichments :** vous pouvez créer des colonnes d&#39;enrichment personnalisées et demander n&#39;importe quelle information. Par exemple : coordonnées (e-mail et numéro de téléphone), chiffre d&#39;affaires, nombre d&#39;employés, analyse de sentiment, summary de l&#39;article, etc. Renseignez :

* Le nom de la colonne (par ex. « Chiffre d&#39;affaires »)

* Le type de colonne (par ex. `Number`)

* Les instructions permettant à Websets de trouver la donnée (par ex. « Trouver le chiffre d&#39;affaires annuel de l&#39;entreprise »)

* Ou cliquez sur « fill in for me » pour que notre agent génère automatiquement les instructions

<br />

<div id="6-share-and-export-your-webset">
  ## 6. Partagez et exportez votre Webset
</div>

1. Cliquez sur export pour télécharger votre Webset au format CSV.

2. Cliquez sur share pour obtenir un lien vers votre Webset.

<br />
