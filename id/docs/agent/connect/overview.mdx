Exa Connect mengintegrasikan data partners premium ke dalam loop Exa Agent. Attach sebuah
provider ke sebuah run, dan Exa Agent akan melakukan query ke database partner tersebut bersama web
search, lalu menggabungkan hasilnya menjadi satu jawaban terstruktur yang grounded.

Baru mengenal agent run? Mulai dari [panduan Exa Agent](/id/docs/agent/quickstart),
lalu kembali ke sini untuk attach data partners.

<Tip>
  Exa Agent sudah melakukan search pada seluruh [data index](/id/docs/search/data/overview), yaitu
  sources berita, kode, perusahaan, dan orang yang sama seperti Search API. Exa Connect menambahkan
  database partner premium di atasnya.
</Tip>

<Tip>
  Lebih suka MCP? Exa Agent dan [Exa Connect](/id/docs/agent/connect/overview) tersedia di [Exa MCP](/id/docs/get-started/exa-mcp#exa-agent). Aktifkan `tools=agent_run` untuk menjalankan Research multi-langkah, list building, enrichment, dan output terstruktur dari Claude, Cursor, dan MCP clients lainnya.
</Tip>

<div id="why-exa-connect">
  ## Mengapa Exa Connect
</div>

* **Data premium tanpa integrasi terpisah.** Akses data partner tanpa perlu
  menandatangani kontrak atau memasang SDK. Anda cukup memanggil satu API Exa.
* **Exa yang mengurus pekerjaan teknisnya.** Kami mengelola autentikasi provider, pemilihan tool,
  percobaan ulang, dan pemeringkatan hasil.
* **Exa Agent yang memilih sumbernya.** Ketika `outputSchema` Anda meminta
  &quot;kunjungan bulanan dari Similarweb&quot; atau &quot;pejabat terverifikasi&quot;, Exa Agent akan memanggil
  tool partner yang sesuai, bukan menebak-nebak dari sebuah halaman web.
* **Data indeks dan partner dalam satu run.** Connect berjalan di atas indeks Exa.
  Exa Agent memanfaatkan setiap sumber pada sisi terkuatnya dan mencantumkan sitasi hasilnya.

<div id="how-it-works">
  ## Cara kerjanya
</div>

1. **Attach** satu atau beberapa provider melalui array `dataSources` pada
   [`POST /agent/runs`](/id/docs/reference/agent-api/create-a-run).
2. Exa Agent **memilih tool yang tepat** untuk setiap langkah berdasarkan query dan
   `outputSchema` Anda: data partner atau Exa web search.
3. Hasil dari partner **digabungkan dengan Research web** menjadi output terstruktur Anda,
   lengkap dengan sources yang terlampir.

Fiber.ai menagih dalam credits, bukan per pemanggilan, karena biayanya sendiri berbeda-beda
tiap pemanggilan: satu search berbiaya 2 credits ditambah 1 per hasil yang dikembalikan; pencarian
perusahaan atau orang ditagih per kandidat yang dikembalikan (sehingga menaikkan
`numResults` pada pencarian perusahaan untuk memilah nama yang ambigu akan lebih mahal); dan satu contact
reveal memakan 2–5 credits, tergantung apakah Anda meminta work email, personal email,
atau nomor telepon. Anda dikenakan credits yang dilaporkan Fiber untuk setiap pemanggilan; pemanggilan yang
tidak menghasilkan kecocokan tidak dikenakan biaya. Lihat [harga Fiber.ai](/id/docs/agent/connect/fiber#pricing).

Similarweb menagih dalam data credits (kira-kira satu per metrik × baris × bulan), sehingga harga
sebuah pemanggilan mengikuti nilai `numResults`/`months` — 1 hingga 15 credits per pemanggilan. Anda
dikenakan credits yang dilaporkan Similarweb untuk setiap pemanggilan; pemanggilan yang tidak mengembalikan
data tidak dikenakan biaya. Lihat [harga Similarweb](/id/docs/agent/connect/similarweb#pricing).

Baselayer menagih per order, dan tarifnya bergantung pada operasinya: KYB
business search seharga $1.00, UCC lien search seharga $2.00 per negara bagian yang dicari,
pencarian dokumen litigasi/kebangkrutan seharga $1.00 per kategori, watchlist screening
seharga $0.10–$0.25 per daftar yang diminta, klasifikasi industri dan analisis situs web
masing-masing $0.35, web presence dihitung dari total analisis yang dipilih
(masing-masing $0.15–$0.35), dan international business search seharga $4.00. Pembacaan follow-up
atas business search sebelumnya (business lookup, pejabat, registrasi,
officer reverse lookup) tidak dikenakan biaya. Lihat [harga Baselayer](/id/docs/agent/connect/baselayer#pricing).

  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="Profile Anthropic: total funding and estimated monthly web traffic.",
      data_sources=[{"provider": "fiber"}, {"provider": "similarweb"}],
      output_schema={
          "type": "object",
          "required": ["company"],
          "properties": {
              "company": {
                  "type": "object",
                  "required": ["name", "totalFunding", "monthlyVisits"],
                  "properties": {

                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

<div id="combining-providers">
  ### Menggabungkan provider
</div>

Attach sebanyak apa pun partner yang dibutuhkan tugas Anda. Exa Agent memanggil masing-masing partner di bidang yang paling dikuasainya dan memadukan hasilnya dengan web search menjadi satu jawaban terstruktur:

```json theme={null}
{
  "dataSources": [
    { "provider": "similarweb" },
    { "provider": "fiber" },
    { "provider": "harmonic" }
  ]
}
```

Untuk panduan lengkap, termasuk cara menyusun query dan `outputSchema` agar setiap
partner terpicu, lihat [Menggabungkan provider](/id/docs/agent/connect/combining-providers).
