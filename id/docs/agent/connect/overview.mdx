Exa Connect mengintegrasikan data partners premium ke dalam loop Exa Agent. Attach sebuah
provider ke sebuah run, lalu Exa Agent akan melakukan kueri ke basis data partner tersebut berdampingan dengan web
search, sebelum menggabungkan hasilnya menjadi satu jawaban terstruktur yang grounded.

Baru mengenal agent runs? Mulailah dari [panduan Exa Agent](/id/docs/agent/quickstart),
lalu kembali ke sini untuk attach data partners.

<Tip>
  Exa Agent sudah melakukan search ke seluruh [data index](/id/docs/search/data/overview), yaitu sumber
  berita, kode, perusahaan, dan orang yang sama seperti pada Search API. Exa Connect menambahkan
  basis data partner premium di atasnya.
</Tip>

<Tip>
  Lebih suka MCP? Exa Agent dan [Exa Connect](/id/docs/agent/connect/overview) tersedia di [Exa MCP](/id/docs/get-started/exa-mcp#exa-agent). Aktifkan `tools=agent_run` untuk menjalankan riset multi-langkah, pembuatan daftar, enrichment, dan structured output dari Claude, Cursor, dan klien MCP lainnya.
</Tip>

<div id="why-exa-connect">
  ## Mengapa Exa Connect
</div>

* **Data premium tanpa integrasi terpisah.** Akses data partner tanpa
  menandatangani kontrak atau menyiapkan SDK. Anda cukup memanggil satu API Exa.
* **Exa yang mengurus hal-hal teknisnya.** Kami mengelola autentikasi provider, pemilihan tool,
  percobaan ulang, dan pemeringkatan hasil.
* **Exa Agent yang memilih sumbernya.** Ketika `outputSchema` Anda meminta
  &quot;kunjungan bulanan dari Similarweb&quot; atau &quot;pejabat terverifikasi&quot;, Exa Agent memanggil
  tool partner yang sesuai, bukan menebak-nebak dari sebuah halaman web.
* **Data indeks dan partner dalam satu run.** Connect berjalan di atas indeks Exa.
  Exa Agent memanfaatkan setiap sumber di bidang terkuatnya dan mencantumkan sitasi hasilnya.

<div id="how-it-works">
  ## Cara kerjanya
</div>

1. **Attach** satu atau beberapa provider melalui array `dataSources` pada
   [`POST /agent/runs`](/id/docs/reference/agent-api/create-a-run).
2. Exa Agent **memilih tool yang tepat** untuk setiap langkah berdasarkan query dan
   `outputSchema` Anda: data partner atau Exa web search.
3. Hasil dari partner **dipadukan dengan riset web** menjadi structured output Anda,
   lengkap dengan sumbernya.

Fiber.ai menagih dalam credit, bukan per call, karena biayanya sendiri berbeda-beda
tiap call: satu search dikenakan 2 credit ditambah 1 credit untuk setiap hasil yang
dikembalikan; pencarian perusahaan atau orang ditagih per kandidat yang
dikembalikan (jadi menaikkan `numResults` pada pencarian perusahaan untuk
memperjelas nama yang ambigu akan lebih mahal); dan pengungkapan kontak dikenakan 2–5
credit, tergantung apakah Anda meminta work email, personal email, atau nomor
telepon. Anda ditagih sebanyak credit yang dilaporkan Fiber untuk setiap call;
call yang tidak menemukan kecocokan tidak dikenakan biaya. Lihat [harga Fiber.ai](/id/docs/agent/connect/fiber#pricing).

Similarweb menagih dalam data credit (kira-kira satu per metrik × baris × bulan),
sehingga harga sebuah call mengikuti nilai `numResults`/`months` — 1 hingga 15 credit
per call. Anda ditagih sebanyak credit yang dilaporkan Similarweb untuk setiap
call; call yang tidak mengembalikan data tidak dikenakan biaya. Lihat [harga Similarweb](/id/docs/agent/connect/similarweb#pricing).

Baselayer menagih per order, dan tarifnya bergantung pada jenis operasinya: KYB
business search seharga $1.00, UCC lien search $2.00 per negara bagian yang
dicari, pencarian dokumen litigasi/kepailitan $1.00 per kategori, penyaringan
watchlist $0.10–$0.25 per daftar yang diminta, klasifikasi industri dan
analisis situs web masing-masing $0.35, kehadiran web dihitung dari total
analisis yang dipilih (masing-masing $0.15–$0.35), dan international business
search $4.00. Pembacaan lanjutan atas business search sebelumnya (business
lookup, officers, registrations, officer reverse lookup) tidak dikenakan biaya. Lihat [harga Baselayer](/id/docs/agent/connect/baselayer#pricing).

  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="Profile Anthropic: total funding and estimated monthly web traffic.",
      data_sources=[{"provider": "fiber"}, {"provider": "similarweb"}],
      output_schema={
          "type": "object",
          "required": ["company"],
          "properties": {
              "company": {
                  "type": "object",
                  "required": ["name", "totalFunding", "monthlyVisits"],
                  "properties": {
                      "name": {"type": "string"},
                      "totalFunding": {"type": "string", "description": "from Fiber.ai"},
                      "monthlyVisits": {"type": "number", "description": "from Similarweb"},
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

<div id="combining-providers">
  ### Menggabungkan provider
</div>

Attach partner sebanyak yang dibutuhkan tugas Anda. Exa Agent akan memanggil masing-masing partner pada bidang yang paling dikuasainya dan memadukan hasilnya dengan web search menjadi satu jawaban terstruktur:

```json theme={null}
{
  "dataSources": [
    { "provider": "similarweb" },
    { "provider": "fiber" },
    { "provider": "harmonic" }
  ]
}
```

Untuk panduan lengkap, termasuk cara menyusun query dan `outputSchema` agar setiap
partner terpicu, lihat [Menggabungkan provider](/id/docs/agent/connect/combining-providers).
