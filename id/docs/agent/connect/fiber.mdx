[Fiber.ai](https://fiber.ai) adalah platform data B2B dengan data terkini tentang 40 juta+
perusahaan, 850 juta+ orang, dan 30 juta+ lowongan kerja. Telusuri data perusahaan, orang, dan
lowongan kerja secara langsung, serta lengkapi data yang belum utuh dengan work email, personal email, dan
nomor telepon.

Attach `fiber` ke sebuah run [Exa Agent](/id/docs/agent/quickstart) melalui
[Exa Connect](/id/docs/agent/connect/overview), dan agent akan melakukan kueri ke
Fiber.ai bersamaan dengan Exa web search.

<div id="use-it-for">
  ## Gunakan untuk
</div>

* Membersihkan CRM dengan menelusuri balik work email atau personal email ke
  seseorang, atau memperkaya data perusahaan/orang yang belum lengkap.
* Melacak sinyal LinkedIn secara real-time: perpindahan pekerjaan, promosi,
  pekerjaan baru, perubahan jumlah karyawan, dan penggalangan dana.
* Menemukan posting relevan di LinkedIn, X, Instagram, TikTok, Reddit, dan
  YouTube, menarik komentar serta reaksinya, lalu memperkaya informasi kontak
  para penulisnya.
* Mencari di lebih dari 40 juta perusahaan dan 850 juta orang serta memperkaya
  data prospect dengan work email, personal email, dan nomor telepon.

<div id="provider-id">
  ## ID Provider
</div>

Gunakan nilai ini pada `dataSources`:

```text theme={null}
fiber
```

<div id="pricing">
  ## Harga
</div>

Fiber.ai menagih dalam credits dengan tarif `$0.02 / credit`, dan setiap call dikenakan
credits sesuai yang dilaporkan Fiber untuk call tersebut:

| Operasi                                 | Credits                           |
| --------------------------------------- | --------------------------------- |
| Search                                  | 2 + 1 per hasil yang dikembalikan |
| Pencarian perusahaan                    | ~2 per kandidat yang dikembalikan |
| Pencarian orang / pencarian balik email | 2                                 |
| Pengungkapan kontak                     | 2 (work email) – 5 (telepon)      |

Call yang tidak menemukan kecocokan (atau yang biayanya dikembalikan Fiber) tidak dikenakan biaya. Pilihan
parameter memengaruhi harga: `numResults` pada pencarian perusahaan menentukan berapa banyak
kandidat yang Anda bayar, dan jumlah hasil pada search menjadi penentu utama cost-nya.

<div id="example">
  ## Contoh
</div>

Bangun daftar prospek B2B berisi perusahaan fintech tahap Series A di New York dengan 50–200 karyawan.

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="I'm building a B2B sales prospecting list using a B2B company database. Find Series A fintech companies in New York with 50-200 employees, and for each return the company's LinkedIn profile, domain, employee count, and funding stage.",
      data_sources=[{"provider": "fiber"}],
      output_schema={
          "type": "object",
          "required": ["companies"],
          "properties": {
              "companies": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["name", "domain", "employeeCount", "fundingStage"],
                      "properties": {
                          "name": {"type": "string"},
                          "domain": {"type": "string"},
                          "employeeCount": {"type": "number"},
                          "fundingStage": {"type": "string"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

  ```javascript JavaScript theme={null}

    },
  });
  ```
