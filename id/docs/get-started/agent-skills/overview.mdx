Exa skills mengajarkan coding agent cara melakukan search, mengambil konten, dan membangun aplikasi dengan API Exa. Temukan semuanya di repositori open-source [exa-labs/agent-skills](https://github.com/exa-labs/agent-skills).

Setiap skill berisi file markdown yang mengikuti standar terbuka [Agent Skills](https://agentskills.io), sehingga file yang sama bisa dipasang di agent mana pun yang kompatibel.

## Pasang {#install}

Instal semua skill Exa sekaligus:

```bash theme={null}
npx skills add exa-labs/agent-skills
```

<Card title="Dapatkan Exa API key Anda" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  Buat key di dashboard. Akun baru langsung mendapatkan credits gratis.
</Card>

<Note>
  Setel key Anda sebagai `EXA_API_KEY` di lingkungan agent Anda.
</Note>

Atau buka salah satu halaman skill di bawah ini dan salin setup prompt-nya ke agent Anda. Prompt tersebut akan menginstal skill tersebut dan memverifikasi API key Anda tanpa menampilkannya.
