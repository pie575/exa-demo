Exa API menandai kegagalan dengan status code HTTP standar dan error body dalam format JSON.

<div id="http-status-codes">
  ## Kode status HTTP
</div>

| Kode                        | Arti                                                                                                                            | Yang harus dilakukan                                                                                                                                          |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `400` Bad Request           | Body, parameter query, header, atau kombinasi opsi tidak valid.                                                                 | Perbaiki permintaan berdasarkan pesan yang dikembalikan.                                                                                                      |
| `401` Unauthorized          | API key tidak disertakan atau tidak valid.                                                                                      | Periksa header autentikasi dan API key.                                                                                                                       |
| `402` Payment Required      | Credits habis atau anggaran pengeluaran terlampaui.                                                                             | [Isi ulang credits](https://dashboard.exa.ai) atau hubungi administrator team Anda.                                                                           |
| `403` Forbidden             | API key tidak memiliki akses ke fitur yang diminta, atau permintaan diblokir oleh kebijakan.                                    | Periksa pesan yang dikembalikan dan akses fitur pada paket Anda.                                                                                              |
| `404` Not Found             | Rute atau sumber daya yang diminta tidak ada.                                                                                   | Periksa endpoint dan ID sumber daya.                                                                                                                          |
| `409` Conflict              | Permintaan bertentangan dengan status saat ini — misalnya, Webset dengan `externalId` yang sama sudah ada.                      | Ambil sumber daya yang sudah ada atau gunakan pengenal yang berbeda.                                                                                          |
| `422` Unprocessable Entity  | Query pratinjau Websets tidak dapat diuraikan menjadi entitas dan criteria yang valid.                                          | Ubah susunan kata pada query pratinjau.                                                                                                                       |
| `429` Too Many Requests     | API key, team, atau jaringan Anda melampaui limit rate atau concurrency.                                                        | Kurangi request rate Anda; tunggu selama `Retry-After` detik jika tersedia, jika tidak gunakan exponential backoff.                                           |
| `500` Internal Server Error | Terjadi kesalahan server yang tidak terduga.                                                                                    | Coba lagi setelah jeda singkat. Hubungi dukungan jika masih berlanjut.                                                                                        |
| `503` Service Unavailable   | Exa untuk sementara melebihi kapasitas (`SERVICE_OVERLOADED`) atau tidak tersedia. Permintaan tidak diproses dan tidak ditagih. | Coba lagi dengan exponential backoff. Hal ini tidak bergantung pada request rate Anda, jadi menguranginya tidak membantu — yang membantu adalah mencoba lagi. |
| `504` Gateway Timeout       | Permintaan melampaui batas waktu pemrosesannya.                                                                                 | Coba lagi permintaan tersebut atau persempit scope-nya.                                                                                                       |

<Note>
  Kegagalan di tingkat URL dari `/contents` dilaporkan pada field `statuses` dalam respons `200` yang berhasil, bukan sebagai kesalahan di tingkat permintaan. Lihat [Content fetch status tags](#content-fetch-status-tags).
</Note>

<div id="error-response-structure">
  ## Struktur respons error
</div>

Respons error mengembalikan `requestId`, pesan `error` yang mudah dibaca manusia, dan `tag` yang dapat diproses mesin:

```json theme={null}
{
  "requestId": "67207943fab9832d162b5317f4cca830",
  "error": "Invalid request body | Validation error: Invalid value for type",
  "tag": "INVALID_REQUEST_BODY"
}
```

<Note>
  Sertakan `requestId` saat menghubungi tim dukungan agar pemecahan masalah lebih cepat.
</Note>

Kumpulan tag bersifat terbuka dan nama tag sudah cukup jelas dengan sendirinya. Lakukan percabangan berdasarkan kode status HTTP terlebih dahulu, dan perlakukan tag yang tidak dikenali sebagai detail tambahan, bukan sebagai kegagalan parsing.

<div id="account-billing-and-access">
  ### Akun, billing, dan akses
</div>

| Tag                       | Kode HTTP | Deskripsi                                                                                                                              |
| ------------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `INVALID_API_KEY`         | `401`     | API key tidak disertakan, kosong, atau tidak valid.                                                                                    |
| `NO_MORE_CREDITS`         | `402`     | Akun tidak memiliki sisa credits — isi ulang di [dashboard.exa.ai](https://dashboard.exa.ai).                                          |
| `API_KEY_BUDGET_EXCEEDED` | `402`     | API key telah melampaui batas anggaran pengeluarannya — hubungi administrator team Anda.                                               |
| `TEAM_BUDGET_EXCEEDED`    | `402`     | Team telah melampaui anggaran pengeluaran untuk periode billing saat ini.                                                              |
| `FEATURE_DISABLED`        | `403`     | Endpoint, search type, atau opsi yang diminta tidak tersedia untuk paket Anda.                                                         |
| `PROHIBITED_CONTENT`      | `403`     | Permintaan ditolak oleh moderasi keamanan konten.                                                                                      |
| `CONTENT_FILTER_ERROR`    | `403`     | Konten ditolak oleh kebijakan keamanan saat pemrosesan.                                                                                |
| `RATE_LIMIT_EXCEEDED`     | `429`     | API key, team, atau jaringan Anda melampaui rate limit-nya — kurangi request rate Anda.                                                |
| `SERVICE_OVERLOADED`      | `503`     | Exa sedang kelebihan kapasitas untuk sementara dan membatalkan permintaan sebelum memprosesnya — coba lagi dengan exponential backoff. |

<div id="request-validation">
  ### Validasi permintaan
</div>

| Tag                       | Kode HTTP | Deskripsi                                                                    |
| ------------------------- | --------- | ---------------------------------------------------------------------------- |
| `INVALID_REQUEST_BODY`    | `400`     | Body JSON tidak lolos validasi schema.                                       |
| `INVALID_REQUEST`         | `400`     | Opsi saling bertentangan, atau fitur beta digunakan tanpa header `Exa-Beta`. |
| `INVALID_NUM_RESULTS`     | `400`     | `numResults` harus ≤ 100 jika highlights diminta.                            |
| `NUM_RESULTS_EXCEEDED`    | `400`     | Jumlah hasil yang diminta melebihi limit paket Anda.                         |
| `INVALID_JSON_SCHEMA`     | `400`     | Schema output yang diberikan tidak valid.                                    |
| `SUBPAGES_LIMIT_EXCEEDED` | `400`     | `/contents` hanya mengizinkan maksimal 100 subhalaman per permintaan.        |

<div id="payment-protocols">
  ### Protokol pembayaran
</div>

Permintaan yang dibayar melalui x402 atau MPP juga dapat mengembalikan:

| Tag                        | Kode HTTP | Deskripsi                                                |
| -------------------------- | --------- | -------------------------------------------------------- |
| `X402_PAYMENT_REQUIRED`    | `402`     | Pembayaran diperlukan.                                   |
| `X402_INVALID_SIGNATURE`   | `400`     | Signature pembayaran x402 tidak valid.                   |
| `X402_VERIFICATION_FAILED` | `402`     | Pembayaran x402 tidak dapat diverifikasi.                |
| `MPP_VERIFICATION_FAILED`  | `402`     | Pembayaran MPP tidak dapat diverifikasi.                 |
| `X402_TOO_MANY_UNPAID`     | `429`     | Terlalu banyak permintaan x402 yang menunggu pembayaran. |
| `X402_WALLET_RATE_LIMITED` | `429`     | Wallet x402 melampaui rate limit-nya.                    |
| `X402_INTERNAL_ERROR`      | `500`     | Exa tidak dapat membuat persyaratan pembayaran x402.     |

<div id="content-fetch-status-tags">
  ## Content fetch status tags
</div>

Ketika `/contents` menerima beberapa URL, satu URL bisa saja gagal sementara URL lainnya berhasil. Kegagalan di level URL dikembalikan pada field `statuses` dan tidak membuat permintaan menjadi gagal:

```json theme={null}
{
  "results": [],
  "statuses": [
    {
      "id": "https://example.com",
      "status": "error",
      "error": {
        "tag": "CRAWL_NOT_FOUND",
        "httpStatusCode": 404
      }
    }
  ]
}
```

`httpStatusCode` menjelaskan halaman target, bukan respons `/contents`.

| Tag                       | Deskripsi                                                       | Cara menangani                                                       |
| ------------------------- | --------------------------------------------------------------- | -------------------------------------------------------------------- |
| `CRAWL_NOT_FOUND`         | Halaman target tidak ditemukan.                                 | Pastikan URL sudah benar dan dapat diakses.                          |
| `CRAWL_HTTP_{status}`     | Target mengembalikan error HTTP, misalnya `CRAWL_HTTP_403`.     | Tangani status target yang disertakan di dalamnya.                   |
| `CRAWL_TIMEOUT`           | Crawl melebihi batas waktu saat mengambil halaman target.       | Ulangi permintaan atau coba lagi nanti.                              |
| `CRAWL_LIVECRAWL_TIMEOUT` | Retrieval langsung melebihi `livecrawlTimeout` yang Anda minta. | Naikkan `livecrawlTimeout` atau sesuaikan `maxAgeHours`.             |
| `SOURCE_NOT_AVAILABLE`    | Akses ke source ditolak atau source tidak tersedia.             | Periksa apakah source memerlukan autentikasi atau bersifat terbatas. |
| `UNSUPPORTED_URL`         | Skema URL tidak didukung untuk pengambilan konten.              | Gunakan URL HTTP atau HTTPS standar.                                 |
| `CRAWL_UNKNOWN_ERROR`     | Crawl gagal karena alasan lain.                                 | Ulangi permintaan; hubungi dukungan jika terus terjadi.              |

Tag status ini khusus untuk `/contents`; `/search` tidak mengembalikan field `statuses`.

<div id="getting-help">
  ## Mendapatkan bantuan
</div>

* Periksa [Status Exa](/id/docs/admin/status) jika error `500`, `503`, atau `504` terus terjadi.
* Periksa [Rate Limit](/id/docs/admin/billing#rate-limits) untuk mengetahui limit yang berlaku saat ini.
* Tinjau [referensi API](/id/docs/reference/search) endpoint terkait untuk mengetahui persyaratan permintaan.
* Hubungi [hello@exa.ai](mailto:hello@exa.ai) dengan menyertakan status respons, error body, dan `requestId`.
