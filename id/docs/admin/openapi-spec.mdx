<Note>
  Spesifikasi OpenAPI mentah adalah acuan utama untuk schema permintaan dan respons. Halaman
  referensi yang dihasilkan otomatis mungkin tidak memuat resep, catatan migrasi, dan nilai default yang direkomendasikan; gunakan panduan dan
  contoh untuk arahan integrasi terkini seperti `type: "auto"`, highlights, dan pengaturan
  freshness. Tautan ini selalu mengarah ke spesifikasi yang disajikan oleh deployment dokumentasi ini.
</Note>
