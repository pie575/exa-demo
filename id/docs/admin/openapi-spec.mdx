<Note>
  Spesifikasi OpenAPI mentah adalah acuan utama untuk schema permintaan dan response. Halaman
  referensi yang dihasilkan otomatis mungkin tidak memuat resep, catatan migrasi, dan default yang direkomendasikan; gunakan panduan dan
  contoh untuk instruksi integrasi terkini seperti pengaturan `type: "auto"`, kutipan, dan kebaruan.
  Tautan ini selalu mengarah ke spesifikasi yang disajikan oleh deployment dokumentasi ini.
</Note>
