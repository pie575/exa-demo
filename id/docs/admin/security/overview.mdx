Exa menaruh perhatian serius pada keamanan dan privasi data. Kami bangga telah tersertifikasi SOC 2 Type II, yang menunjukkan komitmen kami untuk menjaga praktik dan kontrol keamanan informasi yang ketat.

Hubungi kami di [sales@exa.ai](mailto:sales@exa.ai) untuk membahas paket Enterprise jika Anda tertarik dengan [Zero Data Retention](/id/docs/admin/security/zero-data-retention), [kepatuhan HIPAA](/id/docs/admin/security/hipaa), atau solusi keamanan data khusus lainnya.

Kunjungi [Trust Center](https://trust.exa.ai) kami untuk melihat laporan SOC 2, Data Processing Agreement, dan dokumentasi keamanan lainnya.

<div id="regional-access-restrictions">
  ## Pembatasan akses regional
</div>

Untuk mematuhi sanksi dan pembatasan perdagangan, Exa memblokir akses API dari negara dan wilayah yang terkena sanksi atau dibatasi, termasuk Krimea, Kuba, Iran, Korea Utara, Rusia, Suriah, Ukraina, dan Venezuela.

Permintaan dari lokasi tersebut dapat diblokir oleh Cloudflare sebelum sampai ke Exa. Dalam kasus tersebut, respons yang diterima bisa berupa halaman blokir WAF Cloudflare beserta Ray ID, bukan JSON error API Exa yang standar.

Jika Anda menduga lokasi geografis lalu lintas Anda terdeteksi keliru, hubungi [hello@exa.ai](mailto:hello@exa.ai) dengan menyertakan alamat IP sumber, negara atau wilayah, timestamp permintaan, dan Cloudflare Ray ID Anda.
