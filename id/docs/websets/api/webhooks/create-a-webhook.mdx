description: "Membuat Webhook yang mengirimkan events yang dipilih ke URL Anda
  begitu events tersebut terjadi.


  Response menyertakan `secret` penandatanganan yang digunakan untuk
  memverifikasi deliveries; secret ini hanya dikembalikan saat pembuatan."
---

<Warning>
  **Redirect tidak diikuti.** Webhook deliveries dikirim langsung ke URL yang
  terdaftar. Jika endpoint Anda merespons dengan redirect 3xx, delivery
  tersebut akan dianggap gagal. Selalu daftarkan URL tujuan akhir.
</Warning>
