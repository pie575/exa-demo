description: "Membuat `Monitor` baru untuk menjaga Websets Anda selalu
  diperbarui dengan data terkini.


  Monitor berjalan otomatis sesuai jadwal yang Anda tentukan agar Websets Anda
  tetap mutakhir tanpa campur tangan manual:


  - **Menemukan konten baru**: Menjalankan operasi `search` untuk menemukan item
  baru yang sesuai dengan criteria Anda

  - **Memperbarui konten yang ada**: Menjalankan operasi `refresh` untuk
  memperbarui contents dan enrichment pada item

  - **Penjadwalan otomatis**: Mengonfigurasi ekspresi `cron` dan `timezone`
  untuk kendali penjadwalan yang presisi"
