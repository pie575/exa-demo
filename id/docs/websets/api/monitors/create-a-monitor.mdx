description: "Membuat `Monitor` baru agar Websets Anda terus diperbarui dengan
  data terbaru.


  Monitors berjalan otomatis sesuai jadwal yang Anda tentukan agar Websets Anda
  tetap mutakhir tanpa campur tangan manual:


  - **Menemukan konten baru**: Menjalankan operasi `search` untuk menemukan item
  baru yang sesuai dengan kriteria Anda

  - **Memperbarui konten yang ada**: Menjalankan operasi `refresh` untuk
  memperbarui contents dan enrichments item

  - **Penjadwalan otomatis**: Mengonfigurasi ekspresi `cron` dan `timezone`
  untuk kontrol penjadwalan yang presisi"
