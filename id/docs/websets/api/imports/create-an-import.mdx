title: "Membuat impor"
openapi: "/id/docs/exa-spec.yaml POST /v0/imports"
timestamp: false
description: "Membuat impor baru untuk mengunggah data Anda ke Websets. Impor
  dapat digunakan untuk:


  - **Enrich**: Memperkaya data Anda dengan informasi tambahan menggunakan mesin
  enrichment berbasis AI kami

  - **Search**: Melakukan query pada data Anda menggunakan agentic search
  Websets dengan filter bahasa alami

  - **Exclude**: Mencegah hasil duplikat atau yang sudah diketahui muncul dalam
  pencarian Anda


  Setelah impor dibuat, Anda dapat mengunggah data ke `uploadUrl` yang
  dikembalikan hingga `uploadValidUntil` (secara default 1 jam)."
