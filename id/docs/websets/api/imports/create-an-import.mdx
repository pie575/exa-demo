description: "Membuat import baru untuk mengunggah data Anda ke Websets. Import
  dapat digunakan untuk:


  - **Enrich**: Memperkaya data Anda dengan informasi tambahan menggunakan mesin
  enrichment bertenaga AI kami

  - **Search**: Menelusuri data Anda dengan agentic search dari Websets
  menggunakan filter bahasa alami

  - **Exclude**: Mencegah hasil duplikat atau yang sudah diketahui muncul pada
  search Anda


  Setelah import dibuat, Anda dapat mengunggah data ke `uploadUrl` yang
  dikembalikan hingga `uploadValidUntil` (secara bawaan 1 jam)."
