Pasang Exa di Claude Code atau hubungkan ke Claude Web, Desktop, dan Cowork agar Claude memiliki akses ke informasi terkini dari web. Claude dapat mencari dengan bahasa alami, membaca halaman yang penting, dan memanfaatkan sumber-sumber tersebut selama bekerja.

<div id="install-exa">
  ## Instal Exa
</div>

<div id="work-with-whats-on-the-web-right-now">
  ## Manfaatkan apa yang ada di web saat ini
</div>

Di Claude Code, Exa dapat melakukan search terhadap dokumentasi terkini, issue, changelog, dan contoh nyata sambil Anda bekerja di repository. Integrasi yang sama memberi Claude Web, Desktop, dan Cowork akses ke berita terbaru, riset, informasi perusahaan, detail produk, serta sumber lain yang mungkin belum tersedia dalam konteks.

```text theme={null}
Kami masih memakai Tailwind v3. Gunakan Exa untuk mencari dan membaca panduan
upgrade resmi Tailwind v4, lalu migrasikan proyek ini ke v4.
```

Claude Code dapat memanfaatkan apa yang ditemukannya untuk melakukan perubahan di basis kode Anda. Pada klien Claude lainnya, sumber yang sama bisa digunakan dalam jawaban, artifact, dan tugas Cowork.

Pola yang sama berlaku setiap kali jawaban bergantung pada sumber web terkini atau sumber web tertentu:

* &quot;Temukan catatan rilis terbaru untuk dependensi ini dan rangkum perubahan yang bersifat breaking.&quot;
* &quot;Cari riset primer terbaru tentang inference-time scaling dan bandingkan metodenya.&quot;
* &quot;Baca dokumentasi webhook Stripe yang berlaku saat ini dan jelaskan perilaku retry yang direkomendasikan.&quot;
* &quot;Temukan halaman harga resmi untuk produk-produk ini dan bandingkan paket dasarnya.&quot;

<div id="research-without-leaving-claude">
  ## Riset tanpa perlu keluar dari Claude
</div>

Mintalah hasil yang Anda inginkan dan beri tahu Claude jenis sumber apa yang penting:

```text theme={null}
Bandingkan layanan terkelola, lisensi, dan harga dari basis data vektor
open source utama. Gunakan sumber primer terkini dan cantumkan sitasinya.
```

Claude dapat menggunakan Exa sepanjang percakapan untuk menemukan dan membaca sumber yang diperlukan untuk suatu tugas. Gunakan ini untuk riset teknis, analisis kompetitif, pemetaan pasar, riset perusahaan, atau pertanyaan apa pun yang jawabannya tersebar di berbagai situs web.

<div id="use-exa-in-cowork">
  ## Menggunakan Exa di Cowork
</div>

Konektor yang sama juga tersedia di Cowork. Berikan Claude tugas yang membutuhkan informasi dari luar, dan Claude bisa melakukan search atau membaca halaman web sambil mengolah file Anda dan tool lain yang terhubung.

```text theme={null}
Tinjau ringkasan kompetitif ini, verifikasi setiap klaim harga dengan
halaman vendor terkini menggunakan Exa, lalu perbarui dokumen dengan citations.
```

<div id="prefer-mcp-directly">
  ## Lebih suka langsung memakai MCP?
</div>

Jika Anda mengonfigurasi Claude secara manual atau menggunakan klien MCP lain, Anda dapat terhubung langsung ke MCP server milik Exa:

```bash theme={null}
claude mcp add --transport http exa https://mcp.exa.ai/mcp
```

Lihat [Exa MCP](/id/docs/get-started/exa-mcp) untuk klien lainnya, opsi konfigurasi, dan tool yang tersedia.
