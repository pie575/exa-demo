Hadirkan Exa di Slack tim Anda. Tag **@Exa** di channel atau thread mana pun dengan pertanyaan Research, tugas list building, atau permintaan Enrichment. Exa akan menelusuri web, membaca sources, lalu membalas langsung di thread dengan jawaban yang disertai kutipan sumber.

## Memulai {#get-started}

### Instalasi {#installation}

1. Buka [Dashboard &gt; Management &gt; Exa in Slack](https://dashboard.exa.ai/integrations/slack), lalu klik **Install**.

<img src="/docs/images/integrations/exa-slack/dashboard-install.png" alt="Halaman Exa in Slack di dashboard Exa, dengan tombol Install" width="3414" height="900" data-path="images/integrations/exa-slack/dashboard-install.png" />

2. Alur OAuth Slack akan terbuka. Pilih workspace tempat Anda ingin memakai Exa, lalu klik **Allow**.

<img src="/docs/images/integrations/exa-slack/oauth-approval.png" alt="Layar persetujuan OAuth Slack untuk aplikasi Exa, menampilkan pemberitahuan &#x22;App is not approved by Slack&#x22;, pemilih workspace, permissions yang diminta, dan tombol Allow" width="1820" height="1180" data-path="images/integrations/exa-slack/oauth-approval.png" />

<Note>
  Pemberitahuan merah **&quot;App is not approved by Slack&quot;** memang wajar muncul dan aman diabaikan. Itu hanya berarti
  Exa belum terdaftar di Slack Marketplace publik, bukan berarti ada masalah.
</Note>

3. Setelah terpasang, undang @Exa ke sebuah channel (atau kirim DM langsung) dan mulai ajukan pertanyaan.

## Cara menggunakan Exa dari Slack {#how-to-use-exa-from-slack}

Di channel mana pun yang sudah ditambahkan Exa, sebut @Exa beserta pertanyaan Anda:

```text theme={null}
@Exa find all Series A fintech startups in SF
```

Exa membalas pertanyaan Anda di dalam thread.

### Follow-up {#follow-ups}

Setelah Exa menjawab di sebuah thread, cukup balas di thread tersebut untuk melanjutkan percakapan. Anda tidak perlu menyebut @Exa lagi. Exa mengingat percakapan, sehingga follow-up akan mengacu pada jawaban sebelumnya. Siapa pun di thread tersebut bisa mengirim follow-up.

### Pesan langsung {#direct-messages}

Anda juga bisa mengirim pesan langsung ke Exa lewat DM. Di sana Anda tidak perlu menyebut Exa sama sekali. Setiap pesan yang Anda kirim akan memulai permintaan baru, yang dijawab dalam thread di bawah pesan tersebut. Balas di thread itu untuk melanjutkan percakapan tersebut.

### Membatalkan run {#cancelling-a-run}

Selagi run sedang berjalan, balas di thread dan minta Exa untuk menghentikan run tersebut. Tidak perlu menyebut Exa.

```text theme={null}
Stop the current run
```

### Provider Exa Connect {#exa-connect-providers}

Exa secara otomatis menyertakan data provider [Exa Connect](/id/docs/agent/connect/overview) jika relevan dengan pertanyaan Anda. Untuk menggunakan provider tertentu, sebutkan provider tersebut dalam pesan Anda:

```text theme={null}
@Exa find me all AI infrastructure startups that raised funding this quarter using Fiber.ai
```

Untuk melihat daftar semua data provider yang tersedia, cukup tanyakan kepada Exa.

## Keywords {#keywords}

Gunakan ini di dalam thread yang diikuti Exa. Perintah bisa ditulis setelah sebutan `@Exa` atau langsung
di awal pesan:

| Keyword           | Fungsi                                                                                                                      |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `!max <message>`  | Menjalankan permintaan ini dengan effort maksimum, dirancang untuk membuat daftar yang sangat besar.                        |
| `mute`            | Menghentikan Exa merespons balasan tanpa sebutan di dalam thread. Sebutan @Exa yang eksplisit tetap berfungsi.              |
| `unmute`          | Melanjutkan kembali follow-up thread setelah `mute`.                                                                        |
| `sleep`           | Menghentikan Exa sepenuhnya di thread tersebut. Sebut @Exa untuk membangunkannya.                                           |
| `aside <message>` | Mengirim komentar sampingan yang diabaikan Exa, berguna untuk berbicara dengan rekan tim di thread yang sedang diikuti Exa. |
| `help`            | Menampilkan petunjuk penggunaan.                                                                                            |

## Permissions {#permissions}

Aplikasi Exa untuk Slack meminta scope berikut:

| Permission             | Akses Slack                                                            | Alasan Exa membutuhkannya                                                                                              |
| ---------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `app_mentions:read`    | Melihat pesan yang langsung menyebut @Exa                              | Memulai permintaan saat seseorang menyebut Exa di channel atau thread                                                  |
| `assistant:write`      | Bertindak sebagai App Agent di Slack                                   | Memakai pengalaman agent Slack dan melakukan stream jawaban ke DM dan thread channel                                   |
| `channels:history`     | Melihat pesan di public channel tempat Exa ditambahkan                 | Menerima balasan thread di public channel agar follow-up tetap berjalan tanpa perlu disebut lagi                       |
| `channels:read`        | Melihat informasi dasar tentang public channel                         | Menemukan public channel yang sudah berisi Exa saat memilih tempat menyinkronkan sesi web                              |
| `chat:write`           | Mengirim pesan sebagai aplikasi Exa                                    | Mengirim pesan awal thread, jawaban, pembaruan progres, konfirmasi, dan pesan tersinkron dari web                      |
| `chat:write.customize` | Menyesuaikan nama dan avatar pesan yang dibuat aplikasi                | Menampilkan nama dan foto profil peserta web pada pesan yang disinkronkan dari aplikasi web                            |
| `files:read`           | Melihat file yang dibagikan di percakapan tempat Exa ditambahkan       | Membaca file yang dilampirkan pada pertanyaan                                                                          |
| `files:write`          | Mengunggah, mengedit, dan menghapus file sebagai aplikasi Exa          | Melampirkan file hasil, seperti tabel yang di-export, ke jawaban                                                       |
| `groups:history`       | Melihat pesan di private channel tempat Exa ditambahkan                | Menerima balasan thread di private channel agar follow-up tetap berjalan tanpa perlu disebut lagi                      |
| `groups:read`          | Melihat informasi dasar tentang private channel tempat Exa ditambahkan | Menemukan private channel yang memenuhi syarat dan memverifikasi keanggotaan saat memilih tujuan sinkronisasi sesi web |
| `im:history`           | Melihat pesan dalam pesan langsung dengan Exa                          | Menerima permintaan DM dan balasan follow-up                                                                           |
| `im:write`             | Memulai pesan langsung                                                 | Membuka DM Exa milik pengguna terverifikasi saat mereka memilihnya sebagai tujuan sinkronisasi sesi web                |
| `users:read`           | Melihat orang dan profil dasar Slack mereka                            | Mengaitkan sebutan dengan nama dan memakai foto profil Slack peserta web pada pesan tersinkron                         |
| `users:read.email`     | Melihat alamat email anggota workspace                                 | Mencocokkan akun Slack dan Exa untuk atribusi team serta gambar profil pesan web yang disesuaikan                      |

<Note>
  `channels:read`, `groups:read`, dan `im:write` mengaktifkan penemuan tujuan untuk sinkronisasi web ke Slack.
  Instalasi yang sudah ada dapat terus memakai thread Slack mereka saat ini tanpa scope ini, tetapi
  harus menghubungkan ulang sebelum memakai tujuan terkait. `chat:write.customize` bersifat opsional saat
  runtime: tanpanya, pesan tersinkron dari web tetap memakai identitas standar aplikasi Exa dan mencantumkan
  nama peserta di body pesan.
</Note>

Exa hanya menerima pesan dari channel tempat ia diundang secara eksplisit dan dari DM miliknya sendiri.
