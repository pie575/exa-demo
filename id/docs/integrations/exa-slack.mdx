Hadirkan Exa ke Slack Team Anda. Tag **@Exa** di channel atau thread mana pun dengan pertanyaan riset, tugas list building, atau permintaan enrichment. Exa akan mencari di web, membaca sumbernya, dan membalas langsung di thread dengan jawaban yang disertai kutipan sumber.

<div id="get-started">
  ## Memulai
</div>

<div id="installation">
  ### Instalasi
</div>

1. Buka [Dashboard &gt; Management &gt; Exa in Slack](https://dashboard.exa.ai/integrations/slack), lalu klik **Install**.

<img src="/docs/images/integrations/exa-slack/dashboard-install.png" alt="Halaman Exa in Slack di dashboard Exa, dengan tombol Install" width="3414" height="900" data-path="images/integrations/exa-slack/dashboard-install.png" />

2. Alur OAuth Slack akan terbuka. Pilih workspace tempat Anda ingin memasang Exa, lalu klik **Allow**.

<img src="/docs/images/integrations/exa-slack/oauth-approval.png" alt="Layar persetujuan OAuth Slack untuk Exa app, menampilkan pemberitahuan &#x22;App is not approved by Slack&#x22;, pemilih workspace, izin yang diminta, dan tombol Allow" width="1820" height="1180" data-path="images/integrations/exa-slack/oauth-approval.png" />

<Note>
  Pemberitahuan merah **&quot;App is not approved by Slack&quot;** memang wajar muncul dan aman diabaikan. Itu hanya berarti
  Exa belum tersedia di Slack Marketplace publik, bukan karena ada yang bermasalah.
</Note>

3. Setelah terpasang, undang @Exa ke sebuah channel (atau kirimi DM langsung) dan mulailah mengajukan pertanyaan.

<div id="how-to-use-exa-from-slack">
  ## Cara menggunakan Exa dari Slack
</div>

Di channel mana pun yang sudah ditambahkan Exa, mention @Exa beserta pertanyaan Anda:

```text theme={null}
@Exa find all Series A fintech startups in SF
```

Exa membalas pertanyaan Anda di dalam thread.

<div id="follow-ups">
  ### Follow-ups
</div>

Setelah Exa menjawab di sebuah thread, cukup balas di thread tersebut untuk melanjutkan percakapan. Tidak perlu menyebut @Exa lagi. Exa mengingat percakapan sebelumnya, sehingga follow-up akan melanjutkan jawaban sebelumnya. Siapa pun di dalam thread bisa mengirim follow-up.

<div id="direct-messages">
  ### Direct messages
</div>

Anda juga bisa mengirim pesan langsung ke Exa melalui DM. Di sana Anda sama sekali tidak perlu melakukan mention. Setiap pesan yang Anda kirim akan memulai permintaan baru, yang dijawab dalam thread di bawah pesan tersebut. Balas di thread tersebut untuk melanjutkan percakapan itu.

<div id="cancelling-a-run">
  ### Membatalkan run
</div>

Saat run sedang berjalan, balas di thread dan minta Exa untuk menghentikan run tersebut. Tidak perlu mention.

```text theme={null}
Hentikan run saat ini
```

<div id="exa-connect-providers">
  ### Provider Exa Connect
</div>

Exa secara otomatis menyertakan data provider [Exa Connect](/id/docs/agent/connect/overview) jika relevan dengan pertanyaan Anda. Untuk menggunakan provider tertentu, sebutkan provider tersebut di dalam pesan Anda:

```text theme={null}
@Exa find me all AI infrastructure startups that raised funding this quarter using Fiber.ai
```

Untuk melihat daftar semua data provider yang tersedia, cukup tanyakan ke Exa.

<div id="keywords">
  ## Kata Kunci
</div>

Gunakan kata kunci ini di thread yang diikuti Exa. Perintah bisa ditulis setelah mention `@Exa` atau langsung di awal pesan:

| Kata Kunci        | Fungsi                                                                                                                |
| ----------------- | --------------------------------------------------------------------------------------------------------------------- |
| `!max <message>`  | Menjalankan permintaan ini dengan effort maksimal, dirancang untuk menyusun daftar yang sangat besar.                 |
| `mute`            | Membuat Exa berhenti merespons balasan tanpa mention di thread. Mention @Exa secara eksplisit tetap berfungsi.        |
| `unmute`          | Mengaktifkan kembali follow-ups di thread setelah `mute`.                                                             |
| `sleep`           | Menghentikan Exa sepenuhnya di thread. Mention @Exa untuk membangunkannya.                                            |
| `aside <message>` | Mengirim komentar sampingan yang diabaikan Exa, berguna untuk berdiskusi dengan rekan tim di thread yang diikuti Exa. |
| `help`            | Menampilkan petunjuk penggunaan.                                                                                      |

<div id="permissions">
  ## Izin
</div>

Exa app untuk Slack meminta scope berikut:

| Izin                   | Akses Slack                                                           | Mengapa Exa membutuhkannya                                                                                            |
| ---------------------- | --------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `app_mentions:read`    | Melihat pesan yang langsung menyebut @Exa                             | Memulai permintaan saat seseorang menyebut Exa di channel atau thread                                                 |
| `assistant:write`      | Bertindak sebagai App Agent di Slack                                  | Menggunakan pengalaman agent Slack dan mengalirkan jawaban ke direct messages serta thread channel                    |
| `channels:history`     | Melihat pesan di channel publik tempat Exa ditambahkan                | Menerima balasan thread di channel publik agar follow-ups tetap berjalan tanpa perlu menyebut ulang                   |
| `channels:read`        | Melihat informasi dasar tentang channel publik                        | Menemukan channel publik yang sudah memuat Exa saat memilih tujuan sinkronisasi sesi web                              |
| `chat:write`           | Mengirim pesan sebagai Exa app                                        | Mengirim thread root, jawaban, pembaruan progres, konfirmasi, dan pesan hasil sinkronisasi web                        |
| `chat:write.customize` | Menyesuaikan nama dan avatar pesan yang ditulis aplikasi              | Menampilkan nama dan foto profil peserta web pada pesan yang disinkronkan dari aplikasi web                           |
| `files:read`           | Melihat file yang dibagikan di percakapan tempat Exa ditambahkan      | Membaca file yang dilampirkan pada pertanyaan                                                                         |
| `files:write`          | Mengunggah, mengedit, dan menghapus file sebagai Exa app              | Melampirkan file hasil, seperti tabel yang diekspor, ke jawaban                                                       |
| `groups:history`       | Melihat pesan di channel privat tempat Exa ditambahkan                | Menerima balasan thread di channel privat agar follow-ups tetap berjalan tanpa perlu menyebut ulang                   |
| `groups:read`          | Melihat informasi dasar tentang channel privat tempat Exa ditambahkan | Menemukan channel privat yang memenuhi syarat dan memverifikasi keanggotaan saat memilih tujuan sinkronisasi sesi web |
| `im:history`           | Melihat pesan di direct messages dengan Exa                           | Menerima permintaan DM dan balasan lanjutan                                                                           |
| `im:write`             | Memulai direct messages                                               | Membuka DM Exa milik pengguna terverifikasi saat mereka memilihnya sebagai tujuan sinkronisasi sesi web               |
| `users:read`           | Melihat orang dan profil dasar Slack mereka                           | Mencocokkan penyebutan dengan nama dan menggunakan foto profil Slack peserta web pada pesan yang disinkronkan         |
| `users:read.email`     | Melihat alamat email anggota workspace                                | Mencocokkan akun Slack dan Exa untuk atribusi team serta gambar profil pesan web yang disesuaikan                     |

<Note>
  `channels:read`, `groups:read`, dan `im:write` memungkinkan penemuan tujuan untuk sinkronisasi dari web ke Slack.
  Instalasi yang sudah ada dapat terus menggunakan thread Slack mereka saat ini tanpa scope tersebut, tetapi
  harus menghubungkan ulang sebelum memakai tujuan terkait. `chat:write.customize` bersifat opsional saat
  runtime: tanpa scope ini, pesan hasil sinkronisasi web tetap memakai identitas standar Exa app dan mencantumkan
  nama peserta di isi pesan.
</Note>

Exa hanya menerima pesan dari channel tempat ia diundang secara eksplisit dan dari direct messages miliknya sendiri.
