[Stripe Projects](https://projects.dev) memungkinkan Anda dan coding agent Anda menyediakan layanan pihak ketiga langsung dari terminal, tanpa dashboard dan tanpa salin-tempel key. Cukup satu perintah untuk membuat akun Exa dan menyinkronkan API key ke proyek Anda.

## Prasyarat {#prerequisites}

Instal Stripe CLI dan plugin Projects:

```bash theme={null}
brew install stripe/stripe-cli/stripe && stripe plugin install projects
```

Untuk platform lain dan penyiapan CLI selengkapnya, lihat [Stripe Projects](https://projects.dev).

## Memulai {#get-started}

Dari direktori proyek Anda, inisialisasi proyek, tambahkan Exa, lalu tarik credential:

```bash theme={null}
stripe projects init
stripe projects add exa/api
stripe projects env --pull
```

File `.env` Anda kini berisi `EXA_API_KEY`. [SDK Exa](/id/docs/sdks/quickstart) dan [Quickstart](/id/docs/search/quickstart) membaca variabel ini secara otomatis, sehingga kode Anda langsung berjalan tanpa perlu diubah.

<Info>
  Key ini di-provision pada akun Exa milik Anda. Kelola penggunaan, key, dan billing kapan saja melalui [Exa Dashboard](https://dashboard.exa.ai).
</Info>

## Menghubungkan team Exa yang sudah ada {#link-an-existing-exa-team}

Sudah punya akun Exa? Hubungkan terlebih dahulu agar API key di-provision pada team Anda yang sudah ada:

```bash theme={null}
stripe projects link exa
stripe projects add exa/api
```

`stripe projects link` akan membuka Exa agar Anda dapat melakukan autentikasi dan menghubungkan team Anda dengan akun Stripe Anda. Buka Exa Dashboard yang sudah tertaut kapan saja dengan `stripe projects open exa`.

## Provisioning dari coding agent Anda {#provision-from-your-coding-agent}

`stripe projects init` menulis [Agent Skill](https://projects.dev) Stripe Projects ke dalam proyek Anda, sehingga Anda dapat membiarkan agent Anda (Claude Code, Cursor, Codex, dan lainnya) menjalankan flow tersebut untuk Anda:

```text theme={null}
Gunakan Stripe Projects untuk menambahkan Exa dan menyambungkan API key-nya.
```
