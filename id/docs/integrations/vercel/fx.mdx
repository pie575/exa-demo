[fx](https://fx.sh) adalah coding agent dan CLI native dari Vercel Labs, sekaligus klien MCP. Tambahkan MCP server terkelola dari Exa untuk membekalinya dengan web search real-time dan kemampuan membaca halaman.

<div id="installation">
  ## Instalasi
</div>

<Steps>
  <Step title="Instal fx">
    ```bash theme={null}
    curl -fsSL https://fx.sh/setup.sh | bash
    ```

    Lalu masuk dengan `fx login`. Lihat [dokumentasi fx](https://fx.sh/docs) untuk opsi provider.
  </Step>

  <Step title="Tambahkan Exa">
    Jalankan fx dengan perintah `fx`, lalu tambahkan MCP server Exa dari shell interaktif:

    ```text theme={null}
    /mcp add --transport http exa https://mcp.exa.ai/mcp
    ```

    fx akan menyimpan server ke `~/.fx/mcp.json` dan memuat ulang MCP.
  </Step>

  <Step title="Verifikasi koneksi">
    ```text theme={null}
    /mcp list
    ```
  </Step>
</Steps>

<div id="configure-by-hand">
  ## Konfigurasi secara manual
</div>

fx hanya membaca MCP server dari `~/.fx/mcp.json`, jadi Anda juga bisa menambahkan Exa langsung di sana:

```json ~/.fx/mcp.json theme={null}
{
  "mcp": {
    "exa": {
      "type": "http",
      "url": "https://mcp.exa.ai/mcp"
    }
  }
}
```

Jalankan `/mcp reload` untuk menerapkan perubahan tanpa memulai ulang fx.

Paket gratis cukup untuk penggunaan ringan. Untuk menaikkan rate limit, buat API key dan tambahkan ke konfigurasi:

<Card title="Dapatkan Exa API key Anda" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  Buat key di dashboard. Akun baru mendapatkan credit gratis.
</Card>

```json ~/.fx/mcp.json theme={null}
{
  "mcp": {
    "exa": {
      "type": "http",
      "url": "https://mcp.exa.ai/mcp",
      "header_env": {
        "x-api-key": "EXA_API_KEY"
      }
    }
  }
}
```

`header_env` memetakan nama header ke sebuah variabel lingkungan, sehingga key tidak perlu disimpan di file konfigurasi.

<div id="tool-discovery">
  ## Penemuan tool
</div>

fx menemukan tool MCP secara lazy: tool dari server baru dimuat ke konteks model ketika ada giliran yang membutuhkannya, sehingga menambahkan Exa tidak menimbulkan biaya pada giliran yang tidak melakukan search di web.
