[fx](https://fx.sh) adalah coding agent native sekaligus CLI dari Vercel Labs, dan juga MCP client. Tambahkan Exa MCP server terkelola untuk membekalinya dengan web search real-time dan kemampuan membaca halaman.

## Instalasi {#installation}

<Steps>
  <Step title="Pasang fx">
    ```bash theme={null}
    curl -fsSL https://fx.sh/setup.sh | bash
    ```

    Lalu masuk dengan `fx login`. Lihat [dokumentasi fx](https://fx.sh/docs) untuk opsi provider.
  </Step>

  <Step title="Tambahkan Exa">
    Jalankan fx dengan perintah `fx`, lalu tambahkan Exa MCP server dari shell interaktif:

    ```text theme={null}
    /mcp add --transport http exa https://mcp.exa.ai/mcp
    ```

    fx menyimpan server ke `~/.fx/mcp.json` dan memuat ulang MCP.
  </Step>

  <Step title="Verifikasi koneksi">
    ```text theme={null}
    /mcp list
    ```
  </Step>
</Steps>

## Konfigurasi secara manual {#configure-by-hand}

fx hanya membaca MCP server dari `~/.fx/mcp.json`, jadi Anda juga bisa menambahkan Exa langsung di sana:

```json ~/.fx/mcp.json theme={null}
{
  "mcp": {
    "exa": {
      "type": "http",
      "url": "https://mcp.exa.ai/mcp"
    }
  }
}
```

Jalankan `/mcp reload` untuk menerapkan perubahan tanpa memulai ulang fx.

Paket gratis sudah cukup untuk penggunaan ringan. Untuk menaikkan rate limit, buat API key dan tambahkan ke config:

<Card title="Dapatkan Exa API key Anda" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  Buat key di dashboard. Akun baru mendapatkan credits gratis.
</Card>

```json ~/.fx/mcp.json theme={null}
{
  "mcp": {
    "exa": {
      "type": "http",
      "url": "https://mcp.exa.ai/mcp",
      "header_env": {
        "x-api-key": "EXA_API_KEY"
      }
    }
  }
}
```

`header_env` memetakan nama header ke sebuah variabel lingkungan, sehingga key tidak perlu disimpan di dalam file config.

## Tool discovery {#tool-discovery}

fx menemukan tool MCP secara lazy: tool dari server tidak dimuat ke konteks model sampai ada giliran yang membutuhkannya, sehingga menambahkan Exa tidak menimbulkan biaya pada giliran yang tidak melakukan search di web.
