Gunakan package `@exalabs/ai-sdk` untuk menambahkan Exa web search ke aplikasi yang dibangun dengan AI SDK dari Vercel. Cukup sediakan Exa API key, dan tool `webSearch()` akan menangani search request untuk model Anda.

<div id="install">
  ## Instalasi
</div>

```bash install.sh theme={null}
npm install @exalabs/ai-sdk
```

<div id="quick-start">
  ## Mulai cepat
</div>

```typescript quickstart.ts theme={null}
import { generateText, stepCountIs } from 'ai';
import { webSearch } from '@exalabs/ai-sdk';
import { openai } from '@ai-sdk/openai';

const { text } = await generateText({
  model: openai('gpt-5-nano'),
  prompt: 'Tell me the latest developments in AI',
  system: 'Only use web search once per turn. Answer based on the information you have.',
  tools: {
    webSearch: webSearch(),
  },
  stopWhen: stepCountIs(3),
});

console.log(text);
```

<Card title="Dapatkan Exa API key Anda" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  Buat key di dashboard. Akun baru langsung mendapatkan credits gratis.
</Card>

<Info>
  Simpan key Anda sebagai `EXA_API_KEY` sebelum menjalankan contoh ini. Package akan membaca variabel lingkungan tersebut secara otomatis.
</Info>

<div id="defaults">
  ## Default
</div>

`webSearch()` menggunakan nilai default berikut:

* `type`: `auto`
* `numResults`: `10`
* `contents.text`: `3000` karakter per hasil
* `maxAgeHours`: fallback cache default; atur opsi ini jika Anda memerlukan tingkat kebaruan (freshness) yang lebih ketat

<div id="configure-search">
  ## Konfigurasi search
</div>

Gunakan opsi berikut untuk menyetel search dan extraction konten:

```typescript configuration.ts theme={null}
const { text } = await generateText({
  model: openai('gpt-5-nano'),
  prompt: 'Find the top AI companies in Europe founded after 2018',
  tools: {
    webSearch: webSearch({
      type: 'auto',
      numResults: 6,
      category: 'company',
      contents: {
        text: { maxCharacters: 1000 },
        maxAgeHours: 1,
        summary: true,
      },
    }),
  },
  stopWhen: stepCountIs(5),
});

console.log(text);
```

<div id="search-options">
  ### Opsi search
</div>

| Opsi                                      | Deskripsi                                                                                              |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `type`                                    | Search mode: `auto`, `fast`, `instant`, `deep-lite`, `deep`, atau `deep-reasoning`.                    |
| `category`                                | Kategori konten: `company`, `publication`, `news`, `personal site`, `people`, atau `financial report`. |
| `numResults`                              | Jumlah hasil yang dikembalikan.                                                                        |
| `includeDomains` / `excludeDomains`       | Menyertakan atau mengecualikan domain tertentu.                                                        |
| `startPublishedDate` / `endPublishedDate` | Memfilter hasil berdasarkan tanggal publikasi dalam format ISO 8601.                                   |
| `includeText` / `excludeText`             | Mewajibkan atau mengecualikan teks dalam hasil.                                                        |
| `userLocation`                            | Kode negara dua huruf untuk search yang menyesuaikan lokasi.                                           |

<div id="content-options">
  ### Content options
</div>

| Opsi                                                   | Deskripsi                                                                                                      |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| `contents.text`                                        | Mengembalikan teks hasil ekstraksi. Mendukung `maxCharacters` dan `includeHtmlTags`.                           |
| `contents.summary`                                     | Mengembalikan summary yang dihasilkan AI. Mendukung `query`.                                                   |
| `contents.maxAgeHours`                                 | Gunakan konten dari cache hanya jika usianya masih dalam batas yang ditentukan; jika tidak, gunakan livecrawl. |
| `contents.livecrawlTimeout`                            | Mengatur batas waktu livecrawl.                                                                                |
| `contents.subpages` / `contents.subpageTarget`         | Merayapi subhalaman dan secara opsional menargetkan subhalaman tertentu.                                       |
| `contents.extras.links` / `contents.extras.imageLinks` | Mengembalikan tautan atau tautan gambar dari hasil.                                                            |

<div id="typescript-support">
  ## Dukungan TypeScript
</div>

Package ini sudah menyertakan tipe TypeScript:

```typescript types.ts theme={null}
import { webSearch, ExaSearchConfig, ExaSearchResult } from '@exalabs/ai-sdk';

const config: ExaSearchConfig = {
  numResults: 10,
  type: 'auto',
};

const search = webSearch(config);
```
