---

Setiap item dalam `requests` merupakan `POST` ke `/search` atau `/agent/runs` dengan `customId` yang unik di dalam batch tersebut. `customId` yang sama akan dikembalikan dalam file hasil sehingga Anda dapat memetakan baris output kembali ke data input Anda. Lihat [panduan Batch API](/id/docs/batch/quickstart) untuk workflow lengkapnya.
