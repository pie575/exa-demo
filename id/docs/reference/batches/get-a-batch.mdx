Gunakan endpoint ini untuk melakukan poll pada batch hingga statusnya menjadi `completed`, `cancelled`, atau `expired`. Saat batch selesai, `resultsUrl` berisi URL presigned berumur pendek untuk file hasil JSONL; ambil ulang batch tersebut untuk mendapatkan URL yang baru.
