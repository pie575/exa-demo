## Ringkasan {#overview}

Endpoint Mendapatkan penggunaan API key memungkinkan Anda mengambil analitik billing dan penggunaan secara detail untuk sebuah API key tertentu dalam periode waktu tertentu. Endpoint ini mengembalikan data biaya dari sistem billing Exa, sehingga memberikan gambaran resmi mengenai apa saja yang ditagihkan kepada Anda untuk API key tersebut.

## Path Parameters {#path-parameters}

* **id**: Identifier unik dari API key yang ingin diambil data penggunaannya

## Query Parameters {#query-parameters}

* **start&#95;date** (opsional): Tanggal mulai periode penggunaan dalam format ISO 8601 (mis. `2025-01-01T00:00:00Z` atau `2025-01-01`). Default-nya 30 hari yang lalu. Harus berada dalam rentang 6 bulan terakhir (180 hari).
* **end&#95;date** (opsional): Tanggal akhir periode penggunaan dalam format ISO 8601. Default-nya waktu saat ini.
* **group&#95;by** (opsional): Granularitas waktu untuk mengelompokkan hasil (`hour`, `day`, atau `month`). Saat ini dicadangkan untuk pengembangan di masa mendatang dan tidak mengubah bentuk response. Default-nya `day`.

## Response {#response}

Mengembalikan informasi penggunaan dan billing yang terperinci, meliputi:

* **id**: Identifier unik API key
* **api&#95;key&#95;id**: Identifier unik API key
* **api&#95;key&#95;name**: Nama deskriptif API key (jika diatur)
* **team&#95;id**: ID Team pemilik key ini
* **period**: Objek berisi tanggal mulai dan tanggal akhir periode penggunaan
* **total&#95;cost&#95;usd**: Total biaya dalam USD untuk periode yang ditentukan
* **cost&#95;breakdown**: Array rincian biaya berdasarkan jenis harga, masing-masing berisi:
  * **price&#95;id**: Identifier unik untuk harga
  * **price&#95;name**: Nama harga (misalnya, &quot;Neural Search&quot;, &quot;Content Retrieval&quot;)
  * **quantity**: Total kuantitas yang digunakan
  * **amount&#95;usd**: Biaya dalam USD untuk jenis harga ini
* **metadata**: Objek berisi timestamp pembuatan laporan

## Catatan Penting {#important-notes}

* **Batas Penelusuran 6 Bulan**: Sistem billing memiliki batas penelusuran ke belakang selama 6 bulan (180 hari). Permintaan dengan `start_date` yang lebih lama dari 180 hari akan mengembalikan error 400.
* **Tanpa Penggunaan**: Jika API key tidak memiliki penggunaan pada periode yang diminta, `total_cost_usd` akan bernilai 0 dan `cost_breakdown` bisa jadi kosong.
* **Kepemilikan Team**: Service API key yang digunakan untuk autentikasi harus berada dalam Team yang sama dengan API key yang diminta. Akses lintas Team tidak diizinkan.
* **Format Tanggal**: Tanggal dapat diberikan dalam format ISO 8601 dengan atau tanpa komponen waktu (misalnya, `2025-01-01` atau `2025-01-01T00:00:00Z`).

## Kasus Penggunaan {#use-cases}

Endpoint ini berguna untuk:

* Membangun dashboard billing di level API key
* Memantau penggunaan dan biaya untuk API key tertentu
* Membuat peringatan otomatis berdasarkan ambang penggunaan
* Membuat laporan penggunaan untuk alokasi biaya internal
* Menelusuri masalah billing untuk API key tertentu
