description: "Dapatkan jawaban dari LLM untuk sebuah pertanyaan yang didasarkan
  pada hasil Exa search. `/answer` menjalankan Exa search dan menggunakan LLM
  untuk menghasilkan salah satu dari:

  1. Jawaban langsung untuk kueri spesifik. (misalnya \"Apa ibu kota Prancis?\"
  akan mengembalikan \"Paris\")

  2. Ringkasan mendetail dengan sitasi untuk kueri terbuka (misalnya \"Bagaimana
  kondisi ai di bidang kesehatan?\" akan mengembalikan ringkasan dengan sitasi
  ke sources yang relevan)


  Response mencakup jawaban yang dihasilkan sekaligus sources yang digunakan
  untuk menyusunnya. endpoint ini juga mendukung streaming (dengan
  `stream=True`), yang akan mengembalikan token seiring token tersebut
  dihasilkan.


  Sebagai alternatif, Anda dapat menggunakan [antarmuka chat
  completions](/docs/integrations/openai-sdk#answer) yang kompatibel dengan
  OpenAI.\n"
