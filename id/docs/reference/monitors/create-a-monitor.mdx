description: "Membuat Monitor baru untuk menjalankan Exa search secara berulang
  sesuai jadwal.


  Monitors otomatis menjalankan query search Anda pada jadwal berulang dan
  mengirimkan hasil ke endpoint webhook Anda dengan deduplikasi otomatis:


  - **Pemfilteran berbasis tanggal** hanya mengambil konten sejak run terakhir


  - **Deduplikasi semantik** melacak output sebelumnya agar hanya perkembangan
  baru yang ditampilkan


  Response menyertakan `webhookSecret` yang hanya dikembalikan satu kali saat
  pembuatan. Simpan dengan aman untuk verifikasi signature webhook."
