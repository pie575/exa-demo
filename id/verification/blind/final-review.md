  # Tinjauan visual buta akhir
</div>

Meninjau empat pasangan A/B akhir setelah perbaikan kontrol bawah native dan
jarak antar gambar. Kunci identitas A/B tidak dilihat.

| Pasangan                  | Mana yang terlihat lebih baik? | Observasi                                                                |
| ------------------------- | ------------------------------ | ------------------------------------------------------------------------ |
| Beranda desktop           | Seri                           | Navigasi, judul, hero, contoh, bilah alat, dan kontrol bawah sama.       |
| Beranda mobile            | Seri                           | Pembungkusan baris, jarak, banner, kontrol, dan masking tepi bawah sama. |
| Quickstart Search desktop | Seri                           | Tata letak tiga kolom, tipografi, kode, kontrol, dan tepi bawah sama.    |
| Quickstart Search mobile  | Seri                           | Konten, pembungkusan baris, bilah alat, input bawah, dan masking sama.   |

Tidak ada versi yang menunjukkan keunggulan estetika yang teramati pada gambar-gambar akhir ini.
Perbandingan piksel terpisah memastikan dua pasangan identik secara bitmap. Dua
pasangan lainnya hanya berbeda delapan dan satu piksel pada ambang per-kanal
yang tercatat. Pengukuran ini hanya berlaku untuk viewport yang ditangkap.

Observasi peninjau sebelumnya beserta tangkapan layarnya tetap disimpan
di `review-round-2/`; observasi tersebut menjadi dasar koreksi akhir.
