  # Tinjauan visual buta akhir
</div>

Meninjau empat pasangan A/B akhir setelah perbaikan kontrol bawah native dan
jarak antar gambar. Kunci identitas A/B tidak dilihat.

| Pasangan                  | Mana yang terlihat lebih baik? | Pengamatan                                                              |
| ------------------------- | ------------------------------ | ----------------------------------------------------------------------- |
| Beranda desktop           | Seri                           | Navigasi, judul, hero, contoh, bilah alat, dan kontrol bawah sama.      |
| Beranda seluler           | Seri                           | Pembungkusan teks, spasi, banner, kontrol, dan masking tepi bawah sama. |
| Quickstart Search desktop | Seri                           | Tata letak tiga kolom, tipografi, kode, kontrol, dan tepi bawah sama.   |
| Quickstart Search seluler | Seri                           | Konten, pembungkusan teks, bilah alat, input bawah, dan masking sama.   |

Tidak ada versi yang menunjukkan keunggulan estetika pada gambar akhir ini.
Perbandingan piksel terpisah memastikan dua pasangan identik secara bitmap. Dua
pasangan lainnya hanya berbeda delapan dan satu piksel pada ambang per-kanal
yang tercatat. Pengukuran ini berlaku untuk viewport yang ditangkap.

Pengamatan peninjau sebelumnya beserta tangkapan layarnya disimpan
di `review-round-2/`; pengamatan tersebut menjadi dasar koreksi akhir.
