<div id="security-overview">
  # Ikhtisar Keamanan
</div>

> Informasi keamanan, kepatuhan, dan akses regional Exa.

***

Exa menanggapi keamanan dan privasi data dengan serius. Kami bangga telah meraih sertifikasi SOC 2 Type II, yang menunjukkan komitmen kami untuk menjaga praktik dan kontrol keamanan informasi yang ketat.

Hubungi kami di [sales@exa.ai](mailto:sales@exa.ai) untuk membahas paket Enterprise jika Anda tertarik dengan [Zero Data Retention](/id/docs/admin/security/zero-data-retention), [kepatuhan HIPAA](/id/docs/admin/security/hipaa), atau solusi keamanan data khusus lainnya.

Kunjungi [Trust Center](https://trust.exa.ai) kami untuk melihat laporan SOC 2, Data Processing Agreement, dan dokumentasi keamanan lainnya.

<div id="regional-access-restrictions">
  ## Pembatasan akses regional
</div>

Untuk mematuhi sanksi dan pembatasan perdagangan, Exa memblokir akses API dari negara dan wilayah yang terkena sanksi atau dibatasi, termasuk Krimea, Kuba, Iran, Korea Utara, Rusia, Suriah, Ukraina, dan Venezuela.

Permintaan dari lokasi tersebut dapat diblokir oleh Cloudflare sebelum sampai ke Exa. Dalam kasus tersebut, responsnya bisa berupa halaman pemblokiran WAF Cloudflare dengan Ray ID, bukan JSON error standar dari API Exa.

Jika Anda menduga lalu lintas Anda salah terdeteksi lokasinya, hubungi [hello@exa.ai](mailto:hello@exa.ai) dengan menyertakan alamat IP sumber, negara atau wilayah, timestamp permintaan, dan Cloudflare Ray ID.
