  # Spesifikasi OpenAPI
</div>

> Unduh spesifikasi OpenAPI untuk Exa public API dan Team Management API dalam format YAML atau JSON.

***

Anda dapat melihat versi terbaru spesifikasi OpenAPI kami di sini:

* Spesifikasi Public API: [YAML](/id/docs/exa-spec.yaml) · [JSON](/id/docs/exa-spec.json)
* [Spesifikasi Team Management API](/id/docs/team-management-spec.yaml)

<Note>
  Spesifikasi OpenAPI mentah adalah acuan utama untuk schema permintaan dan respons. Halaman
  referensi yang dihasilkan mungkin tidak memuat resep, catatan migrasi, dan nilai bawaan yang direkomendasikan; gunakan panduan dan
  contoh untuk arahan integrasi terkini seperti `type: "auto"`, highlights, dan pengaturan freshness.
  Tautan ini selalu mengarah ke spesifikasi yang disajikan oleh deployment dokumentasi ini.
</Note>
