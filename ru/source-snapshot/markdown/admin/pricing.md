<div id="agent">
  ## Agent
</div>

Задайте фиксированный `effort` для [Agent](/ru/docs/agent/quickstart), чтобы получить предсказуемую цену за запрос. `auto` — режим по умолчанию с тарификацией по фактическому использованию; бета-режим `max` также тарифицируется по использованию и по тем же ставкам:

| Effort    | Цена            |
| --------- | --------------- |
| `minimal` | $0,012 / запрос |
| `low`     | $0,025 / запрос |
| `medium`  | $0,10 / запрос  |
| `high`    | $0,50 / запрос  |
| `xhigh`   | $1,00 / запрос  |

При тарификации по использованию оплачивается фактический расход в пределах лимита на один запуск. Для `auto` лимит по умолчанию — $5, для бета-режима `max` — $20:

| Компонент использования          | Цена                   |
| -------------------------------- | ---------------------- |
| Agent Compute Units              | $0,10 / ACU            |
| Вызовы инструмента search        | $0,005 / search        |
| Обогащение контактов по email    | $0,02 / email          |
| Обогащение контактов по телефону | $0,07 / номер телефона |

<div id="cost-glossary">
  ## Глоссарий стоимости
</div>

<AccordionGroup>
  <Accordion title="Запрос">
    Один вызов API к эндпоинту. Цены указаны за 1 000 запросов, поэтому ставка $7 / 1 тыс. — это $0,007 за вызов.
  </Accordion>

  <Accordion title="Результат">
    Один результат поиска, возвращённый в ответе. Базовая цена включает первые 10 результатов в запросе; каждый результат сверх 10 добавляет $1 / 1 тыс. результатов. Поэтому запрос с `numResults: 20` стоит базовую цену плюс 10 дополнительных результатов.
  </Accordion>

  <Accordion title="Страница и тип контента">
    Страница — это один URL, для которого Exa возвращает контент. Тип контента — это одно представление этой страницы: `text`, `highlights` или `summary`. `/contents` тарифицирует каждый тип контента отдельно, поэтому одна страница с `text` и `highlights` считается за две.
  </Accordion>

  <Accordion title="ИИ-summary страницы">
    Сгенерированная Exa summary страницы — результат дополнительного вызова LLM на нашей стороне. Тарифицируется по $1 / 1 тыс. страниц на любом эндпоинте, который её возвращает.
  </Accordion>

  <Accordion title="Единица вычислений агента (ACU)">
    Единица модельных вычислений, которую расходует запуск Agent; отражается в `usage.agentComputeUnits`. Чем дольше запуск, чем больше `input.data` и чем больше шагов рассуждения, тем больше расходуется ACU.
  </Accordion>

  <Accordion title="Effort">
    Параметр Agent, который балансирует стоимость и задержку с тщательностью. `auto` тарифицируется по потреблению (ACU плюс вызовы инструментов) до лимита по умолчанию в $5; бета-режим `max` использует те же ставки до лимита по умолчанию в $20. Фиксированные режимы тарифицируются по единой цене за запрос. См. [Режимы effort в Agent](/ru/docs/agent/quickstart#effort).
  </Accordion>

  <Accordion title="Обогащение контактов">
    Поиск через Agent, который возвращает адрес электронной почты или номер телефона человека или компании. Тарифицируется за каждый найденный контакт — сверх остальных расходов на запуск.
  </Accordion>

  <Accordion title="Кредиты">
    Предоплаченный долларовый баланс на вашем аккаунте. Использование списывает кредиты по указанным выше ставкам.
  </Accordion>
</AccordionGroup>
