# Pricing {#pricing}

> Тарифы с оплатой по факту использования для Exa Search, Contents, Answer, Monitors и Agent API

***

Exa работает по модели оплаты по факту использования. Никаких подписок и минимальных трат: вы пополняете баланс credits, и плата списывается за каждый запрос по тарифам, указанным ниже.

<Check>
  **Начните бесплатно.** Новые аккаунты получают $20 в credits (примерно 2 800 searches), а на Free Tier ежемесячно начисляется ещё $10 в credits. Получите API key и приступайте к разработке.

  **Нужно больше?** При больших объёмах, потребности в собственных индексах, повышенных лимитах частоты запросов, SLA или нулевом хранении данных [свяжитесь с нами](https://exa.ai/contact/sales) по поводу [плана Enterprise](#enterprise) со скидками за объём.
</Check>

<Card title="Получите свой Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  Создайте ключ в дашборде. Новым аккаунтам начисляются бесплатные credits.
</Card>

## Search, Contents, Answer и Monitors {#search-contents-answer-and-monitors}

У каждого эндпоинта есть базовая цена за запрос, включающая до 10 результатов. Дополнительные результаты и сгенерированные Exa сводки страниц оплачиваются сверх неё.

| Эндпоинт    | Базовая цена<br />(до 10 результатов)         | Каждый результат сверх 10 | ИИ-сводки страниц   |
| ----------- | --------------------------------------------- | ------------------------- | ------------------- |
| `/search`   | $7 / 1 тыс. запросов                          | $1 / 1 тыс. результатов   | $1 / 1 тыс. страниц |
| `/answer`   | $5 / 1 тыс. запросов                          | —                         | —                   |
| `/monitors` | $15 / 1 тыс. запросов                         | $1 / 1 тыс. результатов   | $1 / 1 тыс. страниц |
| `/contents` | $1 / 1 тыс. страниц за каждый тип содержимого | —                         | $1 / 1 тыс. страниц |

## Agent {#agent}

Задайте фиксированный `effort` в [Agent](/ru/docs/agent/quickstart), чтобы получить предсказуемую цену за запрос. `auto` — это режим по умолчанию с оплатой по факту; бета-режим `max` также тарифицируется по факту и использует те же ставки за использование:

| Effort    | Цена            |
| --------- | --------------- |
| `minimal` | $0,012 / запрос |
| `low`     | $0,025 / запрос |
| `medium`  | $0,10 / запрос  |
| `high`    | $0,50 / запрос  |
| `xhigh`   | $1,00 / запрос  |

При оплате по факту тарифицируется фактическое использование в пределах лимита на один запуск. Для `auto` лимит по умолчанию — $5, для бета-режима `max` — $20:

| Компонент использования       | Цена                   |
| ----------------------------- | ---------------------- |
| Agent Compute Units           | $0,10 / ACU            |
| Вызовы инструмента поиска     | $0,005 / поиск         |
| Обогащение контактов: email   | $0,02 / email          |
| Обогащение контактов: телефон | $0,07 / номер телефона |

### Провайдеры Connect {#connect-providers}

Для запусков, использующих источники данных [Exa Connect](/ru/docs/agent/connect/overview),
дополнительно тарифицируется каждый вызов провайдера — например,
[Fiber.ai](/ru/docs/agent/connect/fiber#pricing) по $0.02 за кредит и
[Baselayer](/ru/docs/agent/connect/baselayer#pricing) по $0.15–$4.00 за
заказ в зависимости от операции. Тарифы всех провайдеров смотрите в разделе
[Connect pricing](/ru/docs/agent/connect/overview#pricing).

## Глубокий поиск {#deep-search}

Задаётся параметром `type` в [`/search`](/ru/docs/search/deep-search). Дополнительные результаты и ИИ-сводки страниц стоят столько же, сколько при обычном поиске.

| Тип              | Базовая цена<br />(до 10 результатов) | Задержка     | Подходит для                                          |
| ---------------- | ------------------------------------- | ------------ | ----------------------------------------------------- |
| `deep-lite`      | $12 / 1 тыс. запросов                 | ~4 секунды   | Лёгкий синтез                                         |
| `deep`           | $12 / 1 тыс. запросов                 | 4–15 секунд  | Многошаговые рассуждения со структурированным выводом |
| `deep-reasoning` | $15 / 1 тыс. запросов                 | 12–40 секунд | Более сложные исследовательские задачи                |

## Глоссарий стоимости {#cost-glossary}

<AccordionGroup>
  <Accordion title="Запрос">
    Один вызов API к эндпоинту. Цены указаны за 1 000 запросов, поэтому тариф $7 / 1k означает $0,007 за вызов.
  </Accordion>

  <Accordion title="Результат">
    Один результат поиска, возвращённый в ответе. Базовая цена покрывает первые 10 результатов в запросе; каждый результат сверх 10 добавляет $1 / 1k результатов. Поэтому запрос с `numResults: 20` обойдётся в базовую цену плюс 10 дополнительных результатов.
  </Accordion>

  <Accordion title="Страница и тип содержимого">
    Страница — это один URL, для которого Exa возвращает содержимое. Тип содержимого — это одно представление этой страницы: `text`, `highlights` или `summary`. `/contents` тарифицирует каждый тип содержимого отдельно, поэтому одна страница с `text` и `highlights` считается за две.
  </Accordion>

  <Accordion title="ИИ-сводка страницы">
    Сгенерированная Exa сводка страницы, созданная дополнительным вызовом LLM на нашей стороне. Тарифицируется по $1 / 1k страниц на любом эндпоинте, который её возвращает.
  </Accordion>

  <Accordion title="Agent Compute Unit (ACU)">
    Единица вычислений модели, которую потребляет запуск Agent; отображается в `usage.agentComputeUnits`. Чем дольше запуски, больше объём `input.data` и число шагов рассуждения, тем больше расходуется ACU.
  </Accordion>

  <Accordion title="Effort">
    Параметр Agent, который позволяет找 находить баланс между стоимостью и задержкой с одной стороны и тщательностью с другой. `auto` тарифицируется по потреблению (ACU плюс tool calls) до лимита по умолчанию $5; бета-режим `max` использует те же тарифы использования до лимита по умолчанию $20. Фиксированные режимы effort тарифицируются по единой цене за запрос. См. [режимы effort в Agent](/ru/docs/agent/quickstart#effort).
  </Accordion>

  <Accordion title="Обогащение контактов">
    Поиск через Agent, возвращающий адрес электронной почты или номер телефона человека или компании. Тарифицируется за каждый найденный контакт, дополнительно к прочим расходам запуска.
  </Accordion>

  <Accordion title="Credits">
    Предоплаченный баланс в долларах на вашем аккаунте. Использование списывает credits по указанным выше тарифам.
  </Accordion>
</AccordionGroup>
