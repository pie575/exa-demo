<div id="billing-basics">
  ## Основы биллинга
</div>

Запросы оплачиваются из предоплаченных credits по тарифам, указанным в разделе [Цены](/ru/docs/admin/pricing), или согласно вашему корпоративному договору. Владельцы команды могут пополнять credits в [панели биллинга](https://dashboard.exa.ai/billing); платежи обрабатываются через Stripe.

Если у команды заканчиваются credits, запросы возвращают `402 Payment Required`. API key, исчерпавший выделенный ему бюджет, также возвращает `402`. Пополните credits или попросите администратора команды изменить бюджет ключа. См. [Коды ошибок](/ru/docs/admin/error-codes).

Историю использования по API key можно получить через [Get API key usage](/ru/docs/reference/team-management/get-api-key-usage).

<div id="rate-limits">
  ## Лимиты по частоте запросов
</div>

Лимиты измеряются в запросах в секунду (QPS) и применяются ко всей команде — сразу ко всем её API key. Для отдельного ключа можно задать более низкий лимит на странице [API Keys](https://dashboard.exa.ai/api-keys), но его трафик всё равно учитывается в командном лимите.

| Эндпоинт                                                    | Лимит по умолчанию           |
| ----------------------------------------------------------- | ---------------------------- |
| `/search`, `/answer`, `/chat/completions`                   | 10 QPS                       |
| `/search` с `type` `deep-lite`, `deep` или `deep-reasoning` | 5 QPS                        |
| `/contents`                                                 | 100 QPS                      |
| `/agent/runs`, `/responses`                                 | 5 QPS и 50 активных запусков |
| `/websets/*`                                                | 20 QPS                       |

У некоторых эндпоинтов общий запас лимита на всех. Лимиты могут меняться и зависят от тарифного плана; для поиска в Websets также действуют лимиты параллелизма, зависящие от плана, — узнать их можно через [Get Team Info](/ru/docs/websets/api/teams/get-team-info).

При превышении лимита запросы возвращают `429 Too Many Requests`. Дождитесь времени, указанного в header `Retry-After`, если он присутствует, либо повторите запрос с экспоненциальной задержкой. См. [Коды ошибок](/ru/docs/admin/error-codes).

<div id="agent-limits">
  ### Лимиты Agent
</div>

Лимиты Agent — это два отдельных механизма: сколько запусков может выполняться одновременно и как быстро можно запускать новые.

* **Параллелизм**: одновременно может выполняться 50 запусков Agent. Этот лимит не связан с вашим QPS и не меняется при его повышении. Попытка запуска сверх лимита возвращает `429` с кодом ошибки `CONCURRENCY_LIMIT_REACHED`; дождитесь завершения одного из запусков или свяжитесь с нами, чтобы увеличить лимит параллелизма.
* **Запуск задач**: `POST /agent/runs` расходует QPS вашего аккаунта, причём каждый запуск считается за два запроса. Запускать задачи можно со скоростью, равной половине вашего QPS: аккаунт со стандартными 10 QPS может создавать 5 запусков в секунду, а при 25 QPS — 12 в секунду.
* **Опрос**: `GET`-запросы статуса запуска, событий и списков запусков не учитываются в QPS и никогда не блокируют отправку новых задач, поэтому опрашивать выполняющиеся Agent можно независимо от того, как быстро вы создаёте новые запуски.

<div id="25-qps-on-pay-as-you-go">
  ### 25 QPS при оплате по мере использования
</div>

Приобретите credits на $1 000 в течение любого 30-дневного периода — и лимит запросов вашей команды автоматически вырастет до **25 QPS на 90 дней**. Учитываются купленные credits, а не израсходованные, а повторное выполнение условия обнуляет отсчёт 90 дней. Следите за прогрессом на [панели биллинга](https://dashboard.exa.ai/billing).

Нужно больше 25 QPS? [Свяжитесь с отделом продаж](https://exa.ai/contact/sales).

<div id="auto-recharge">
  ## Автопополнение
</div>

Автопополнение покупает credits, когда ваш баланс опускается до выбранного вами порога. Настроить его можно на [панели биллинга](https://dashboard.exa.ai/billing).

| Настройка             | Описание                                                                                                                               |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **Сумма пополнения**  | Объём credits, приобретаемых при каждом срабатывании автопополнения, от $5 до $10,000.                                                 |
| **Порог пополнения**  | Баланс, при котором срабатывает пополнение.                                                                                            |
| **Месячный максимум** | Необязательное ограничение на автопополнения в течение расчётного периода. Укажите $0 или оставьте поле пустым, чтобы не ограничивать. |

Например, при сумме пополнения $100, пороге $10 и месячном максимуме $500 каждый раз, когда баланс опустится до $10, будет покупаться credits на $100 — но не более чем на $500 автоматических покупок за расчётный период.

Перед запуском продукта или другой высоконагруженной задачей заранее пополните баланс credits и задайте такую сумму автопополнения, чтобы избежать множества мелких списаний.

<div id="receipts-and-invoices">
  ## Чеки и счета
</div>

Exa отправляет чеки за покупку кредитов и автоматические пополнения по электронной почте с адреса [billing@exa.ai](mailto:billing@exa.ai). При необходимости добавьте этот адрес в список разрешённых. Полная история счетов доступна на странице [панели биллинга](https://dashboard.exa.ai/billing).

Выставление счетов с постоплатой доступно в рамках плана Enterprise.
