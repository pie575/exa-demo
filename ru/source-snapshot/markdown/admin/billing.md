<div id="billing-basics">
  ## Основы биллинга
</div>

Запросы списываются с предоплаченных credits по тарифам из раздела [Pricing](/ru/docs/admin/pricing) или по условиям вашего контракта Enterprise. Владельцы команды могут пополнить credits в [панели биллинга](https://dashboard.exa.ai/billing); платежи обрабатываются через Stripe.

Если credits команды закончились, запросы возвращают `402 Payment Required`. API key, исчерпавший назначенный ему бюджет, также возвращает `402`. Пополните credits или попросите администратора команды изменить бюджет ключа. См. [Error codes](/ru/docs/admin/error-codes).

Историю использования по API key можно получить через [Get API key usage](/ru/docs/reference/team-management/get-api-key-usage).

<div id="rate-limits">
  ## Лимит частоты запросов
</div>

Лимит частоты запросов измеряется в запросах в секунду (QPS) и применяется к команде целиком, ко всем её API key. Для отдельного ключа можно задать более низкий лимит на странице [API Keys](https://dashboard.exa.ai/api-keys), но его трафик всё равно учитывается в общем лимите команды.

| Эндпоинт                                                    | Лимит по умолчанию             |
| ----------------------------------------------------------- | ------------------------------ |
| `/search`, `/answer`, `/chat/completions`                   | 10 QPS                         |
| `/search` с `type` `deep-lite`, `deep` или `deep-reasoning` | 5 QPS                          |
| `/contents`                                                 | 100 QPS                        |
| `/agent/runs`, `/responses`                                 | 5 QPS и 50 активных запусков |
| `/websets/*`                                                | 20 QPS                         |

У некоторых эндпоинтов общая ёмкость лимита частоты запросов. Лимиты могут меняться и зависят от тарифа; для Websets searches также действуют лимиты параллелизма по тарифу, их можно посмотреть через [Get Team Info](/ru/docs/websets/api/teams/get-team-info).

При превышении лимита запросы возвращают `429 Too Many Requests`. Дождитесь времени, указанного в header `Retry-After`, если он присутствует, либо повторите запрос с экспоненциальной задержкой. См. [Error codes](/ru/docs/admin/error-codes).

<div id="agent-limits">
  ### Лимиты Agent
</div>

Лимиты Agent — это два отдельных механизма: сколько запусков может идти одновременно и как быстро можно запускать новые.

* **Параллелизм**: одновременно может выполняться 50 запусков Agent. Этот лимит не связан с вашим QPS и не меняется при его повышении. Запуск сверх лимита возвращает `429` с кодом ошибки `CONCURRENCY_LIMIT_REACHED`; дождитесь завершения одного из запусков или свяжитесь с нами, чтобы повысить лимит параллелизма.
* **Запуск запусков**: `POST /agent/runs` расходует QPS вашего аккаунта, причём каждый запуск считается за два запроса. Запускать запуски можно со скоростью, равной половине вашего QPS: аккаунт со стандартными 10 QPS может стартовать 5 запусков в секунду, а при 25 QPS — 12 в секунду.
* **Опрос**: `GET`-запросы статуса запуска, событий и списков запусков не учитываются в вашем QPS и никогда не блокируют отправку новых задач, поэтому опрашивайте работающие Agent независимо от того, как быстро вы запускаете новые.

<div id="25-qps-on-pay-as-you-go">
  ### 25 QPS при оплате по факту использования
</div>

Пополните баланс на $1 000 в credits в течение любого 30-дневного периода, и лимит запросов вашей команды автоматически вырастет до **25 QPS на 90 дней**. Порог считается по купленным credits, а не по потраченным; при повторном выполнении условия отсчёт 90 дней начинается заново. Следить за прогрессом можно в [панели биллинга](https://dashboard.exa.ai/billing).

Нужно больше 25 QPS? [Свяжитесь с отделом продаж](https://exa.ai/contact/sales).

<div id="auto-recharge">
  ## Auto recharge
</div>

Auto recharge покупает credits, когда баланс опускается до выбранного вами порога. Настроить эту функцию можно в [панели биллинга](https://dashboard.exa.ai/billing).

| Настройка             | Описание                                                                                                                                            |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Сумма пополнения**  | Credits, приобретаемые при каждом срабатывании auto recharge, от $5 до $10,000.                                                                     |
| **Порог пополнения**  | Баланс, при котором срабатывает пополнение.                                                                                                         |
| **Месячный максимум** | Необязательное ограничение на автоматические пополнения в течение расчётного периода. Укажите $0 или оставьте поле пустым, чтобы снять ограничение. |

Например, при сумме пополнения $100, пороге $10 и месячном максимуме $500 каждый раз, когда баланс опускается до $10, будет списываться $100, но суммарно не более $500 автоматических покупок за период.

Перед предстоящим запуском или другой высоконагруженной задачей заранее добавьте достаточно credits и задайте такую сумму auto recharge, чтобы избежать множества мелких попыток списания.

  ## Чеки и счета
</div>

Exa отправляет чеки за покупку credits и автопополнения по электронной почте с адреса [billing@exa.ai](mailto:billing@exa.ai). При необходимости добавьте этот адрес в список разрешённых. Полная история счетов доступна в [панели биллинга](https://dashboard.exa.ai/billing).

Постоплатное выставление счетов доступно на тарифе Enterprise.
