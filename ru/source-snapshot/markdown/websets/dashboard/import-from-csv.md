<div id="import-from-csv">
  # Импорт из CSV
</div>

> Превратите имеющиеся данные из CSV в Webset

<br />

<div id="overview">
  ## Обзор
</div>

Функция Импорт из CSV позволяет превратить имеющиеся CSV-файлы со списками URL в полноценные Websets. Это идеальный вариант, если у вас уже есть перечень сайтов, компаний или ресурсов, которые нужно обогатить дополнительными данными или отфильтровать по критерию поиска.

<br />

<div id="how-it-works">
  ## Как это работает
</div>

<img src="https://mintcdn.com/exa-52/tmzyKnsgpKLGddKC/images/websets/import-flow.png?fit=max&auto=format&n=tmzyKnsgpKLGddKC&q=85&s=6cf23e9e291fe7811942d18c3aa08b33" alt="Процесс импорта CSV для создания Webset" width="1512" height="857" data-path="images/websets/import-flow.png" />

1. Нажмите «Start from CSV» и выберите CSV-файл
2. Укажите, в каком столбце находятся URL-адреса, которые нужно проанализировать
3. Перед продолжением проверьте, как будут импортированы данные
4. Ваши URL-адреса превращаются в Webset с enrichment и метаданными

<br />

<div id="csv-preparation">
  ## Подготовка CSV
</div>

Убедитесь, что в CSV-файле есть столбец с URL

* Для поиска по людям: URL должны быть ссылками на профили LinkedIn (например, [https://linkedin.com/in/username](https://linkedin.com/in/username))
* Для поиска по компаниям: URL должны быть ссылками на главные страницы сайтов компаний (например, [https://example.com](https://example.com))
* Для остальных типов поиска: подойдёт URL любого типа

Если URL нет, Websets попробует определить их по информации из каждой строки CSV и по дополнительным сведениям, которые вы укажете.

Максимальное количество импортируемых результатов зависит от вашего тарифного плана.

<div id="what-happens-next">
  ## Что дальше?
</div>

После импорта ваш CSV превращается в полноценный Webset, в котором можно:

<div id="enrich-with-custom-columns">
  ### Обогащение пользовательскими столбцами
</div>

Добавляйте любую нужную информацию о каждом URL:

* Контактные данные (адреса электронной почты, телефоны)
* Показатели компании (выручка, численность сотрудников)
* Анализ контента (тональность, темы, краткие содержания)
* Собственные данные под ваш сценарий использования

<div id="apply-search-criteria">
  ### Применение критериев поиска
</div>

Фильтруйте импортированные URL по заданным критериям:

* Стадия развития или размер компании
* Отрасль или сектор
* Географическое расположение
* Тип контента или тема
