<div id="exclude-results">
  # Исключение результатов
</div>

> Избегайте дублирования результатов в новых поисках, исключая URL из ранее созданных Websets или CSV-файлов.

<br />

<div id="overview">
  ## Обзор
</div>

Функция Exclude Results избавляет от дублирующихся результатов при создании новых поисков. Указав URL, которые нужно исключить, на основе предыдущих Websets или загруженного CSV-файла, вы сможете сосредоточиться на поиске новых, уникальных результатов, дополняющих уже имеющиеся данные.

<br />

<div id="how-it-works">
  ## Как это работает
</div>

<img src="https://mintcdn.com/exa-52/tmzyKnsgpKLGddKC/images/websets/exclude-flow.png?fit=max&auto=format&n=tmzyKnsgpKLGddKC&q=85&s=b28ac0441991bc4543571ffc2a900963" alt="Параметры исключения результатов при создании Webset" width="1466" height="857" data-path="images/websets/exclude-flow.png" />

1. Начните создание нового Webset
2. Под criteria на боковой панели нажмите «Exclude»
3. Выберите один из прежних Websets или загрузите CSV со списком URL для исключения. Источников для исключения можно выбрать несколько.
4. Запустите search — в результатах останутся только новые элементы, не попадающие под исключения

Максимальное количество результатов, которые можно исключить, зависит от вашего тарифного плана.

<br />

<div id="when-to-use-exclusions">
  ## Когда использовать исключения
</div>

* Поиск лидов, которых ещё нет в вашей CRM
* Повторный запуск предыдущих поисков с уточнёнными критериями
* Исключение результатов, которые вам уже известны
