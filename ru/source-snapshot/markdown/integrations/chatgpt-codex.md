# Exa в Codex и ChatGPT {#exa-in-codex-and-chatgpt}

> Ищите в интернете, читайте любую страницу и проводите исследования с Exa прямо из Codex и ChatGPT.

Установите плагин Exa один раз, чтобы открыть Codex и ChatGPT доступ к актуальному вебу через Exa. Находите свежую информацию, читайте нужные источники и запускайте более глубокие исследования, не прерывая диалог или сессию написания кода.

## Установка Exa {#install-exa}

<Steps>
  <Step title="Откройте плагин">
    Перейдите на [chatgpt.com/plugins/exa](https://chatgpt.com/plugins/exa?open_in_app). Откроется страница **Exa** в каталоге плагинов OpenAI, это один и тот же каталог для ChatGPT и для Codex.
  </Step>

  <Step title="Установите его">
    Нажмите кнопку с плюсом, чтобы установить. Войдите в Exa, когда появится запрос: либо во время установки, либо при первом использовании плагина в Codex или ChatGPT.

## Разрабатывайте с учётом того, что есть в вебе прямо сейчас {#build-with-whats-on-the-web-right-now}

Библиотеки, API и инструменты, с которыми вы работаете, меняются каждый день. С установленным Exa агент Codex может прямо в процессе работы искать актуальную документацию, issues, чейнджлоги и примеры из реальной практики.

Прямо из вашего репозитория:

```text theme={null}
У нас Tailwind v3. Найди руководство по обновлению до Tailwind v4, прочитай его,
а затем переведи этот проект на v4.
```

Codex может искать через Exa, читать нужные источники и использовать найденное, чтобы внести изменения в ваш код.

Это работает в любом случае, когда ответ может находиться за пределами вашего репозитория:

* «Прежде чем пытаться исправить эту ошибку, поищи её в issues и чейнджлоге `tokio-tungstenite`».
* «Найди реальные примеры рекомендательных блокировок Postgres на Rust и посоветуй паттерн, который подходит для этого пула воркеров».
* «Прочитай актуальную документацию по вебхукам Stripe и сверь с ней наше внедрение».
* «Найди последнее руководство по миграции для этой зависимости и обнови её».

## Исследования, не покидая ChatGPT {#research-without-leaving-chatgpt}

Exa работает и в ChatGPT. Задайте вопрос, для которого нужна свежая информация, и используйте Exa, чтобы искать и исследовать веб прямо в диалоге.

```text theme={null}
Сравни облачные管 managed-решения, лицензирование и цены основных
векторных баз данных с открытым исходным кодом. Используй актуальные первоисточники и ссылайся на них.
```

Вместо того чтобы полагаться только на информацию, уже имеющуюся в контексте, ChatGPT может использовать Exa, чтобы найти и прочитать источники, необходимые для задачи.

Используйте это для конкурентного анализа, технических исследований, картирования рынка, изучения компаний и любых других задач, ответы на которые разбросаны по всему вебу.

## MCP + навыки вместе {#mcp-skills-together}

Под капотом плагин объединяет две части agent-стека Exa.

[Exa MCP](/ru/docs/get-started/exa-mcp) даёт Codex и ChatGPT инструменты для доступа к Exa. Это связующее звено между agent и возможностями search и research в Exa.

[Навыки Exa](/ru/docs/get-started/agent-skills/overview) дают agent дополнительные инструкции по применению этих возможностей в полезных рабочих процессах, включая веб-research и [Exa Agent](/ru/docs/agent/quickstart).

При установке плагина ни то, ни другое настраивать отдельно не нужно.

## Предпочитаете подключаться к MCP напрямую? {#prefer-mcp-directly}

Плагин — рекомендуемый способ использовать Exa с Codex и ChatGPT. Если вы настраиваете Codex вручную или используете другой MCP-клиент, можно подключиться напрямую к размещённому MCP-серверу Exa:

```bash theme={null}
codex mcp add exa --url https://mcp.exa.ai/mcp
```

Информацию о других клиентах, параметрах настройки и доступных инструментах смотрите в разделе [Exa MCP](/ru/docs/get-started/exa-mcp).
