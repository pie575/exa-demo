<div id="exa-in-codex-and-chatgpt">
  # Exa в Codex и ChatGPT
</div>

> Ищите в интернете, читайте любые страницы и проводите исследования с Exa прямо из Codex и ChatGPT.

Установите плагин Exa один раз — и Codex с ChatGPT получат доступ к актуальному вебу через Exa. Находите свежую информацию, читайте нужные источники и проводите глубокие исследования, не прерывая диалог или работу над кодом.

<div id="install-exa">
  ## Установка Exa
</div>

<Steps>
  <Step title="Откройте плагин">
    Перейдите на [chatgpt.com/plugins/exa](https://chatgpt.com/plugins/exa?open_in_app). Откроется страница **Exa** в каталоге плагинов OpenAI — это общий каталог для ChatGPT и Codex.
  </Step>

  <Step title="Установите его">
    Нажмите кнопку с плюсом, чтобы установить. Войдите в Exa, когда появится запрос, — во время установки или при первом обращении к плагину из Codex или ChatGPT.

    <Frame caption="Открытие раздела Plugins в Codex, добавление Exa и предоставление доступа">
      <img src="https://mintcdn.com/exa-52/Una64IRjof2yadw_/images/integrations/chatgpt-codex/install-codex.gif?s=170c67f79603bc3a0dc470266a3f29f7" alt="Открытие раздела Plugins в Codex, просмотр плагина Exa и предоставление доступа" style={{width: "100%", height: "auto"}} width="1100" height="825" data-path="images/integrations/chatgpt-codex/install-codex.gif" />
    </Frame>
  </Step>

  <Step title="Начните новую сессию">
    Навыки подгружаются в чатах и CLI-сессиях, запущенных уже после установки, поэтому откройте новую сессию и задайте вопрос, для ответа на который нужен веб.
  </Step>
</Steps>

Готово. Плагин включает и MCP-интеграцию Exa, и навыки, так что отдельно настраивать MCP или навыки не нужно.

<div id="build-with-whats-on-the-web-right-now">
  ## Разрабатывайте с учётом того, что есть в вебе прямо сейчас
</div>

Библиотеки, API и инструменты, с которыми вы работаете, меняются каждый день. Если установлен Exa, Codex может прямо в процессе работы искать свежую документацию, issues, changelog&#39;и и реальные примеры.

Прямо из вашего репозитория:

```text theme={null}
У нас Tailwind v3. Найди руководство по переходу на Tailwind v4, изучи его,
а затем переведи этот проект на v4.
```

Codex может выполнить поиск через Exa, прочитать релевантные источники и на основе найденного внести изменения в вашу кодовую базу.

Это работает в любом случае, когда ответ может находиться за пределами вашего репозитория:

* «Поищи эту ошибку в issues и changelog `tokio-tungstenite`, прежде чем пытаться её исправить».
* «Найди реальные примеры advisory-блокировок Postgres на Rust и предложи паттерн, подходящий для этого пула воркеров».
* «Прочитай актуальную документацию по вебхукам Stripe и сверь с ней нашу реализацию».
* «Найди свежее руководство по миграции для этой зависимости и обнови её».

<div id="research-without-leaving-chatgpt">
  ## Исследования, не покидая ChatGPT
</div>

Exa работает и в ChatGPT. Задайте вопрос, требующий свежей информации, и используйте Exa для поиска и исследования веба прямо из диалога.

```text theme={null}
Сравни облачные (managed) решения, лицензирование и цены основных
векторных баз данных с открытым исходным кодом. Опирайся на актуальные первоисточники и указывай ссылки на них.
```

Вместо того чтобы полагаться только на информацию, уже имеющуюся в контексте, ChatGPT может использовать Exa, чтобы найти и прочитать источники, нужные для решения задачи.

Применяйте это для конкурентного анализа, технических исследований, картирования рынка, изучения компаний и любых других задач, ответ на которые разбросан по интернету.

<div id="mcp-skills-together">
  ## MCP и навыки вместе
</div>

Под капотом плагин объединяет две части агентного стека Exa.

[Exa MCP](/ru/docs/get-started/exa-mcp) даёт Codex и ChatGPT инструменты для доступа к Exa. Это связующее звено между агентом и возможностями Exa по поиску и исследованиям.

[Навыки Exa](/ru/docs/get-started/agent-skills/overview) дают агенту дополнительные инструкции по применению этих возможностей в полезных рабочих процессах, включая веб-исследования и [Exa Agent](/ru/docs/agent/quickstart).

При установке плагина ничего из этого настраивать отдельно не нужно.

<div id="prefer-mcp-directly">
  ## Предпочитаете подключаться к MCP напрямую?
</div>

Плагин — рекомендуемый способ использовать Exa с Codex и ChatGPT. Если вы настраиваете Codex вручную или используете другой MCP-клиент, вы можете подключиться напрямую к размещённому MCP-серверу Exa:

```bash theme={null}
codex mcp add exa --url https://mcp.exa.ai/mcp
```

Информацию о других клиентах, параметрах настройки и доступных инструментах см. в разделе [Exa MCP](/ru/docs/get-started/exa-mcp).
