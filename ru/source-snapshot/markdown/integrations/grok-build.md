<div id="grok-build">
  # Grok Build
</div>

> Используйте веб-поиск Exa в Grok Build. Установите плагин Exa из marketplace Grok Build и войдите в свою учётную запись Exa.

Exa доступна как плагин в marketplace [Grok Build](https://docs.x.ai/build/overview). Она обеспечивает Grok веб-поиск в реальном времени, чтение страниц и навык deep research.

<div id="installation">
  ## Установка
</div>

<Steps>
  <Step title="Установите Grok Build">
    Установите Grok CLI (подробности см. в [документации Grok Build](https://docs.x.ai/build/overview)):

    ```bash theme={null}
    curl -fsSL https://x.ai/cli/install.sh | bash
    ```

    Затем войдите в свою учётную запись xAI:

    ```bash theme={null}
    grok login
    ```
  </Step>

  <Step title="Откройте marketplace">
    Запустите Grok Build командой `grok`, затем откройте marketplace:

    ```text theme={null}
    /marketplace
    ```
  </Step>

  <Step title="Установите плагин Exa">
    Найдите **exa** в списке и нажмите `i`, чтобы установить плагин.
  </Step>

  <Step title="Войдите в Exa">
    Откройте вкладку MCP-серверов командой `/mcp`, выберите **exa** и нажмите `i` для входа. В браузере откроется страница входа Exa. Новым учётным записям при регистрации начисляются бесплатные credits.
  </Step>
</Steps>

Как только у exa появится статус **ready**, задавайте Grok любые вопросы, требующие доступа к вебу.

<div id="what-you-get">
  ## Что вы получаете
</div>

* **web&#95;search&#95;exa**: веб-поиск в реальном времени. Поддерживает запросы на естественном языке и фильтры по категориям: новости, компании, люди, научные статьи и GitHub.
* **web&#95;fetch&#95;exa**: читает любой URL и возвращает содержимое страницы в виде чистого markdown.
* **exa-search skill**: навык deep research. Попросите Grok детально разобраться в теме, и он выполнит несколько поисковых запросов, прочитает лучшие источники и даст ответ со ссылками на них.
