# n8n {#n8n}

> Используйте Exa search и contents в рабочих процессах n8n.

Официальный [узел Exa для n8n](https://github.com/exa-labs/n8n-integration) добавляет в визуальные рабочие процессы web search, извлечение контента, ответы с опорой на источники и запуски Exa Agent. Используйте его как обычный шаг рабочего процесса или подключите к n8n AI Agent в качестве инструмента.

## Установка узла Exa {#install-the-exa-node}

Название пакета — `n8n-nodes-exa-official`.

<Steps>
  <Step title="Добавьте узел сообщества">
    Найдите **Exa** в списке узлов n8n. Если он недоступен в вашем инстансе, владелец инстанса может установить `n8n-nodes-exa-official`, следуя [руководству n8n по установке узлов сообщества](https://docs.n8n.io/integrations/community-nodes/installation/).

    Для работы узла требуется n8n 1.60 или новее и Node.js 20.15 или новее.
  </Step>

  <Step title="Создайте Exa API key">
    <Card title="Получите свой Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      Создайте key в панели управления. Новым аккаунтам начисляются бесплатные credits.
    </Card>
  </Step>

  <Step title="Добавьте учётные данные Exa">
    Добавьте в n8n учётные данные **Exa API** и вставьте свой key. Указывайте эти учётные данные в каждом узле Exa, который должен работать с этой учётной записью.
  </Step>
</Steps>

## Выполнение поиска {#run-a-search}

1. Добавьте триггер в рабочий процесс.
2. Добавьте узел **Exa**.
3. Выберите **Search**.
4. Введите запрос и выберите тип поиска.
5. Выберите формат ответа:
   * **Results** — ранжированные страницы
   * **Text** — синтезированный ответ
   * **Structured** — JSON по вашей схеме
6. Запустите узел и передайте его результат на следующий шаг рабочего процесса.

Поиск также может возвращать текст, highlights, краткие изложения, ссылки и изображения по каждому результату. Фильтры по доменам, даты публикации, категории, `maxAgeHours` и обход подстраниц доступны в необязательных полях узла.

## Доступные ресурсы {#available-resources}

| Ресурс       | Операции                                                                                                                                              |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Search**   | Поиск в интернете в режимах `auto`, `instant`, `fast`, `deep-lite`, `deep` или `deep-reasoning`, с опциональным синтезом и структурированным выводом. |
| **Contents** | Получение очищенного текста, highlights, кратких изложений, ссылок и изображений для списка URL.                                                      |
| **Answer**   | Генерация ответа с опорой на источники с цитированием источников и опциональным структурированным выводом.                                                    |
| **Agent**    | Создание, просмотр, вывод списка, стриминг, опрос и отмена многошаговых запусков Agent.                                                               |

## Использование Exa с узлом AI Agent в n8n {#use-exa-with-an-n8n-ai-agent}

Подключите узел Exa к узлу **AI Agent** через его вход для инструментов. Для параметров, которые должна заполнять модель, можно использовать выражение n8n `$fromAI()`:

```javascript theme={null}
{{ $fromAI("query", "What should Exa search for?", "string") }}
```

Search и Answer хорошо подходят в качестве инструментов grounding. Используйте ресурс Agent, если задача требует многошагового исследования, построения списков, структурированного enrichment или премиальных данных [Exa Connect](/ru/docs/agent/connect/overview).

## Ожидание завершения запуска Agent {#wait-for-an-agent-run}

При создании запуска Agent параметр **Wait for Completion** поддерживает:

* **Stream** — держать открытым одно соединение server-sent events до завершения запуска
* **Poll** — проверять состояние запуска с заданным интервалом

Для длительных или асинхронных рабочих процессов отключите **Wait for Completion**, сохраните возвращённый `id` запуска и позже воспользуйтесь **Get Run**. Запуск продолжит выполняться на стороне Exa уже после завершения шага n8n.

## Устранение неполадок {#troubleshooting}

<AccordionGroup>
  <Accordion title="Узел Exa отсутствует в списке выбора узлов">
    Попросите владельца инстанса установить проверенный community-пакет `n8n-nodes-exa-official`. Доступность community-узлов зависит от того, как размещён ваш инстанс n8n.
  </Accordion>

  <Accordion title="Учётные данные Exa отклоняются">
    Убедитесь, что выбранные учётные данные содержат активный ключ из [панели управления Exa](https://dashboard.exa.ai/api-keys) и что на этом ключе есть доступные кредиты.
  </Accordion>

  <Accordion title="Рабочий процесс Agent завершается по тайм-ауту">
    Отключите **Wait for Completion**, сохраните возвращённый `id` запуска и получите результат на одном из последующих шагов с помощью **Get Run**.
  </Accordion>
</AccordionGroup>
