<div id="gumloop">
  # Gumloop
</div>

> Используйте Exa search и contents в потоках Gumloop.

[Gumloop](https://www.gumloop.com/) включает Exa как встроенную интеграцию MCP. Добавьте её в agent или Agent Node, чтобы искать в интернете, извлекать содержимое страниц, находить похожие источники и получать ответы со ссылками на источники прямо внутри workflow.

<div id="add-exa-to-a-gumloop-agent">
  ## Добавление Exa в agent Gumloop
</div>

<Steps>
  <Step title="Откройте agent">
    Откройте настройки своего agent, затем выберите **Add tools** → **Connect an app with MCP**.
  </Step>

  <Step title="Подключите Exa">
    Найдите **Exa**, выберите интеграцию и пройдите аутентификацию.
  </Step>

  <Step title="Выберите инструменты">
    Откройте подключённую интеграцию Exa и включите только те инструменты, которые нужны agent. Так выбор инструментов станет понятнее, а agent не будет вызывать лишние действия.
  </Step>

  <Step title="Проверьте подключение">
    Отправьте agent запрос:

    ```text theme={null}
    Find five recent articles about AI regulation and summarize the key changes with source links.
    ```

    Просмотрите результат запуска и убедитесь, что agent обратился к Exa и вернул источники со ссылками.
  </Step>
</Steps>

<div id="available-tools">
  ## Доступные инструменты
</div>

| Инструмент               | Для чего использовать                                                       |
| ------------------------ | --------------------------------------------------------------------------- |
| **Search**               | Поиск релевантных страниц нейронным или ключевым поиском.                   |
| **Get Contents**         | Извлечение полного текста, кратких изложений и метаданных по известным URL. |
| **Find Similar**         | Поиск страниц, похожих на исходный URL.                                     |
| **Answer**               | Генерация обоснованного ответа со ссылками на источники.                    |
| **Create Research Task** | Запуск длительного исследования.                                            |
| **Get Research Task**    | Получение статуса и результата исследовательской задачи.                    |

Для диалогового agent сначала включите Search, Get Contents и Answer. Остальные инструменты добавляйте только тогда, когда этого требует workflow.

<div id="use-exa-in-a-workflow">
  ## Использование Exa в workflow
</div>

<div id="agent-node">
  ### Agent Node
</div>

Добавьте **Agent Node** в детерминированный поток Gumloop и подключите Exa как один из его инструментов. Узел сам решит, выполнить ли search, получить страницы целиком или связать несколько вызовов Exa в цепочку, прежде чем передать результат на следующий шаг workflow.

Это хорошо подходит для:

* обогащения строк CRM или таблиц актуальными данными из веба
* отслеживания новостей и отправки summary со ссылками на источники в Slack или на почту
* исследования компаний перед маршрутизацией записей в workflow продаж
* сравнения продуктов и записи результата в документ

<div id="reusable-custom-mcp-node">
  ### Переиспользуемый пользовательский MCP-узел
</div>

Для одного повторяющегося действия создайте отдельный узел:

1. Откройте библиотеку узлов и найдите Exa.
2. Выберите **Create a node with AI**.
3. Опишите одно действие, например `Search for funding announcements from the past seven days`.
4. Протестируйте созданный узел, проверьте его входные и выходные данные и сохраните его.

Используйте Agent Node, если задача требует динамического планирования или нескольких инструментов. Используйте пользовательский MCP-узел, если одна и та же операция Exa должна предсказуемо выполняться для каждого элемента.

<div id="troubleshooting">
  ## Устранение неполадок
</div>

<AccordionGroup>
  <Accordion title="Exa недоступна agentу">
    Откройте заново MCP-инструменты agentа, убедитесь, что Exa подключена, и включите нужный инструмент. Даже у подключённой интеграции отдельные инструменты могут быть отключены.
  </Accordion>

  <Accordion title="Agent выбирает не то действие">
    Явно укажите в запросе, что именно нужно сделать: выполнить search, прочитать известные URL, найти похожие страницы или ответить на основе источников. Отключите те инструменты Exa, которые agentу не нужны в этом workflow.
  </Accordion>

  <Accordion title="Workflow требует предсказуемого одиночного вызова">
    Замените универсальный шаг с agentом на пользовательский MCP-узел Exa с фиксированными входными данными и задачей.
  </Accordion>
</AccordionGroup>
