<div id="gumloop">
  # Gumloop
</div>

> Используйте Exa search и содержимое в потоках Gumloop.

[Gumloop](https://www.gumloop.com/) включает Exa как встроенную MCP-интеграцию. Добавьте её к agent или в Agent Node, чтобы искать в вебе, извлекать страницы, находить связанные источники и получать ответы со ссылками на источники прямо в рабочем процессе.

<div id="add-exa-to-a-gumloop-agent">
  ## Добавление Exa в agent Gumloop
</div>

<Steps>
  <Step title="Откройте agent">
    Откройте настройки своего agent, затем выберите **Add tools** → **Connect an app with MCP**.
  </Step>

  <Step title="Подключите Exa">
    Найдите **Exa**, выберите интеграцию и пройдите аутентификацию.
  </Step>

  <Step title="Выберите инструменты">
    Откройте подключённую интеграцию Exa и включите только те инструменты, которые нужны agent. Так выбор инструмента будет понятнее, а agent не станет вызывать посторонние действия.
  </Step>

  <Step title="Проверьте подключение">
    Попросите agent:

    ```text theme={null}
    Find five recent articles about AI regulation and summarize the key changes with source links.
    ```

    Просмотрите выполнение и убедитесь, что agent вызвал Exa и вернул sources со ссылками.
  </Step>
</Steps>

<div id="available-tools">
  ## Доступные инструменты
</div>

| Инструмент               | Для чего использовать                                                    |
| ------------------------ | ------------------------------------------------------------------------ |
| **Search**               | Поиск релевантных страниц с помощью нейросетевого или ключевого поиска.  |
| **Get содержимое**       | Извлечение полного текста, summary и метаданных по известным URL.        |
| **Find Similar**         | Поиск страниц, похожих на исходный URL.                                  |
| **Answer**               | Генерация ответа с опорой на источники и ссылками на них.                |
| **Create Research Task** | Запуск длительного исследования.                                         |
| **Get Research Task**    | Получение статуса и результата исследовательской задачи.                 |

Для диалогового agent сначала включите Search, Get содержимое и Answer. Остальные инструменты добавляйте только тогда, когда этого требует рабочий процесс.

<div id="use-exa-in-a-workflow">
  ## Использование Exa в рабочем процессе
</div>

<div id="agent-node">
  ### Agent Node
</div>

Добавьте **Agent Node** в детерминированный поток Gumloop и подключите Exa как один из его инструментов. Узел сам решает, выполнить ли search, получить полные страницы или объединить в цепочку несколько Exa calls, прежде чем передать свой вывод на следующий шаг рабочего процесса.

Это хорошо подходит для:

* обогащения строк CRM или таблиц актуальными данными из веба
* отслеживания новостей и отправки summary со ссылками на источники в Slack или на почту
* исследования компаний перед маршрутизацией записей в рабочий процесс продаж
* сравнения продуктов и записи результата в документ

<div id="reusable-custom-mcp-node">
  ### Многоразовый пользовательский MCP-узел
</div>

Для одного повторяющегося действия создайте отдельный узел:

1. Откройте библиотеку узлов и найдите Exa.
2. Выберите **Create a node with AI**.
3. Опишите одно действие, например `Search for funding announcements from the past seven days`.
4. Протестируйте созданный узел, проверьте его входные данные и вывод и сохраните его.

Используйте Agent Node, когда задача требует динамического планирования или нескольких инструментов. Используйте пользовательский MCP-узел, когда одна и та же операция Exa должна предсказуемо выполняться для каждого item.

<div id="troubleshooting">
  ## Устранение неполадок
</div>

<AccordionGroup>
  <Accordion title="Exa недоступен для agent">
    Снова откройте MCP-инструменты agent, убедитесь, что Exa подключён, и включите нужный инструмент. Даже у подключённой интеграции отдельные инструменты могут быть отключены.
  </Accordion>

  <Accordion title="Agent выбирает неверное действие">
    Явно укажите в запросе, что именно требуется: выполнить search, прочитать известные URL, найти похожие страницы или ответить на основе источников. Отключите те инструменты Exa, которые agent не использует в этом рабочем процессе.
  </Accordion>

  <Accordion title="Рабочему процессу нужен предсказуемый единичный вызов">
    Замените универсальный шаг с agent на пользовательский MCP-узел Exa с фиксированными входными данными и задачей.
  </Accordion>
</AccordionGroup>
