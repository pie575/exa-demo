# Независимая слепая визуальная проверка — итоговые снимки {#independent-blinded-visual-review-final-captures}

Проверены четыре обновлённых сравнительных A/B-изображения без ключа соответствия «источник — метка».

| Пара | Предпочтение | Видимое обоснование                                                                                                                                                                      |
| ---- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | Ничья        | Совпадают типографика, геометрия, баннер, цвета, навигация, содержимое и элементы управления действиями.                                                                                 |
| 2    | Ничья        | Мобильная компоновка страницы, содержимое, баннер, элементы управления в header и поле вопроса внизу выглядят одинаково.                                                                 |
| 3    | Ничья        | Совпадают перенос текста, оформление кода, отступы, оглавление и набор элементов управления. Незначительная разница в отступах у действий для кода не делает ни один из вариантов лучше. |
| 4    | Ничья        | Совпадают мобильная компоновка содержимого, отступы, header и действия. Небольшая разница в отступах между значками кода заметна, но не даёт оснований для эстетического предпочтения.   |

Ни одна из версий не выглядит заметно лучше на этих скриншотах. На более ранних
снимках с одной стороны отсутствовали значки действий; в итоговых версиях эти
элементы управления есть в обеих. Скриншоты подтверждают визуальное
сходство, но не эквивалентность поведения удалённых ИИ-сервисов.
