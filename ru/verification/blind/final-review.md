# Финальная слепая визуальная проверка {#final-blind-visual-review}

Проверены четыре финальные пары A/B после исправления нативных нижних элементов управления и
отступов изображений. Ключ соответствия A/B не использовался.

| Пара                         | Что выглядит лучше? | Наблюдение                                                                                           |
| ---------------------------- | ------------------- | ---------------------------------------------------------------------------------------------------- |
| Главная страница, десктоп    | Ничья               | Совпадают навигация, заголовок, hero-блок, примеры, панель инструментов и нижний элемент управления. |
| Главная страница, мобильная  | Ничья               | Совпадают переносы, отступы, баннер, элементы управления и маскирование у нижнего края.              |
| Search quickstart, десктоп   | Ничья               | Совпадают трёхколоночная вёрстка, типографика, код, элементы управления и нижний край.               |
| Search quickstart, мобильная | Ничья               | Совпадают содержимое, переносы, панель инструментов, нижнее поле ввода и маскирование.               |

Ни одна из версий не имеет заметного эстетического преимущества на этих финальных изображениях.
Отдельное попиксельное сравнение подтверждает, что две пары идентичны на уровне растра. Две
другие различаются всего на восемь и на один пиксель соответственно при зафиксированном
поканальном пороге. Эти измерения относятся к снятым областям просмотра.

Более ранние наблюдения рецензентов и соответствующие скриншоты сохранены
в `review-round-2/`; именно они легли в основу финальных исправлений.
