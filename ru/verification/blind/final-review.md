  # Финальная слепая визуальная проверка
</div>

Проверены четыре финальные пары A/B после исправления нативных нижних элементов управления
и отступов изображений. Ключ соответствия A/B не использовался.

| Пара                                   | Что выглядит лучше? | Наблюдение                                                                                           |
| -------------------------------------- | ------------------- | ---------------------------------------------------------------------------------------------------- |
| Главная страница, десктоп              | Ничья               | Совпадают навигация, заголовок, hero-блок, примеры, панель инструментов и нижний элемент управления. |
| Главная страница, мобильная версия     | Ничья               | Совпадают переносы, отступы, баннер, элементы управления и маскирование нижнего края.                |
| Быстрый старт Search, десктоп          | Ничья               | Совпадают трёхколоночная вёрстка, типографика, код, элементы управления и нижний край.               |
| Быстрый старт Search, мобильная версия | Ничья               | Совпадают содержимое, переносы, панель инструментов, нижнее поле ввода и маскирование.               |

Ни у одной из версий нет заметного эстетического преимущества на этих финальных изображениях.
Отдельное попиксельное сравнение подтверждает, что две пары идентичны на уровне растра. Две
другие различаются всего на восемь и один пиксель соответственно при зафиксированном
пороге по каналам. Эти измерения относятся к снятым областям просмотра.

Более ранние наблюдения проверяющих и соответствующие им скриншоты сохранены
в `review-round-2/`; именно они легли в основу финальных исправлений.
