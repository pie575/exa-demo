<div id="blind-visual-review">
  ## Слепой визуальный обзор
</div>

[Откройте галерею A/B-сравнения из 159 страниц](blind/index.html). Два
скриншота каждой страницы перемешиваются независимо друг от друга. Галерея
сохраняет выбор A/B/ничья в браузере. Четыре репрезентативные пары
десктоп/мобильная версия также были просмотрены без обращения к ключу
соответствия: [итоговый обзор](blind/final-review.md).
Более ранние независимые обзоры и соответствующие им скриншоты заархивированы в
`blind/review-round-2/`.

Итоговые обзоры репрезентативных пар не выявили заметного эстетического
преимущества ни у одной из версий. Две итоговые репрезентативные пары
побитово идентичны; две другие различаются всего на 8 и 1 пиксель
соответственно при зафиксированном пороге
([пиксельные измерения](representative-pixel-comparison.json)). Это проверки
снятых областей просмотра, а не утверждение о полной пиксельной
идентичности или эквивалентности размещённого сервиса. Из всех 159 страниц
основной текст совпадает на 158; единственное расхождение — отметка времени
проверки на странице статуса в реальном времени.

<div id="fidelity-details">
  ## Детали точности воспроизведения
</div>

При импорте сохраняются продакшен-тема, навигация, пользовательские стили и
скрипты, шрифты, метаданные страниц, спецификации API и исходные компоненты MDX.
Кроме того, восстанавливаются таблица Agent Examples, отсутствовавшая в экспорте
в Markdown, и 85 опубликованных меток изменений, пропущенных локальным
рендерером. Исходные ответы и контрольные суммы хранятся в `source-snapshot/`.

Размещённый у Exa ИИ-ассистент недоступен в локальном предпросмотре Mintlify.
Его локальные элементы управления вместо этого открывают рабочий поиск по
документации. Внешние панели управления и ссылки на API playground по-прежнему
ведут на внешние ресурсы. Ссылки на скачивание Markdown и схем ведут через
перенаправления на идентичные `.txt`-файлы, поскольку встроенный сервер
разработки не отдаёт файлы с такими расширениями напрямую. Метки времени
текущего статуса и анимированные медиа могут различаться между снимками.

<div id="reproduce">
  ## Воспроизведение
</div>

```sh
pnpm validate
pnpm check:links
pnpm audit:content
pnpm dev
# В другом терминале, пока запущен предпросмотр:
python3 verification/audit-content.py --url http://localhost:3000 --output verification/route-audit.json
python3 verification/check-exports.py
node verification/audit-interactions.mjs
node verification/audit-api-content.mjs
node verification/compare-all.mjs
node verification/mobile-theme-check.mjs
node verification/build-blind-gallery.mjs
```

Для браузерных проверок нужен Google Chrome; они используют установленный пакет Playwright.
Скриншоты всех страниц — локальные артефакты, которые не хранятся в Git;
перед использованием галереи в свежей копии репозитория сгенерируйте их заново.
