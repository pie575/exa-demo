<div id="blind-visual-review">
  ## Слепая визуальная проверка
</div>

[Откройте галерею A/B-сравнений на 159 страниц](blind/index.html). Два скриншота
каждой страницы перемешиваются независимо друг от друга. Галерея сохраняет выбор
A/B/ничья в браузере. Четыре репрезентативные пары для десктопной и мобильной
версий также были проверены без обращения к ключу соответствия:
[итоговая проверка](blind/final-review.md). Более ранние независимые проверки
и соответствующие скриншоты хранятся в `blind/review-round-2/`.

Итоговые проверки репрезентативных пар не выявили значимого эстетического
преимущества ни у одной из версий. Две итоговые репрезентативные пары идентичны
попиксельно; остальные две различаются всего на 8 и 1 пиксель соответственно при
зафиксированном пороге ([измерения пикселей](representative-pixel-comparison.json)).
Это проверки снятых областей просмотра, а не утверждение о полной попиксельной
идентичности или эквивалентности размещённых сервисов. Из всех 159 страниц
основной текст совпадает на 158; единственное расхождение — временная метка
проверки на странице статуса, обновляемой в реальном времени.

<div id="fidelity-details">
  ## Детали точности воспроизведения
</div>

Импорт сохраняет production-тему, навигацию, пользовательские стили и
скрипты, шрифты, метаданные страниц, спецификации API и исходные MDX-компоненты.
Также восстанавливаются таблица Agent Examples, отсутствовавшая в экспорте в
Markdown, и 85 опубликованных меток изменений, пропущенных локальным рендерером.
Исходные ответы и контрольные суммы сохраняются в `source-snapshot/`.

Размещённый ИИ-ассистент Exa недоступен в локальном предпросмотре Mintlify. Его
локальные элементы управления вместо этого открывают рабочий поиск по документации. Внешние дашборды и
страницы API playground остаются внешними. URL для скачивания Markdown и схем
перенаправляют на идентичные `.txt`-файлы, поскольку встроенный сервер разработки
не отдаёт файлы с такими расширениями напрямую. Временные метки актуального статуса и
анимированные медиафайлы могут различаться от снимка к снимку.

<div id="reproduce">
  ## Воспроизведение
</div>

```sh
pnpm validate
pnpm check:links
pnpm audit:content
pnpm dev
# В другом терминале, при запущенном предпросмотре:
python3 verification/audit-content.py --url http://localhost:3000 --output verification/route-audit.json
python3 verification/check-exports.py
node verification/audit-interactions.mjs
node verification/audit-api-content.mjs
node verification/compare-all.mjs
node verification/mobile-theme-check.mjs
node verification/build-blind-gallery.mjs
```

Проверки в браузере требуют Google Chrome и используют установленный package Playwright.
Скриншоты всех страниц — это локально создаваемые артефакты, исключённые из Git;
пересоздайте их перед использованием галереи в новой копии репозитория.
