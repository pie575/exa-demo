[Polymarket](https://polymarket.com) — это платформа прогнозных рынков, где
рыночные цены отражают подразумеваемую вероятность реальных событий участниками
рынка. [Exa Connect](/ru/docs/agent/connect/overview) предоставляет
доступ только для чтения к публичным рыночным данным Polymarket.

Подключите `polymarket` к запуску [Exa Agent](/ru/docs/agent/quickstart) — и
агент будет обращаться к Polymarket параллельно с веб-поиском Exa.

<div id="use-it-for">
  ## Для чего использовать
</div>

* Поиск прогнозных рынков и текущей подразумеваемой рынком вероятности по интересующей теме.
* Сравнение того, как подразумеваемая вероятность исхода менялась со временем.
* Анализ ликвидности рынка, глубины заявок на покупку/продажу и крупнейших держателей позиций.
* Просмотр текущих позиций трейдера и его недавней ончейн-активности.

<div id="provider-id">
  ## ID провайдера
</div>

Используйте это значение в `dataSources`:

```text theme={null}
polymarket
```

<div id="pricing">
  ## Тарификация
</div>

API чтения Polymarket бесплатны и не требуют аутентификации, поэтому вызовы инструментов Polymarket
ничего не стоят: вы платите только по
[стандартным тарифам за запуск Agent](/ru/docs/agent/quickstart#pricing).

<div id="data-available">
  ## Доступные данные
</div>

| Данные               | Описание                                                                                                        |
| -------------------- | --------------------------------------------------------------------------------------------------------------- |
| Рынки и события      | Текущие прогнозные рынки и события с ценами, отражающими подразумеваемую вероятность, объёмом и ликвидностью. |
| История цен          | Как подразумеваемая вероятность исхода менялась во времени.                                                     |
| Книги заявок         | Актуальная глубина заявок на покупку/продажу и спред по исходу рынка.                                           |
| Держатели и трейдеры | Крупнейшие держатели позиций по рынку, а также текущие позиции трейдера и его недавняя ончейн-активность.       |

<div id="example">
  ## Пример
</div>

Узнайте подразумеваемую рынком вероятность снижения ставки ФРС и то, как она менялась в течение последнего месяца.

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query=(
          "What are the current market-implied odds of a Fed rate cut at the "
          "next FOMC meeting, and how have they moved over the past month?"
      ),
      data_sources=[{"provider": "polymarket"}],
      output_schema={
          "type": "object",
          "required": ["market", "currentProbability", "trend"],
          "properties": {
              "market": {"type": "string", "description": "the market question"},
              "currentProbability": {"type": "number", "description": "between 0 and 1"},
              "trend": {"type": "string", "description": "how the implied probability moved over the past month"},
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

  ```typescript TypeScript theme={null}
  import Exa from "exa-js";

  const exa = new Exa();
  const run = await exa.agent.runs.create({
    query:
      "What are the current market-implied odds of a Fed rate cut at the next FOMC meeting, and how have they moved over the past month?",
    dataSources: [{ provider: "polymarket" }],
    outputSchema: {
      type: "object",
      required: ["market", "currentProbability", "trend"],
      properties: {
        market: { type: "string", description: "the market question" },
        currentProbability: { type: "number", description: "between 0 and 1" },
        trend: { type: "string", description: "how the implied probability moved over the past month" },
      },
    },
  });
  ```

