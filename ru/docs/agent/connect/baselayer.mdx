[Baselayer](https://baselayer.com) — это платформа Know Your Business (KYB), которая
проверяет юридические лица США по авторитетным регистрационным данным и данным о рисках. Она
находит компанию по названию и адресу и возвращает полный профиль: руководителей,
регистрации в штатах, структуру юридического лица и статус проверки.

Подключите `baselayer` к запуску [Exa Agent](/ru/docs/agent/quickstart) через
[Exa Connect](/ru/docs/agent/connect/overview) — и агент будет обращаться к
Baselayer наряду с веб-поиском Exa.

<div id="use-it-for">
  ## Для чего использовать
</div>

* KYB-онбординг и проверка поставщиков и клиентов.
* Due diligence в отношении руководителей, регистрационных данных и структуры юридического лица.
* Скрининг компаний на риски и попадание в списки наблюдения.

<div id="provider-id">
  ## ID провайдера

<div id="pricing">
  ## Тарификация
</div>

Baselayer тарифицирует каждый заказ отдельно, и ставка зависит от операции и её
параметров:

| Операция                                                                         | Цена                                              |
| -------------------------------------------------------------------------------- | ------------------------------------------------- |
| Поиск компаний                                                                   | `$1.00 / search`                                  |
| Просмотр компании / руководителей / регистраций / обратный поиск по руководителю | Бесплатно (чтение результатов предыдущего поиска) |
| Поиск залоговых обременений                                                      | `$2.00 / state searched`                          |
| Поиск судебных дел                                                               | `$1.00 / category (litigation, bankruptcy)`       |
| Проверка по спискам наблюдения                                                   | `$0.10 – $0.25 / list requested`                  |
| Отраслевая классификация                                                         | `$0.35 / call`                                    |
| Анализ сайта                                                                     | `$0.35 / call`                                    |
| Присутствие в вебе                                                               | `$0.15 – $0.35 / selected analysis`               |
| Международный поиск компаний                                                     | `$4.00 / search`                                  |

Выбор параметров влияет на цену: поиск залоговых обременений по двум штатам обойдётся
в $4.00, проверка по всем шести поддерживаемым спискам наблюдения — в $1.35, а вызов
для анализа присутствия в вебе оценивается как сумма выбранных вами видов анализа (или
набора Baselayer по умолчанию — прогноз NAICS и анализ сайта — если вы не выбрали ни одного).

  exa = Exa()
  run = exa.agent.runs.create(

      output_schema={
          "type": "object",
          "required": ["business"],
          "properties": {
              "business": {
                  "type": "object",
                  "required": ["name", "verified", "incorporationState", "officers"],
                  "properties": {
                      "name": {"type": "string"},

                      "incorporationState": {"type": "string"},
                      "officers": {
                          "type": "array",
                          "items": {
                              "type": "object",

                              "properties": {
                                  "name": {"type": "string"},
                                  "title": {"type": "string"},
                              },
                          },
                      },
                  },
              }
          },
      },
  )
