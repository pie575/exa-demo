[Fiber.ai](https://fiber.ai) — это B2B-платформа данных с актуальной информацией о более чем 40 млн компаний, 850 млн человек и 30 млн вакансий. Ищите актуальные данные о компаниях, людях и вакансиях и дополняйте неполные записи рабочими и личными адресами электронной почты и номерами телефонов.

Подключите `fiber` к запуску [Exa Agent](/ru/docs/agent/quickstart) через
[Exa Connect](/ru/docs/agent/connect/overview) — и агент будет обращаться к
Fiber.ai параллельно с веб-поиском Exa.

<div id="use-it-for">
  ## Для чего использовать
</div>

* Очистка CRM: поиск человека по рабочему адресу электронной
  почты или личному адресу электронной почты, а также обогащение неполных записей о компаниях и людях.
* Отслеживание сигналов LinkedIn в реальном времени: смена работы, повышения, новые
  должности, изменения численности персонала и привлечение инвестиций.
* Поиск релевантных публикаций в LinkedIn, X, Instagram, TikTok, Reddit и
  YouTube, сбор комментариев и реакций к ним и последующее обогащение контактных
  данных авторов.
* Поиск среди более чем 40 млн компаний и 850 млн людей и обогащение данных о
  потенциальных клиентах рабочим адресом электронной почты и личным адресом электронной почты и номерами телефонов.

<div id="pricing">
  ## Тарификация
</div>

Fiber.ai тарифицирует услуги в кредитах по цене `$0.02 / credit`, и с каждого вызова списывается
столько кредитов, сколько по нему сообщает Fiber:

| Операция                                 | Кредиты                                |
| ---------------------------------------- | -------------------------------------- |
| Search                                   | 2 + 1 за каждый возвращённый результат |
| Поиск компании                           | ~2 за каждого возвращённого кандидата  |
| Поиск человека / обратный поиск по email | 2                                      |
| Раскрытие контакта                       | 2 (рабочий адрес электронной почты) – 5 (телефон)        |

Вызовы, не вернувшие совпадений (или списания по которым Fiber возвращает), бесплатны. Стоимость зависит от выбранных параметров: `numResults` при поиске компании задаёт, за какое количество кандидатов вы платите, а для поиска основную часть стоимости определяет число результатов.

<div id="example">
  ## Пример
</div>

Составьте B2B-список потенциальных клиентов: финтех-компании из Нью-Йорка на стадии Series A со штатом 50–200 сотрудников.

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="I'm building a B2B sales prospecting list using a B2B company database. Find Series A fintech companies in New York with 50-200 employees, and for each return the company's LinkedIn profile, domain, employee count, and funding stage.",
      data_sources=[{"provider": "fiber"}],
      output_schema={
          "type": "object",
          "required": ["companies"],
          "properties": {
              "companies": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["name", "domain", "employeeCount", "fundingStage"],
                      "properties": {
                          "name": {"type": "string"},
                          "domain": {"type": "string"},
                          "employeeCount": {"type": "number"},
                          "fundingStage": {"type": "string"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

  ```javascript JavaScript theme={null}

            },
          },

    },
  });
  ```
