[Fiber.ai](https://fiber.ai) — это B2B-платформа данных с актуальной информацией о более чем 40 млн
компаний, 850 млн людей и 30 млн вакансий. Ищите свежие данные о компаниях, людях и вакансиях,
а также дополняйте неполные записи рабочими и личными адресами электронной почты и
номерами телефонов.

Подключите `fiber` к выполнению [Exa Agent](/ru/docs/agent/quickstart) через
[Exa Connect](/ru/docs/agent/connect/overview), и agent будет обращаться к
Fiber.ai одновременно с веб-поиском Exa.

<div id="use-it-for">
  ## Для чего использовать
</div>

* Очистка CRM: обратный поиск человека по рабочему или личному адресу электронной
  почты, а также обогащение неполных записей о компании или человеке.
* Отслеживание сигналов LinkedIn в реальном времени: смена должности, повышения,
  новые места работы, изменение численности персонала и привлечение
  финансирования.
* Поиск релевантных публикаций в LinkedIn, X, Instagram, TikTok, Reddit и
  YouTube, сбор комментариев и реакций к ним и последующее обогащение
  контактных данных авторов.
* Поиск по более чем 40 млн компаний и 850 млн человек с обогащением данных о
  потенциальных клиентах рабочими и личными адресами электронной почты, а также
  номерами телефонов.

<div id="pricing">
  ## Цены
</div>

Fiber.ai тарифицирует использование в credits по ставке `$0.02 / credit`, и за каждый вызов списывается
столько credits, сколько укажет Fiber:

| Операция                                             | Credits                                           |
| ---------------------------------------------------- | ------------------------------------------------- |
| Search                                               | 2 + 1 за каждый возвращённый результат            |
| Поиск компании                                       | ~2 за каждого возвращённого кандидата             |
| Поиск человека / обратный поиск по электронной почте | 2                                                 |
| Раскрытие контакта                                   | 2 (рабочий адрес электронной почты) – 5 (телефон) |

Вызовы, не вернувшие совпадений (или те, плату за которые Fiber возвращает), бесплатны. Стоимость зависит от
выбранных параметров: `numResults` при поиске компании определяет, за сколько
кандидатов вы платите, а для search основную часть стоимости формирует количество результатов.

<div id="example">
  ## Пример
</div>

Соберите список потенциальных клиентов B2B: финтех-компании стадии Series A в Нью-Йорке с числом сотрудников от 50 до 200.

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="I'm building a B2B sales prospecting list using a B2B company database. Find Series A fintech companies in New York with 50-200 employees, and for each return the company's LinkedIn profile, domain, employee count, and funding stage.",
      data_sources=[{"provider": "fiber"}],
      output_schema={
          "type": "object",
          "required": ["companies"],
          "properties": {
              "companies": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["name", "domain", "employeeCount", "fundingStage"],
                      "properties": {
                          "name": {"type": "string"},
                          "domain": {"type": "string"},
                          "employeeCount": {"type": "number"},
                          "fundingStage": {"type": "string"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

  ```javascript JavaScript theme={null}

            },
          },
        },
      },
    },
  });
  ```
