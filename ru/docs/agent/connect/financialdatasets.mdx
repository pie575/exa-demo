[Financial Datasets](https://financialdatasets.ai) предоставляет готовые к
машинной обработке данные о компаниях и рынках для AI agents. Через
[Exa Connect](/ru/docs/agent/connect/overview) agents могут получать
текущие и исторические цены, сведения о компаниях, финансовую отчётность и
оценочные мультипликаторы, прибыль, данные о владении инсайдерами и
институциональными инвесторами, документы SEC и их отдельные разделы, новости
компаний, а также проводить скрининг рынка США по фундаментальным criteria.

Подключите `financial_datasets` к выполнению [Exa Agent](/ru/docs/agent/quickstart),
и agent будет обращаться к Financial Datasets параллельно с веб-поиском Exa.

<div id="use-it-for">
  ## Для чего использовать
</div>

* Создание структурированных аналитических срезов по компаниям.
* Анализ финансовых показателей, оценки стоимости и исторических трендов.
* Чтение документов SEC и извлечение разделов, таких как факторы риска и MD&amp;A.
* Изучение инсайдерских сделок и институциональной доли владения.
* Скрининг рынка США по фундаментальным criteria.
* Отслеживание новостей компаний и значимых событий.

<div id="data-available">
  ## Доступные данные
</div>

Каждый из перечисленных ниже наборов данных доступен у провайдера `financial_datasets`;
agent сам выбирает подходящий под задачу:

| Набор данных                | Что возвращает                                                                                       |
| --------------------------- | ---------------------------------------------------------------------------------------------------- |
| Бенефициарное владение      | Бенефициарные владельцы с долей от 5% по формам 13D/13G, включая активистские и пассивные доли.      |
| Сведения о компании         | Название, сектор, отрасль, биржа, местоположение, SEC CIK, классификация SIC.                        |
| Новости компании            | Свежие новостные статьи по ticker.                                                                   |
| Прибыль                     | Квартальная выручка и EPS с изменением год к году и превышением/недобором прогноза.                  |
| Финансовые метрики          | Рыночная капитализация, EV, P/E, P/B, P/S, EV/EBITDA, PEG, маржинальность, ROE/ROA/ROIC, рост, EPS.  |
| Финансовая отчётность       | Отчёт о прибылях и убытках, баланс и отчёт о движении денежных средств из документов SEC.            |
| Исторические цены акций     | Бары OHLCV за период с детализацией по дням/неделям/месяцам/годам.                                   |
| Состав индексных фондов     | Составляющие ETF/индексных фондов по весу либо фонды, владеющие заданной ценной бумагой.             |
| Владение инсайдеров         | Доли инсайдеров по формам SEC 3 и 5 (акции, принадлежащие officers, директорам, владельцам 10%).     |
| Сделки инсайдеров           | Инсайдерские сделки по форме SEC 4 (имя, role, тип, количество акций, стоимость).                    |
| Институциональное владение  | Институциональные держатели по 13F, количество акций и заявленная стоимость.                         |
| Процентные ставки           | Текущие и исторические ключевые ставки центральных банков (ФРС, ЕЦБ, Банк Японии и другие).          |
| Разделы документов SEC      | Извлечённый текст конкретных разделов 10-K/10-Q/8-K (например, факторы риска, MD&amp;A).             |
| Документы SEC               | Metadata документов и прямые ссылки на EDGAR, с возможностью фильтрации по типу формы.               |
| Сегментированная отчётность | Выручка, операционная прибыль и другие статьи в разбивке по продуктам, бизнес-сегментам и географии. |
| Снимок цены акции           | Текущая цена в реальном времени, изменение за день и время quote.                                    |
| Скринер акций               | Компании, соответствующие фундаментальным criteria фильтрации.                                       |

<div id="provider-id">
  ## Идентификатор провайдера
</div>

Используйте это значение в `dataSources`:

```text theme={null}
financial_datasets
```
