[Financial Datasets](https://financialdatasets.ai) предоставляет готовые для
машинной обработки данные о компаниях и рынках для ИИ-агентов. Через
[Exa Connect](/ru/docs/agent/connect/overview) агенты могут получать
текущие и исторические цены, сведения о компаниях, финансовую отчётность и
оценочные метрики, данные о прибыли, информацию о владении со стороны инсайдеров и
институциональных инвесторов, документы SEC и их отдельные разделы, новости компаний,
а также проводить скрининг американского рынка по фундаментальным
критериям.

Подключите `financial_datasets` к запуску [Exa Agent](/ru/docs/agent/quickstart) —
и агент будет обращаться к Financial Datasets параллельно с веб-поиском Exa.

<div id="use-it-for">
  ## Для чего использовать
</div>

* Формирование структурированных аналитических срезов по компаниям.
* Анализ финансовых показателей, оценки стоимости и исторических трендов.
* Чтение документов SEC и извлечение отдельных разделов — например, факторов риска и MD&amp;A.
* Изучение сделок инсайдеров и институциональной структуры владения.
* Скрининг рынка США по фундаментальным критериям.
* Отслеживание новостей компаний и значимых событий.

<div id="data-available">
  ## Доступные данные
</div>

Каждый из перечисленных ниже наборов данных доступен у провайдера `financial_datasets`;
агент сам выбирает подходящий под задачу:

| Набор данных               | Что возвращает                                                                                       |
| -------------------------- | ---------------------------------------------------------------------------------------------------- |
| Бенефициарное владение     | Бенефициарные владельцы с долей от 5% из форм 13D/13G, включая активистские и пассивные пакеты.      |
| Сведения о компании        | Название, сектор, отрасль, биржа, местоположение, SEC CIK, классификация SIC.                        |
| Новости компании           | Свежие новостные статьи по тикеру.                                                                   |
| Отчётность о прибыли       | Квартальная выручка и EPS с изменением год к году и отклонениями от прогнозов.                       |
| Финансовые показатели      | Капитализация, EV, P/E, P/B, P/S, EV/EBITDA, PEG, маржинальность, ROE/ROA/ROIC, рост, EPS.           |
| Финансовая отчётность      | Отчёт о прибылях и убытках, баланс и отчёт о движении денежных средств из документов SEC.            |
| Исторические котировки     | Бары OHLCV за период с детализацией по дням/неделям/месяцам/годам.                                   |
| Активы индексных фондов    | Состав ETF/индексных фондов по весам либо фонды, владеющие заданной бумагой.                         |
| Владение инсайдеров        | Доли инсайдеров из форм SEC 3 и 5 (акции во владении руководителей, директоров, владельцев 10%).     |
| Сделки инсайдеров          | Сделки инсайдеров по форме SEC 4 (имя, роль, тип, количество акций, стоимость).                      |
| Институциональное владение | Институциональные держатели по 13F, количество акций и заявленная стоимость.                         |
| Процентные ставки          | Текущие и исторические ключевые ставки центробанков (ФРС, ЕЦБ, Банк Японии и другие).                |
| Разделы отчётов SEC        | Извлечённый текст конкретных разделов 10-K/10-Q/8-K (например, факторы риска, MD&amp;A).             |
| Документы SEC              | Метаданные документов и прямые ссылки на EDGAR, при необходимости с фильтром по типу формы.          |
| Сегментная отчётность      | Выручка, операционная прибыль и другие статьи в разбивке по продуктам, бизнес-сегментам и географии. |
| Снимок цены акции          | Текущая цена в реальном времени, изменение за день и время котировки.                                |
| Скринер акций              | Компании, соответствующие заданным фундаментальным критериям фильтрации.                             |

<div id="provider-id">
  ## Идентификатор провайдера
</div>

Используйте это значение в `dataSources`:

```text theme={null}
financial_datasets
```
