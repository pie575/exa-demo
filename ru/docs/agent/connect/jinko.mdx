[Jinko](https://gojinko.com) — это тревел-платформа для поиска авиабилетов и
отелей с ценами в реальном времени. Ищите актуальные предложения по маршруту и
дате, подбирайте номера и тарифы отелей по направлению или конкретным объектам, а также
изучайте направления, доступные из ваших аэропортов вылета.

Подключите `jinko` к запуску [Exa Agent](/ru/docs/agent/quickstart) через
[Exa Connect](/ru/docs/agent/connect/overview) — и агент будет обращаться к
Jinko наряду с веб-поиском Exa.

<div id="use-it-for">
  ## Для чего использовать
</div>

* Поиск актуальных предложений на авиабилеты с тарифами, правилами провоза багажа и условиями обмена для конкретного маршрута и даты.
* Подбор отелей с актуальными ценами на номера в нужном направлении или повторная проверка цен по конкретным отелям.
* Подбор направлений и гибких дат с учётом диапазонов дат, классов обслуживания и бюджета.

<div id="provider-id">
  ## Provider ID
</div>

Используйте это значение в `dataSources`:

```text theme={null}
jinko
```

<div id="example">
  ## Пример
</div>

Найдите пляжные направления, куда можно улететь из Нью-Йорка в марте дешевле $400 за перелёт туда и обратно.

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="Find beach destinations reachable from New York for under $400 round-trip in March.",
      data_sources=[{"provider": "jinko"}],
      output_schema={
          "type": "object",
          "required": ["destinations"],
          "properties": {
              "destinations": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["city", "iataCode", "lowestFare"],
                      "properties": {
                          "city": {"type": "string"},
                          "iataCode": {"type": "string"},
                          "lowestFare": {"type": "number", "description": "round-trip fare in USD"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

  ```javascript JavaScript theme={null}

  const exa = new Exa();

      },
    },
  });
  ```
