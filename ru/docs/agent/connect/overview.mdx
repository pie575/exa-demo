Exa Connect встраивает премиум-партнёров данных в рабочий цикл Exa Agent. Подключите
провайдера к запуску — и Exa Agent обратится к базе данных этого партнёра параллельно с веб-поиском,
а затем объединит результаты в один структурированный ответ, подкреплённый источниками.

Ещё не работали с запусками агента? Начните с [руководства по Exa Agent](/ru/docs/agent/quickstart),
а затем возвращайтесь, чтобы подключить партнёров данных.

<Tip>
  Exa Agent уже ищет по всему [индексу данных](/ru/docs/search/data/overview) — тем же источникам
  новостей, кода, компаний и людей, что и Search API. Exa Connect добавляет к этому
  премиум-базы данных партнёров.
</Tip>

<Tip>
  Предпочитаете MCP? Exa Agent и [Exa Connect](/ru/docs/agent/connect/overview) доступны в [Exa MCP](/ru/docs/get-started/exa-mcp#exa-agent). Включите `tools=agent_run`, чтобы выполнять многошаговые исследования, составлять списки, проводить enrichment и получать структурированный вывод из Claude, Cursor и других MCP-клиентов.
</Tip>

<div id="why-exa-connect">
  ## Зачем нужен Exa Connect
</div>

* **Премиальные данные без отдельных интеграций.** Получайте доступ к данным партнёров без заключения договоров и подключения SDK. Вы обращаетесь к одному API Exa.
* **Exa берёт техническую часть на себя.** Мы отвечаем за аутентификацию у провайдеров, выбор инструментов, повторные попытки и ранжирование результатов.
* **Exa Agent сам выбирает источник.** Когда ваш `outputSchema` запрашивает «ежемесячные посещения по данным Similarweb» или «подтверждённых руководителей», Exa Agent вызывает подходящий партнёрский инструмент, а не строит догадки по веб-странице.
* **Данные индекса и партнёров за один запуск.** Connect работает поверх индекса Exa. Exa Agent задействует каждый источник там, где тот сильнее всего, и приводит ссылки на результаты.

<div id="how-it-works">
  ## Как это работает
</div>

1. **Подключите** одного или нескольких провайдеров через массив `dataSources` в
   [`POST /agent/runs`](/ru/docs/reference/agent-api/create-a-run).
2. Exa Agent **выбирает подходящий инструмент** для каждого шага на основе вашего запроса и
   `outputSchema`: данные партнёра или веб-поиск Exa.
3. Данные партнёров **объединяются с результатами веб-исследования** в структурированном ответе
   с указанием источников.

<div id="pricing">
  ## Тарификация
</div>

<Note>
  Стоимость Exa Connect добавляется к стандартной [стоимости запусков Agent](/ru/docs/agent/quickstart#pricing).
  Вы оплачиваете обычные расходы Agent на вычисления и search, а также плату за вызов провайдера для каждого вызова инструмента Exa Connect.
</Note>

| Провайдер                                            | Цена                                          |
| ---------------------------------------------------- | --------------------------------------------- |
| [Fiber.ai](/ru/docs/agent/connect/fiber#pricing)        | `$0.02 / credit`                              |
| [Similarweb](/ru/docs/agent/connect/similarweb#pricing) | `$0.30 / credit`                              |
| [Baselayer](/ru/docs/agent/connect/baselayer#pricing)   | `$0.10 – $4.00 / order (varies by operation)` |
| [Polymarket](/ru/docs/agent/connect/polymarket#pricing) | `Free`                                        |
| Affiliate.com                                        | `$0.015 / call`                               |
| Particle                                             | `$0.015 / call`                               |
| Financial Datasets                                   | `$0.01 / call`                                |
| Jinko                                                | `$0.005 / call`                               |

Fiber.ai тарифицируется в credits, а не за вызов, поскольку её собственная плата
зависит от типа вызова: search стоит 2 credits плюс 1 за каждый возвращённый результат,
поиск компании или человека оплачивается за каждого возвращённого кандидата
(поэтому увеличение `numResults` при поиске компании ради уточнения неоднозначного
названия обойдётся дороже), а раскрытие контакта — 2–5 credits в зависимости от
того, запрашиваете ли вы рабочую почту, личную почту или телефон. С вас списывается
столько credits, сколько Fiber указывает по каждому вызову; вызовы без совпадений бесплатны.
См. [Тарификацию Fiber.ai](/ru/docs/agent/connect/fiber#pricing).

Similarweb тарифицируется в data credits (примерно один на метрику × строку × месяц),
поэтому цена вызова зависит от значений `numResults`/`months` — от 1 до 15 credits за вызов.
С вас списывается столько credits, сколько Similarweb указывает по каждому вызову; вызовы,
не возвращающие данных, бесплатны. См. [Тарификацию Similarweb](/ru/docs/agent/connect/similarweb#pricing).

Baselayer тарифицируется за заказ, и ставка зависит от операции: KYB-поиск бизнеса —
$1.00, поиск залогов UCC — $2.00 за каждый штат, поиск по судебным и банкротным
делам — $1.00 за категорию, проверка по спискам наблюдения — $0.10–$0.25 за
запрошенный список, отраслевая классификация и анализ сайта — по $0.35,
веб-присутствие — сумма выбранных видов анализа ($0.15–$0.35 каждый), международный
поиск бизнеса — $4.00. Последующие обращения к результатам ранее выполненного
поиска бизнеса (просмотр компании, руководители, регистрации, обратный поиск по
руководителю) бесплатны. См. [Тарификацию Baselayer](/ru/docs/agent/connect/baselayer#pricing).

          "required": ["company"],

<div id="combining-providers">
  ### Комбинирование провайдеров
</div>

Подключайте столько партнёров, сколько требуется вашей задаче. Exa Agent обращается к каждому из них в той области, где он наиболее силён, и объединяет полученные результаты с веб-поиском в единый структурированный ответ:

```json theme={null}
{
  "dataSources": [
    { "provider": "similarweb" },
    { "provider": "fiber" },
    { "provider": "harmonic" }
  ]
}
```

Полное пошаговое руководство, в том числе о том, как составить запрос и `outputSchema`, чтобы срабатывал каждый
partner, см. в разделе [Combining providers](/ru/docs/agent/connect/combining-providers).
