Exa Connect встраивает премиальных партнёров данных в рабочий цикл Exa Agent. Присоедините
провайдера к выполнению, и Exa Agent обратится к базе данных этого партнёра параллельно с веб-поиском,
а затем объединит результаты в единый структурированный ответ, подкреплённый источниками.

Впервые работаете с выполнениями агента? Начните с [руководства по Exa Agent](/ru/docs/agent/quickstart),
а затем возвращайтесь, чтобы присоединить партнёров данных.

<Tip>
  Exa Agent уже ищет по всему [индексу данных](/ru/docs/search/data/overview) — тем же источникам
  новостей, кода, компаний и людей, что и Search API. Exa Connect добавляет
  к этому премиальные базы данных партнёров.
</Tip>

<Tip>
  Предпочитаете MCP? Exa Agent и [Exa Connect](/ru/docs/agent/connect/overview) доступны в [Exa MCP](/ru/docs/get-started/exa-mcp#exa-agent). Включите `tools=agent_run`, чтобы выполнять многошаговые исследования, list-building, enrichment и получать структурированный вывод из Claude, Cursor и других MCP-клиентов.
</Tip>

<div id="why-exa-connect">
  ## Зачем нужен Exa Connect
</div>

* **Премиальные данные без отдельных интеграций.** Получайте доступ к данным партнёров, не заключая договоры и не подключая SDK. Вы обращаетесь к одному API Exa.
* **Exa берёт на себя всю техническую обвязку.** Мы отвечаем за аутентификацию провайдеров, выбор инструментов, повторные попытки и ранжирование результатов.
* **Exa Agent сам выбирает источник.** Когда ваш `outputSchema` запрашивает «ежемесячные посещения по данным Similarweb» или «подтверждённых руководителей», Exa Agent вызывает подходящий инструмент партнёра, а не пытается угадать данные по веб-странице.
* **Данные индекса и партнёров в одном выполнении.** Connect работает поверх индекса Exa. Exa Agent задействует каждый источник там, где тот силён, и приводит ссылки на результаты.

<div id="how-it-works">
  ## Как это работает
</div>

1. **Подключите** одного или нескольких провайдеров через массив `dataSources` в
   [`POST /agent/runs`](/ru/docs/reference/agent-api/create-a-run).
2. Exa Agent **выбирает подходящий инструмент** для каждого шага на основе вашего запроса и
   `outputSchema`: данные партнёра или веб-поиск Exa.
3. Данные партнёра **объединяются с результатами веб-исследования** в структурированном выводе,
   к которому прилагаются источники.

<div id="pricing">
  ## Pricing
</div>

<Note>
  Стоимость Exa Connect суммируется со стандартной [стоимостью выполнения Agent](/ru/docs/agent/quickstart#pricing).
  Вы оплачиваете обычные затраты Agent на вычисления и search, а также плату за вызов провайдера за каждый tool call в Exa Connect.
</Note>

| Провайдер                                            | Цена                                          |
| ---------------------------------------------------- | --------------------------------------------- |
| [Fiber.ai](/ru/docs/agent/connect/fiber#pricing)        | `$0.02 / credit`                              |
| [Similarweb](/ru/docs/agent/connect/similarweb#pricing) | `$0.30 / credit`                              |
| [Baselayer](/ru/docs/agent/connect/baselayer#pricing)   | `$0.10 – $4.00 / order (varies by operation)` |
| [Polymarket](/ru/docs/agent/connect/polymarket#pricing) | `Free`                                        |
| Affiliate.com                                        | `$0.015 / call`                               |
| Particle                                             | `$0.015 / call`                               |
| Financial Datasets                                   | `$0.01 / call`                                |
| Jinko                                                | `$0.005 / call`                               |

Fiber.ai тарифицирует в credits, а не по вызовам, поскольку его собственная плата
зависит от типа вызова: search стоит 2 credits плюс 1 за каждый возвращённый результат,
поиск компании или человека тарифицируется за каждого возвращённого кандидата
(поэтому увеличение `numResults` при поиске компании для устранения неоднозначности
имени обойдётся дороже), а раскрытие контакта — 2–5 credits в зависимости от того,
запрашиваете ли вы рабочий адрес электронной почты, личный адрес электронной почты
или телефон. С вас списывается то количество credits, которое Fiber указывает по каждому вызову;
вызовы без совпадений бесплатны. См. [стоимость Fiber.ai](/ru/docs/agent/connect/fiber#pricing).

Similarweb тарифицирует в data credits (примерно по одному на метрику × строку × месяц),
поэтому цена вызова зависит от `numResults`/`months` — от 1 до 15 credits за вызов.
С вас списывается то количество credits, которое Similarweb указывает по каждому вызову; вызовы,
не возвращающие данных, бесплатны. См. [стоимость Similarweb](/ru/docs/agent/connect/similarweb#pricing).

Baselayer тарифицирует по заказам, и ставка зависит от операции: KYB-поиск бизнеса —
$1.00, поиск залогов UCC — $2.00 за каждый state, по которому выполняется поиск, поиск судебных дел и дел
о банкротстве — $1.00 за категорию, проверка по контрольным спискам — $0.10–$0.25
за каждый запрошенный список, отраслевая классификация и анализ сайта — по $0.35,
веб-присутствие — сумма выбранных видов анализа ($0.15–$0.35 за каждый), а
международный поиск бизнеса — $4.00. Последующие обращения к результатам ранее
выполненного поиска бизнеса (просмотр компании, руководителей, регистрации, обратный
поиск по руководителям) бесплатны. См. [стоимость Baselayer](/ru/docs/agent/connect/baselayer#pricing).

  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="Profile Anthropic: total funding and estimated monthly web traffic.",
      data_sources=[{"provider": "fiber"}, {"provider": "similarweb"}],
      output_schema={
          "type": "object",
          "required": ["company"],
          "properties": {
              "company": {
                  "type": "object",
                  "required": ["name", "totalFunding", "monthlyVisits"],
                  "properties": {

                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

<div id="combining-providers">
  ### Комбинирование провайдеров
</div>

Подключайте столько партнёров, сколько нужно для вашей задачи. Exa Agent обращается к каждому из них в той области, где он сильнее всего, и объединяет результаты с веб-поиском в единый структурированный ответ:

```json theme={null}
{
  "dataSources": [
    { "provider": "similarweb" },
    { "provider": "fiber" },
    { "provider": "harmonic" }
  ]
}
```

Полное пошаговое руководство, в том числе о том, как составить запрос и `outputSchema`, чтобы срабатывал каждый
partner, см. в разделе [Комбинирование провайдеров](/ru/docs/agent/connect/combining-providers).
