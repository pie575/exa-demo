[Similarweb](https://www.similarweb.com) — один из ведущих источников аналитики
цифрового рынка. Сервис моделирует трафик и вовлечённость миллионов сайтов и
приложений: оценку посещений, источники трафика, демографию аудитории и
конкурентное окружение любого домена.

Подключите `similarweb` к выполнению [Exa Agent](/ru/docs/agent/quickstart) через
[Exa Connect](/ru/docs/agent/connect/overview), и agent будет обращаться к
Similarweb параллельно с веб-поиском Exa.

## Для чего использовать {#use-it-for}

* Сравнение веб-трафика и вовлечённости компании с показателями конкурентов.
* Построение карты конкурентов домена и сайтов с пересекающейся аудиторией.
* Оценка ёмкости рынков и отбор компаний по цифровому следу.
* Обогащение исследований компаний и категорий реальными поведенческими данными.

## Идентификатор провайдера {#provider-id}

Используйте это значение в `dataSources`:

```text theme={null}
similarweb
```

## Pricing {#pricing}

Similarweb тарифицирует данные в credits по ставке `$0.30 / credit`, и за каждый call списывается столько credits, сколько сообщает Similarweb. Количество credits растёт вместе с объёмом возвращаемых данных — примерно один credit на точку данных (метрика × строка × месяц), — поэтому стоимость call определяется его parameters:

| Tool                  | Credits                                                                             |
| --------------------- | ----------------------------------------------------------------------------------- |
| Traffic and rank      | до 7 за каждый запрошенный месяц (1–2 месяца)                                       |
| Similar sites         | 3 за возвращённый сайт (1–5 сайтов)                                                 |
| Traffic sources       | 10                                                                                  |
| Top referrers         | 3 за возвращённый источник перехода (1–5)                                           |
| Top countries         | 3 за возвращённую страну (1–5)                                                      |
| Top pages             | 2 за возвращённую страницу (1–7)                                                    |
| Top keywords          | 1–10 (примерно 1 на 100 точек данных по ключевым словам; 50 ключевых слов — это ~7) |
| Keyword overview      | 1–2                                                                                 |
| Audience demographics | 8                                                                                   |
| Audience overlap      | 2 за комбинацию доменов (2–3 домена: 6–14)                                          |
| Technologies          | 10                                                                                  |
| Top sites by category | 1 за возвращённый сайт (1–10)                                                       |

Calls, не вернувшие данных (неизвестный домен или домен с низким traffic, ключевое слово без объёма search), бесплатны. `numResults` и `months` определяют, за сколько точек данных вы платите, поэтому указывайте минимальные значения, достаточные для задачи.

## Пример {#example}

Найдите 10 быстрорастущих B2B SaaS-компаний и оцените их веб-трафик.

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="Find 10 fast-growing B2B SaaS companies and their estimated web traffic.",
      data_sources=[{"provider": "similarweb"}],
      output_schema={
          "type": "object",
          "required": ["companies"],
          "properties": {
              "companies": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["name", "domain", "monthlyVisits"],
                      "properties": {
                          "name": {"type": "string"},
                          "domain": {"type": "string"},
                          "monthlyVisits": {"type": "number", "description": "from Similarweb"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

  ```javascript JavaScript theme={null}
  import Exa from "exa-js";

  const exa = new Exa();
  const run = await exa.agent.runs.create({
    query: "Find 10 fast-growing B2B SaaS companies and their estimated web traffic.",
    dataSources: [{ provider: "similarweb" }],
    outputSchema: {
      type: "object",
      required: ["companies"],
      properties: {
        companies: {
          type: "array",

              name: { type: "string" },
              domain: { type: "string" },
              monthlyVisits: { type: "number", description: "from Similarweb" },
            },
          },
        },
      },
    },
  });
  ```
