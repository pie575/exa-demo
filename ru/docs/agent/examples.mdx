<div id="production-checklist">
  ## Чек-лист перед запуском в продакшн
</div>

* Задавайте Agent конкретный `query`, в котором указаны единица работы и желаемое качество источников.
* Для известных записей используйте `input.data`, а не вставляйте строки прямо в промпт.
* Используйте `input.exclusion` для записей, которые не должны возвращаться повторно.
* Добавляйте `outputSchema`, если результат обрабатывается кодом далее по цепочке.
* Используйте `maxItems` для массивов, когда нужны предсказуемые объём и стоимость.
* Сохраняйте возвращённый `id` запуска, чтобы опрашивать его статус, воспроизводить события, анализировать затраты или позже продолжить с этого запуска.
