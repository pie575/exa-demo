title: "Пакетное действие над мониторами"
description: "Выполняет пакетное действие над мониторами, которые соответствуют
  заданным фильтрам.


  Поддерживаемые действия:

  - **delete**: безвозвратно удалить подходящие мониторы

  - **pause**: приостановить подходящие мониторы

  - **unpause**: возобновить подходящие мониторы


  Укажите `dry_run: true` (значение по умолчанию), чтобы заранее посмотреть,
  какие мониторы будут затронуты, прежде чем выполнять действие. Результаты
  возвращаются постранично с помощью параметра `limit`; повторяйте запросы в
  цикле, пока `has_more` не станет `false`, чтобы обработать все подходящие
  мониторы."
