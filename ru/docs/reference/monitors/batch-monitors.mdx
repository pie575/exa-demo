title: "Пакетное действие над мониторами"
description: "Выполняет пакетное действие над monitor'ами, соответствующими
  заданным фильтрам.


  Поддерживаемые действия:

  - **delete**: безвозвратно удалить подходящие monitor'ы

  - **pause**: приостановить подходящие monitor'ы

  - **unpause**: возобновить подходящие monitor'ы


  Укажите `dry_run: true` (значение по умолчанию), чтобы заранее посмотреть,
  какие monitor'ы будут затронуты, не выполняя само действие. Результаты
  разбиваются на страницы с помощью параметра `limit`; повторяйте запросы, пока
  `has_more` не станет `false`, чтобы обработать все подходящие monitor'ы."
