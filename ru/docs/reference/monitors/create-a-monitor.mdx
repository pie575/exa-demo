title: "Создание monitor"
description: "Создаёт новый Monitor для регулярного выполнения поисков Exa по
  расписанию.


  Monitor автоматически выполняет ваш поисковый запрос по заданному расписанию и
  доставляет результаты на ваш эндпоинт вебхука с автоматической дедупликацией:


  - **Фильтрация по дате** — загружается только контент, появившийся после
  последнего запуска


  - **Семантическая дедупликация** — отслеживаются предыдущие результаты, чтобы
  показывать только новое


  В ответе возвращается `webhookSecret` — он передаётся только один раз, при
  создании. Сохраните его в надёжном месте для проверки подписи вебхука."
