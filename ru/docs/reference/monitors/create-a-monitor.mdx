title: "Создание монитора"
description: "Создаёт новый Monitor для запуска повторяющихся Exa search по
  расписанию.


  Monitors автоматически выполняют ваш поисковый запрос по заданному расписанию
  и доставляют результаты на ваш эндпоинт вебхука с автоматической
  дедупликацией:


  - **Фильтрация по дате** загружает только контент, появившийся с момента
  последнего выполнения


  - **Семантическая дедупликация** отслеживает предыдущие выводы, чтобы
  показывать только новое


  Ответ содержит `webhookSecret`, который возвращается только один раз при
  создании. Сохраните его в надёжном месте для верификации подписи вебхука."
