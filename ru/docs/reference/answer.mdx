  Exa. `/answer` выполняет Exa search и с помощью LLM формирует:

  1. Прямой ответ на конкретные запросы (например, на вопрос «Какая столица
  Франции?» вернётся «Париж»)

  2. Подробное summary со ссылками на источники для открытых запросов (например,
  на запрос «Каково состояние ИИ в здравоохранении?» вернётся summary со
  ссылками на релевантные источники)


  Ответ включает как сгенерированный текст, так и источники, использованные при
  его создании. Эндпоинт также поддерживает потоковую передачу (`stream=True`),
  при которой токены возвращаются по мере генерации.


  Кроме того, можно использовать совместимый с OpenAI [интерфейс chat
  completions](/docs/integrations/openai-sdk#answer).\n"
