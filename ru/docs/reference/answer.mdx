description: "Получите ответ LLM на вопрос, подкреплённый результатами поиска
  Exa. `/answer` выполняет поиск Exa и с помощью LLM генерирует одно из двух:

  1. Прямой ответ на конкретные вопросы (например, на запрос «Какая столица
  Франции?» вернётся «Париж»)

  2. Подробную сводку со ссылками на источники для открытых вопросов (например,
  на запрос «Каково состояние ИИ в здравоохранении?» вернётся сводка со ссылками
  на релевантные источники)


  Ответ включает как сгенерированный текст, так и источники, использованные для
  его создания. Эндпоинт также поддерживает потоковую передачу (`stream=True`),
  при которой токены возвращаются по мере генерации.


  Кроме того, можно использовать совместимый с OpenAI [интерфейс chat
  completions](/docs/integrations/openai-sdk#answer).\n"

<Info>
  `/answer` поддерживает структурированный вывод через параметр `outputSchema`. Передайте объект [JSON Schema](https://json-schema.org/draft-07) — и вместо обычной строки ответ вернётся в виде структурированного JSON, соответствующего вашей схеме.
</Info>
