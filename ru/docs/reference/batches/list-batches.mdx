Пакеты возвращаются от новых к старым. Используйте `limit`, чтобы задать размер страницы, и `cursor` со значением `nextCursor` из предыдущего ответа, чтобы получить следующую страницу. Передайте `status=completed`, чтобы вывести только завершённые пакеты; для таких выборок используется отдельный cursor, поэтому передавайте `status=completed` при запросе каждой страницы.
