Батчи возвращаются от новых к старым. Используйте `limit` для управления размером страницы и `cursor` со значением `nextCursor` из предыдущего ответа, чтобы получить следующую страницу. Передайте `status=completed`, чтобы получить только завершённые батчи; для таких списков используется отдельный cursor, поэтому передавайте `status=completed` при запросе каждой страницы.
