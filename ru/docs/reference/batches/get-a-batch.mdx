Используйте этот эндпоинт, чтобы опрашивать пакет, пока он не перейдёт в состояние `completed`, `cancelled` или `expired`. После завершения пакета поле `resultsUrl` содержит недолговечную предподписанную ссылку на файл результатов в формате JSONL; запросите пакет повторно, чтобы получить новую ссылку.
