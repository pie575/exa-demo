Используйте этот эндпоинт, чтобы опрашивать пакет, пока он не перейдёт в статус `completed`, `cancelled` или `expired`. После завершения пакета в `resultsUrl` возвращается предподписанный URL с коротким сроком действия для файла результатов в формате JSONL; запросите пакет повторно, чтобы получить новый URL.
