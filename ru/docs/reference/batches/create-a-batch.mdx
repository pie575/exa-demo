Каждый элемент в `requests` — это `POST`-запрос к `/search` или `/agent/runs` с уникальным в пределах батча `customId`. Этот же `customId` возвращается в файле результатов, что позволяет сопоставить строки вывода с исходными данными. Полный рабочий процесс описан в [руководстве по Batch API](/ru/docs/batch/quickstart).
