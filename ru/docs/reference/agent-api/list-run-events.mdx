openapi: "/ru/docs/exa-spec.yaml GET /agent/runs/{id}/events"
timestamp: false

По умолчанию этот эндпоинт возвращает постраничный список сохранённых событий в формате JSON. Укажите `Accept: text/event-stream`, чтобы воспроизвести сохранённые события через SSE. Для постраничной выдачи JSON используйте `cursor`, а для воспроизведения через SSE — `Last-Event-ID`.
