openapi: "/ru/docs/exa-spec.yaml GET /agent/runs/{id}/events"
timestamp: false
---

По умолчанию этот эндпоинт возвращает постраничный JSON-список сохранённых событий. Укажите `Accept: text/event-stream`, чтобы воспроизвести сохранённые события через SSE. Для постраничного вывода в JSON используйте `cursor`, а для воспроизведения через SSE — `Last-Event-ID`.
