---
title: "Остановка запуска"
description: "Корректно остановите выполняющийся запуск Agent и сохраните уже
  собранные результаты."
openapi: "/ru/docs/exa-spec.yaml POST /agent/runs/{id}/stop"
timestamp: false
---

Если запуск всё ещё активен, агент досрочно завершает работу и закрывает запуск с уже собранными результатами. Запуск завершается со статусом `completed` и `stopReason: stopped`. Оплачивается использование, накопленное до момента остановки. Если запуск уже достиг терминального статуса (completed, failed или cancelled), эндпоинт возвращает существующий запуск без изменений.

Чтобы немедленно прервать запуск без возврата результатов, используйте [cancel](/ru/docs/reference/agent-api/cancel-a-run).

<Note>
  Поддерживается только для запусков с уровнем усилий `max`. В заголовке запроса необходимо передать
  `Exa-Beta: agent-max-effort-2026-07-27`. Заголовок принимает список бета-токенов, разделённых запятыми.
</Note>
