---
title: "Остановка выполнения"
description: "Корректно остановите активное выполнение Agent и сохраните уже
  собранные результаты."
openapi: "/ru/docs/exa-spec.yaml POST /agent/runs/{id}/stop"
timestamp: false
---

Если выполнение ещё активно, agent подводит итоги и завершает его досрочно с уже собранными результатами. Выполнение заканчивается со статусом `completed` и `stopReason: stopped`. Оплачивается использование, накопленное до момента остановки. Если выполнение уже достигло терминального статуса (completed, failed или cancelled), эндпоинт возвращает существующее выполнение без изменений.

Чтобы немедленно прервать выполнение без возврата результатов, используйте [cancel](/ru/docs/reference/agent-api/cancel-a-run).

<Note>
  Поддерживается только для выполнений с `effort` `max`. В header запроса необходимо передать
  `Exa-Beta: agent-max-effort-2026-07-27`. Header принимает список бета-токенов через запятую.
</Note>
