Создайте выполнение, задав `query` на естественном языке. Добавьте `outputSchema` для валидированного структурированного JSON, `input.data` для строк, которые нужно обработать, `input.exclusion` для записей или сущностей, которые следует исключить, либо `previousRunId`, чтобы продолжить с завершённого выполнения.

Укажите `Accept: text/event-stream`, чтобы получать события потоком по мере того, как выполнение создаётся, запускается и завершается.

<Note>
  **Connect:** Передайте `dataSources`, чтобы предоставить agent доступ к сторонним провайдерам данных во время выполнения. Подробности см. в [руководстве по Connect](/ru/docs/agent/quickstart#connect-data-sources).
</Note>
