timestamp: false
---

Создайте запуск, задав `query` на естественном языке. Добавьте `outputSchema` для валидированного структурированного JSON, `input.data` — для строк, которые нужно обработать, `input.exclusion` — для записей или сущностей, которые следует исключить, либо `previousRunId`, чтобы продолжить с завершённого запуска.

Укажите `Accept: text/event-stream`, чтобы получать события потоком по мере создания, запуска и завершения.

<Note>
  **Connect:** передайте `dataSources`, чтобы предоставить агенту доступ к сторонним поставщикам данных во время запуска. Подробности см. в [руководстве по Connect](/ru/docs/agent/quickstart#connect-data-sources).
</Note>
