---
title: "Отмена выполнения"
description: "Отмена выполнения Agent, находящегося в очереди или уже запущенного."
openapi: "/ru/docs/exa-spec.yaml POST /agent/runs/{id}/cancel"
timestamp: false
---

Если выполнение ещё активно, оно сразу переходит в состояние `cancelled` и завершается, не возвращая результатов. Выполнение завершается со статусом `cancelled` и `stopReason: cancelled`. Использование, накопленное до отмены, тарифицируется. Если выполнение уже достигло терминального статуса (completed, failed или cancelled), эндпоинт вернёт существующее выполнение без изменений.
