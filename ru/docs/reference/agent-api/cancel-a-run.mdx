---
title: "Отмена запуска"
description: "Отмена запуска Agent, находящегося в очереди или выполняющегося."
openapi: "/ru/docs/exa-spec.yaml POST /agent/runs/{id}/cancel"
timestamp: false
---

Если запуск ещё активен, он сразу переходит в состояние `cancelled` и завершается, не возвращая результатов. Запуск заканчивается со статусом `cancelled` и `stopReason: cancelled`. Использование, накопленное до отмены, тарифицируется. Если запуск уже перешёл в терминальный статус (completed, failed или cancelled), эндпоинт вернёт существующий запуск без изменений.
