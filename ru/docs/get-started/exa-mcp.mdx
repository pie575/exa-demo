Используйте Exa MCP, чтобы расширить встроенный веб-поиск в ChatGPT, Claude и MCP-совместимых инструментах поисковыми возможностями Exa, включая веб-поиск, поиск по коду, [Exa Agent](/ru/docs/agent/quickstart) и [Exa Connect](/ru/docs/agent/connect/overview).

Exa предоставляет размещённый сервер, который работает в любом MCP-клиенте:

```text theme={null}
https://mcp.exa.ai/mcp
```

Чтобы начать, API key не требуется. Exa MCP имеет открытый исходный код и доступен на [GitHub](https://github.com/exa-labs/exa-mcp-server).

## Аутентификация {#authentication}

Exa MCP поддерживает три режима аутентификации:

| Режим     | Когда использовать                                                            | Настройка                                                                                                                  |
| --------- | ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Без ключа | Бесплатное использование с ограничением частоты запросов, без входа и API key | Подключитесь к `https://mcp.exa.ai/mcp`                                                                                    |
| OAuth     | Интерактивные клиенты, установка из marketplace, использование в production   | Подключитесь к `https://mcp.exa.ai/mcp?login` и войдите в Exa в браузере. Использование учитывается за вашей командой Exa. |
| API key   | Клиенты без поддержки MCP OAuth                                               | Подключитесь к `https://mcp.exa.ai/mcp`, передав ваш API key в header `x-api-key`                                          |

### Вход через OAuth {#sign-in-with-oauth}

ChatGPT, Claude и другие установки из marketplace при необходимости предложат вам выполнить вход. В любом клиент с поддержкой MCP OAuth вы можете запустить тот же процесс, подключившись к:

```text theme={null}
https://mcp.exa.ai/mcp?login
```

Ваш клиент находит сервер авторизации Exa, открывает окно входа в браузере и управляет доступом.

### Использование API key {#use-an-api-key}

<Card title="Получите свой Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  Создайте ключ в дашборде. Новые аккаунты получают бесплатные credits.
</Card>

Добавьте header `x-api-key` в настройки MCP-сервера Exa:

```text theme={null}
x-api-key: YOUR_EXA_API_KEY
```

## Доступные инструменты {#available-tools}

| Инструмент                | Доступность                  | Для чего использовать                                                 |
| ------------------------- | ---------------------------- | --------------------------------------------------------------------- |
| `web_search_exa`          | Включён по умолчанию         | Веб-поиск и получение релевантного, готового к использованию контента |
| `web_fetch_exa`           | Включён по умолчанию         | Чтение очищенного контента с одного или нескольких известных URL      |
| `web_search_advanced_exa` | Доступен при подключении     | Настройка веб-поиска с расширенными фильтрами и параметрами           |
| `agent_run`               | Доступен с OAuth или API key | Многошаговый Research, list-building, enrichment и структурированный вывод  |

Используйте параметр URL `tools`, чтобы выбрать, какие инструменты видит ваш клиент. Например, чтобы включить все инструменты:

```text theme={null}
https://mcp.exa.ai/mcp?tools=web_search_exa,web_fetch_exa,web_search_advanced_exa,agent_run
```

<Tip>
  Явно заданный список `tools` заменяет набор по умолчанию, поэтому перечислите в нём все инструменты, которые хотите включить, в том числе веб-поиск и загрузку контента.
</Tip>

## Exa Agent {#exa-agent}

Используйте [Exa Agent](/ru/docs/agent/quickstart) для исследований, в которых недостаточно одного search — например, чтобы собрать список, проверить каждый item по criteria или получить структурированные результаты.

Выполнения Agent тарифицируются по использованию, поэтому для `agent_run` нужен OAuth или API key. Этот URL запускает OAuth и добавляет Agent к инструментам по умолчанию:

```text theme={null}
https://mcp.exa.ai/mcp?login&tools=web_search_exa,web_fetch_exa,agent_run
```

Если вы используете API key, опустите `login` и добавьте ключ, как описано в разделе [Аутентификация](#authentication).

<Steps>
  <Step title="Опишите, что вам нужно">
    Сформулируйте исследовательскую задачу обычным языком. Ваш ассистент передаёт запрос в `agent_run` вместе с `query`, а Exa Agent сам определяет, что искать, читает источники и сверяет найденное с запросом.

    Просите Agent вернуть `outputSchema` только тогда, когда вашему приложению нужны результаты в едином формате JSON. Вы можете передать схему ассистенту в system prompt или попросить сгенерировать её за вас.
  </Step>

  <Step title="Получите результат">
    По завершении исследования tool call передаёт вашему ассистенту полный пакет результатов:

    * Текстовые выводы
    * Источники, на которых они основаны
    * Проверенный JSON, если вы указали `outputSchema`
    * Использование и стоимость

    Ответ ассистента строится на основе этого пакета, поэтому сразу скажите, что делать с выводом. Можно попросить кратко изложить результаты, сравнить их, сохранить в файл или что-то ещё.
  </Step>

  <Step title="Продолжите, если нужно больше времени">
    Исследование, которое не укладывается в один вызов MCP, не завершается ошибкой: инструмент возвращает `status: "running"` вместе с `id`, пока выполнение продолжается на стороне Exa. Ваш ассистент снова вызывает `agent_run`, передавая этот `id` как `runId`, и подхватывает то же выполнение.
  </Step>
</Steps>

<Accordion title="Дополнительные параметры управления" icon="sliders-horizontal">
  | Поле              | Для чего использовать                                                     |
  | ----------------- | ------------------------------------------------------------------------- |
  | `systemPrompt`    | Дать Agent дополнительные указания по исследованию или оценке результатов |
  | `outputSchema`    | Вернуть ответ в конкретном формате JSON                                   |
  | `input.data`      | Обогатить строки или сущности, которые у вас уже есть                     |
  | `input.exclusion` | Пропустить результаты, о которых вы уже знаете                            |
  | `dataSources`     | Добавить до пяти провайдеров [Exa Connect](/ru/docs/agent/connect/overview)  |
  | `previousRunId`   | Построить новый запрос на основе завершённого исследования                |
  | `effort`          | Выбрать глубину исследования, которое выполнит Agent                      |
</Accordion>

<Tip>
  Используйте `runId`, чтобы продолжать ждать результатов текущей работы. Используйте `previousRunId`, чтобы задать новый follow-up на основе уже завершённой работы.
</Tip>

Шаблоны схем вывода, режимы effort, источники данных и цены смотрите в [руководстве по Exa Agent](/ru/docs/agent/quickstart).

## Расширенный поиск {#advanced-search}

Используйте `web_search_advanced_exa`, когда в запросе нужны явные фильтры по категориям или доменам, диапазоны дат, текстовые ограничения, геотаргетинг, расширение запроса, краткие сводки, highlights, контроль свежести или обход подстраниц. Для обычных поисковых запросов оставляйте `web_search_exa`: он даёт модели меньший набор инструментов и требует меньше настройки.

Расширенный поиск не требует аутентификации, однако для аутентифицированных подключений применяются ваш тарифный план и ваши лимиты частоты запросов. Включите его вместе с инструментами по умолчанию так:

```text theme={null}
https://mcp.exa.ai/mcp?tools=web_search_exa,web_fetch_exa,web_search_advanced_exa
```

Инструмент MCP предоставляет основные параметры [Search API](/ru/docs/reference/search) в виде удобных для инструмента полей, таких как `includeDomains`, `startPublishedDate`, `enableHighlights` и `maxAgeHours`. Точные имена полей смотрите в схеме инструмента в вашем клиенте.

## Устранение неполадок {#troubleshooting}

<AccordionGroup>
  <Accordion title="Ошибка превышения лимита частоты запросов (429)">
    Подключение использует бесплатные лимиты частоты запросов Exa. Войдите через OAuth или добавьте собственный API key, затем переподключитесь, чтобы запросы шли по тарифному плану и лимитам вашей команды.

    <Card title="Получите свой Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      Создайте ключ в дашборде. Новым аккаунтам начисляются бесплатные credits.
    </Card>
  </Accordion>

  <Accordion title="Agent отсутствует или запрашивает аутентификацию">
    `agent_run` не включён по умолчанию и не может использовать бесплатные лимиты частоты запросов. Добавьте его в URL-параметр `tools`, затем подключитесь с `?login` или настройте API key. Полный URL смотрите в разделе [Exa Agent](#exa-agent).
  </Accordion>

  <Accordion title="Вход через OAuth не открывается">
    Убедитесь, что ваш клиент поддерживает MCP OAuth, и подключитесь к `https://mcp.exa.ai/mcp?login`. После изменения URL перезапустите клиент. Если клиент не может завершить MCP OAuth, используйте вместо этого API key.
  </Accordion>

  <Accordion title="Инструменты не отображаются">
    Явно заданный параметр `tools` заменяет список инструментов по умолчанию. Проверьте, что все нужные инструменты присутствуют в URL, затем перезапустите MCP-клиент, чтобы он заново получил список инструментов.
  </Accordion>

  <Accordion title="Claude desktop не подключается">
    Используйте встроенный коннектор: выберите **+** (или **Add connectors**) → вкладка **Connectors** → найдите **Exa** → нажмите **+**.
  </Accordion>

  <Accordion title="Файл конфигурации не найден">
    Типичные расположения файла конфигурации:

    * Cursor: `~/.cursor/mcp.json`
    * fx: `~/.fx/mcp.json`
    * VS Code: `.vscode/mcp.json` (в корне проекта)
    * Claude desktop (macOS): `~/Library/Application Support/Claude/claude_desktop_config.json`
    * Claude desktop (Windows): `%APPDATA%\Claude\claude_desktop_config.json`
  </Accordion>
</AccordionGroup>
