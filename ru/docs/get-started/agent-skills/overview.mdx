Навыки Exa учат кодинг-агентов выполнять search, получать content и создавать решения на базе API Exa. Найти их можно в репозитории с открытым исходным кодом [exa-labs/agent-skills](https://github.com/exa-labs/agent-skills).

Каждый навык содержит markdown-файлы, соответствующие открытому стандарту [Agent Skills](https://agentskills.io), поэтому одни и те же файлы устанавливаются в любой совместимый agent.

<div id="install">
  ## Установка
</div>

Установите все навыки Exa сразу:

```bash theme={null}
npx skills add exa-labs/agent-skills
```

<Card title="Получите свой Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  Создайте ключ в дашборде. Новые аккаунты получают бесплатные credits.
</Card>

<Note>
  Укажите свой ключ в переменной `EXA_API_KEY` в окружении вашего agent.
</Note>

Либо откройте страницу навыка ниже и скопируйте её установочный промпт в свой agent. Промпт установит этот навык и проверит ваш API key, не выводя его на экран.
