Используйте этот навык, чтобы научить своего агента вызывать Exa Search через cURL или обычный HTTP с соблюдением лучших практик.

<Card title="Получите Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  Создайте key в панели управления. Новым аккаунтам начисляются бесплатные credits.
</Card>

<Note>
  Задайте свой key в переменной `EXA_API_KEY` в окружении агента.
</Note>

<div id="setup">
  ## Настройка
</div>

**Вариант A: установить навык напрямую:**

```bash theme={null}
npx skills add exa-labs/agent-skills --skill "exa-search"
```

**Вариант B: скопируйте этот промпт в свой кодинг-агент.**

Приведённый ниже промпт установит навык и проверит ваш API key, не выводя его на экран:

```text Copy this setup prompt into your agent theme={null}
Настрой на этой машине навык агента Exa exa-search.

Цель:
- Установить навык exa-search, чтобы мой кодинг-агент мог обращаться к Exa Search напрямую через cURL или обычный HTTP.
- Добиться, чтобы Exa API key работал, НЕ раскрывая, не выводя и не вставляя ключ в этот чат.

Выбранный агент:
- Claude Code, Codex, Cursor или любой агент, совместимый с Agent Skills
- Глобальные каталоги установки: ~/.claude/skills (Claude Code), ~/.codex/skills (Codex), ~/.agents/skills (Cursor / другие)
- Локальные каталоги установки в проекте: .claude/skills (Claude Code), .agents/skills (Codex / Cursor / другие)

Источник навыка:
- URL SKILL.md: https://raw.githubusercontent.com/exa-labs/agent-skills/main/skills/exa-search/SKILL.md

Что нужно сделать:
1. СНАЧАЛА установи навык, до любой настройки ключа. Если работаешь внутри репозитория, предпочитай локальную установку в проекте; иначе используй соответствующий глобальный каталог из списка выше. Создай выбранный каталог навыков и скачай навык:
   mkdir -p <skills-dir>/exa-search && curl -fsSL "https://raw.githubusercontent.com/exa-labs/agent-skills/main/skills/exa-search/SKILL.md" -o <skills-dir>/exa-search/SKILL.md
   Затем убедись, что файл <skills-dir>/exa-search/SKILL.md существует.
2. Проверь, доступен ли уже Exa API key ИЗ ТВОЕГО СОБСТВЕННОГО ОКРУЖЕНИЯ ВЫПОЛНЕНИЯ КОМАНД — используй тот же инструмент/оболочку, в которой будешь запускать навык, а не проси меня вывести ключ. Навык сначала берёт ключ из EXA_API_KEY, затем из файла ~/.config/exa/key, поэтому проверь оба варианта, ни разу не выводя значение:
   printf '%s\n' "${EXA_API_KEY:+env-set}"; [ -s ~/.config/exa/key ] && printf 'file-set\n'
   Твоя оболочка, скорее всего, неинтерактивная и НЕ подгружает автоматически интерактивные профили вроде ~/.zshrc или ~/.bashrc, поэтому заданный мной там ключ может выглядеть установленным для меня, но пустым для тебя. Если ни одна проверка ничего не показала, ключ всё равно может лежать в интерактивном профиле, который твоя оболочка пропускает: найди нужный файл, НЕ выводя его значение, командой `grep -l EXA_API_KEY ~/.zshrc ~/.zshenv ~/.bashrc ~/.profile ~/.config/fish/config.fish 2>/dev/null` (выводятся только имена файлов — НИКОГДА не запускай обычный `grep`/`cat`/`echo` по профилю, так как строка `export EXA_API_KEY=...` раскроет секрет в нашем чате). Затем выполни `source` для этого файла внутри своей команды и повтори проверку наличия выше; если ключ появился, добавляй тот же префикс `source ...;` ко всем последующим командам, которым нужен ключ.
3. Только если ключ нигде не удалось найти, настрой его БЕЗ ручного редактирования профилей оболочки и БЕЗ вставки ключа в этот чат. Скажи мне создать/скопировать ключ на https://dashboard.exa.ai/api-keys, а дальше я сам в своём терминале либо экспортирую EXA_API_KEY, либо запишу его в ~/.config/exa/key с правами 600 — никогда не проси меня вставлять ключ в чат. После этого дождись моего подтверждения, прежде чем продолжать.
4. Проверь ключ пробным запросом из своей оболочки — возьми его из переменной окружения или из файла и выведи только код состояния:
   KEY="${EXA_API_KEY:-$(cat ~/.config/exa/key 2>/dev/null)}"
   curl -s -o /dev/null -w "%{http_code}\n" -X POST https://api.exa.ai/search \
     -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
     -d '{"query":"exa.ai","numResults":1}'
   Оставь конечную точку, заголовки и тело запроса ровно в том виде, как они записаны (не угадывай схему). Ответ должен быть 200, а не 401/429. Если на шаге 2 тебе понадобился префикс `source ...;`, чтобы увидеть ключ из окружения, добавь его и здесь.
5. Объясни, как перезапустить моего агента или заново просканировать навыки, чтобы он обнаружил навык.

Жёсткое правило на всех шагах: ключ — это секрет. Проверять его можно только по наличию/длине (`${EXA_API_KEY:+set}`, `[ -s ~/.config/exa/key ]`) или по HTTP-коду состояния — никогда не выводи на экран и не применяй `echo`, `cat` или `grep` с выводом к файлам и переменным, которые могут его содержать, и никогда не пытайся «замаскировать» файл с ключом регулярным выражением. Если ключ всё же оказался раскрыт, скажи мне заменить его на https://dashboard.exa.ai/api-keys.
```
