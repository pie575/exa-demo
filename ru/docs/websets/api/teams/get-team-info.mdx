<div id="overview">
  ## Обзор
</div>

Эндпоинт Get Team Info возвращает информацию об аутентифицированной команде, в том числе о текущем использовании параллелизма и заданных лимитах. Это полезно для мониторинга использования Websets API и понимания действующих лимитов частоты запросов.

<div id="response">
  ## Ответ
</div>

Ответ содержит:

* **object**: всегда «team»
* **id**: уникальный идентификатор вашей команды
* **name**: название вашей команды
* **concurrency**: текущее использование — количество активных запросов и запросов в очереди
* **limits**: лимиты параллелизма вашей команды

<div id="concurrency-fields">
  ### Поля параллелизма
</div>

Объект `concurrency` отражает текущее состояние ваших запросов:

* **active**: количество запросов, обрабатываемых в данный момент
* **queued**: количество запросов, ожидающих обработки

<div id="limits-fields">
  ### Поля лимитов
</div>

Объект `limits` отображает лимиты, настроенные для вашей команды:

* **maxConcurrent**: максимальное количество запросов, обрабатываемых одновременно (null — без ограничений)
* **maxQueued**: максимальное количество запросов, которые могут находиться в очереди (null — без ограничений)
