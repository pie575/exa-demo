description: "Обновляет целевой URL, список подписанных событий или метаданные
  вебхука. Незаданные поля остаются без изменений."
---

<Warning>
  **Перенаправления не выполняются.** Если вы меняете URL, убедитесь, что это
  конечный адрес. Эндпоинты, отвечающие перенаправлением 3xx, будут считаться
  неудачными доставками.
</Warning>
