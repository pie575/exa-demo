---
title: "Создание вебхука"
openapi: "/ru/docs/exa-spec.yaml POST /v0/webhooks"
timestamp: false
description: "Создаёт вебхук, который доставляет выбранные события на ваш URL по
  мере их возникновения.


  В ответе содержится подписывающий `secret`, используемый для проверки
  доставок; он возвращается только при создании."
---

<Warning>
  **Перенаправления не выполняются.** Доставки вебхуков отправляются напрямую на
  зарегистрированный URL. Если ваш эндпоинт отвечает перенаправлением 3xx,
  доставка будет считаться неуспешной. Всегда регистрируйте конечный URL назначения.
</Warning>
