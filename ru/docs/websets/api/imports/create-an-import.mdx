description: "Создаёт новый импорт для загрузки ваших данных в Websets. Импорты
  можно использовать, чтобы:


  - **Enrich**: обогащать данные дополнительной информацией с помощью нашего
  движка enrichment на базе ИИ

  - **Search**: искать по вашим данным с помощью агентного search в Websets с
  фильтрами на естественном языке

  - **Exclude**: исключать дубликаты и уже известные результаты из результатов
  поиска


  После создания импорта вы можете загрузить данные по возвращённому `uploadUrl`
  до истечения `uploadValidUntil` (по умолчанию 1 час)."
