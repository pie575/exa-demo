description: "Создаёт новый import для загрузки ваших данных в Websets. Imports
  можно использовать, чтобы:


  - **Enrich**: обогатить данные дополнительной информацией с помощью нашего
  движка enrichment на базе ИИ

  - **Search**: выполнять запросы к данным через агентный поиск Websets с
  фильтрами на естественном языке

  - **Exclude**: не допустить появления дубликатов или уже известных результатов
  в ваших searches


  После создания import вы можете загружать данные по возвращённому `uploadUrl`
  до момента `uploadValidUntil` (по умолчанию 1 час)."
