description: "Создаёт новый `Monitor`, который постоянно пополняет ваши Websets
  свежими данными.


  Monitors автоматически запускаются по заданному вами расписанию, благодаря
  чему ваши Websets остаются актуальными без ручного вмешательства:


  - **Поиск нового содержимого**: выполняйте операции `search`, чтобы находить
  новые items, соответствующие вашим criteria

  - **Обновление существующего содержимого**: выполняйте операции `refresh`,
  чтобы обновлять содержимое и enrichments у items

  - **Автоматическое расписание**: задавайте выражения `cron` и `timezone` для
  точного управления расписанием"
