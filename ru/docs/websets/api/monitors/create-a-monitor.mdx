description: "Создаёт новый `Monitor`, который будет непрерывно поддерживать
  ваши Websets в актуальном состоянии.


  Мониторы автоматически запускаются по заданному вами расписанию, так что ваши
  Websets остаются актуальными без ручного вмешательства:


  - **Поиск нового контента**: выполнение операций `search` для обнаружения
  новых элементов, соответствующих вашим criteria

  - **Обновление существующего контента**: выполнение операций `refresh` для
  обновления contents элементов и enrichment

  - **Автоматическое расписание**: настройка выражений `cron` и `timezone` для
  точного управления расписанием"
