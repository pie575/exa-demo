## Обзор {#overview}

Функция исключения результатов гарантирует, что при создании новых searches вы не получите дублирующихся результатов. Указав URL, которые нужно исключить, на основе предыдущих Websets или загруженных CSV-файлов, вы сможете сосредоточиться на поиске новых, уникальных результатов, дополняющих уже имеющиеся данные.

<br />

## Как это работает {#how-it-works}

<img src="/docs/images/websets/exclude-flow.png" alt="Параметры исключения результатов при создании Webset" width="1466" height="857" data-path="images/websets/exclude-flow.png" />

1. Начните создание нового Webset
2. Под criteria на боковой панели нажмите «Exclude»
3. Выберите один из прошлых Websets или загрузите CSV-файл со списком URL для исключения. Источников для исключения можно выбрать несколько.
4. Запустите search — в результатах будут только новые элементы, не попавшие в ваши исключения

Максимальное количество результатов, которые можно исключить, зависит от вашего тарифного плана.

<br />

## Когда использовать исключения {#when-to-use-exclusions}

* Поиск лидов, которых ещё нет в вашей CRM
* Повторный запуск предыдущих searches с уточнёнными criteria
* Исключение результатов, о которых вы уже знаете
