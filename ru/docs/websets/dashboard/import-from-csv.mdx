<div id="overview">
  ## Обзор
</div>

Функция импорта из CSV позволяет превратить имеющиеся CSV-файлы со ссылками в полноценные Websets. Это идеальный вариант, если у вас уже есть список сайтов, компаний или ресурсов, который нужно обогатить дополнительными данными или отфильтровать по criteria поиска.

<br />

<div id="how-it-works">
  ## Как это работает
</div>

<img src="/docs/images/websets/import-flow.png" alt="Процесс импорта CSV для создания Webset" width="1512" height="857" data-path="images/websets/import-flow.png" />

1. Нажмите «Start from CSV» и выберите CSV-файл
2. Укажите, в каком столбце находятся URL для анализа
3. Прежде чем продолжить, проверьте, как будут импортированы ваши данные
4. Ваши URL превращаются в Webset с enrichment&#39;ами и метаданными

<br />

<div id="csv-preparation">
  ## Подготовка CSV
</div>

Убедитесь, что в CSV-файле есть столбец с URL

* Для поиска по людям: URL должны быть ссылками на профили LinkedIn (например, [https://linkedin.com/in/username](https://linkedin.com/in/username))
* Для поиска по компаниям: URL должны быть ссылками на главные страницы сайтов компаний (например, [https://example.com](https://example.com))
* Для остальных видов поиска: подойдёт URL любого типа

Если URL отсутствуют, Websets попытается определить их по информации в каждой строке CSV и по дополнительным сведениям, которые вы укажете.

Максимальное количество результатов для импорта зависит от вашего тарифного плана.

<div id="what-happens-next">
  ## Что дальше?
</div>

После импорта ваш CSV превращается в полноценный Webset, в котором вы можете:

<div id="enrich-with-custom-columns">
  ### Обогащение данных пользовательскими столбцами
</div>

Добавляйте любую нужную информацию о каждом URL:

* Контактные данные (адреса электронной почты, номера телефонов)
* Метрики компании (выручка, численность сотрудников)
* Анализ контента (тональность, темы, краткие изложения)
* Собственные данные под ваш сценарий использования

<div id="apply-search-criteria">
  ### Применение criteria поиска
</div>

Фильтруйте импортированные URL по заданным criteria:

* Стадия развития или размер компании
* Отрасль или сектор
* Географическое расположение
* Тип контента или тема
