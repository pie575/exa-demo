## Обзор {#overview}

Функция «Импорт из CSV» позволяет превращать имеющиеся CSV-файлы с URL в полноценные Websets. Это идеальный вариант, когда у вас уже есть список сайтов, компаний или ресурсов, который нужно обогатить дополнительными данными или отфильтровать по критериям поиска.

<br />

## Как это работает {#how-it-works}

<img src="/docs/images/websets/import-flow.png" alt="Процесс импорта CSV для создания Webset" width="1512" height="857" data-path="images/websets/import-flow.png" />

1. Нажмите «Start from CSV» и выберите CSV-файл
2. Укажите, в каком столбце находятся URL, которые нужно проанализировать
3. Перед продолжением проверьте, как будут импортированы ваши данные
4. Ваши URL превращаются в Webset с enrichment и метаданными

<br />

## Подготовка CSV {#csv-preparation}

Убедитесь, что в вашем CSV-файле есть столбец с URL

* Для поиска по людям: URL должны быть ссылками на профили LinkedIn (например, [https://linkedin.com/in/username](https://linkedin.com/in/username))
* Для поиска по компаниям: URL должны быть ссылками на главные страницы сайтов компаний (например, [https://example.com](https://example.com))
* Для остальных типов поиска: подойдут URL любого типа

Если URL отсутствуют, Websets попытается определить их по информации в каждой строке CSV и дополнительным сведениям, которые вы укажете.

Максимальное количество импортируемых результатов зависит от вашего тарифного плана.

## Что дальше? {#what-happens-next}

После импорта ваш CSV превращается в полноценный Webset, в котором можно:

### Обогащение с помощью пользовательских колонок {#enrich-with-custom-columns}

Добавляйте любую нужную информацию о каждом URL:

* Контактные данные (адреса электронной почты, номера телефонов)
* Метрики компании (выручка, численность сотрудников)
* Анализ контента (тональность, темы, краткие сводки)
* Произвольные данные под ваш сценарий использования

### Применение критериев поиска {#apply-search-criteria}

Фильтруйте импортированные URL по заданным criteria:

* Стадия развития или размер компании
* Отрасль или сектор
* Географическое расположение
* Тип контента или тема
