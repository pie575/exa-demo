## Что такое Websets? {#what-are-websets}

Webset начинается с запроса на естественном языке и целевого количества items. Задайте criteria, которым должен соответствовать каждый результат, и поля enrichment, которые нужно заполнить для каждого принятого item. Результаты поступают асинхронно через дашборд, API или вебхуки.

Кроме того, websets можно собирать визуально в [Dashboard](/ru/docs/websets/dashboard/get-started), без единой строки кода.

<Info>
  Начинаете новый рабочий процесс list-building или enrichment? Используйте [Exa Agent](/ru/docs/agent/quickstart).
  Это руководство пригодится для поддержки или расширения существующей интеграции с Websets.
  Для Websets API нужен платный тариф Websets; credits для Search API и credits для Websets учитываются отдельно.
</Info>

## Как это работает {#how-it-works}

1. **Определите search:** укажите запрос на естественном языке, количество результатов, а также при необходимости criteria верификации и enrichments.
2. **Поиск и верификация:** Websets находит кандидатов и проверяет каждого по вашим criteria. Только подходящие результаты становятся items.
3. **Запуск enrichments:** для каждого проверенного item Websets находит запрошенные вами дополнительные данные, например имя CEO, сумму финансирования или контактную информацию.
4. **Получение результатов:** опрашивайте статус, подписывайтесь на обновления через вебхуки или следите за появлением items в дашборде.

## Ключевые возможности {#key-capabilities}

| Возможность              | Что она делает                                                                                             |
| ------------------------ | ---------------------------------------------------------------------------------------------------------- |
| **Верификация criteria** | Каждый результат проверяется по заданным вами правилам, поэтому вы получаете только релевантные совпадения |
| **Enrichments**          | Извлечение конкретных данных (текст, числа, даты, логические значения) для каждого результата              |
| **Monitors**             | Запуск searches по расписанию, чтобы ваш webset обновлялся автоматически                                   |
| **Вебхуки**              | HTTP-обратные вызовы в реальном времени при добавлении или enrichment items                                |
| **Imports**              | Загрузка собственных URL и запуск enrichments по ним                                                       |

## Quickstart для человека {#human-quickstart}

<Card title="Получите свой Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  Создайте ключ в дашборде. Новым аккаунтам начисляются бесплатные credits.
</Card>

Установите SDK:

<CodeGroup>
  ```bash Python theme={null}
  pip install exa-py
  ```

  ```bash JavaScript theme={null}
  npm install exa-js
  ```
</CodeGroup>

Затем выполните первый запрос:

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa
  from exa_py.websets.types import CreateWebsetParameters, CreateEnrichmentParameters
  import os

  exa = Exa(api_key=os.getenv("EXA_API_KEY"))

  webset = exa.websets.create(
      params=CreateWebsetParameters(
          search={
              "query": "Top AI research labs focusing on large language models",
              "count": 5
          },
          enrichments=[
              CreateEnrichmentParameters(
                  description="LinkedIn profile of VP of Engineering or related role",
                  format="text",
              ),
          ],
      )
  )

  print(f"Webset created with ID: {webset.id}")
  print(f"View your Webset at: {webset.dashboard_url}")

  # Дождитесь завершения обработки Webset
  webset = exa.websets.wait_until_idle(webset.id)

  # Получите items из Webset
  items = exa.websets.items.list(webset_id=webset.id)
  for item in items.data:
      print(f"Item: {item.model_dump_json(indent=2)}")
  ```

  ```javascript JavaScript theme={null}
  import Exa from "exa-js";

  const exa = new Exa(process.env.EXA_API_KEY);

  const webset = await exa.websets.create({
    search: {
      query: "Top AI research labs focusing on large language models",
      count: 10
    },
    enrichments: [
      { description: "Estimate the company's founding year", format: "number" }
    ],
  });

  console.log(`Webset created with ID: ${webset.id}`);
  console.log(`View your Webset at: ${webset.dashboardUrl}`);

  const idleWebset = await exa.websets.waitUntilIdle(webset.id, {
    timeout: 60000,
    pollInterval: 2000,
    onPoll: (status) => console.log(`Current status: ${status}...`)
  });

  const items = await exa.websets.items.list(webset.id, { limit: 10 });
  for (const item of items.data) {
    console.log(`Item: ${JSON.stringify(item, null, 2)}`);
  }
  ```

  ```bash cURL theme={null}
  curl -s -X POST "https://api.exa.ai/websets/v0/websets/" \
    -H "accept: application/json" \
    -H "content-type: application/json" \

    -d '{

        "count": 5
      },
      "enrichments": [
        {"description": "Find the company'\''s founding year", "format": "number"}
      ]
    }'
  ```
</CodeGroup>
