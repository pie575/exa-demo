Подключите Exa к Slack вашей команды. Упомяните **@Exa** в любом канале или треде и задайте исследовательский вопрос, поставьте задачу по составлению списка или запросите enrichment. Exa выполнит поиск в вебе, изучит источники и ответит прямо в треде, указав источники.

## Начало работы {#get-started}

### Установка {#installation}

1. Перейдите в [Dashboard &gt; Management &gt; Exa in Slack](https://dashboard.exa.ai/integrations/slack) и нажмите **Install**.

<img src="/docs/images/integrations/exa-slack/dashboard-install.png" alt="Страница Exa in Slack в дашборде Exa с кнопкой Install" width="3414" height="900" data-path="images/integrations/exa-slack/dashboard-install.png" />

2. Откроется окно авторизации OAuth в Slack. Выберите рабочее пространство, в которое нужно добавить Exa, и нажмите **Allow**.

<img src="/docs/images/integrations/exa-slack/oauth-approval.png" alt="Экран подтверждения OAuth в Slack для приложения Exa с уведомлением &#x22;App is not approved by Slack&#x22;, выбором рабочего пространства, запрашиваемыми разрешениями и кнопкой Allow" width="1820" height="1180" data-path="images/integrations/exa-slack/oauth-approval.png" />

<Note>
  Красное уведомление **«App is not approved by Slack»** появляется штатно, его можно игнорировать. Оно лишь означает,
  что Exa нет в публичном Slack Marketplace, и не указывает на какую-либо проблему.
</Note>

3. После установки пригласите @Exa в канал (или напишите ему в личные сообщения) и начинайте задавать вопросы.

## Как использовать Exa из Slack {#how-to-use-exa-from-slack}

В любом канале, куда добавлен Exa, упомяните @Exa и задайте свой вопрос:

```text theme={null}
@Exa найди все финтех-стартапы из Сан-Франциско на стадии Series A
```

Exa отвечает на ваш вопрос в тред.

### Уточняющие вопросы {#follow-ups}

Когда Exa ответила в треде, просто напишите в этом треде, чтобы продолжить разговор. Повторно упоминать @Exa не нужно. Exa помнит контекст беседы, поэтому уточняющие вопросы опираются на предыдущий ответ. Задать уточняющий вопрос может любой участник треда.

### Личные сообщения {#direct-messages}

Вы также можете написать Exa напрямую в личные сообщения. Упоминание в этом случае не нужно. Каждое отправленное сообщение создаёт новый запрос, ответ на который приходит в тред под этим сообщением. Чтобы продолжить разговор, отвечайте в треде.

### Отмена выполнения {#cancelling-a-run}

Пока выполнение ещё идёт, ответьте в треде и попросите Exa остановить его. Mention при этом не нужен.

```text theme={null}
Остановить текущее выполнение
```

### Провайдеры Exa Connect {#exa-connect-providers}

Exa автоматически подключает провайдеров данных [Exa Connect](/ru/docs/agent/connect/overview), если они релевантны вашему вопросу. Чтобы использовать конкретного провайдера, упомяните его в сообщении:

```text theme={null}
@Exa найди все стартапы в сфере ИИ-инфраструктуры, которые привлекли финансирование в этом квартале, используя Fiber.ai
```

Чтобы получить список всех доступных провайдеров данных, просто спросите Exa.

## Ключевые слова {#keywords}

Используйте их в треде, где присутствует Exa. Команды можно указать после mention `@Exa` либо начать с них само сообщение:

| Ключевое слово    | Функция                                                                                                        |
| ----------------- | -------------------------------------------------------------------------------------------------------------- |
| `!max <message>`  | Выполняет этот request с максимальным effort; подходит для составления очень больших списков.                  |
| `mute`            | Exa перестаёт отвечать на сообщения в треде без mention. Явные mention @Exa по-прежнему работают.             |
| `unmute`          | Возвращает ответы на уточняющие вопросы в треде после `mute`.                                                 |
| `sleep`           | Exa полностью прекращает работу в треде. Упомяните @Exa, чтобы разбудить.                                     |
| `aside <message>` | Публикует комментарий, который Exa игнорирует; удобно для общения с коллегами в треде, за которым следит Exa. |
| `help`            | Показывает инструкции по использованию.                                                                        |

## Разрешения {#permissions}

Exa app для Slack запрашивает следующие области доступа:

| Разрешение             | Доступ в Slack                                                      | Зачем это нужно Exa                                                                                                            |
| ---------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `app_mentions:read`    | Просмотр сообщений с прямым упоминанием @Exa                        | Запускать request, когда кто-то упоминает Exa в канале или в треде                                                            |
| `assistant:write`      | Работа в качестве App Agent в Slack                                 | Использовать возможности agent в Slack и передавать ответы потоком в личные сообщения и треды каналов                         |
| `channels:history`     | Просмотр сообщений в публичных каналах, куда добавлен Exa           | Получать ответы в тредах публичных каналов, чтобы уточняющие вопросы работали без повторного упоминания                        |
| `channels:read`        | Просмотр базовой информации о публичных каналах                     | Находить публичные каналы, где уже есть Exa, при выборе места синхронизации веб-сессии                                         |
| `chat:write`           | Отправка сообщений от имени Exa app                                 | Публиковать корневые сообщения тредов, ответы, обновления о ходе работы, подтверждения и сообщения, синхронизированные с вебом |
| `chat:write.customize` | Настройка имени и аватара сообщения, созданного приложением         | Показывать имя и изображение профиля веб-участника в сообщениях, синхронизированных из веб-приложения                          |
| `files:read`           | Просмотр файлов в беседах, куда добавлен Exa                        | Читать файлы, приложенные к вопросам                                                                                           |
| `files:write`          | Загрузка, изменение и удаление файлов от имени Exa app              | Прикреплять к ответам файлы с результатами, например выгруженные таблицы                                                       |
| `groups:history`       | Просмотр сообщений в приватных каналах, куда добавлен Exa           | Получать ответы в тредах приватных каналов, чтобы уточняющие вопросы работали без повторного упоминания                        |
| `groups:read`          | Просмотр базовой информации о приватных каналах, куда добавлен Exa  | Находить подходящие приватные каналы и проверять участие в них при выборе места синхронизации веб-сессии                       |
| `im:history`           | Просмотр сообщений в личных сообщениях с Exa                        | Получать requests и уточняющие вопросы в личных сообщениях                                                                     |
| `im:write`             | Начало личных сообщений                                             | Открывать личные сообщения проверенного пользователя с Exa, если он выбрал их как место синхронизации веб-сессии               |
| `users:read`           | Просмотр людей и их базовых профилей Slack                          | Сопоставлять упоминания с именами и использовать изображение профиля Slack веб-участника в синхронизированных сообщениях       |
| `users:read.email`     | Просмотр адресов электронной почты участников рабочего пространства | Сопоставлять учётные записи Slack и Exa для привязки к team и настройки изображений профиля в веб-сообщениях                   |

<Note>
  `channels:read`, `groups:read` и `im:write` обеспечивают поиск мест назначения для синхронизации из веба в Slack.
  Уже выполненные установки могут продолжать работать с текущими тредами в Slack без этих областей доступа, но
  их необходимо переподключить перед использованием соответствующего места назначения. `chat:write.customize` необязателен во
  время работы: без него синхронизированные с вебом сообщения сохраняют стандартное оформление Exa app, а имя
  участника указывается в body сообщения.
</Note>

Exa получает сообщения только из каналов, куда его явно пригласили, и из собственных личных сообщений.
