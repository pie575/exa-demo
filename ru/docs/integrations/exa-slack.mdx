Подключите Exa к Slack вашей команды. Упомяните **@Exa** в любом канале или треде и задайте исследовательский вопрос, поставьте задачу по составлению списка или отправьте запрос на обогащение данных. Exa выполнит поиск в интернете, изучит источники и ответит прямо в треде, указав ссылки на источники.

<div id="get-started">
  ## Начало работы
</div>

<div id="installation">
  ### Установка
</div>

1. Перейдите в [Dashboard &gt; Management &gt; Exa in Slack](https://dashboard.exa.ai/integrations/slack) и нажмите **Install**.

<img src="/docs/images/integrations/exa-slack/dashboard-install.png" alt="Страница Exa in Slack в панели управления Exa с кнопкой Install" width="3414" height="900" data-path="images/integrations/exa-slack/dashboard-install.png" />

2. Откроется окно авторизации Slack через OAuth. Выберите рабочее пространство, в которое нужно добавить Exa, и нажмите **Allow**.

<img src="/docs/images/integrations/exa-slack/oauth-approval.png" alt="Экран подтверждения OAuth в Slack для приложения Exa с уведомлением &#x22;App is not approved by Slack&#x22;, выбором рабочего пространства, запрашиваемыми разрешениями и кнопкой Allow" width="1820" height="1180" data-path="images/integrations/exa-slack/oauth-approval.png" />

<Note>
  Красное уведомление **«App is not approved by Slack»** появляется штатно, его можно спокойно проигнорировать. Оно лишь означает,
  что приложения Exa нет в публичном Slack Marketplace, а не то, что что-то пошло не так.
</Note>

3. После установки пригласите @Exa в канал (или напишите ему в личные сообщения) и задавайте вопросы.

<div id="how-to-use-exa-from-slack">
  ## Как использовать Exa в Slack
</div>

В любом канале, куда добавлен Exa, упомяните @Exa и задайте свой вопрос:

```text theme={null}
@Exa find all Series A fintech startups in SF
```

Exa отвечает на ваш вопрос прямо в треде.

<div id="follow-ups">
  ### Уточняющие вопросы
</div>

После того как Exa ответила в треде, просто напишите в этом же треде, чтобы продолжить разговор. Повторно упоминать @Exa не нужно. Exa помнит контекст беседы, поэтому уточняющие вопросы опираются на предыдущий ответ. Задать уточняющий вопрос может любой участник треда.

<div id="direct-messages">
  ### Личные сообщения
</div>

Вы также можете написать Exa напрямую в личные сообщения — упоминание там вообще не нужно. Каждое отправленное сообщение создаёт новый запрос, ответ на который приходит в тред под этим сообщением. Чтобы продолжить разговор, отвечайте в треде.

<div id="cancelling-a-run">
  ### Отмена запуска
</div>

Пока запуск выполняется, ответьте в треде и попросите Exa остановить его. Упоминание не требуется.

```text theme={null}
Остановить текущий запуск
```

<div id="exa-connect-providers">
  ### Провайдеры Exa Connect
</div>

Exa автоматически подключает провайдеров данных [Exa Connect](/ru/docs/agent/connect/overview), если они релевантны вашему вопросу. Чтобы использовать конкретного провайдера, упомяните его в сообщении:

```text theme={null}
@Exa find me all AI infrastructure startups that raised funding this quarter using Fiber.ai
```

Чтобы получить список всех доступных провайдеров данных, просто спросите Exa.

<div id="keywords">
  ## Ключевые слова
</div>

Используйте их в треде, где присутствует Exa. Команду можно указать после упоминания `@Exa` или начать с неё сообщение:

| Ключевое слово    | Действие                                                                                                        |
| ----------------- | --------------------------------------------------------------------------------------------------------------- |
| `!max <message>`  | Выполняет запрос на максимальном уровне усилий; подходит для сбора очень больших списков.                       |
| `mute`            | Exa перестаёт отвечать на сообщения в треде без упоминания. Явные упоминания @Exa по-прежнему работают.         |
| `unmute`          | Возобновляет уточняющие вопросы в треде после `mute`.                                                           |
| `sleep`           | Exa полностью прекращает работу в треде. Упомяните @Exa, чтобы разбудить.                                       |
| `aside <message>` | Публикует комментарий, который Exa игнорирует, — удобно для общения с коллегами в треде, за которым следит Exa. |
| `help`            | Показывает инструкции по использованию.                                                                         |

<div id="permissions">
  ## Разрешения
</div>

Приложение Exa для Slack запрашивает следующие разрешения (scopes):

| Разрешение             | Доступ в Slack                                                      | Зачем это нужно Exa                                                                                                               |
| ---------------------- | ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `app_mentions:read`    | Просмотр сообщений с прямым упоминанием @Exa                        | Запускать запрос, когда кто-то упоминает Exa в канале или треде                                                                   |
| `assistant:write`      | Работа в качестве App Agent в Slack                                 | Использовать агентный режим Slack и передавать ответы потоком в личные сообщения и треды каналов                                  |
| `channels:history`     | Просмотр сообщений в публичных каналах, куда добавлено Exa          | Получать ответы в тредах публичных каналов, чтобы уточняющие вопросы работали без нового упоминания                               |
| `channels:read`        | Просмотр базовой информации о публичных каналах                     | Находить публичные каналы, где уже есть Exa, при выборе места синхронизации веб-сессии                                            |
| `chat:write`           | Отправка сообщений от имени приложения Exa                          | Публиковать корневые сообщения тредов, ответы, обновления статуса, подтверждения и сообщения, синхронизированные из веба          |
| `chat:write.customize` | Настройка имени и аватара сообщения, созданного приложением         | Показывать имя и изображение профиля веб-участника в сообщениях, синхронизированных из веб-приложения                             |
| `files:read`           | Просмотр файлов из бесед, куда добавлено Exa                        | Читать файлы, прикреплённые к вопросам                                                                                            |
| `files:write`          | Загрузка, изменение и удаление файлов от имени приложения Exa       | Прикреплять к ответам файлы с результатами, например экспортированные таблицы                                                     |
| `groups:history`       | Просмотр сообщений в приватных каналах, куда добавлено Exa          | Получать ответы в тредах приватных каналов, чтобы уточняющие вопросы работали без нового упоминания                               |
| `groups:read`          | Просмотр базовой информации о приватных каналах, куда добавлено Exa | Находить подходящие приватные каналы и проверять участие в них при выборе места синхронизации веб-сессии                          |
| `im:history`           | Просмотр сообщений в личных сообщениях с Exa                        | Получать запросы и уточняющие ответы в личных сообщениях                                                                          |
| `im:write`             | Начало личного сообщения                                            | Открывать личное сообщение с Exa для подтверждённого пользователя, если он выбрал её как место синхронизации веб-сессии           |
| `users:read`           | Просмотр людей и их базовых профилей в Slack                        | Сопоставлять упоминания с именами и использовать изображение профиля веб-участника в Slack для синхронизированных сообщений       |
| `users:read.email`     | Просмотр адресов электронной почты участников рабочего пространства | Сопоставлять учётные записи Slack и Exa для атрибуции по командам и настройки изображений профиля в синхронизированных сообщениях |

<Note>
  `channels:read`, `groups:read` и `im:write` обеспечивают поиск мест назначения для синхронизации из веба в Slack.
  Уже установленные приложения могут продолжать работать с текущими тредами Slack без этих разрешений, но
  перед использованием соответствующего места назначения их нужно переподключить. `chat:write.customize` опционально во
  время работы: без него сообщения, синхронизированные из веба, сохраняют стандартный вид приложения Exa, а
  имя участника указывается в тексте сообщения.
</Note>

Exa получает сообщения только из каналов, куда его явно пригласили, и из собственных личных сообщений.
