Exa — провайдер веб-поиска в [Baseten Hosted Tools](https://www.baseten.co/blog/introducing-baseten-hosted-tools/). Baseten Model APIs обслуживают модели с открытым исходным кодом, а Hosted Tools позволяют этим моделям искать в интернете без самостоятельной настройки цикла вызова инструментов: вы добавляете селектор инструмента Exa к обычному запросу, Baseten выполняет модель и поиски Exa вместе в серверном цикле, и в том же ответе вы получаете ответ с опорой на источники. API key Exa при этом не нужен. Baseten включает стоимость Exa в ваш счёт Baseten без наценки.

<div id="use-the-exa-web-search-tools">
  ## Использование инструментов веб-поиска Exa
</div>

Задайте header `x-baseten-server-tools: true` и добавьте один или несколько селекторов Exa в массив `tools`. Нужен только `type`; Baseten разворачивает tool schema автоматически, а модель сама решает, когда искать, что искать и какие страницы читать. Серверные инструменты работают с эндпоинтами Baseten [Chat Completions](https://docs.baseten.co/reference/inference-api/chat-completions), [Messages](https://docs.baseten.co/reference/inference-api/messages) и Responses, как в буферизованном режиме, так и с потоковой передачей.

<CodeGroup>
  ```python Python theme={null}
  from openai import OpenAI

  client = OpenAI(
      api_key="<BASETEN_API_KEY>",
      base_url="https://inference.baseten.co/v1",
      default_headers={"x-baseten-server-tools": "true"},
  )

  response = client.chat.completions.create(
      model="zai-org/GLM-5.3-Fast",
      messages=[
          {"role": "user", "content": "What were the major AI announcements this week?"}
      ],
      tools=[
          {"type": "baseten__exa__web_search_exa"},
          {"type": "baseten__exa__web_fetch_exa"},
      ],
      extra_body={"baseten": {"tool_settings": {"max_react_iterations": 5}}},
  )

  print(response.choices[0].message.content)
  ```

  ```javascript JavaScript theme={null}
  import OpenAI from "openai";

  const client = new OpenAI({
    apiKey: "<BASETEN_API_KEY>",
    baseURL: "https://inference.baseten.co/v1",
    defaultHeaders: { "x-baseten-server-tools": "true" },
  });

  const response = await client.chat.completions.create({
    model: "zai-org/GLM-5.3-Fast",
    messages: [
      { role: "user", content: "What were the major AI announcements this week?" },
    ],
    tools: [
      { type: "baseten__exa__web_search_exa" },
      { type: "baseten__exa__web_fetch_exa" },
    ],
    baseten: { tool_settings: { max_react_iterations: 5 } },
  });

  console.log(response.choices[0].message.content);
  ```

  ```bash cURL theme={null}
  curl https://inference.baseten.co/v1/chat/completions \
    -H "Authorization: Bearer <BASETEN_API_KEY>" \
    -H "Content-Type: application/json" \
    -H "x-baseten-server-tools: true" \
    -d '{
      "model": "zai-org/GLM-5.3-Fast",
      "messages": [
        { "role": "user", "content": "What were the major AI announcements this week?" }
      ],
      "tools": [
        { "type": "baseten__exa__web_search_exa" },
        { "type": "baseten__exa__web_fetch_exa" }
      ],
      "baseten": { "tool_settings": { "max_react_iterations": 5 } }
    }'
  ```
</CodeGroup>

Доступны три инструмента Exa. Дайте модели поиск вместе с загрузкой страниц, если она должна находить источники, а затем читать выбранные страницы.

| Селектор                                | Что получает модель                                                                            |
| --------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `baseten__exa__web_search_exa`          | [Exa search](/ru/docs/search/quickstart): релевантные результаты с содержимым страниц по запросу  |
| `baseten__exa__web_search_advanced_exa` | Поиск с фильтрами по доменам, обходом подстраниц и опциональным summary для каждого результата |
| `baseten__exa__web_fetch_exa`           | [Полное содержимое страницы](/ru/docs/contents/quickstart) по URL, который у модели уже есть      |

Селекторы не принимают дополнительных полей; аргументы инструмента модель заполняет сама по schema Exa. С помощью system prompt задайте политику поиска: когда искать, нужно ли обращаться к первоисточникам и как оформлять ссылки. Ограничить цикл можно через `baseten.tool_settings`:

| Настройка                      | Для чего использовать                                                                                                                                                               |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `max_react_iterations`         | Ограничить число итераций модели на запрос (по умолчанию 12, диапазон от 2 до 20). Последняя итерация зарезервирована для ответа, поэтому `N` допускает `N - 1` раундов tool call. |
| `max_tool_calls_per_iteration` | Ограничить число вызовов серверных инструментов в одной итерации (по умолчанию 10, диапазон от 1 до 10)                                                                             |

<div id="how-results-come-back">
  ## Как возвращаются результаты
</div>

Итоговый ответ приходит в обычном поле эндпоинта. Завершённые вызовы Exa фиксируются в соответствии с протоколом: блоки `tool_use` и `tool_result` в Messages, элементы `mcp_call` в Responses и `baseten.iterations[].continuation_messages` в Chat Completions. При потоковой передаче каждый поисковый вызов и его результат приходят в виде server-sent events, пока работает цикл, так что вы можете показывать прогресс ещё до получения ответа. Массив `baseten.request.server_tool_calls[]` сообщает исход каждого вызова Exa в рамках запроса.

<div id="pricing">
  ## Pricing
</div>

Вызовы Exa списываются с вашего аккаунта Baseten по тарифу Exa без наценки, дополнительно к стоимости токенов модели: примерно $0,007 за search и $0,001 за каждый загруженный URL. Exa сообщает стоимость каждого вызова во время выполнения, поэтому отдельные вызовы могут отличаться от указанных значений. Оплачиваемые tool calls отображаются в настройках рабочего пространства Baseten в разделе Billing → Usage с группировкой по провайдерам. Актуальные тарифы смотрите в [таблице цен Baseten](https://docs.baseten.co/inference/model-apis/web-search#pricing).

Hosted Tools доступны на Baseten в режиме раннего доступа с лимитом 25 запросов в минуту на организацию. Попробуйте Exa search в [песочнице Baseten](https://app.baseten.co/model-apis/zai-org/GLM-5.3-Fast/playground) или обратитесь в Baseten, чтобы повысить лимит для production-нагрузок.
