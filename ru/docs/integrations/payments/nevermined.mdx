Agentы оплачивают Exa банковской картой по схеме [delegation карты x402](https://nevermined.ai/docs/specs/x402-card-delegation) от [Nevermined](https://nevermined.ai). Каждая **покупка на $7** возвращает Exa API key с **$7 в credits Exa**.

<Info>
  Используйте этот идентификатор плана Nevermined:<br />`27800462147494506865542649899724877617306579171265399959488097895839186996870`<br />Этот план работает в рабочей среде Nevermined (API key с префиксом live). Покупка оплачивает credits API, а не один поисковый запрос.
</Info>

Если плательщик Nevermined обращается впервые, `POST /team-management/nevermined/purchase-key` создаёт новый Exa API key и начисляет $7 в credits. Когда credits на ключе заканчиваются, выпустите новый token x402 с той же delegation и снова вызовите тот же эндпоинт. Exa вернёт тот же API key, начислив на него ещё $7 в credits.

## Купить ключ {#buy-a-key}

```bash theme={null}
POST https://admin-api.exa.ai/team-management/nevermined/purchase-key
payment-signature: <x402-token>
```

* **Стоимость:** $7 за покупку, списывается с карты, привязанной к delegation, на которую ссылается x402 token.
* **Ответ (новый плательщик):** `{ status: "ok", apiKey: "…", expiresAt: null }` — новый Exa API key с $7 credits.
* **Ответ (повторный плательщик):** `{ status: "ok", apiKey: "…", expiresAt: null }` — тот же Exa API key ещё с $7 credits.
* **Ответ (повторно отправленный token):** кэшированный результат, повторное списание не выполняется.
* **Отсутствующая или недействительная подпись:** `402 Payment Required` с требованиями к оплате в body.

## Как это работает {#how-it-works}

Платёжную часть берёт на себя Nevermined; Exa видит только подписанный x402 token.

1. **Однократная настройка (выполняет владелец карты):** зарегистрируйте карту на [nevermined.app](https://nevermined.app), создайте на ней **delegation** (разрешение на расходование: владелец задаёт лимит и срок действия и может ограничить его конкретным API key), а затем выпустите Nevermined API key для agent.
2. **Agent находит свой delegation.** Nevermined SDK позволяет agent найти delegations, из которых может тратить его ключ, и выбрать тот, где осталось достаточно бюджета (не менее $7). Если подходящего нет, владелец создаёт его в дашборде, либо полностью автономный agent создаёт его через SDK в пределах лимитов карты.
3. **Agent выпускает x402 access token** для указанного выше идентификатора плана по схеме делегирования карты, ссылаясь на delegation по ID. Delegations должны существовать до выпуска токена; токены не создают их на лету.
4. **Agent отправляет POST-запрос с токеном на указанный выше эндпоинт** в header `payment-signature` и получает Exa API key в ответе.
5. **Ключ сразу же работает** со стандартным [Exa Search API](/ru/docs/search/quickstart).

Полное руководство, готовое для agent (методы SDK, параметры, поиск и создание delegation, устранение неполадок), смотрите в Exa integration guide от Nevermined: [nevermined.ai/docs/integrations/exa](https://nevermined.ai/docs/integrations/exa) (для agents: загрузите [nevermined.ai/docs/integrations/exa.md](https://nevermined.ai/docs/integrations/exa.md)).

## Когда ключ исчерпан {#when-the-key-runs-out}

Как только credits у API key заканчиваются, Exa возвращает **`HTTP 402`** на обычных эндпоинтах API:

```json theme={null}
{
  "requestId": "...",
  "error": "You have exceeded your credits limit. Please top up to keep using Exa at dashboard.exa.ai",
  "tag": "NO_MORE_CREDITS"
}
```

Сминтите новый x402 token с тем же идентификатором плана и delegation, затем снова отправьте его POST-запросом на тот же эндпоинт `/purchase-key`. Exa добавит к тому же API key ещё $7 credits.
