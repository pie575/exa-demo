Достаточно один раз установить плагин Exa, чтобы открыть Codex и ChatGPT доступ к живому вебу через Exa. Ищите актуальную информацию, читайте по-настоящему важные источники и проводите глубокие исследования, не прерывая диалог или работу над кодом.

<div id="install-exa">
  ## Установка Exa
</div>

<Steps>
  <Step title="Откройте плагин">
    Перейдите на [chatgpt.com/plugins/exa](https://chatgpt.com/plugins/exa?open_in_app). Откроется страница **Exa** в каталоге плагинов OpenAI — это общий каталог для ChatGPT и Codex.
  </Step>

  <Step title="Установите его">
    Нажмите кнопку с плюсом, чтобы установить. Войдите в Exa по запросу — либо во время установки, либо при первом обращении к плагину из Codex или ChatGPT.

    <Frame caption="Открытие раздела Plugins в Codex, добавление Exa и предоставление доступа">
      <img src="/docs/images/integrations/chatgpt-codex/install-codex.gif" alt="Открытие раздела Plugins в Codex, просмотр плагина Exa и предоставление доступа" style={{width: "100%", height: "auto"}} width="1100" height="825" data-path="images/integrations/chatgpt-codex/install-codex.gif" />
    </Frame>
  </Step>

  <Step title="Начните новую сессию">
    Навыки подгружаются в чатах и CLI-сессиях, запущенных уже после установки, поэтому откройте новую сессию и задайте вопрос, для ответа на который нужен веб.
  </Step>
</Steps>

Готово. Плагин включает и MCP-интеграцию Exa, и навыки, поэтому отдельно настраивать MCP или навыки не нужно.

<div id="build-with-whats-on-the-web-right-now">
  ## Разрабатывайте с опорой на то, что есть в вебе прямо сейчас
</div>

Библиотеки, API и инструменты, с которыми вы работаете, меняются каждый день. С установленной Exa Codex может прямо в процессе работы искать свежую документацию, issues, чейнджлоги и реальные примеры.

Прямо из вашего репозитория:

```text theme={null}
У нас Tailwind v3. Найди руководство по переходу на Tailwind v4, прочитай его,
а затем переведи этот проект на v4.
```

Codex может искать через Exa, читать релевантные источники и использовать найденное, чтобы внести изменения в вашу кодовую базу.

Это работает всякий раз, когда ответ может находиться за пределами вашего репозитория:

* «Поищи эту ошибку в issues и чейнджлоге `tokio-tungstenite`, прежде чем пытаться её исправить».
* «Найди реальные примеры advisory locks в Postgres на Rust и порекомендуй паттерн, который подойдёт для этого пула воркеров».
* «Прочитай актуальную документацию по вебхукам Stripe и сверь с ней нашу реализацию».
* «Найди свежее руководство по миграции для этой зависимости и обнови её».

<div id="research-without-leaving-chatgpt">
  ## Исследования, не покидая ChatGPT
</div>

Exa работает и в ChatGPT. Задайте вопрос, для которого нужна актуальная информация, и используйте Exa, чтобы искать и исследовать веб прямо в диалоге.

```text theme={null}
Сравни облачные管 (managed) сервисы, лицензирование и цены основных
открытых векторных баз данных. Опирайся на актуальные первоисточники и ссылайся на них.
```

Вместо того чтобы полагаться только на информацию, уже имеющуюся в контексте, ChatGPT может с помощью Exa найти и прочитать источники, необходимые для выполнения задачи.

Используйте это для анализа конкурентов, технических исследований, картирования рынка, изучения компаний и любых других задач, ответы на которые разбросаны по всему вебу.

<div id="mcp-skills-together">
  ## MCP + навыки вместе
</div>

Под капотом плагин объединяет две части агентного стека Exa.

[Exa MCP](/ru/docs/get-started/exa-mcp) даёт Codex и ChatGPT инструменты для доступа к Exa. Это связующее звено между агентом и возможностями Exa по поиску и исследованию.

[Навыки Exa](/ru/docs/get-started/agent-skills/overview) дают агенту дополнительные инструкции о том, как применять эти возможности в полезных рабочих сценариях, включая веб-исследования и [Exa Agent](/ru/docs/agent/quickstart).

При установке плагина настраивать что-либо из этого по отдельности не нужно.

<div id="prefer-mcp-directly">
  ## Предпочитаете подключаться к MCP напрямую?
</div>

Плагин — рекомендуемый способ использовать Exa с Codex и ChatGPT. Если вы настраиваете Codex вручную или используете другой MCP-клиент, можно подключиться напрямую к размещённому MCP-серверу Exa:

```bash theme={null}
codex mcp add exa --url https://mcp.exa.ai/mcp
```

Информацию о других клиентах, параметрах конфигурации и доступных инструментах см. в разделе [Exa MCP](/ru/docs/get-started/exa-mcp).
