Установите плагин Exa один раз, и Codex с ChatGPT получат доступ к актуальному вебу через Exa. Ищите свежую информацию, читайте нужные источники и проводите более глубокие исследования, не прерывая диалог или сеанс работы с кодом.

## Установка Exa {#install-exa}

<Steps>
  <Step title="Откройте плагин">
    Перейдите на [chatgpt.com/plugins/exa](https://chatgpt.com/plugins/exa?open_in_app). Откроется страница **Exa** в каталоге плагинов OpenAI — это общий каталог для ChatGPT и Codex.
  </Step>

  <Step title="Установите его">
    Нажмите кнопку с плюсом, чтобы установить. Войдите в Exa по запросу — либо во время установки, либо при первом обращении к плагину из Codex или ChatGPT.

    <Frame caption="Открытие раздела Plugins в Codex, добавление Exa и предоставление доступа">
      <img src="/docs/images/integrations/chatgpt-codex/install-codex.gif" alt="Открытие раздела Plugins в Codex, просмотр плагина Exa и предоставление доступа" style={{width: "100%", height: "auto"}} width="1100" height="825" data-path="images/integrations/chatgpt-codex/install-codex.gif" />
    </Frame>
  </Step>

  <Step title="Начните новую сессию">
    Навыки загружаются в чатах и CLI-сессиях, запущенных после установки, поэтому откройте новую сессию и спросите что-нибудь, для чего нужен веб.
  </Step>
</Steps>

Готово. Плагин включает и MCP-интеграцию Exa, и навыки, так что отдельно настраивать MCP или навыки не нужно.

## Разрабатывайте с учётом того, что есть в вебе прямо сейчас {#build-with-whats-on-the-web-right-now}

Библиотеки, API и инструменты, с которыми вы работаете, меняются каждый день. С установленной Exa Codex может искать актуальную документацию, issues, чейнджлоги и примеры из реальных проектов прямо по ходу работы.

Из вашего репозитория:

```text theme={null}
У нас Tailwind v3. Найди руководство по обновлению до Tailwind v4, прочитай его,
а затем переведи этот проект на v4.
```

Codex может выполнять поиск через Exa, читать релевантные источники и использовать найденное, чтобы внести изменения в вашу кодовую базу.

То же самое работает в любом случае, когда ответ может находиться за пределами вашего репозитория:

* «Прежде чем исправлять эту ошибку, поищи её в issues и чейнджлоге `tokio-tungstenite`».
* «Найди реальные примеры рекомендательных блокировок Postgres на Rust и предложи паттерн, который подходит для этого пула воркеров».
* «Прочитай актуальную документацию по вебхукам Stripe и сверь с ней наше внедрение».
* «Найди последнее руководство по миграции для этой зависимости, а затем обнови её».

## Исследования, не покидая ChatGPT {#research-without-leaving-chatgpt}

Exa работает и в ChatGPT. Задайте вопрос, требующий актуальной информации, и используйте Exa для поиска и исследования веба прямо в диалоге.

```text theme={null}
Сравни управляемые сервисы, лицензирование и цены основных
векторных баз данных с открытым исходным кодом. Используй актуальные первоисточники и ссылайся на них.
```

Вместо того чтобы полагаться только на информацию, уже имеющуюся в контексте, ChatGPT может использовать Exa, чтобы найти и прочитать источники, необходимые для решения задачи.

Используйте это для конкурентного анализа, технических исследований, картирования рынка, изучения компаний и любых других задач, ответ на которые рассредоточен по вебу.

## MCP и навыки вместе {#mcp-skills-together}

Под капотом плагин объединяет две части агентного стека Exa.

[Exa MCP](/ru/docs/get-started/exa-mcp) даёт Codex и ChatGPT инструменты для доступа к Exa. Это связующее звено между агентом и возможностями Exa по поиску и исследованиям.

[Навыки Exa](/ru/docs/get-started/agent-skills/overview) дают агенту дополнительные инструкции по применению этих возможностей в полезных рабочих процессах, включая веб-исследования и [Exa Agent](/ru/docs/agent/quickstart).

Ни то, ни другое не нужно настраивать отдельно: достаточно установить плагин.

## Предпочитаете использовать MCP напрямую? {#prefer-mcp-directly}

Плагин — рекомендуемый способ работы с Exa в Codex и ChatGPT. Если вы настраиваете Codex вручную или используете другой MCP-клиент, можно подключиться напрямую к размещённому MCP-серверу Exa:

```bash theme={null}
codex mcp add exa --url https://mcp.exa.ai/mcp
```

Информацию о других клиентах, параметрах настройки и доступных инструментах смотрите в разделе [Exa MCP](/ru/docs/get-started/exa-mcp).
