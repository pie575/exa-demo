Официальный [узел Exa для n8n](https://github.com/exa-labs/n8n-integration) добавляет в визуальные рабочие процессы веб-поиск, извлечение содержимого, ответы с опорой на источники и выполнения Exa Agent. Используйте его как обычный шаг рабочего процесса или подключите к n8n AI Agent в качестве инструмента.

<div id="install-the-exa-node">
  ## Установка узла Exa
</div>

Название пакета — `n8n-nodes-exa-official`.

<Steps>
  <Step title="Добавьте community node">
    Найдите **Exa** в списке выбора узлов n8n. Если узел недоступен на вашем инстансе, владелец инстанса может установить `n8n-nodes-exa-official`, следуя [руководству n8n по установке community node](https://docs.n8n.io/integrations/community-nodes/installation/).

    Узлу требуется n8n 1.60 или новее и Node.js 20.15 или новее.
  </Step>

  <Step title="Создайте Exa API key">
    <Card title="Получите свой Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      Создайте ключ в дашборде. Новым аккаунтам начисляются бесплатные credits.
    </Card>
  </Step>

  <Step title="Добавьте учётные данные Exa">
    Добавьте в n8n credential **Exa API** и вставьте свой ключ. Указывайте этот credential в каждом узле Exa, который должен работать с этим аккаунтом.
  </Step>
</Steps>

<div id="run-a-search">
  ## Выполнение поиска
</div>

1. Добавьте триггер в рабочий процесс.
2. Добавьте узел **Exa**.
3. Выберите **Search**.
4. Введите запрос и выберите тип поиска.
5. Выберите формат ответа:
   * **Results** — ранжированные страницы
   * **Text** — синтезированный ответ
   * **Structured** — JSON, соответствующий вашей schema
6. Запустите узел и передайте его вывод на следующий шаг рабочего процесса.

Search также может возвращать текст, highlights, краткие сводки, ссылки и изображения для каждого результата. Фильтры по доменам, даты публикации, категории, `maxAgeHours` и обход подстраниц доступны в необязательных полях узла.

<div id="available-resources">
  ## Доступные ресурсы
</div>

| Ресурс       | Операции                                                                                                                                              |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Search**   | Поиск в интернете с помощью `auto`, `instant`, `fast`, `deep-lite`, `deep` или `deep-reasoning`, с опциональным синтезом и структурированным выводом. |
| **Contents** | Получение очищенного текста, highlights, кратких сводок, ссылок и изображений для списка URL.                                                         |
| **Answer**   | Формирование ответа с опорой на источники, с citations и опциональным структурированным выводом.                                                      |
| **Agent**    | Создание, просмотр, получение списка, потоковая передача, опрос и отмена многошаговых выполнений Agent.                                               |

<div id="use-exa-with-an-n8n-ai-agent">
  ## Использование Exa с AI Agent в n8n
</div>

Подключите узел Exa к узлу **AI Agent** через его вход для инструментов. Для параметров, значения которых должна подставлять модель, можно использовать выражение n8n `$fromAI()`:

```javascript theme={null}
{{ $fromAI("query", "What should Exa search for?", "string") }}
```

Search и Answer хорошо подходят в качестве инструментов grounding. Используйте ресурс Agent, если задача требует многошагового исследования, построения списков, структурированного enrichment или премиальных данных [Exa Connect](/ru/docs/agent/connect/overview).

<div id="wait-for-an-agent-run">
  ## Ожидание выполнения Agent
</div>

При создании выполнения Agent параметр **Wait for Completion** поддерживает:

* **Stream** — держать открытым одно соединение server-sent events до завершения выполнения
* **Poll** — проверять состояние выполнения с заданным интервалом

Для длительных или асинхронных рабочих процессов отключите **Wait for Completion**, сохраните возвращённый `id` выполнения и позже обратитесь к **Get Run**. Выполнение продолжится на стороне Exa уже после завершения шага n8n.

<div id="troubleshooting">
  ## Устранение неполадок
</div>

<AccordionGroup>
  <Accordion title="Узла Exa нет в списке выбора узлов">
    Попросите владельца инстанса установить проверенный пакет сообщества `n8n-nodes-exa-official`. Доступность узлов сообщества зависит от того, как размещён ваш инстанс n8n.
  </Accordion>

  <Accordion title="Credential Exa отклонён">
    Убедитесь, что выбранный credential содержит активный ключ из [дашборда Exa](https://dashboard.exa.ai/api-keys) и что на ключе есть доступные credits.
  </Accordion>

  <Accordion title="Рабочий процесс Agent завершается по тайм-ауту">
    Отключите **Wait for Completion**, сохраните возвращённый `id` выполнения и получите результат на следующем шаге с помощью **Get Run**.
  </Accordion>
</AccordionGroup>
