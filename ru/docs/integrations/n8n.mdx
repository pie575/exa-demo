Официальный [узел Exa для n8n](https://github.com/exa-labs/n8n-integration) добавляет в визуальные рабочие процессы веб-поиск, извлечение контента, ответы с опорой на источники и запуски Exa Agent. Используйте его как обычный шаг рабочего процесса или подключите к AI Agent в n8n в качестве инструмента.

<div id="install-the-exa-node">
  ## Установка узла Exa
</div>

Название пакета — `n8n-nodes-exa-official`.

<Steps>
  <Step title="Добавьте узел сообщества">
    Найдите **Exa** в списке узлов n8n. Если он недоступен в вашем экземпляре, владелец экземпляра может установить `n8n-nodes-exa-official`, следуя [руководству n8n по установке узлов сообщества](https://docs.n8n.io/integrations/community-nodes/installation/).

    Для работы узла требуется n8n 1.60 или новее и Node.js 20.15 или новее.
  </Step>

  <Step title="Создайте Exa API key">
    <Card title="Получите свой Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      Создайте key в панели управления. Новым аккаунтам начисляются бесплатные кредиты.
    </Card>
  </Step>

  <Step title="Добавьте учётные данные Exa">
    Добавьте в n8n учётные данные **Exa API** и вставьте свой key. Выбирайте эти учётные данные в каждом узле Exa, который должен работать с этим аккаунтом.
  </Step>
</Steps>

<div id="run-a-search">
  ## Выполнение поиска
</div>

1. Добавьте триггер в рабочий процесс.
2. Добавьте узел **Exa**.
3. Выберите **Search**.
4. Введите запрос и выберите тип поиска.
5. Выберите формат ответа:
   * **Results** — ранжированные страницы
   * **Text** — сгенерированный ответ
   * **Structured** — JSON, соответствующий вашей схеме
6. Запустите узел и передайте его результат на следующий шаг рабочего процесса.

Search также может возвращать текст, highlights, краткие описания, ссылки и изображения для каждого результата. Фильтры по доменам, даты публикации, категории, `maxAgeHours` и обход подстраниц доступны в необязательных полях узла.

<div id="available-resources">
  ## Доступные ресурсы
</div>

| Ресурс       | Операции                                                                                                                                              |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Search**   | Поиск в интернете в режимах `auto`, `instant`, `fast`, `deep-lite`, `deep` или `deep-reasoning`, с опциональным синтезом и структурированным выводом. |
| **Contents** | Получение очищенного текста, highlights, кратких сводок, ссылок и изображений для списка URL.                                                         |
| **Answer**   | Формирование обоснованного ответа с цитированием источников и опциональным структурированным выводом.                                                 |
| **Agent**    | Создание, просмотр, получение списка, потоковая передача, опрос и отмена многошаговых запусков Agent.                                                 |

<div id="use-exa-with-an-n8n-ai-agent">
  ## Использование Exa с AI Agent в n8n
</div>

Подключите узел Exa к узлу **AI Agent** через его вход для инструментов. Для параметров, которые должна подставлять модель, можно использовать выражение n8n `$fromAI()`:

```javascript theme={null}
{{ $fromAI("query", "What should Exa search for?", "string") }}
```

Search и Answer хорошо подходят в качестве инструментов grounding. Используйте ресурс Agent, если задача требует многошагового исследования, построения списков, структурированного enrichment или премиальных данных [Exa Connect](/ru/docs/agent/connect/overview).

<div id="wait-for-an-agent-run">
  ## Ожидание завершения запуска Agent
</div>

При создании запуска Agent параметр **Wait for Completion** поддерживает два режима:

* **Stream** — удерживать открытым одно соединение server-sent events до завершения запуска
* **Poll** — проверять состояние запуска с заданным интервалом

Для длительных или асинхронных рабочих процессов отключите **Wait for Completion**, сохраните возвращённый `id` запуска и позже используйте **Get Run**. Запуск продолжит выполняться на стороне Exa после того, как шаг n8n завершится.

<div id="troubleshooting">
  ## Устранение неполадок
</div>

<AccordionGroup>
  <Accordion title="Узел Exa отсутствует в списке узлов">
    Попросите владельца экземпляра установить проверенный пакет сообщества `n8n-nodes-exa-official`. Доступность узлов сообщества зависит от того, как размещён ваш экземпляр n8n.
  </Accordion>

  <Accordion title="Учётные данные Exa отклоняются">
    Убедитесь, что в выбранных учётных данных указан активный key из [панели управления Exa](https://dashboard.exa.ai/api-keys) и что на нём есть доступные кредиты.
  </Accordion>

  <Accordion title="Рабочий процесс Agent завершается по тайм-ауту">
    Отключите **Wait for Completion**, сохраните возвращённый `id` запуска и получите результат на одном из следующих шагов с помощью **Get Run**.
  </Accordion>
</AccordionGroup>
