[Stripe Projects](https://projects.dev) позволяет вам и вашим coding agent&#39;ам подключать сторонние сервисы прямо из терминала: без дашбордов и без копирования ключей вручную. Одна команда создаёт аккаунт Exa и синхронизирует API key с вашим проектом.

<div id="prerequisites">
  ## Предварительные требования
</div>

Установите Stripe CLI и плагин Projects:

```bash theme={null}
brew install stripe/stripe-cli/stripe && stripe plugin install projects
```

Информацию о других платформах и полной настройке CLI см. в [Stripe Projects](https://projects.dev).

<div id="get-started">
  ## Начало работы
</div>

В каталоге вашего проекта инициализируйте проект, добавьте Exa и загрузите учётные данные:

```bash theme={null}
stripe projects init
stripe projects add exa/api
stripe projects env --pull
```

Теперь в вашем `.env` есть `EXA_API_KEY`. [SDK Exa](/ru/docs/sdks/quickstart) и [Быстрый старт](/ru/docs/search/quickstart) считывают эту переменную автоматически, поэтому ваш код будет работать без каких-либо изменений.

<Info>
  Ключ создаётся в принадлежащем вам аккаунте Exa. Управлять использованием, ключами и биллингом можно в любой момент в [Exa Dashboard](https://dashboard.exa.ai).
</Info>

<div id="link-an-existing-exa-team">
  ## Привязка существующей команды Exa
</div>

Уже есть аккаунт Exa? Сначала подключите его, чтобы API key был создан в вашей существующей команде:

```bash theme={null}
stripe projects link exa
stripe projects add exa/api
```

`stripe projects link` открывает Exa, чтобы вы могли пройти аутентификацию и связать свою команду с аккаунтом Stripe. Открыть связанный Exa Dashboard можно в любой момент командой `stripe projects open exa`.

<div id="provision-from-your-coding-agent">
  ## Подготовка через ваш coding agent
</div>

`stripe projects init` добавляет в ваш проект [Agent Skill](https://projects.dev) для Stripe Projects, так что весь процесс за вас может выполнить ваш agent (Claude Code, Cursor, Codex и другие):

```text theme={null}
Используй Stripe Projects, чтобы добавить Exa и подключить API key.
```
