LlamaIndex — это фреймворк для создания LLM-приложений на основе структурированных данных. В этом руководстве мы воспользуемся интеграцией Exa с LlamaIndex, чтобы:

1. Подключить инструмент Exa Search and Retrieve Highlight как retriever в LlamaIndex
2. Настроить OpenAI agent, который использует этот инструмент при формировании ответов

***

<div id="get-started">
  ## Get started
</div>

<Steps>
  <Step title="Требования и установка">
    Установите библиотеки llama-index, llama-index core, llama-index-tools-exa. Зависимости OpenAI входят в основную библиотеку, поэтому указывать их отдельно не нужно.

    ```Python Python theme={null}
    pip install llama-index llama-index-core llama-index-tools-exa
    ```

    Также убедитесь, что API key инициализированы корректно. В приведённом ниже коде в качестве имени соответствующей переменной окружения используется `EXA_API_KEY`.

    <Card title="Получите свой Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      Создайте ключ в дашборде. Новым аккаунтам начисляются бесплатные credits.
    </Card>
  </Step>

  <Step title="Создание экземпляра инструмента Exa">
    Импортируйте библиотеку интеграции с Exa и создайте экземпляр `ExaToolSpec` из LlamaIndex.

    ```Python Python theme={null}
    from llama_index.tools.exa import ExaToolSpec
    import os

    exa_tool = ExaToolSpec(
        api_key=os.environ["EXA_API_KEY"],
    )
    ```
  </Step>

  <Step title="Выбор используемого метода Exa">
    В этом примере нам нужно передать agentу только метод [search&#95;and&#95;retrieve&#95;highlights](https://docs.llamaindex.ai/en/stable/api_reference/tools/exa/), поэтому указываем его с помощью метода `.to_tool_list` из LlamaIndex. Кроме того, мы передаём `current_date` — простую утилиту, благодаря которой agent знает текущую дату.

    ```Python Python theme={null}
    print('Tools that are provide by Exa LlamaIndex integration:')
    print('\n'.join(map(str, (exa_tool.spec_functions))))

    search_and_retrieve_highlights_tool = exa_tool.to_tool_list(
        spec_functions=["search_and_retrieve_highlights", "current_date"]
    )
    ```
  </Step>

  <Step title="Настройка OpenAI agent и выполнение запросов на базе Exa">
    Настройте [OpenAIAgent](https://docs.llamaindex.ai/en/stable/examples/agent/Chatbot%5FSEC/), передав ему отфильтрованный набор инструментов из предыдущего шага.

    ```Python Python theme={null}
    from llama_index.agent.openai import OpenAIAgent

    agent = OpenAIAgent.from_tools(
        search_and_retrieve_highlights_tool,
        verbose=True,
    )
    ```

    Далее для взаимодействия с agentом можно использовать метод chat.

    ```Python Python theme={null}
    agent.chat(
        "Can you summarize the news from the last month related to the US stock market?"
    )
    ```

    Agent вызывает переданные ему инструменты Exa и формирует ответ на основе полученных результатов. Конкретный вывод зависит от запроса и дат публикации страниц, которые вернёт Exa.
  </Step>
</Steps>
