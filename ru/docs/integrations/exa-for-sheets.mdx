<Warning>
  **Несколько аккаунтов Google:** дополнение должно работать под первым (основным) аккаунтом Google в профиле браузера. Если вы вошли сразу в несколько аккаунтов, сохранить или загрузить API key может не получиться. Чтобы это исправить, откройте Таблицы в окне инкогнито с одним аккаунтом или выйдите из лишних аккаунтов, чтобы нужный стал основным. [Подробнее](https://developers.google.com/apps-script/guides/projects#fix_issues_with_multiple_google_accounts).
</Warning>

Используйте Exa прямо в Google Таблицах, чтобы искать информацию в вебе, формировать таблицы и заполнять недостающие данные.

Дополнение предлагает два способа работы:

* **Exa Agent** — для целых таблиц и задач с несколькими ячейками
* **`=EXA(...)`** — для одного ответа в одной ячейке

<div id="install">
  ## Установка
</div>

<Steps>
  <Step title="Установите дополнение">
    Перейдите к [дополнению Exa AI](https://workspace.google.com/marketplace/app/exa_ai/465545439521) в Google Workspace Marketplace и нажмите **Install**.
  </Step>

  <Step title="Откройте Google Таблицу">
    Откройте новую или существующую таблицу.
  </Step>

  <Step title="Откройте боковую панель">
    Перейдите в **Extensions → Exa AI → Open Sidebar**.
  </Step>

  <Step title="Добавьте свой API key">
    <Card title="Получите свой Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      Создайте ключ в панели управления. Новым аккаунтам начисляются бесплатные кредиты.
    </Card>

    Вставьте ключ в боковую панель.
  </Step>

  <Step title="Начните работать с Exa">
    Откройте **Exa Agent** и приступайте к работе с Exa прямо в таблице.
  </Step>
</Steps>

<div id="exa-agent">
  ## Exa Agent
</div>

Exa Agent позволяет использовать Exa сразу в нескольких ячейках Google Таблиц.

Используйте его, когда нужно:

* сгенерировать таблицу целиком по одному запросу
* заполнить пустые ячейки в существующей таблице
* дополнить таблицу новыми строками
* обогатить список данными из интернета

<div id="generate-a-table">
  ### Создание таблицы
</div>

Используйте **Generate table**, когда нужно, чтобы Exa создала новую таблицу.

1. Откройте боковую панель.
2. Перейдите в раздел **Exa Agent**.
3. Выберите **Generate table**.
4. Опишите, что вам нужно.
5. Нажмите **Generate table**.

Пример запроса:

```text theme={null}
Найди 40 ведущих ИИ-компаний и верни название компании, адрес сайта, имя генерального директора, дату основания, штаб-квартиру и краткое описание.
```

Exa исследует веб и записывает таблицу на ваш лист.

По умолчанию таблица начинается с выбранной ячейки. Другую начальную ячейку можно указать в разделе **More options**.

<div id="fill-cells">
  ### Заполнение ячеек
</div>

Используйте **Fill cells**, если у вас уже есть таблица и вы хотите, чтобы Exa заполнила недостающие данные.

1. Выделите пустые ячейки в таблице.
2. Откройте **Exa Agent**.
3. Выберите **Fill cells**.
4. Нажмите **Fill selected cells**.

Exa анализирует таблицу вокруг выделения и заполняет пропуски.

Перед использованием **Fill cells** выделяйте пустые ячейки в таблице, где уже заданы понятные заголовки.

Пример:

| Компания | Сайт                                     | CEO           | Штаб-квартира |
| -------- | ---------------------------------------- | ------------- | ------------- |
| Apple    | [https://apple.com](https://apple.com)   |               |               |
| Google   | [https://google.com](https://google.com) | Sundar Pichai | Mountain View |

Выделите пустые ячейки в строке Apple и нажмите **Fill selected cells**. Exa использует название компании и соседние строки как контекст.

<div id="continue-rows">
  ### Продолжение строк
</div>

Вы также можете выделить пустые строки под таблицей.

Если таблица заканчивается на позиции 55 и вы выделите две следующие пустые строки, Exa продолжит её позициями 56 и 57.

Exa берёт существующие строки за образец, сохраняет те же столбцы и не повторяет элементы, которые уже есть в таблице.

<div id="exa">
  ## `=EXA(...)`
</div>

Используйте `=EXA(...)`, когда нужен один ответ в одной ячейке. Функция ищет в интернете, читает первые результаты и возвращает краткий ответ.

```text theme={null}
=EXA("what you want", cell)
```

| Параметр  | Обязательный | Описание                                                                        |
| --------- | ------------ | ------------------------------------------------------------------------------- |
| `prompt`  | Да           | Какая информация вам нужна (например, `"Return only the CEO name"`).            |
| `context` | Нет          | Ссылка на ячейку или текст для обогащения (например, название компании в `A2`). |

Примеры:

```text theme={null}
=EXA("Return only the company website URL", A2)
=EXA("Return only the CEO name", A2)
=EXA("Return only the headquarters", A2)
=EXA("Return the Amazon rating of this product", A2)
```

Второй аргумент — контекст. Формулу можно протянуть вниз по столбцу, чтобы применить её сразу ко многим строкам.

Используйте `=EXA(...)` для простых ответов в одной ячейке. А **Exa Agent** — когда нужно создать или заполнить целую таблицу.

<div id="exa_answer">
  ## `=EXA_ANSWER(...)`
</div>

Расширенные ответы ИИ с полным контролем над форматом вывода. Используйте эту функцию, когда нужны системные промпты, структурированный вывод в JSON, ссылки на источники или определённый тип поиска.

```text theme={null}
=EXA_ANSWER(prompt, [prefix], [suffix], [includeCitations], [systemPrompt], [outputSchema], [returnRawJson], [type])
```

| Параметр           | Обязательный | По умолчанию | Описание                                                                                                                 |
| ------------------ | ------------ | ------------ | ------------------------------------------------------------------------------------------------------------------------ |
| `prompt`           | Да           | —            | Основной вопрос или запрос.                                                                                              |
| `prefix`           | Нет          | `""`         | Текст, добавляемый перед запросом.                                                                                       |
| `suffix`           | Нет          | `""`         | Текст, добавляемый после запроса.                                                                                        |
| `includeCitations` | Нет          | `FALSE`      | Если `TRUE`, добавляет пронумерованные ссылки на источники.                                                              |
| `systemPrompt`     | Нет          | `""`         | Системные инструкции для управления форматом вывода (например, `"only return a number"`).                                |
| `outputSchema`     | Нет          | `""`         | JSON-схема для структурированного вывода. [Сгенерировать схему можно здесь](https://dashboard.exa.ai/playground/answer). |
| `returnRawJson`    | Нет          | `FALSE`      | Если `TRUE` и задан `outputSchema`, возвращает полный JSON вместо извлечения значения.                                   |
| `type`             | Нет          | `"deep"`     | Тип поиска: `"auto"`, `"neural"`, `"fast"` или `"deep"`.                                                                 |

Примеры:

```text theme={null}
=EXA_ANSWER("OpenAI CEO", "", "", FALSE, "only return a name")
=EXA_ANSWER("Modal AI headcount", "", "", FALSE, "only return a number")
=EXA_ANSWER("ceo of exa.ai", "", "", FALSE, "", "{""type"":""object"",""properties"":{""name"":{""type"":""string""}}}")
```

<div id="exa_search">
  ## `=EXA_SEARCH(...)`
</div>

Выполняет поиск в интернете и возвращает вертикальный список URL. Поддерживает фильтрацию по доменам и категориям, highlights содержимого, а также синтезированный вывод через `outputSchema`.

```text theme={null}
=EXA_SEARCH(query, [numResults], [searchType], [prefix], [suffix], [includeDomainsStr], [excludeDomainsStr], [category], [highlightsMaxChars], [outputSchemaJson])
```

| Параметр             | Обязательный | По умолчанию | Описание                                                                                                                                                    |
| -------------------- | ------------ | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `query`              | Да           | —            | Поисковый запрос.                                                                                                                                           |
| `numResults`         | Нет          | `1`          | Количество результатов (1–10).                                                                                                                              |
| `searchType`         | Нет          | `"auto"`     | `"auto"`, `"neural"` или `"keyword"`.                                                                                                                       |
| `prefix`             | Нет          | `""`         | Текст, добавляемый перед запросом.                                                                                                                          |
| `suffix`             | Нет          | `""`         | Текст, добавляемый после запроса.                                                                                                                           |
| `includeDomainsStr`  | Нет          | `""`         | Список доменов через запятую, которые нужно включить (например, `"linkedin.com,crunchbase.com"`).                                                           |
| `excludeDomainsStr`  | Нет          | `""`         | Список доменов через запятую, которые нужно исключить.                                                                                                      |
| `category`           | Нет          | `""`         | Фильтр по типу: `"company"`, `"publication"`, `"news"`, `"personal site"`, `"financial report"`, `"people"`.                                                |
| `highlightsMaxChars` | Нет          | `0`          | Если &gt; 0, запрашивает highlights контента с указанным лимитом символов на каждый результат.                                                              |
| `outputSchemaJson`   | Нет          | `""`         | JSON-строка для `outputSchema` (например, `"{""type"":""text"",""description"":""summarize""}"`). Если задано, возвращает синтезированный текст вместо URL. |

Примеры:

```text theme={null}
=EXA_SEARCH("AI startups", 5, "auto", "", "", "linkedin.com,crunchbase.com")
=EXA_SEARCH("transformer architecture", 5, "auto", "", "", "", "", "publication")
```

<div id="exa_contents">
  ## `=EXA_CONTENTS(...)`
</div>

Извлекает текстовое содержимое страницы по URL.

```text theme={null}
=EXA_CONTENTS(url)
```

| Параметр | Обязательный | Описание                                             |
| -------- | ------------ | ---------------------------------------------------- |
| `url`    | Да           | Полный URL (должен начинаться с `http` или `https`). |

<div id="exa_findsimilar">
  ## `=EXA_FINDSIMILAR(...)`
</div>

Находит URL, похожие на заданный URL, с возможностью фильтрации по доменам и тексту.

```text theme={null}
=EXA_FINDSIMILAR(url, [numResults], [includeDomainsStr], [excludeDomainsStr], [includeTextStr], [excludeTextStr])
```

| Параметр            | Обязательный | По умолчанию | Описание                                            |
| ------------------- | ------------ | ------------ | --------------------------------------------------- |
| `url`               | Да           | —            | Исходный URL для поиска похожих.                    |
| `numResults`        | Нет          | `1`          | Количество результатов (1–10).                      |
| `includeDomainsStr` | Нет          | `""`         | Домены для включения, через запятую.                |
| `excludeDomainsStr` | Нет          | `""`         | Домены для исключения, через запятую.               |
| `includeTextStr`    | Нет          | `""`         | Фраза, которая должна присутствовать в результатах. |
| `excludeTextStr`    | Нет          | `""`         | Фраза, которой не должно быть в результатах.        |

<div id="batch">
  ## Batch
</div>

Используйте **Batch**, когда нужно работать сразу с множеством ячеек с формулами Exa.

Batch позволяет:

* обновлять выбранные ячейки с формулами Exa
* преобразовывать выбранные формулы Exa в обычные значения

Преобразуйте формулы в значения, если хотите сохранить текущие результаты и предотвратить повторное выполнение формул.

<div id="when-to-use-what">
  ## Что и когда использовать
</div>

| Задача                                                            | Инструмент                 |
| ----------------------------------------------------------------- | -------------------------- |
| Создать таблицу целиком по промпту                                | Exa Agent → Generate table |
| Заполнить пустые ячейки таблицы                                   | Exa Agent → Fill cells     |
| Дополнить таблицу новыми строками                                 | Exa Agent → Fill cells     |
| Получить одно значение в одной ячейке                             | `=EXA(...)`                |
| Получить ответ с системным промптом или структурированным выводом | `=EXA_ANSWER(...)`         |
| Выполнить search и получить список URL                            | `=EXA_SEARCH(...)`         |
| Извлечь текст со страницы по URL                                  | `=EXA_CONTENTS(...)`       |
| Найти страницы, похожие на указанный URL                          | `=EXA_FINDSIMILAR(...)`    |
| Обновить сразу много формул Exa                                   | Batch                      |
| Сохранить результаты формул как обычный текст                     | Batch → Convert to values  |

<div id="notes">
  ## Примечания
</div>

* Запросы к Exa API расходуют вашу квоту использования. Используйте **Batch → Convert to values**, чтобы зафиксировать результаты и отключить пересчёт формул.
* При превышении лимита запросов (HTTP 429) дополнение автоматически повторяет запрос до 3 раз с экспоненциальной задержкой.
* Начните с небольших пакетов (10–20 строк) и лишь затем переходите к сотням.
