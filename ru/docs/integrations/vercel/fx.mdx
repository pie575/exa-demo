[fx](https://fx.sh) — это нативный coding agent и CLI от Vercel Labs, а также MCP-клиент. Подключите размещённый MCP-сервер Exa, чтобы он мог выполнять веб-поиск в реальном времени и читать страницы.

## Установка {#installation}

<Steps>
  <Step title="Установите fx">
    ```bash theme={null}
    curl -fsSL https://fx.sh/setup.sh | bash
    ```

    Затем выполните вход командой `fx login`. Варианты провайдеров смотрите в [документации fx](https://fx.sh/docs).
  </Step>

  <Step title="Добавьте Exa">
    Запустите fx командой `fx`, затем добавьте MCP-сервер Exa из интерактивной оболочки:

    ```text theme={null}
    /mcp add --transport http exa https://mcp.exa.ai/mcp
    ```

    fx сохранит сервер в `~/.fx/mcp.json` и перезагрузит MCP.
  </Step>

  <Step title="Проверьте подключение">
    ```text theme={null}
    /mcp list
    ```
  </Step>
</Steps>

## Настройка вручную {#configure-by-hand}

fx считывает MCP-серверы только из `~/.fx/mcp.json`, поэтому Exa можно добавить прямо туда:

```json ~/.fx/mcp.json theme={null}
{
  "mcp": {
    "exa": {
      "type": "http",
      "url": "https://mcp.exa.ai/mcp"
    }
  }
}
```

Выполните `/mcp reload`, чтобы применить изменения без перезапуска fx.

Бесплатного плана достаточно для нерегулярного использования. Чтобы повысить лимит частоты запросов, создайте API key и добавьте его в конфигурацию:

<Card title="Получите свой Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  Создайте ключ в дашборде. Новым аккаунтам начисляются бесплатные credits.
</Card>

```json ~/.fx/mcp.json theme={null}
{
  "mcp": {
    "exa": {
      "type": "http",
      "url": "https://mcp.exa.ai/mcp",
      "header_env": {
        "x-api-key": "EXA_API_KEY"
      }
    }
  }
}
```

`header_env` сопоставляет имя header с переменной окружения, благодаря чему ключ не попадает в файл конфигурации.

## Обнаружение tools {#tool-discovery}

fx обнаруживает MCP tools лениво: tools сервера не попадают в context модели, пока они не понадобятся на очередном шаге, поэтому подключение Exa ничего не стоит на тех шагах, где поиск в вебе не выполняется.
