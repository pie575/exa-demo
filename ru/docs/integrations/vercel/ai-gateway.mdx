Используйте веб-поиск Exa через [Vercel AI Gateway](https://vercel.com/docs/ai-gateway) с помощью `gateway.tools.exaSearch()` из пакета `ai`. API key Exa не требуется: Vercel тарифицирует такие запросы через AI Gateway. Полный справочник смотрите в [документации Vercel по веб-поиску](https://vercel.com/docs/ai-gateway/models-and-providers/web-search).

<div id="install">
  ## Установка
</div>

Установите AI SDK 5 или новее:

```bash install.sh theme={null}
npm install ai
```

<div id="authentication">
  ## Аутентификация
</div>

<Info>
  Для AI Gateway требуется API key или OIDC-токен. Создайте `AI_GATEWAY_API_KEY` в дашборде Vercel в разделе **AI Gateway &gt; API Keys**, затем добавьте его в переменные окружения.
</Info>

```bash .env theme={null}
AI_GATEWAY_API_KEY=your-api-key-here
```

При развёртывании приложения на Vercel вместо этого можно использовать автоматически доступный `VERCEL_OIDC_TOKEN`. См. [документацию Vercel по аутентификации и BYOK](https://vercel.com/docs/ai-gateway/authentication-and-byok).

<div id="quick-start">
  ## Быстрый старт
</div>

Exa search можно использовать с любой поддерживаемой моделью:

```typescript quickstart.ts theme={null}
import { gateway, generateText, stepCountIs } from 'ai';

const { text } = await generateText({
  model: 'openai/gpt-5.6-sol',
  prompt: 'What are the latest developments in AI this week?',
  tools: {
    exa_search: gateway.tools.exaSearch(),
  },
  stopWhen: stepCountIs(3),
});

console.log(text);
```

<div id="streaming">
  ## Потоковая передача
</div>

Используйте `streamText` для обработки генерируемого текста и событий инструмента search по мере их поступления:

```typescript stream.ts theme={null}
import { gateway, streamText } from 'ai';

const result = streamText({
  model: 'openai/gpt-5.6-sol',
  prompt: 'What are the latest developments in AI this week?',
  tools: {
    exa_search: gateway.tools.exaSearch(),
  },
});

for await (const part of result.fullStream) {
  if (part.type === 'text-delta') {
    process.stdout.write(part.text);
  } else if (part.type === 'tool-call') {
    console.log('Tool call:', part.toolName);
  } else if (part.type === 'tool-result') {
    console.log('Search results received');
  }
}
```

В route handler Next.js верните поток клиенту с помощью `return result.toUIMessageStreamResponse()`.

<div id="configuration">
  ## Настройка
</div>

Передайте параметры в `gateway.tools.exaSearch()`, чтобы настроить search:

```typescript configuration.ts theme={null}
tools: {
  exa_search: gateway.tools.exaSearch({
    type: 'fast',
    numResults: 5,
    category: 'news',
    includeDomains: ['reuters.com', 'bbc.com', 'nytimes.com'],
    contents: {
      highlights: true,
      maxAgeHours: 24,
    },
  }),
},
```

Доступны следующие опции:

| Опция                                                  | Описание                                                              |
| ------------------------------------------------------ | --------------------------------------------------------------------- |
| `type`                                                 | Режим поиска: `auto` (по умолчанию), `fast` или `instant`.            |
| `numResults`                                           | Количество возвращаемых результатов, от 1 до 100. По умолчанию 10.    |
| `category`                                             | Категория содержимого.                                                |
| `includeDomains` / `excludeDomains`                    | Включить или исключить определённые домены.                           |
| `startPublishedDate` / `endPublishedDate`              | Фильтрация результатов по дате публикации.                            |
| `userLocation`                                         | Двухбуквенный код страны ISO для поиска с учётом местоположения.      |
| `contents.text`                                        | Возвращать извлечённый текст страницы.                                |
| `contents.highlights`                                  | Возвращать релевантные highlights страницы.                           |
| `contents.maxAgeHours`                                 | Задать максимальный срок актуальности кешированного содержимого.      |
| `contents.livecrawlTimeout`                            | Задать таймаут livecrawl.                                             |
| `contents.subpages` / `contents.subpageTarget`         | Обходить подстраницы и при необходимости указать целевую подстраницу. |
| `contents.extras.links` / `contents.extras.imageLinks` | Возвращать ссылки или ссылки на изображения из результатов.           |

Полный список parameters и описание их поведения см. в [справочнике по веб-поиску Exa](https://vercel.com/docs/ai-gateway/models-and-providers/web-search) от Vercel.

<div id="vercel-eve-agents">
  ## Агенты Vercel eve
</div>

Агенты, созданные с помощью [eve](https://eve.dev), получают встроенный инструмент `web_search`, а модели AI Gateway по умолчанию выполняют его через Exa — без дополнительных настроек и API key Exa. Чтобы задать провайдера явно, экспортируйте его из `agent/tools/web_search.ts`:

```typescript agent/tools/web_search.ts theme={null}
import { webSearch } from 'eve/tools';

export default webSearch({ provider: 'exa' });
```

Модели, вызываемые напрямую через провайдера, а не через AI Gateway, сохраняют свой встроенный веб-поиск. Полный набор инструментов описан в [документации по harness](https://eve.dev/docs/concepts/default-harness#built-in-tools) eve.

<div id="pricing">
  ## Цены
</div>

<Tip>
  Веб-поиск Exa **бесплатен до 31 августа** в AI Gateway и eve, так что вы можете начать разработку с ним уже сегодня совершенно бесплатно.
</Tip>

После этого Vercel будет тарифицировать запросы через AI Gateway по ценам, указанным в [документации Vercel по веб-поиску](https://vercel.com/docs/ai-gateway/models-and-providers/web-search).

<Note>
  Эта интеграция пока поддерживает стандартные режимы поиска Exa и параметры извлечения контента. Режимы глубокого синтеза и генерируемые краткие сводки ещё не доступны.
</Note>
