Exa серьёзно относится к безопасности и конфиденциальности данных. Мы гордимся сертификацией SOC 2 Type II, которая подтверждает нашу приверженность строгим практикам и средствам контроля информационной безопасности.

Свяжитесь с нами по адресу [sales@exa.ai](mailto:sales@exa.ai), чтобы обсудить план Enterprise, если вас интересует [нулевое хранение данных](/ru/docs/admin/security/zero-data-retention), [соответствие требованиям HIPAA](/ru/docs/admin/security/hipaa) или другие индивидуальные решения по безопасности данных.

Посетите наш [Trust Center](https://trust.exa.ai), чтобы ознакомиться с отчётами SOC 2, соглашением об обработке данных и другой документацией по безопасности.

## Региональные ограничения доступа {#regional-access-restrictions}

В соответствии с санкциями и торговыми ограничениями Exa блокирует доступ к API из подсанкционных и иных ограниченных стран и регионов, включая Крым, Кубу, Иран, Северную Корею, Россию, Сирию, Украину и Венесуэлу.

Запросы из этих регионов могут блокироваться Cloudflare ещё до того, как они дойдут до Exa. В этом случае вместо стандартного JSON с ошибкой Exa API в ответе может прийти страница блокировки Cloudflare WAF с идентификатором Ray ID.

Если вы считаете, что ваш трафик определяется по геолокации неверно, напишите на [hello@exa.ai](mailto:hello@exa.ai), указав исходный IP-адрес, страну или регион, временную метку запроса и Cloudflare Ray ID.
