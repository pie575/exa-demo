Exa серьёзно относится к безопасности и конфиденциальности данных. Мы гордимся сертификацией SOC 2 Type II: она подтверждает, что мы придерживаемся строгих практик и мер контроля в области информационной безопасности.

Свяжитесь с нами по адресу [sales@exa.ai](mailto:sales@exa.ai), чтобы обсудить план Enterprise, если вас интересует [нулевое хранение данных](/ru/docs/admin/security/zero-data-retention), [соответствие требованиям HIPAA](/ru/docs/admin/security/hipaa) или другие индивидуальные решения по защите данных.

Зайдите в наш [Trust Center](https://trust.exa.ai), чтобы ознакомиться с отчётами SOC 2, соглашением об обработке данных и другой документацией по безопасности.

<div id="regional-access-restrictions">
  ## Региональные ограничения доступа
</div>

В соответствии с санкциями и торговыми ограничениями Exa блокирует доступ к API из стран и регионов, находящихся под санкциями или иными ограничениями, включая Крым, Кубу, Иран, Северную Корею, Россию, Сирию, Украину и Венесуэлу.

Запросы из этих регионов могут блокироваться Cloudflare ещё до того, как они дойдут до Exa. В этом случае вместо стандартного JSON с ошибкой Exa API в ответе может прийти страница блокировки Cloudflare WAF с Ray ID.

Если вы считаете, что геолокация вашего трафика определяется неверно, напишите на [hello@exa.ai](mailto:hello@exa.ai), указав исходный IP-адрес, страну или регион, время запроса и Cloudflare Ray ID.
