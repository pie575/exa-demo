---
title: "Нулевое хранение данных"
description: "Доступность нулевого хранения данных в продуктах Exa."
---

Нулевое хранение данных (ZDR) доступно в планах Enterprise и включается отдельно для каждой команды. За подробностями обращайтесь по адресу [sales@exa.ai](mailto:sales@exa.ai).

| Продукт  | Доступность ZDR        |
| -------- | ---------------------- |
| Search   | Доступно               |
| Contents | Доступно               |
| Agent    | Доступно               |
| Answer   | Пока не поддерживается |
| Websets  | Пока не поддерживается |
