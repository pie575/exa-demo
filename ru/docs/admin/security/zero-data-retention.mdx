---
title: "Нулевое хранение данных"
description: "Доступность Zero Data Retention в продуктах Exa."
---

Нулевое хранение данных (Zero Data Retention, ZDR) доступно в тарифах Enterprise и включается отдельно для каждой команды. За подробностями обращайтесь на [sales@exa.ai](mailto:sales@exa.ai).

| Продукт  | Доступность ZDR        |
| -------- | ---------------------- |
| Search   | Доступно               |
| Contents | Доступно               |
| Agent    | Доступно               |
| Answer   | Пока не поддерживается |
| Websets  | Пока не поддерживается |
