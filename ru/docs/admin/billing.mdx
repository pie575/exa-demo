<div id="billing-basics">
  ## Основы биллинга
</div>

Запросы оплачиваются из предоплаченных credits по тарифам, указанным в разделе [Цены](/ru/docs/admin/pricing), или по условиям вашего контракта Enterprise. Владельцы команды могут пополнить credits в [панели биллинга](https://dashboard.exa.ai/billing); платежи обрабатываются через Stripe.

Если credits команды закончились, запросы возвращают `402 Payment Required`. API key, исчерпавший выделенный ему бюджет, также возвращает `402`. Пополните credits или попросите администратора команды изменить бюджет ключа. См. [Коды ошибок](/ru/docs/admin/error-codes).

Чтобы посмотреть историю использования по API key, воспользуйтесь методом [Статистика использования ключа API](/ru/docs/reference/team-management/get-api-key-usage).

<div id="rate-limits">
  ## Лимиты частоты запросов
</div>

Лимиты частоты запросов измеряются в запросах в секунду (QPS) и действуют на всю вашу команду сразу, для всех её API key. Отдельному ключу можно задать более низкий лимит на странице [API Keys](https://dashboard.exa.ai/api-keys), но его трафик всё равно засчитывается в общий лимит команды.

| Эндпоинт                                                    | Лимит по умолчанию             |
| ----------------------------------------------------------- | ------------------------------ |
| `/search`, `/answer`, `/chat/completions`                   | 10 QPS                         |
| `/search` с `type` `deep-lite`, `deep` или `deep-reasoning` | 5 QPS                          |
| `/contents`                                                 | 100 QPS                        |
| `/agent/runs`, `/responses`                                 | 5 QPS и 50 активных выполнений |
| `/websets/*`                                                | 20 QPS                         |

Часть эндпоинтов делит общий лимит частоты запросов. Лимиты могут меняться и зависят от тарифного плана; для Websets searches также действуют лимиты параллелизма, зависящие от плана, — их можно узнать через [Информация о команде](/ru/docs/websets/api/teams/get-team-info).

При превышении лимита запросы возвращают `429 Too Many Requests`. Дождитесь времени, указанного в header `Retry-After`, если он присутствует, либо повторите запрос с экспоненциальной задержкой. См. [Коды ошибок](/ru/docs/admin/error-codes).

<div id="agent-limits">
  ### Лимиты Agent
</div>

Лимиты Agent — это два отдельных механизма: сколько выполнений может выполняться одновременно и как быстро можно запускать новые.

* **Параллелизм**: одновременно может выполняться 50 выполнений Agent. Этот лимит не связан с вашим QPS и не меняется при его повышении. Попытка запустить выполнение сверх лимита возвращает `429` с кодом ошибки `CONCURRENCY_LIMIT_REACHED`; дождитесь завершения одного из выполнений или свяжитесь с нами, чтобы увеличить лимит параллелизма.
* **Запуск**: `POST /agent/runs` расходует QPS вашего аккаунта, причём каждое выполнение считается за два запроса. Запускать выполнения можно со скоростью, равной половине вашего QPS: аккаунт со стандартными 10 QPS может стартовать 5 выполнений в секунду, а при 25 QPS — 12 в секунду.
* **Опрос**: `GET`-запросы статуса выполнения, событий и списков выполнений не расходуют QPS и никогда не блокируют отправку новых, поэтому опрашивайте работающие Agent независимо от того, как быстро вы запускаете новые.

<div id="25-qps-on-pay-as-you-go">
  ### 25 QPS при оплате по факту использования
</div>

Пополните баланс на $1 000 в credits в течение любого 30-дневного периода, и лимит частоты запросов вашей team автоматически вырастет до **25 QPS на 90 дней**. Учитываются купленные credits, а не потраченные, а повторное выполнение условия обнуляет отсчёт 90 дней. Следите за прогрессом в [панели биллинга](https://dashboard.exa.ai/billing).

Нужно больше 25 QPS? [Свяжитесь с отделом продаж](https://exa.ai/contact/sales).

<div id="auto-recharge">
  ## Автопополнение
</div>

Автопополнение покупает credits, когда баланс достигает выбранного вами порога. Настроить эту функцию можно в [панели биллинга](https://dashboard.exa.ai/billing).

| Настройка             | Описание                                                                                                                                           |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Сумма пополнения**  | Credits, приобретаемые при каждом срабатывании автопополнения, от $5 до $10 000.                                                                    |
| **Порог пополнения**  | Баланс, при котором срабатывает пополнение.                                                                                                        |
| **Месячный максимум** | Необязательный лимит на автоматические пополнения в течение расчётного периода. Укажите $0 или оставьте поле пустым, чтобы не устанавливать лимит. |

Например, при сумме пополнения $100, пороге $10 и месячном максимуме $500 каждый раз, когда баланс опускается до $10, будет списываться $100, но не более $500 автоматических покупок за период.

Перед запуском продукта или другой высоконагруженной задачей заранее добавьте достаточно credits и задайте такую сумму автопополнения, чтобы избежать множества мелких списаний.

<div id="receipts-and-invoices">
  ## Чеки и счета
</div>

Exa отправляет чеки за покупку кредитов и автопополнения по электронной почте с адреса [billing@exa.ai](mailto:billing@exa.ai). При необходимости добавьте этот адрес в список разрешённых. Полная история счетов доступна в [панели биллинга](https://dashboard.exa.ai/billing).

Постоплатный биллинг по счетам доступен на плане Enterprise.
