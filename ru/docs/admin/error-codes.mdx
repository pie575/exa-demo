API Exa сообщают о сбоях стандартными HTTP-кодами состояния и телом ошибки.

<div id="http-status-codes">
  ## HTTP-коды состояния
</div>

| Код                         | Значение                                                                                                     | Что делать                                                                                                                                           |
| --------------------------- | ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `400` Bad Request           | Тело запроса, запрос-параметры, заголовки или сочетание опций некорректны.                                    | Исправьте запрос, опираясь на возвращённое сообщение.                                                                                                |
| `401` Unauthorized          | API key отсутствует или недействителен.                                                                      | Проверьте заголовок аутентификации и API key.                                                                                                        |
| `402` Payment Required      | Кредиты исчерпаны или превышен бюджет расходов.                                                              | [Пополните кредиты](https://dashboard.exa.ai) или обратитесь к администратору вашей команды.                                                         |
| `403` Forbidden             | У API key нет доступа к запрошенной функции, либо запрос заблокирован политикой.                             | Проверьте возвращённое сообщение и набор функций вашего тарифа.                                                                                      |
| `404` Not Found             | Маршрут или запрошенный ресурс не существует.                                                                | Проверьте эндпоинт и идентификатор ресурса.                                                                                                          |
| `409` Conflict              | Запрос конфликтует с текущим состоянием — например, Webset с таким же `externalId` уже существует.           | Получите существующий ресурс или используйте другой идентификатор.                                                                                   |
| `422` Unprocessable Entity  | Запрос предпросмотра Websets не удалось разложить на корректную сущность и criteria.                         | Переформулируйте запрос предпросмотра.                                                                                                               |
| `429` Too Many Requests     | Ваш API key, команда или сеть превысили лимит частоты запросов или параллелизма.                             | Снизьте частоту запросов; если присутствует `Retry-After`, подождите указанное в нём число секунд, иначе используйте экспоненциальную задержку.      |
| `500` Internal Server Error | Произошла непредвиденная ошибка сервера.                                                                     | Повторите запрос через небольшую паузу. Если проблема сохраняется, обратитесь в поддержку.                                                           |
| `503` Service Unavailable   | Exa временно перегружена (`SERVICE_OVERLOADED`) или недоступна. Запрос не был обработан и не тарифицируется. | Повторите запрос с экспоненциальной задержкой. Это не связано с частотой ваших запросов, поэтому её снижение не поможет — помогут повторные попытки. |
| `504` Gateway Timeout       | Запрос превысил отведённое время обработки.                                                                  | Повторите запрос или сократите его scope.                                                                                                            |

<Note>
  Ошибки на уровне отдельных URL из `/contents` возвращаются в поле `statuses` успешного ответа `200`, а не как ошибки уровня запроса. См. [теги статуса получения содержимого](#content-fetch-status-tags).
</Note>

<div id="error-response-structure">
  ## Структура ответа с ошибкой
</div>

Ответы с ошибкой содержат `requestId`, понятное человеку сообщение `error` и машиночитаемый `tag`:

```json theme={null}
{
  "requestId": "67207943fab9832d162b5317f4cca830",
  "error": "Invalid request body | Validation error: Invalid value for type",
  "tag": "INVALID_REQUEST_BODY"
}
```

<Note>
  Указывайте `requestId` при обращении в поддержку — это ускорит диагностику.
</Note>

Набор тегов открыт для расширения, а их имена говорят сами за себя. Сначала выполняйте ветвление по HTTP-коду состояния, а нераспознанные теги считайте дополнительной информацией, а не ошибкой разбора.

<div id="account-billing-and-access">
  ### Учётная запись, оплата и доступ
</div>

| Тег                       | HTTP-код | Описание                                                                                                   |
| ------------------------- | -------- | ---------------------------------------------------------------------------------------------------------- |
| `INVALID_API_KEY`         | `401`    | API key отсутствует, пуст или недействителен.                                                              |
| `NO_MORE_CREDITS`         | `402`    | На счёте не осталось кредитов — пополните баланс на [dashboard.exa.ai](https://dashboard.exa.ai).          |
| `API_KEY_BUDGET_EXCEEDED` | `402`    | API key исчерпал свой бюджет расходов — обратитесь к администратору команды.                               |
| `TEAM_BUDGET_EXCEEDED`    | `402`    | Команда превысила бюджет расходов за текущий расчётный период.                                             |
| `FEATURE_DISABLED`        | `403`    | Запрошенный эндпоинт, тип search или параметр недоступны в вашем тарифе.                                   |
| `PROHIBITED_CONTENT`      | `403`    | Запрос отклонён системой модерации контента.                                                               |
| `CONTENT_FILTER_ERROR`    | `403`    | Контент отклонён политикой безопасности в ходе обработки.                                                  |
| `RATE_LIMIT_EXCEEDED`     | `429`    | Ваш API key, команда или сеть превысили свой лимит частоты запросов — снизьте частоту обращений.           |
| `SERVICE_OVERLOADED`      | `503`    | Exa временно перегружена и отклонила запрос до обработки — повторите попытку с экспоненциальной задержкой. |

<div id="request-validation">
  ### Валидация запроса
</div>

| Тег                       | HTTP-код | Описание                                                                                  |
| ------------------------- | -------- | ----------------------------------------------------------------------------------------- |
| `INVALID_REQUEST_BODY`    | `400`    | Тело JSON не прошло проверку по схеме.                                                    |
| `INVALID_REQUEST`         | `400`    | Параметры конфликтуют друг с другом либо бета-функция использована без header `Exa-Beta`. |
| `INVALID_NUM_RESULTS`     | `400`    | При запросе highlights значение `numResults` должно быть ≤ 100.                           |
| `NUM_RESULTS_EXCEEDED`    | `400`    | Запрошенное количество результатов превышает лимит вашего тарифа.                         |
| `INVALID_JSON_SCHEMA`     | `400`    | Переданная схема вывода некорректна.                                                      |
| `SUBPAGES_LIMIT_EXCEEDED` | `400`    | `/contents` допускает не более 100 подстраниц на один запрос.                             |

<div id="payment-protocols">
  ### Платёжные протоколы
</div>

Запросы, оплаченные через x402 или MPP, также могут возвращать:

| Тег                        | HTTP-код | Описание                                              |
| -------------------------- | -------- | ----------------------------------------------------- |
| `X402_PAYMENT_REQUIRED`    | `402`    | Требуется оплата.                                     |
| `X402_INVALID_SIGNATURE`   | `400`    | Недействительная подпись платежа x402.                |
| `X402_VERIFICATION_FAILED` | `402`    | Не удалось проверить платёж x402.                     |
| `MPP_VERIFICATION_FAILED`  | `402`    | Не удалось проверить платёж MPP.                      |
| `X402_TOO_MANY_UNPAID`     | `429`    | Слишком много запросов x402 ожидают оплаты.           |
| `X402_WALLET_RATE_LIMITED` | `429`    | Кошелёк x402 превысил лимит частоты запросов.         |
| `X402_INTERNAL_ERROR`      | `500`    | Exa не смогла сформировать платёжные требования x402. |

<div id="content-fetch-status-tags">
  ## Теги статуса получения содержимого
</div>

Когда `/contents` принимает несколько URL, по одному из них запрос может завершиться ошибкой, а по остальным — успешно. Ошибки на уровне отдельных URL возвращаются в поле `statuses` и не приводят к сбою всего запроса:

```json theme={null}
{
  "results": [],
  "statuses": [
    {
      "id": "https://example.com",
      "status": "error",
      "error": {
        "tag": "CRAWL_NOT_FOUND",
        "httpStatusCode": 404
      }
    }
  ]
}
```

`httpStatusCode` описывает целевую страницу, а не ответ `/contents`.

| Тег                       | Описание                                                               | Что делать                                                             |
| ------------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `CRAWL_NOT_FOUND`         | Целевая страница не найдена.                                           | Проверьте, что URL указан верно и страница доступна.                   |
| `CRAWL_HTTP_{status}`     | Целевой ресурс вернул ошибку HTTP, например `CRAWL_HTTP_403`.          | Обработайте статус целевого ресурса, указанный в теге.                 |
| `CRAWL_TIMEOUT`           | Истекло время ожидания при обходе целевой страницы.                    | Повторите запрос или попробуйте позже.                                 |
| `CRAWL_LIVECRAWL_TIMEOUT` | Получение в реальном времени превысило запрошенный `livecrawlTimeout`. | Увеличьте `livecrawlTimeout` или измените `maxAgeHours`.               |
| `SOURCE_NOT_AVAILABLE`    | Доступ к источнику запрещён или источник недоступен.                   | Проверьте, требует ли источник аутентификации или ограничивает доступ. |
| `UNSUPPORTED_URL`         | Схема URL не поддерживается для получения содержимого.                 | Используйте стандартный URL с HTTP или HTTPS.                          |
| `CRAWL_UNKNOWN_ERROR`     | Обход завершился ошибкой по иной причине.                              | Повторите запрос; если проблема сохраняется, обратитесь в поддержку.   |

Эти теги статуса относятся только к `/contents`; `/search` поле `statuses` не возвращает.

<div id="getting-help">
  ## Как получить помощь
</div>

* Проверьте [статус Exa](/ru/docs/admin/status), если ошибки `500`, `503` или `504` повторяются.
* Посмотрите текущие значения в разделе [Лимит запросов](/ru/docs/admin/billing#rate-limits).
* Уточните требования к запросу в [справочнике API](/ru/docs/reference/search) для нужного эндпоинта.
* Напишите на [hello@exa.ai](mailto:hello@exa.ai), указав статус ответа, тело ошибки и `requestId`.
