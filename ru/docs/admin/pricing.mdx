<Check>
  **Начните бесплатно.** Новые аккаунты получают credits на $20 (примерно 2 800 searches), а на Free Tier ежемесячно начисляется ещё $10 в credits. Получите API key и приступайте к разработке.

  **Нужно больше?** Если вам требуются большие объёмы, собственные индексы, повышенные лимиты частоты запросов, SLA или нулевое хранение данных, [свяжитесь с нами](https://exa.ai/contact/sales) по поводу [плана Enterprise](#enterprise) со скидками за объём.
</Check>

| Эндпоинт    | Базовая цена<br />(до 10 результатов)         | Каждый результат сверх 10 | ИИ-сводки страниц   |

| `/search`   | $7 / 1 тыс. запросов                          | $1 / 1 тыс. результатов   | $1 / 1 тыс. страниц |
| `/answer`   | $5 / 1 тыс. запросов                          | —                         | —                   |
| `/monitors` | $15 / 1 тыс. запросов                         | $1 / 1 тыс. результатов   | $1 / 1 тыс. страниц |
| `/contents` | $1 / 1 тыс. страниц за каждый тип содержимого | —                         | $1 / 1 тыс. страниц |

<div id="agent">
  ## Agent
</div>

Задайте фиксированный `effort` для [Agent](/ru/docs/agent/quickstart), чтобы получить предсказуемую цену за запрос. `auto` — режим с оплатой по факту, используемый по умолчанию; бета-режим `max` также тарифицируется по факту и использует те же ставки за использование:

| Effort    | Цена            |
| --------- | --------------- |
| `minimal` | $0.012 / запрос |
| `low`     | $0.025 / запрос |
| `medium`  | $0.10 / запрос  |
| `high`    | $0.50 / запрос  |
| `xhigh`   | $1.00 / запрос  |

При оплате по факту тарифицируется фактическое использование в пределах лимита на одно выполнение. Для `auto` лимит по умолчанию составляет $5, для бета-режима `max` — $20:

| Компонент использования       | Цена                   |
| ----------------------------- | ---------------------- |
| Agent Compute Units           | $0.10 / ACU            |
| Вызовы инструмента search     | $0.005 / search        |
| Обогащение контактов: email   | $0.02 / email          |
| Обогащение контактов: телефон | $0.07 / номер телефона |

  ### Провайдеры Connect
</div>

Запуски, использующие источники данных [Exa Connect](/ru/docs/agent/connect/overview),
дополнительно тарифицируются за каждый вызов провайдера: например,
[Fiber.ai](/ru/docs/agent/connect/fiber#pricing) — $0.02 за кредит, а
[Baselayer](/ru/docs/agent/connect/baselayer#pricing) — от $0.15 до $4.00 за
заказ в зависимости от операции. Тарифы всех провайдеров см. в разделе
[Connect pricing](/ru/docs/agent/connect/overview#pricing).

</div>

Задаётся параметром `type` в [`/search`](/ru/docs/search/deep-search). Дополнительные результаты и ИИ-сводки страниц стоят столько же, сколько и стандартный поиск.

| Тип              | Базовая цена<br />(до 10 результатов) | Задержка     | Лучше всего подходит для                              |
| ---------------- | ------------------------------------- | ------------ | ----------------------------------------------------- |
| `deep-lite`      | $12 / 1 тыс. запросов                 | ~4 секунды   | лёгкого синтеза                                       |
| `deep`           | $12 / 1 тыс. запросов                 | 4–15 секунд  | многошаговых рассуждений со структурированным выводом |
| `deep-reasoning` | $15 / 1 тыс. запросов                 | 12–40 секунд | более сложных исследовательских задач                 |

<div id="cost-glossary">
  ## Глоссарий по стоимости
</div>

<AccordionGroup>
  <Accordion title="Запрос">
    Один вызов API к эндпоинту. Цены указаны за 1 000 запросов, поэтому тариф $7 / 1k соответствует $0,007 за вызов.
  </Accordion>

  <Accordion title="Результат">
    Один результат поиска, возвращённый в ответе. Базовая цена покрывает первые 10 результатов в запросе; каждый результат сверх 10 добавляет $1 / 1k результатов. Поэтому запрос с `numResults: 20` стоит базовую цену плюс 10 дополнительных результатов.
  </Accordion>

  <Accordion title="Страница и тип содержимого">
    Страница — это один URL, для которого Exa возвращает содержимое. Тип содержимого — это одно представление этой страницы: `text`, `highlights` или `summary`. `/contents` тарифицирует каждый тип содержимого отдельно, поэтому одна страница с `text` и `highlights` считается за две.
  </Accordion>

  <Accordion title="AI-сводка страницы">
    Сгенерированная Exa сводка страницы, созданная дополнительным вызовом LLM на нашей стороне. Тарифицируется по $1 / 1k страниц на любом эндпоинте, который её возвращает.
  </Accordion>

  <Accordion title="Agent Compute Unit (ACU)">
    Единица вычислений модели, которую потребляет выполнение Agent; отражается в `usage.agentComputeUnits`. Чем дольше выполнение, больше объём `input.data` и число шагов рассуждения, тем больше расходуется ACU.
  </Accordion>

  <Accordion title="Effort">
    Параметр Agent, который балансирует стоимость и задержку против тщательности. `auto` тарифицируется по потреблению (ACU плюс tool calls) до лимита по умолчанию $5; бета-режим `max` использует те же тарифы потребления до лимита по умолчанию $20. Фиксированные значения effort тарифицируются по единой цене за запрос. См. [Режимы effort в Agent](/ru/docs/agent/quickstart#effort).
  </Accordion>

  <Accordion title="Обогащение контактов">
    Поиск через Agent, возвращающий адрес электронной почты или номер телефона человека либо компании. Тарифицируется за каждый найденный контакт, сверх остальных затрат выполнения.
  </Accordion>

  <Accordion title="Credits">
    Предоплаченный долларовый баланс вашего аккаунта. Использование списывает credits по указанным выше тарифам.
  </Accordion>
</AccordionGroup>
