| `/answer`   | $5 / 1 тыс. запросов                       | —                         | —                   |

<div id="agent">
  ## Agent
</div>

Задайте фиксированное значение `effort` для [Agent](/ru/docs/agent/quickstart), чтобы получить предсказуемую стоимость запроса. По умолчанию используется режим `auto` с тарификацией по факту; бета-режим `max` тоже тарифицируется по факту и по тем же ставкам:

| Effort    | Цена            |
| --------- | --------------- |
| `minimal` | $0,012 / запрос |
| `low`     | $0,025 / запрос |
| `medium`  | $0,10 / запрос  |
| `high`    | $0,50 / запрос  |
| `xhigh`   | $1,00 / запрос  |

Запуски с тарификацией по факту оплачиваются по фактическому потреблению в пределах лимита на один запуск. Для `auto` лимит по умолчанию — $5, для бета-режима `max` — $20:

| Компонент потребления          | Цена                   |
| ------------------------------ | ---------------------- |
| Agent Compute Units            | $0,10 / ACU            |
| Вызовы инструмента search      | $0,005 / search        |
| Enrichment контактов (email)   | $0,02 / email          |
| Enrichment контактов (телефон) | $0,07 / номер телефона |

Задаётся параметром `type` в [`/search`](/ru/docs/search/deep-search). Дополнительные результаты и ИИ-сводки страниц стоят столько же, сколько обычный search.

| Тип              | Базовая цена<br />(до 10 результатов) | Задержка     | Лучше всего подходит для                              |
| ---------------- | ------------------------------------- | ------------ | ----------------------------------------------------- |
| `deep-lite`      | $12 / 1 тыс. запросов                 | ~4 секунды   | лёгкого обобщения                                     |
| `deep`           | $12 / 1 тыс. запросов                 | 4–15 секунд  | многошаговых рассуждений со структурированным выводом |
| `deep-reasoning` | $15 / 1 тыс. запросов                 | 12–40 секунд | более сложных исследовательских задач                 |

<div id="cost-glossary">
  ## Глоссарий по стоимости
</div>

<AccordionGroup>
  <Accordion title="Запрос">
    Один вызов API к эндпоинту. Цены указаны за 1 000 запросов, то есть ставка $7 / 1k — это $0.007 за вызов.
  </Accordion>

  <Accordion title="Результат">
    Один результат поиска, возвращённый в ответе. Базовая цена покрывает первые 10 результатов в запросе; каждый результат сверх 10 добавляет $1 / 1k результатов. Поэтому запрос с `numResults: 20` обойдётся в базовую цену плюс 10 дополнительных результатов.
  </Accordion>

  <Accordion title="Страница и тип контента">
    Страница — это один URL, для которого Exa возвращает контент. Тип контента — одно представление этой страницы: `text`, `highlights` или `summary`. `/contents` тарифицирует каждый тип контента отдельно, поэтому одна страница с `text` и `highlights` считается за две.
  </Accordion>

  <Accordion title="Сводка страницы, созданная ИИ">
    Сгенерированная Exa сводка страницы, которая создаётся дополнительным вызовом LLM на нашей стороне. Тарифицируется по $1 / 1k страниц на любом эндпоинте, который её возвращает.
  </Accordion>

  <Accordion title="Agent Compute Unit (ACU)">
    Единица вычислений модели, которую потребляет запуск Agent; отражается в `usage.agentComputeUnits`. Более длительные запуски, больший объём `input.data` и большее число шагов рассуждения потребляют больше ACU.
  </Accordion>

  <Accordion title="Effort">
    Параметр Agent, который позволяет найти баланс между стоимостью и задержкой с одной стороны и тщательностью с другой. `auto` тарифицируется по потреблению (ACU плюс вызовы инструментов) до лимита по умолчанию в $5; бета-режим `max` использует те же ставки потребления до лимита по умолчанию в $20. Фиксированные режимы тарифицируются по единой цене за запрос. См. [режимы effort в Agent](/ru/docs/agent/quickstart#effort).
  </Accordion>

  <Accordion title="Enrichment контактов">
    Поиск через Agent, возвращающий адрес электронной почты или номер телефона человека либо компании. Тарифицируется за каждый найденный контакт — сверх остальных затрат на запуск.
  </Accordion>

  <Accordion title="Кредиты">
    Предоплаченный долларовый баланс на вашем аккаунте. Использование списывает кредиты по указанным выше ставкам.
  </Accordion>
</AccordionGroup>
