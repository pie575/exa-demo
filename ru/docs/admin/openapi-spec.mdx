<Note>
  Исходные спецификации OpenAPI — источник истины для схем запросов и ответов.
  Сгенерированные страницы справочника могут не содержать рецептов, заметок о миграции и рекомендуемых
  значений по умолчанию; за актуальными рекомендациями по интеграции, такими как `type: "auto"`,
  highlights и настройки свежести, обращайтесь к руководствам и примерам. Эти ссылки всегда указывают
  на спецификации, которые отдаёт текущее развёртывание документации.
</Note>
