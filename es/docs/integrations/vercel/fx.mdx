[fx](https://fx.sh) es un agente de programación nativo y una CLI de Vercel Labs, y también un MCP client. Añade el MCP server alojado de Exa para dotarlo de búsqueda web en tiempo real y lectura de páginas.

<div id="installation">
  ## Instalación
</div>

<Steps>
  <Step title="Instalar fx">
    ```bash theme={null}
    curl -fsSL https://fx.sh/setup.sh | bash
    ```

    Luego inicia sesión con `fx login`. Consulta la [documentación de fx](https://fx.sh/docs) para ver las opciones de proveedor.
  </Step>

  <Step title="Añadir Exa">
    Inicia fx ejecutando `fx` y luego añade el Exa MCP server desde el shell interactivo:

    ```text theme={null}
    /mcp add --transport http exa https://mcp.exa.ai/mcp
    ```

    fx guarda el server en `~/.fx/mcp.json` y recarga MCP.
  </Step>

  <Step title="Verificar la conexión">
    ```text theme={null}
    /mcp list
    ```
  </Step>
</Steps>

<div id="configure-by-hand">
  ## Configuración manual
</div>

fx lee los MCP servers únicamente desde `~/.fx/mcp.json`, así que también puedes añadir Exa ahí directamente:

```json ~/.fx/mcp.json theme={null}
{
  "mcp": {
    "exa": {
      "type": "http",
      "url": "https://mcp.exa.ai/mcp"
    }
  }
}
```

Ejecuta `/mcp reload` para aplicar el cambio sin reiniciar fx.

El plan gratuito cubre un uso ocasional. Para ampliar los límites de tasa, crea una API key y añádela a la configuración:

<Card title="Obtén tu API key de Exa" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  Crea una key en el panel. Las cuentas nuevas empiezan con créditos gratuitos.
</Card>

```json ~/.fx/mcp.json theme={null}
{
  "mcp": {
    "exa": {
      "type": "http",
      "url": "https://mcp.exa.ai/mcp",
      "header_env": {
        "x-api-key": "EXA_API_KEY"
      }
    }
  }
}
```

`header_env` asocia un nombre de encabezado a una variable de entorno, de modo que la key no queda expuesta en el archivo de configuración.

<div id="tool-discovery">
  ## Descubrimiento de herramientas
</div>

fx descubre las herramientas MCP de forma diferida: las herramientas del server no están en el contexto del modelo hasta que un turno las necesita, por lo que agregar Exa no tiene ningún costo en los turnos que no hacen búsquedas en la web.
