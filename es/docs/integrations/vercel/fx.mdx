[fx](https://fx.sh) es un agente de programación nativo y una CLI de Vercel Labs, además de un cliente MCP. Añade el servidor MCP alojado de Exa para dotarlo de búsqueda web en tiempo real y lectura de páginas.

<div id="installation">
  ## Instalación
</div>

<Steps>
  <Step title="Instala fx">
    ```bash theme={null}
    curl -fsSL https://fx.sh/setup.sh | bash
    ```

    Luego inicia sesión con `fx login`. Consulta la [documentación de fx](https://fx.sh/docs) para conocer las opciones de proveedores.
  </Step>

  <Step title="Agrega Exa">
    Inicia fx ejecutando `fx` y luego agrega el servidor MCP de Exa desde el shell interactivo:

    ```text theme={null}
    /mcp add --transport http exa https://mcp.exa.ai/mcp
    ```

    fx guarda el servidor en `~/.fx/mcp.json` y recarga MCP.
  </Step>

  <Step title="Verifica la conexión">
    ```text theme={null}
    /mcp list
    ```
  </Step>
</Steps>

<div id="configure-by-hand">
  ## Configuración manual
</div>

fx lee los servidores MCP únicamente de `~/.fx/mcp.json`, así que también puedes añadir Exa ahí directamente:

```json ~/.fx/mcp.json theme={null}
{
  "mcp": {
    "exa": {
      "type": "http",
      "url": "https://mcp.exa.ai/mcp"
    }
  }
}
```

Ejecuta `/mcp reload` para aplicar el cambio sin reiniciar fx.

El plan gratuito cubre un uso ocasional. Para ampliar los límites de tasa, crea una API key y añádela a la configuración:

<Card title="Obtén tu Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  Crea una key en el panel. Las cuentas nuevas empiezan con créditos gratuitos.
</Card>

```json ~/.fx/mcp.json theme={null}
{
  "mcp": {
    "exa": {
      "type": "http",
      "url": "https://mcp.exa.ai/mcp",
      "header_env": {
        "x-api-key": "EXA_API_KEY"
      }
    }
  }
}
```

`header_env` asocia un nombre de encabezado a una variable de entorno, de modo que la key no queda en el archivo de configuración.

<div id="tool-discovery">
  ## Descubrimiento de herramientas
</div>

fx descubre las herramientas MCP de forma diferida: las herramientas del servidor no entran en el contexto del modelo hasta que un turno las necesita, por lo que añadir Exa no supone ningún coste en los turnos que no buscan en la web.
