Exa es un proveedor de búsqueda web en [Baseten Hosted Tools](https://www.baseten.co/blog/introducing-baseten-hosted-tools/). Las Model APIs de Baseten sirven modelos de código abierto y las Hosted Tools permiten que esos modelos busquen en la web sin que tengas que montar un bucle de herramientas: agregas un selector de herramienta de Exa a una solicitud estándar, Baseten ejecuta el modelo y las búsquedas de Exa en conjunto dentro de un bucle del lado del servidor, y obtienes una respuesta fundamentada en esa misma respuesta. No hace falta una API key de Exa. Baseten traslada el costo de Exa a tu factura de Baseten sin recargo.

## Usa las herramientas de Exa web search {#use-the-exa-web-search-tools}

Establece el encabezado `x-baseten-server-tools: true` y agrega uno o más selectores de Exa a tu arreglo `tools`. Solo se necesita el `type`; Baseten expande el esquema de la herramienta automáticamente, y el modelo decide cuándo buscar, qué buscar y qué páginas leer. Las herramientas del lado del servidor funcionan en los endpoints [Chat Completions](https://docs.baseten.co/reference/inference-api/chat-completions), [Messages](https://docs.baseten.co/reference/inference-api/messages) y Responses de Baseten, tanto en modo almacenado como en streaming.

<CodeGroup>
  ```python Python theme={null}
  from openai import OpenAI

  client = OpenAI(
      api_key="<BASETEN_API_KEY>",
      base_url="https://inference.baseten.co/v1",
      default_headers={"x-baseten-server-tools": "true"},
  )

  response = client.chat.completions.create(
      model="zai-org/GLM-5.3-Fast",
      messages=[
          {"role": "user", "content": "What were the major AI announcements this week?"}
      ],
      tools=[
          {"type": "baseten__exa__web_search_exa"},
          {"type": "baseten__exa__web_fetch_exa"},
      ],
      extra_body={"baseten": {"tool_settings": {"max_react_iterations": 5}}},
  )

  print(response.choices[0].message.content)
  ```

  ```javascript JavaScript theme={null}
  import OpenAI from "openai";

  const client = new OpenAI({
    apiKey: "<BASETEN_API_KEY>",
    baseURL: "https://inference.baseten.co/v1",
    defaultHeaders: { "x-baseten-server-tools": "true" },
  });

  const response = await client.chat.completions.create({
    model: "zai-org/GLM-5.3-Fast",
    messages: [
      { role: "user", content: "What were the major AI announcements this week?" },
    ],
    tools: [
      { type: "baseten__exa__web_search_exa" },
      { type: "baseten__exa__web_fetch_exa" },
    ],
    baseten: { tool_settings: { max_react_iterations: 5 } },
  });

  console.log(response.choices[0].message.content);
  ```

Hay tres herramientas de Exa disponibles. Dale al modelo búsqueda y fetch cuando necesite descubrir fuentes y luego leer las páginas que elija.

| Selector                                | Qué obtiene el modelo                                                                                     |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `baseten__exa__web_search_exa`          | [Exa Search](/es/docs/search/quickstart): resultados relevantes con contenido de la página para una consulta |
| `baseten__exa__web_search_advanced_exa` | Búsqueda con filtros de dominio, rastreo de subpáginas y un resumen opcional por resultado                |
| `baseten__exa__web_fetch_exa`           | [Contenido completo de la página](/es/docs/contents/quickstart) para una URL que el modelo ya tiene          |

Los selectores no requieren campos adicionales; el modelo completa los argumentos de la herramienta a partir del esquema de Exa. Usa el prompt de sistema para orientar la política de búsqueda: cuándo buscar, si conviene obtener fuentes primarias y cómo citar. Usa `baseten.tool_settings` para acotar el bucle:

| Configuración                  | Úsala para                                                                                                                                                                                              |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `max_react_iterations`         | Limitar las iteraciones del modelo por solicitud (12 por defecto, rango de 2 a 20). La última iteración se reserva para la respuesta, por lo que `N` permite `N - 1` rondas de llamadas a herramientas. |
| `max_tool_calls_per_iteration` | Limitar las llamadas a herramientas del lado del servidor en una misma iteración (10 por defecto, rango de 1 a 10)                                                                                      |

## Cómo se devuelven los resultados {#how-results-come-back}

La respuesta final llega a través del campo habitual del endpoint. Las llamadas a Exa completadas se registran según el protocolo: bloques `tool_use` y `tool_result` en Messages, elementos `mcp_call` en Responses y `baseten.iterations[].continuation_messages` en Chat Completions. Las solicitudes con streaming reciben cada llamada de búsqueda y su resultado como server-sent events mientras se ejecuta el bucle, de modo que puedes mostrar el progreso antes de que llegue la respuesta. El arreglo `baseten.request.server_tool_calls[]` informa del resultado de cada llamada a Exa en la solicitud.

## Precios {#pricing}

Las llamadas a Exa se facturan a tu cuenta de Baseten a la tarifa de Exa, sin recargo, además de los costos de tokens del modelo: alrededor de $0.007 por búsqueda y $0.001 por cada URL obtenida. Exa informa el cargo de cada llamada en tiempo de ejecución, por lo que las llamadas individuales pueden diferir de estas cifras. Las llamadas a herramientas facturadas aparecen en la configuración del espacio de trabajo de Baseten, en Billing → Usage, agrupadas por proveedor. Consulta la [tabla de precios de Baseten](https://docs.baseten.co/inference/model-apis/web-search#pricing) para ver las tarifas actuales.

Las Hosted Tools están en acceso anticipado en Baseten, con un límite de 25 solicitudes por minuto por organización. Prueba Exa Search en el [playground de Baseten](https://app.baseten.co/model-apis/zai-org/GLM-5.3-Fast/playground) o contacta a Baseten para aumentar el límite en cargas de trabajo de producción.
