[Hermes Agent](https://github.com/NousResearch/hermes-agent) incluye Exa como backend nativo para sus herramientas `web_search` y `web_extract`, invocables por el modelo. Usa Exa para ambas capacidades o combínalo con otro proveedor web de Hermes.

## Conecta tu cuenta de Exa {#connect-your-exa-account}

<Steps>
  <Step title="Obtén una API key de Exa">
    <Card title="Obtén tu API key de Exa" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      Crea una key en el panel. Las cuentas nuevas incluyen créditos gratuitos.
    </Card>
  </Step>

  <Step title="Selecciona Exa en Hermes">
    Ejecuta el asistente de configuración de herramientas:

    ```bash theme={null}
    hermes tools
    ```

    Abre **Web Search &amp; Extract**, elige Exa y selecciona la opción autenticada con API key. Cuando se te solicite, introduce tu API key de Exa. Hermes guarda los secretos en `~/.hermes/.env` y la selección de proveedor en `~/.hermes/config.yaml`.
  </Step>

  <Step title="Prueba el acceso web">
    Inicia Hermes y pídele que haga una búsqueda y luego lea uno de los resultados:

    ```text theme={null}
    Busca en la web las últimas novedades del producto Exa y luego lee el resultado más relevante.
    ```

    Hermes debería llamar a `web_search` y, después, a `web_extract` cuando necesite la página en sí.
  </Step>
</Steps>

## Configurar manualmente {#configure-manually}

Agrega tu key al archivo de entorno de Hermes:

```bash ~/.hermes/.env theme={null}
EXA_API_KEY=your-exa-api-key
```

Luego selecciona Exa para ambas capacidades web:

```yaml ~/.hermes/config.yaml theme={null}
web:
  search_backend: "exa"
  extract_backend: "exa"
```

En su lugar, puedes usar el respaldo compartido:

```yaml ~/.hermes/config.yaml theme={null}
web:
  backend: "exa"
```

La configuración por capacidad tiene prioridad sobre `web.backend`. Esto te permite usar Exa solo para búsqueda o solo para extracción al combinar proveedores.

## Herramientas que obtiene Hermes {#tools-hermes-gets}

| Herramienta   | Comportamiento de Exa                                                                              |
| ------------- | -------------------------------------------------------------------------------------------------- |
| `web_search`  | Busca con Exa y devuelve páginas ordenadas por relevancia con títulos, URLs y fragmentos de texto. |
| `web_extract` | Recupera contenido legible de una o varias URLs mediante Exa Contents.                             |

Hermes trunca las páginas extraídas extensas según el presupuesto de caracteres configurado y guarda el texto completo en disco. Cambia el valor predeterminado con `web.extract_char_limit` o deja que el agente solicite un `char_limit` mayor para una llamada concreta.

<Note>
  Hermes puede usar Exa a través de su grupo de proveedores gratuitos sin clave, sin necesidad de una API key. Ese grupo tiene límites de tasa y puede rotar entre proveedores. Configura `EXA_API_KEY` y selecciona la opción de Exa autenticada con API key cuando necesites que las solicitudes usen siempre tu cuenta de Exa.
</Note>

## Solución de problemas {#troubleshooting}

<AccordionGroup>
  <Accordion title="Hermes no selecciona Exa">
    Ejecuta `hermes tools` y selecciona Exa explícitamente. Si configuras los archivos manualmente, comprueba que `web.search_backend`, `web.extract_backend` o `web.backend` tenga el valor `exa`.
  </Accordion>

  <Accordion title="Hermes indica que falta EXA_API_KEY">
    Añade la key a `~/.hermes/.env` y luego reinicia Hermes para que recargue el entorno.
  </Accordion>

  <Accordion title="La búsqueda funciona, pero la extracción usa otro proveedor">
    Hermes puede configurar la búsqueda y la extracción de forma independiente. Establece tanto `web.search_backend` como `web.extract_backend` en `exa`.
  </Accordion>
</AccordionGroup>
