<div id="getting-started">
  ## Primeros pasos
</div>

Inicializa el cliente y ejecuta tu primera búsqueda:

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()

  results = exa.search(
      "latest developments in fusion energy",
      type="auto",
      contents={"highlights": True},
  )

  for source in results.results:
      print(source.url, source.highlights)
  ```

  ```javascript JavaScript theme={null}
  import Exa from "exa-js";

  const exa = new Exa();

  const results = await exa.search("latest developments in fusion energy", {
    type: "auto",
    contents: {
      highlights: true,
    },
  });

  for (const source of results.results) {
    console.log(source.url, source.highlights);
  }
  ```
</CodeGroup>

<Note>
  Ambos clientes leen tu key desde la variable de entorno `EXA_API_KEY`. Si prefieres definirla de forma explícita,
  pásala directamente: `Exa(api_key="your-api-key")` o `new Exa("your-api-key")`.
</Note>

<div id="recommended-defaults">
  ## Valores predeterminados recomendados
</div>

| Decisión            | Valor predeterminado recomendado                                                                  |
| ------------------- | ------------------------------------------------------------------------------------------------- |
| Punto de partida    | Usa `search`                                                                                      |
| Tipo de búsqueda    | Mantén `auto` salvo que la latencia o las necesidades de síntesis exijan otro tipo                |
| Contenido de página | Empieza con `highlights: true`                                                                    |
| URL conocidas       | Usa `get_contents` / `getContents`                                                                |
| Frescura            | Define `max_age_hours` / `maxAgeHours` solo cuando el contenido desactualizado resulte inservible |

<Warning>
  Los dos tipos de solicitud aceptan las mismas opciones de contenido, pero en lugares distintos:

  | Método                         | Ubicación de la opción de contenido                                              |
  | ------------------------------ | -------------------------------------------------------------------------------- |
  | `search`                       | Dentro de `contents`, como en `exa.search(query, contents={"highlights": True})` |
  | `get_contents` / `getContents` | Directamente en la solicitud, como en `exa.get_contents(urls, highlights=True)`  |
</Warning>

<div id="search">
  ## Search
</div>

Search encuentra páginas relevantes y devuelve su contenido en una sola llamada.

<Tip>
  Usa `highlights: true` para respuestas de IA, RAG y vistas previas de búsqueda. Exa ajusta los
  extractos de cada resultado según su relevancia; define `max_characters` / `maxCharacters` solo cuando tu aplicación
  requiera un límite fijo.
</Tip>

Filtros, rangos de fechas y cantidad de resultados:

<CodeGroup>
  ```python Python theme={null}
  results = exa.search(
      "climate tech news",
      num_results=20,
      start_published_date="2024-01-01",
      include_domains=["techcrunch.com", "wired.com"],
      contents={"highlights": True}
  )
  ```

  ```javascript JavaScript theme={null}
  const result = await exa.search("interesting articles about space", {
    numResults: 10,
    includeDomains: ["nasa.gov", "space.com"],
    startPublishedDate: "2024-01-01",
    contents: {
      highlights: true,
    },
  });
  ```
</CodeGroup>

<div id="output-schema">
  ### Esquema de salida
</div>

<CodeGroup>
  ```python Python theme={null}
  structured_results = exa.search(
      "Who is the CEO of OpenAI?",
      type="deep",
      system_prompt="Prefer official sources and avoid duplicate results",
      output_schema={
          "type": "object",
          "properties": {
              "leader": {"type": "string"},
              "title": {"type": "string"},
              "source_count": {"type": "number"}
          },
          "required": ["leader", "title"]
      },
      contents={"highlights": True}
  )

  print(structured_results.output.content if structured_results.output else None)
  ```

  ```javascript JavaScript theme={null}
  const structuredResult = await exa.search("Who is the CEO of OpenAI?", {
    type: "deep",
    systemPrompt: "Prefer official sources and avoid duplicate results",
    outputSchema: {
      type: "object",
      properties: {
        leader: { type: "string" },
        title: { type: "string" },
        sourceCount: { type: "number" },
      },
      required: ["leader", "title"],
    },
    contents: {
      highlights: true,
    },
  });

  console.log(structuredResult.output?.content);
  ```
</CodeGroup>

<Note>
  `output_schema` / `outputSchema` funciona con cualquier tipo de búsqueda y devuelve el valor sintetizado
  en `output.content`. Usa `system_prompt` / `systemPrompt` para indicar preferencias de fuentes o énfasis.
  El grounding se devuelve automáticamente en `output.grounding`, así que no dupliques las citas ni la
  confianza en tu esquema.
</Note>

Los modos deep son recomendables cuando el output requiere investigación en varias búsquedas. Usa `deep-lite` para una investigación ligera o `deep` para búsquedas de varios pasos y una síntesis más sólida. Consulta la [guía de Search](/es/docs/search/quickstart) para ver todas las opciones de la solicitud.

<div id="contents">
  ## Contents
</div>

Extrae highlights, texto completo o resúmenes de URLs que ya conoces. Empieza con highlights y
añade una consulta para enfocarlos en la información que necesitas.

<CodeGroup>
  ```python Python theme={null}
  results = exa.get_contents(
      ["https://exa.ai/blog/dynamic-highlights"],
      highlights={"query": "token efficiency and result quality"},
  )
  ```

  ```javascript JavaScript theme={null}
  const results = await exa.getContents(["https://exa.ai/blog/dynamic-highlights"], {
    highlights: {
      query: "token efficiency and result quality",
    },
  });
  ```
</CodeGroup>

Usa el texto completo cuando necesites más contexto o la estructura del documento. Consulta la [guía de Contents](/es/docs/contents/quickstart) para conocer los formatos del output, los controles de frescura y el rastreo de subpáginas.

<div id="answer">
  ## Answer
</div>

Obtén respuestas a tus preguntas con citas.

<CodeGroup>
  ```python Python theme={null}
  response = exa.answer("What caused the 2008 financial crisis?")
  print(response.answer)

  for chunk in exa.stream_answer("Explain quantum computing"):
      print(chunk, end="", flush=True)
  ```

  ```javascript JavaScript theme={null}
  const response = await exa.answer("What caused the 2008 financial crisis?");
  console.log(response.answer);

  for await (const chunk of exa.streamAnswer("Explain quantum computing")) {
    if (chunk.content) {
      process.stdout.write(chunk.content);
    }
  }
  ```
</CodeGroup>

<div id="async-and-types">
  ## Asincronía y tipos
</div>

Python expone `AsyncExa` para operaciones asíncronas, y el SDK de JavaScript incluye tipos de TypeScript para
cada método.

<CodeGroup>
  ```python Python theme={null}
  from exa_py import AsyncExa

  exa = AsyncExa()

  results = await exa.search(
      "machine learning startups",
      contents={"highlights": True}
  )
  ```

  ```typescript TypeScript theme={null}
  import Exa from "exa-js";
  import type { SearchResponse, RegularSearchOptions } from "exa-js";
  ```
</CodeGroup>
