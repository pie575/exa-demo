---
title: "Retención de datos cero"
description: "Disponibilidad de la retención de datos cero en los productos de Exa."
---

La retención de datos cero (ZDR) está disponible en los planes Enterprise y se habilita por equipo. Escribe a [sales@exa.ai](mailto:sales@exa.ai) para obtener más detalles.

| Producto | Disponibilidad de ZDR |
| -------- | --------------------- |
| Search   | Disponible            |
| Contents | Disponible            |
| Agent    | Disponible            |
| Answer   | Aún no compatible     |
| Websets  | Aún no compatible     |
