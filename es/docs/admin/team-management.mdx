Exa organiza el uso de la cuenta y el acceso a las funciones de pago mediante «equipos»:

Al crear tu cuenta, se te asigna a un equipo «Personal». Puedes usar el menú desplegable de la parte superior izquierda del panel de Exa que se muestra a continuación para crear un equipo nuevo o cambiar entre los equipos que tengas. Puedes crear tantos equipos como quieras.

<div id="inviting-people-to-your-team">
  ## Invitar personas a tu equipo
</div>

Los administradores del equipo pueden añadir miembros mediante la función Invite en Team settings.

<img src="/docs/images/admin/team-management/dashboard_invite.png" alt="Invitar a un miembro en Team settings" width="2954" height="1916" data-path="images/admin/team-management/dashboard_invite.png" />

Una vez invitado un miembro del equipo, su estado aparecerá como &#39;Pending&#39; en el menú de gestión del equipo.

<img src="/docs/images/admin/team-management/dashboard_invite_pending.png" alt="Miembro del equipo con estado de invitación Pending" width="2954" height="1916" data-path="images/admin/team-management/dashboard_invite_pending.png" />

Recibirá un correo electrónico con la invitación para unirse al equipo.

<img src="/docs/images/admin/team-management/dashboard_invite_email.png" alt="Correo de invitación al equipo" width="1094" height="1082" data-path="images/admin/team-management/dashboard_invite_email.png" />

Cuando la acepte, verás que ambos miembros figuran como &#39;Accepted&#39;. Todos los miembros del equipo comparten los limits de uso y las funciones del plan de su respectivo equipo.

<img src="/docs/images/admin/team-management/dashboard_invite_accepted.png" alt="Lista de miembros del equipo con estado Accepted" width="2954" height="1916" data-path="images/admin/team-management/dashboard_invite_accepted.png" />

<div id="team-management-api">
  ## API de gestión de equipos
</div>

Crea y gestiona API keys de forma programática con la [API de gestión de equipos](/es/docs/reference/team-management/create-api-key).

<Info>
  La API de gestión de equipos se habilita por equipo. Se autentica mediante una API key de cuenta de servicio, que se crea desde la pestaña **Service keys** de la [página de API keys](https://dashboard.exa.ai/api-keys) una vez que la función esté habilitada para tu equipo. Escribe a [support@exa.ai](mailto:support@exa.ai) para solicitar acceso.
</Info>
