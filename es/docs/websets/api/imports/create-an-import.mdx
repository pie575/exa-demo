description: "Crea un nuevo import para cargar tus datos en Websets. Los imports
  se pueden usar para:


  - **Enriquecer**: mejorar tus datos con información adicional mediante nuestro
  motor de enrichment impulsado por IA

  - **Buscar**: consultar tus datos con la búsqueda agéntica de Websets mediante
  filtros en lenguaje natural

  - **Excluir**: evitar que aparezcan resultados duplicados o ya conocidos en
  tus búsquedas


  Una vez creado el import, puedes subir tus datos a la `uploadUrl` devuelta
  hasta `uploadValidUntil` (1 hora por defecto)."
