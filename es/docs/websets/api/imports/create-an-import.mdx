description: "Crea un nuevo import para cargar tus datos en Websets. Los imports
  se pueden usar para:


  - **Enriquecer**: amplía tus datos con información adicional mediante nuestro
  motor de enrichment con IA

  - **Buscar**: consulta tus datos con la search agéntica de Websets mediante
  filtros en lenguaje natural

  - **Excluir**: evita que aparezcan resultados duplicados o ya conocidos en tus
  búsquedas


  Una vez creado el import, puedes cargar tus datos en la `uploadUrl` devuelta
  hasta `uploadValidUntil` (por defecto, 1 hora)."
