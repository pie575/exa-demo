---
title: "Crear un webhook"
openapi: "/es/docs/exa-spec.yaml POST /v0/webhooks"
timestamp: false
description: "Crea un Webhook que envía los eventos seleccionados a tu URL a
  medida que ocurren.


  La respuesta incluye el `secret` de firma que se usa para verificar las
  entregas; solo se devuelve al crearlo."
---

<Warning>
  **No se siguen las redirecciones.** Las entregas de webhook se envían
  directamente a la URL registrada. Si tu endpoint responde con una redirección
  3xx, la entrega se considerará fallida. Registra siempre la URL de destino final.
</Warning>
