Las skills de Exa enseñan a los agentes de programación a buscar, recuperar contenido y crear con las APIs de Exa. Encuéntralas en el repositorio de código abierto [exa-labs/agent-skills](https://github.com/exa-labs/agent-skills).

Cada skill contiene archivos markdown que siguen el estándar abierto [Skills de agente](https://agentskills.io), de modo que los mismos archivos se instalan en cualquier agente compatible.

## Instalación {#install}

Instala todas las skills de Exa a la vez:

```bash theme={null}
npx skills add exa-labs/agent-skills
```

<Card title="Obtén tu API key de Exa" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  Crea una key en el panel. Las cuentas nuevas incluyen créditos gratuitos.
</Card>

<Note>
  Define tu key como `EXA_API_KEY` en el entorno de tu agente.
</Note>

O abre una de las páginas de skills que aparecen abajo y copia su setup prompt en tu agente. El prompt instala esa skill y verifica tu API key sin mostrarla.
