  forma asíncrona."
openapi: "/es/docs/exa-spec.yaml POST /batches"
timestamp: false
---

Cada elemento de `requests` es un `POST` a `/search` o `/agent/runs` con un `customId` único dentro del batch. Ese mismo `customId` se devuelve en el archivo de resultados, de modo que puedas asociar las filas de salida con tus datos de entrada. Consulta la [guía de la API de Batch](/es/docs/batch/quickstart) para ver el flujo de trabajo de principio a fin.
