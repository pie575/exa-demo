  forma asíncrona."

timestamp: false
---

Cada elemento de `requests` es un `POST` a `/search` o `/agent/runs` con un `customId` único dentro del batch. Ese mismo `customId` se devuelve en el archivo de resultados, de modo que puedes asociar las filas del output con tus datos de entrada. Consulta la [guía de la Batch API](/es/docs/batch/quickstart) para ver el flujo de trabajo completo.
