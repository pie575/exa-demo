---
title: "Detener un run"
description: "Detén de forma controlada un Agent run en ejecución y conserva los
  resultados obtenidos hasta ese momento."
openapi: "/es/docs/exa-spec.yaml POST /agent/runs/{id}/stop"
timestamp: false
---

Si el run sigue activo, el agente cierra el trabajo y finaliza el run anticipadamente con los resultados obtenidos hasta ese momento. El run termina con estado `completed` y `stopReason: stopped`. Se te factura el uso acumulado antes de la detención. Si el run ya alcanzó un estado terminal (completed, failed o cancelled), el endpoint devuelve el run existente sin cambios.

Para terminar un run de inmediato sin devolver ningún resultado, usa [cancel](/es/docs/reference/agent-api/cancel-a-run) en su lugar.

<Note>
  Solo se admite en runs con effort `max`. Se debe enviar `Exa-Beta: agent-max-effort-2026-07-27`
  como encabezado de la solicitud. El encabezado acepta una lista de tokens beta separados por comas.
</Note>
