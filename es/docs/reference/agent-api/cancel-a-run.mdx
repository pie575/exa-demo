---
title: "Cancelar un run"
description: "Cancela un run de Agent en cola o en ejecución."
openapi: "/es/docs/exa-spec.yaml POST /agent/runs/{id}/cancel"
timestamp: false
---

Si el run sigue activo, pasa a `cancelled` de inmediato y termina sin devolver ningún resultado. El run finaliza con estado `cancelled` y `stopReason: cancelled`. Se te cobra el uso acumulado antes de la cancelación. Si el run ya alcanzó un estado terminal (completed, failed o cancelled), el endpoint devuelve el run existente sin cambios.
