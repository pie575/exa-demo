title: "Crear un monitor"
description: "Crea un nuevo Monitor para ejecutar búsquedas recurrentes de Exa
  según una programación.


  Los monitores ejecutan automáticamente tu consulta de búsqueda de forma
  recurrente y entregan los resultados al endpoint de tu webhook con
  deduplicación automática:


  - El **filtrado por fecha** solo obtiene contenido posterior al último run


  - La **deduplicación semántica** hace seguimiento de los outputs anteriores
  para mostrar únicamente novedades


  La respuesta incluye un `webhookSecret` que solo se devuelve una vez, en el
  momento de la creación. Guárdalo de forma segura para la verificación de la
  firma del webhook."
