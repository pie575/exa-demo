title: "Acción batch sobre monitors"
description: "Realiza una acción batch sobre los monitors que coincidan con los
  filtros proporcionados.


  Acciones admitidas:

  - **delete**: elimina de forma permanente los monitors coincidentes

  - **pause**: pausa los monitors coincidentes

  - **unpause**: reanuda los monitors coincidentes


  Usa `dry_run: true` (el valor por defecto) para previsualizar qué monitors se
  verían afectados antes de ejecutar la acción. Los resultados se paginan
  mediante el parámetro `limit`; repite el bucle hasta que `has_more` sea
  `false` para procesar todos los monitors coincidentes."
