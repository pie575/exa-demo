<div id="overview">
  ## Descripción general
</div>

El endpoint Get API Key te permite obtener información detallada sobre una API key específica a partir de su identificador único.

<div id="path-parameters">
  ## Parámetros de ruta
</div>

* **id**: El identificador único de la API key que se desea obtener

<div id="response">
  ## Respuesta
</div>

Devuelve información detallada sobre la API key, que incluye:

* **id**: Identificador único
* **name**: Nombre descriptivo
* **rateLimit**: Límite de tasa en solicitudes por minuto (si está definido)
* **teamId**: ID del equipo al que pertenece esta key
* **createdAt**: Fecha de creación de la key
