## Descripción general {#overview}

El endpoint List API Keys devuelve todas las API keys asociadas a tu equipo. Para cada key se incluye el ID, el nombre, el límite de tasa y el timestamp de creación.

## Formato de respuesta {#response-format}

La respuesta incluye un arreglo de objetos de API key con la siguiente información:

* **id**: Identificador único de la API key
* **name**: Nombre legible (si se proporcionó al crearla)
* **rateLimit**: Límite de tasa en solicitudes por minuto (si está configurado)
* **createdAt**: Timestamp en formato ISO 8601 de la creación de la key
