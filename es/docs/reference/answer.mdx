title: "Answer"
description: "Obtén la respuesta de un LLM a una pregunta, fundamentada en
  resultados de Exa Search. `/answer` realiza una búsqueda en Exa y usa un LLM
  para generar:

  1. Una respuesta directa para consultas específicas (p. ej., \"¿Cuál es la
  capital de Francia?\" devolvería \"París\").

  2. Un resumen detallado con citas para consultas abiertas (p. ej., \"¿Cuál es
  la situación de la IA en el sector salud?\" devolvería un resumen con citas a
  fuentes relevantes).


  La respuesta incluye tanto la respuesta generada como las fuentes usadas para
  crearla. El endpoint también admite streaming (con `stream=True`), que
  devuelve los tokens a medida que se generan.


  Como alternativa, puedes usar la [interfaz de chat
  completions](/docs/integrations/openai-sdk#answer) compatible con OpenAI.\n"

<Info>

</Info>
