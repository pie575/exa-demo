[Baselayer](https://baselayer.com) es una plataforma de Know Your Business (KYB) que
verifica entidades de EE. UU. frente a datos oficiales de registro y riesgo.
Identifica una empresa por nombre y dirección y devuelve su perfil completo: directivos,
registrations estatales, estructura de la entidad y estado de verificación.

Adjunta `baselayer` a un run de [Exa Agent](/es/docs/agent/quickstart) mediante
[Exa Connect](/es/docs/agent/connect/overview), y el agente consultará
Baselayer junto con Exa web search.

## Úsalo para {#use-it-for}

* Onboarding KYB y verificación de vendors y clientes.
* Diligencia debida sobre directivos, registrations y estructura de la entidad.
* Cribar empresas para detectar riesgos y coincidencias en watchlists.

## ID del proveedor {#provider-id}

Usa este valor en `dataSources`:

```text theme={null}
baselayer
```

## precio {#pricing}

Baselayer factura por pedido, y la tarifa depende de la operación y sus
parámetros:

| Operación                                                                    | Precio                                      |
| ---------------------------------------------------------------------------- | ------------------------------------------- |
| Search de empresas                                                           | `$1.00 / Search`                            |
| Consulta de empresa / directivos / registrations / consulta inversa de directivo | Gratis (lecturas de una Search previa)    |
| Search de gravámenes                                                         | `$2.00 / state searched`                    |
| Search de litigios                                                           | `$1.00 / category (litigation, bankruptcy)` |
| Verificación de watchlist                                                    | `$0.10 – $0.25 / list requested`            |
| Clasificación industrial                                                     | `$0.35 / call`                              |
| Análisis de sitio web                                                        | `$0.35 / call`                              |
| Presencia web                                                                | `$0.15 – $0.35 / selected analysis`         |
| Search internacional de empresas                                             | `$4.00 / Search`                            |

Los parámetros que elijas modifican el precio: una Search de gravámenes en dos estados cuesta
$4.00, una verificación de watchlist con las seis listas admitidas cuesta $1.35, y una llamada de
presencia web equivale a la suma de los análisis que selecciones (o del conjunto
predeterminado de Baselayer — predicción NAICS y análisis de sitio web — si no seleccionas ninguno).
