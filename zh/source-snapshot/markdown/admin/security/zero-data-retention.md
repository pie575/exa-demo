  # 零数据留存
</div>

> Exa 各产品的零数据留存支持情况。

零数据留存 (ZDR) 仅面向企业版套餐提供，并按团队启用。详情请联系 [sales@exa.ai](mailto:sales@exa.ai)。

| 产品       | ZDR 支持情况 |
| -------- | -------- |
| Search   | 支持       |
| Contents | 支持       |
| Agent    | 支持       |
| Answer   | 暂不支持     |
| Websets  | 暂不支持     |
