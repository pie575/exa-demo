# 开始使用 {#get-started}

> 欢迎使用 Websets 控制台！无论需求多么复杂，都能在网上找到你想要的内容。

<br />

## 1. 注册 {#1-sign-up}

Websets 现已正式上线，访问地址：[https://websets.exa.ai/](https://websets.exa.ai/)！

如果想进一步了解，欢迎[点此预约通话](https://scheduler.default.com/exa/websets-intro/30min)。

<br />

## 2. 开始使用 {#2-get-started}

Websets 用起来非常简单。

<img src="https://mintcdn.com/exa-52/tmzyKnsgpKLGddKC/images/websets/websets-landing.png?fit=max&auto=format&n=tmzyKnsgpKLGddKC&q=85&s=8573cf90a9e9f98c757ac0fa56c8a64d" alt="Websets landing page" width="2870" height="1726" data-path="images/websets/websets-landing.png" />

1. 用日常英语描述你想要的内容，写得再复杂也没关系！

<img src="https://mintcdn.com/exa-52/tmzyKnsgpKLGddKC/images/websets/websets-preview.png?fit=max&auto=format&n=tmzyKnsgpKLGddKC&q=85&s=15c47c556750ad0f1cebfb78b1ea52aa" alt="Webset preview of generated criteria" width="2870" height="1726" data-path="images/websets/websets-preview.png" />

2. 确认 criteria 和数据类别是否符合预期。

3. 确认需要的结果数量，然后启动 search。

<br />

## 3. 深入了解你的 Webset {#3-inside-your-webset}

简而言之，Websets 会完成以下工作：

1. 拆解你的需求

2. 找到可能满足需求的数据

3. 通过 AI agent 并交叉查找多个 source 来验证所有 criteria

4. 根据你向我们的 agent 提供的反馈来调整 search

<Info>
  如果对初始结果不满意，可以在 “Edit criteria” 中或在聊天中进一步优化 criteria。
</Info>

<br />

## 4. 与你的 Webset 交互 {#4-interacting-with-your-webset}

Webset 生成完成后，你就可以与其中的各个部分进行交互了！

点击某个 result，可以查看：

<img src="https://mintcdn.com/exa-52/tmzyKnsgpKLGddKC/images/websets/websets-result.png?fit=max&auto=format&n=tmzyKnsgpKLGddKC&q=85&s=793c040207129ee6c2efc1c8d922d6fe" alt="包含 AI 摘要、已匹配 criteria 和 sources 的 Webset result 详情" width="2870" height="1734" data-path="images/websets/websets-result.png" />

1. AI 生成的 摘要

2. 它被纳入 Webset 所满足的 criteria

3. 支撑该匹配判断的 sources (可在此直接点击查看这些 sources)

你也可以手动删除 result，在导出前整理你的 Webset。

<br />

## 5. 添加更多 result criteria 和自定义列 {#5-add-more-result-criteria-and-custom-columns}

<img src="https://mintcdn.com/exa-52/tmzyKnsgpKLGddKC/images/websets/add-enrichment.png?fit=max&auto=format&n=tmzyKnsgpKLGddKC&q=85&s=5d94338cdb1931e9afced3c196acf075" alt="添加增强列" width="2870" height="1734" data-path="images/websets/add-enrichment.png" />

1. **添加增强：** 你可以创建自定义的增强列，获取任何你想要的信息，比如联系方式 (邮箱和电话号码) 、营收、员工人数、情感分析、论文摘要等等。需要填写：

* 列名 (例如“Revenue”)

* 列的类型 (例如“Number”)

* 供 Websets 查找数据的说明 (例如“查找该公司的年度营收”)

* 或者点击“fill in for me”，由我们的 agent 自动生成说明

<br />

## 6. 分享并导出你的 Webset {#6-share-and-export-your-webset}

1. 点击导出，将 Webset 下载为 CSV 文件。

2. 点击分享，获取 Webset 的链接。

<br />

## 7. 搜索历史 {#7-search-history}

点击左上角的 sidebar 图标，即可在左侧面板中查看包含所有历史 Websets 的完整记录。
