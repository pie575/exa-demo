<div id="exclude-results">
  # 排除结果
</div>

> 排除以往 Websets 或 CSV 文件中的 URL，避免新搜索中出现重复结果。

<br />

<div id="overview">
  ## 概览
</div>

排除结果 (Exclude Results) 功能可确保你在创建新 search 时不会得到重复结果。你可以基于以往的 Websets 或上传的 CSV 文件指定需要排除的 URL，从而专注于发现全新、独特、可与现有数据形成互补的结果。

<br />

<div id="how-it-works">
  ## 工作原理
</div>

<img src="https://mintcdn.com/exa-52/tmzyKnsgpKLGddKC/images/websets/exclude-flow.png?fit=max&auto=format&n=tmzyKnsgpKLGddKC&q=85&s=b28ac0441991bc4543571ffc2a900963" alt="创建 Webset 时的排除结果选项" width="1466" height="857" data-path="images/websets/exclude-flow.png" />

1. 开始创建一个新的 Webset
2. 在侧边栏的 criteria 下方，点击“Exclude”
3. 从已有的 Websets 中选择，或上传包含待排除 URL 的 CSV 文件。可同时选择多个排除来源。
4. 启动 search，结果中将只包含未命中排除项的新结果

可排除的结果数量上限取决于你的套餐。

<br />

<div id="when-to-use-exclusions">
  ## 何时使用排除功能
</div>

* 查找 CRM 中尚未收录的潜在客户
* 用更精细的 criteria 对此前的 search 进行跟进
* 排除你已知的结果
