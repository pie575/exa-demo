`requests` 中的每个项目都是对 `/search` 或 `/agent/runs` 的一次 `POST` 请求，并带有在批次内唯一的 `customId`。结果文件中会返回相同的 `customId`，便于你将输出行对应回输入数据。端到端工作流请参阅 [Batch API 指南](/zh/docs/batch/quickstart)。
