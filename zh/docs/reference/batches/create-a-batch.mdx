`requests` 中的每一项都是发往 `/search` 或 `/agent/runs` 的 `POST` 请求，并带有在该批次内唯一的 `customId`。结果文件中会返回相同的 `customId`，便于你将输出行对应回输入数据。端到端的完整流程请参阅 [Batch API 指南](/zh/docs/batch/quickstart)。
