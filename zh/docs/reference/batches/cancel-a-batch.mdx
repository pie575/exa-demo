---
title: "取消批次"
description: "取消进行中的批次。"
openapi: "/zh/docs/exa-spec.yaml POST /batches/{id}/cancel"
timestamp: false
---

批次会停止调度新的请求，并在处理完进行中的工作后进入 `cancelled` 状态。对已处于 `cancelling` 或 `cancelled` 状态的批次执行取消操作，将原样返回该批次；处于 `completed` 或 `expired` 状态的批次无法取消。
