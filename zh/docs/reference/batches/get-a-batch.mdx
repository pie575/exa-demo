---

使用该端点轮询批次，直到其状态变为 `completed`、`cancelled` 或 `expired`。批次完成后，`resultsUrl` 会包含一个指向 JSONL 结果文件的预签名 URL，该 URL 有效期较短；重新获取该批次即可得到新的 URL。
