title: "对 monitor 执行批量操作"
description: "对符合所提供筛选条件的 monitor 执行批量操作。


  支持的操作：

  - **delete**：永久删除匹配的 monitor

  - **pause**：暂停匹配的 monitor

  - **unpause**：取消暂停匹配的 monitor


  使用 `dry_run: true`（默认值）可在实际执行操作前预览哪些 monitor 会受到影响。结果通过 `limit` 参数分页；可循环调用直到
  `has_more` 为 `false`，以处理所有匹配的 monitor。"
