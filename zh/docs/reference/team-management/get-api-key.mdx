</Info>

<div id="overview">
  ## 概述
</div>

Get API Key 端点用于通过唯一标识符获取特定 API 密钥的详细信息。

<div id="path-parameters">
  ## 路径参数
</div>

* **id**：要获取的 API 密钥的唯一标识符

<div id="response">
  ## 响应
</div>

返回该 API 密钥的详细信息，包括：

* **id**：唯一标识符
* **name**：描述性名称
* **rateLimit**：速率限制，单位为每分钟请求数 (如已设置) 
* **teamId**：该密钥所属的团队 ID
* **createdAt**：密钥的创建时间
