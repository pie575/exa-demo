## 概览 {#overview}

List API Keys 端点会返回与你的团队关联的所有 API 密钥，其中包含每个密钥的 ID、名称、速率限制和创建时间戳。

## 响应格式 {#response-format}

响应中包含一个 API 密钥对象数组，每个对象包含以下信息：

* **id**：API 密钥的唯一标识符
* **name**：易读名称 (如果创建时提供)
* **rateLimit**：速率限制，以每分钟请求数计 (如果已设置)
* **createdAt**：密钥创建时间的 ISO 8601 时间戳
