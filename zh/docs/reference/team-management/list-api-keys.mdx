</Info>

<div id="overview">
  ## 概览
</div>

List API Keys 端点会返回与你的团队关联的所有 API key，包括每个 key 的 key ID、名称、速率限制和创建时间戳。

<div id="response-format">
  ## 响应格式
</div>

响应包含一个 API key 对象数组，每个对象包含以下信息：

* **id**：API key 的唯一标识符
* **name**：易读名称 (如果创建时提供了该名称) 
* **rateLimit**：速率限制，单位为每分钟请求数 (如果已设置) 
* **createdAt**：key 创建时间的 ISO 8601 时间戳
