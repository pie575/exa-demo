## 概述 {#overview}

Update API Key 端点用于修改已有的 API 密钥

## 路径参数 {#path-parameters}

* **id**：要更新的 API 密钥的唯一标识符。

## 可选参数 {#optional-parameters}

* **name**：API 密钥的新描述性名称
* **rateLimit**：新的速率限制，单位为每分钟请求数
