<Info>
  Team Management API 需按团队单独启用。它使用服务账户 API 密钥进行身份验证；该功能为你的团队启用后，可在 [API 密钥页面](https://dashboard.exa.ai/api-keys) 的 **Service keys** 标签页中创建此密钥。如需申请访问权限，请联系 [support@exa.ai](mailto:support@exa.ai)。
</Info>

创建 API 密钥端点可让你使用服务 API 密钥，以编程方式为团队生成新的 API 密钥。

## 可选参数 {#optional-parameters}

* **name**：该 API 密钥的描述性名称，便于识别其用途
* **rateLimit**：该 API 密钥每分钟允许的最大请求数
