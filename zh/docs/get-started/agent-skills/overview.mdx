Exa skills 可以教会编码 agent 如何搜索、获取内容，以及基于 Exa 的 API 进行开发。这些 skills 都在开源仓库 [exa-labs/agent-skills](https://github.com/exa-labs/agent-skills) 中。

每个 skill 都由若干 markdown 文件组成，它们遵循开放的 [Agent Skills](https://agentskills.io) 标准，因此同一套文件可以安装到任何兼容的 agent 中。

<div id="install">
  ## 安装
</div>

一次性安装所有 Exa skill：

```bash theme={null}
npx skills add exa-labs/agent-skills
```

<Card title="获取你的 Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  在控制台创建一个 key。新账户可获赠免费积分。
</Card>

<Note>
  在 agent 运行环境中将 key 设置为 `EXA_API_KEY`。
</Note>

或者打开下方的 skill 页面，把页面上的设置提示词复制到你的 agent 中。该提示词会安装对应 skill，并在不输出 API key 的前提下完成验证。
