使用 Exa MCP，借助 Exa 的搜索能力增强 ChatGPT、Claude 及各类兼容 MCP 的工具中内置的网页搜索，涵盖网页搜索、代码搜索、[Exa Agent](/zh/docs/agent/quickstart) 和 [Exa Connect](/zh/docs/agent/connect/overview)。

Exa 提供了一个托管 server，可在任何 MCP 客户端中使用：

```text theme={null}
https://mcp.exa.ai/mcp
```

无需 API 密钥即可开始使用。Exa MCP 已开源，代码托管在 [GitHub](https://github.com/exa-labs/exa-mcp-server)。

      | OpenCode                                     | `opencode.json` (在 `mcp` 下，并设置 `"type": "remote"`)                                           | `url`       |
      | Kiro                                         | `~/.kiro/settings/mcp.json` (在 `mcpServers` 下)                                               | `url`       |

      | Gemini CLI                                   | `~/.gemini/settings.json` (在 `mcpServers` 下)                                                 | `httpUrl`   |
      | Warp                                         | Settings → MCP Servers → Add MCP Server (顶层 `exa`)                                           | `url`       |
      | v0 by Vercel                                 | Prompt Tools → Add MCP                                                                       | 直接粘贴该 URL   |

      ```json theme={null}
      {
        "mcpServers": {

            "command": "npx",
            "args": ["-y", "mcp-remote", "https://mcp.exa.ai/mcp"]
          }
        }
      }
      ```

      ```json theme={null}
        "mcpServers": {
          "exa": {

            "args": ["-y", "exa-mcp-server"],
      ```

<div id="authentication">
  ## 认证
</div>

Exa MCP 支持三种身份验证模式：

| 模式     | 适用场景                        | 设置方式                                                            |
| ------ | --------------------------- | --------------------------------------------------------------- |
| 无密钥    | 无需登录或 API 密钥的免费限速用量         | 连接到 `https://mcp.exa.ai/mcp`                                    |
| OAuth  | 交互式客户端、插件市场安装、production 用量 | 连接到 `https://mcp.exa.ai/mcp?login`，在浏览器中登录 Exa。用量计入你的 Exa 团队。   |
| API 密钥 | 不支持 MCP OAuth 的客户端          | 连接到 `https://mcp.exa.ai/mcp`，并将 `x-api-key` header 设置为你的 API 密钥 |

<div id="sign-in-with-oauth">
  ### 使用 OAuth 登录
</div>

在 ChatGPT、Claude 以及其他插件市场中安装时，系统会在需要时提示你登录。在任何支持 MCP OAuth 的客户端中，你都可以连接以下地址来发起相同的流程：

```text theme={null}
https://mcp.exa.ai/mcp?login
```

你的客户端会发现 Exa 的授权 server，打开浏览器登录页面，并管理访问权限。

<div id="use-an-api-key">
  ### 使用 API 密钥
</div>

<Card title="获取你的 Exa API 密钥" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  在控制台中创建密钥。新账户会附赠免费积分。
</Card>

```text theme={null}
x-api-key: YOUR_EXA_API_KEY
```

<div id="available-tools">
  ## 可用工具
</div>

| 工具                        | 可用性                  | 适用场景                    |
| ------------------------- | -------------------- | ----------------------- |
| `web_search_exa`          | 默认启用                 | 搜索网页并返回相关的、可直接使用的内容     |
| `web_fetch_exa`           | 默认启用                 | 从一个或多个已知 URL 中读取干净的正文内容 |
| `web_search_advanced_exa` | 选择启用后可用              | 通过高级筛选和控制项配置网页搜索        |
| `agent_run`               | 使用 OAuth 或 API 密钥时可用 | 运行多步骤研究、列表构建、增强和结构化输出   |

使用 `tools` URL 参数来指定客户端可见的工具。例如，启用全部工具：

```text theme={null}
https://mcp.exa.ai/mcp?tools=web_search_exa,web_fetch_exa,web_search_advanced_exa,agent_run
```

<Tip>
  显式指定 `tools` 列表会覆盖默认配置，因此请列出所有希望启用的工具，包括网页搜索和抓取。
</Tip>

<div id="exa-agent">
  ## Exa Agent
</div>

对于需要多次 search 的研究任务,请使用 [Exa Agent](/zh/docs/agent/quickstart),例如构建列表、按 criteria 逐项核对,或返回结构化结果。

Agent 运行按用量计费,因此 `agent_run` 需要 OAuth 或 API 密钥。以下 URL 会启动 OAuth,并在默认 tools 的基础上加入 Agent:

```text theme={null}
https://mcp.exa.ai/mcp?login&tools=web_search_exa,web_fetch_exa,agent_run
```

如果你使用 API 密钥，请省略 `login`，并按照[认证](#authentication)中的说明添加密钥。

<Steps>
  <Step title="描述你的需求">
    用自然语言说明你要做的研究。你的助手会把请求作为 `query` 传给 `agent_run`，Exa Agent 会自行决定搜索什么、阅读来源，并对照请求核查所得内容。

    只有当你的应用需要以统一的 JSON 格式获取结果时，才让 Agent 提供 `outputSchema`。你可以在 system prompt 中给助手一个，也可以让它替你生成。
  </Step>

  <Step title="获取结果">
    研究完成后，这次工具调用会把完整的研究成果交给你的助手：

    * 撰写好的研究结论
    * 支撑这些结论的来源
    * 如果你提供了 `outputSchema`，还包括校验通过的 JSON
    * 用量与费用

    你的助手会基于这些内容撰写回复，因此请告诉它你希望如何处理这些输出。你可以让它总结结论、进行对比、保存到文件，或做任何其他处理。
  </Step>

  <Step title="需要更多时间时继续">
    超出单次 MCP 调用时长的研究不会失败：工具会返回 `status: "running"` 和一个 `id`，运行则在 Exa 上继续进行。你的助手可以把这个 `id` 作为 `runId` 再次调用 `agent_run`，接续同一次运行。
  </Step>
</Steps>

<Accordion title="可选控制项" icon="sliders-horizontal">
  | Field             | 用途                                                     |
  | ----------------- | ------------------------------------------------------ |
  | `systemPrompt`    | 为 Agent 提供额外指引，用于研究或判定结果                               |
  | `outputSchema`    | 以特定的 JSON 格式返回答案                                       |
  | `input.data`      | 丰富你已有的行数据或实体                                           |
  | `input.exclusion` | 跳过你已知的结果                                               |
  | `dataSources`     | 最多添加五个 [Exa Connect](/zh/docs/agent/connect/overview) 提供方 |
  | `previousRunId`   | 在已完成的研究基础上发起新请求                                        |
  | `effort`          | 选择 Agent 研究的深入程度                                       |
</Accordion>

<Tip>
  用 `runId` 继续等待进行中的工作；用 `previousRunId` 基于已完成的工作发起新的追问。
</Tip>

有关 output schema 写法、effort 模式、数据源和定价，请参阅 [Exa Agent 指南](/zh/docs/agent/quickstart)。

<div id="advanced-search">
  ## 高级 search
</div>

当请求需要明确的类别或域名过滤、日期范围、文本约束、地理定向、query 扩展、摘要、highlights、新鲜度控制或子页面抓取时，请使用 `web_search_advanced_exa`。普通 search 则继续使用 `web_search_exa`，它暴露给模型的工具面更小，所需配置也更少。

Advanced Search 无需认证，不过已认证的连接会使用你自己的 plan 和速率限制。可通过以下方式将其与默认 tools 一并启用：

```text theme={null}
https://mcp.exa.ai/mcp?tools=web_search_exa,web_fetch_exa,web_search_advanced_exa
```

MCP 工具将常用的 [Search API](/zh/docs/reference/search) 控制项以适合工具调用的 field 形式暴露出来，例如 `includeDomains`、`startPublishedDate`、`enableHighlights` 和 `maxAgeHours`。确切的 field 名称请查阅你所用客户端中的 tool schema。

<div id="troubleshooting">
  ## 故障排查
</div>

<AccordionGroup>
  <Accordion title="速率限制错误（429）">
    当前连接使用的是 Exa 的免费速率限制。请通过 OAuth 登录或添加你自己的 API 密钥，然后重新连接，使请求走你所在团队的 plan 和限制。

    <Card title="获取你的 Exa API 密钥" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      在控制台中创建密钥。新账户可获得免费积分。
    </Card>
  </Accordion>

  <Accordion title="Agent 缺失或提示需要身份验证">
    `agent_run` 默认未启用，且无法使用免费速率限制。请将其添加到 `tools` URL 参数中，然后使用 `?login` 连接或配置 API 密钥。完整 URL 参见 [Exa Agent](#exa-agent)。
  </Accordion>

  <Accordion title="OAuth 登录页面无法打开">
    请确认你的客户端支持 MCP OAuth，并连接到 `https://mcp.exa.ai/mcp?login`。修改 URL 后重启客户端。如果客户端无法完成 MCP OAuth，请改用 API 密钥。
  </Accordion>

  <Accordion title="工具未显示">
    显式指定 `tools` 参数会替换默认的工具列表。请检查 URL 中是否包含你需要的每个工具，然后重启 MCP 客户端，使其重新获取工具列表。
  </Accordion>

  <Accordion title="Claude desktop 无法连接">
    使用内置连接器：选择 **+** (或 **Add connectors**) → **Connectors** 标签页 → 搜索 **Exa** → 选择 **+**。
  </Accordion>

  <Accordion title="找不到配置文件">
    常见配置文件位置：

    * Cursor：`~/.cursor/mcp.json`
    * fx：`~/.fx/mcp.json`
    * VS Code：`.vscode/mcp.json` (位于项目根目录)
    * Claude desktop (macOS) ：`~/Library/Application Support/Claude/claude_desktop_config.json`
    * Claude desktop (Windows) ：`%APPDATA%\Claude\claude_desktop_config.json`
  </Accordion>
</AccordionGroup>
