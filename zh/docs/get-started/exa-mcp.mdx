借助 Exa MCP，用 Exa 的搜索能力增强 ChatGPT、Claude 及各类兼容 MCP 的工具中内置的网页搜索，涵盖网页搜索、代码搜索、[Exa Agent](/zh/docs/agent/quickstart) 和 [Exa Connect](/zh/docs/agent/connect/overview)。

Exa 提供了一个托管服务器，可在任意 MCP 客户端中使用：

```text theme={null}
https://mcp.exa.ai/mcp
```

无需 API key 即可开始使用。Exa MCP 已开源，代码托管在 [GitHub](https://github.com/exa-labs/exa-mcp-server) 上。

      | Gemini CLI                                   | `~/.gemini/settings.json` (在 `mcpServers` 下)                                                 | `httpUrl`   |
      | Warp                                         | Settings → MCP Servers → Add MCP Server (顶层 `exa`)                                           | `url`       |
      | v0 by Vercel                                 | Prompt Tools → Add MCP                                                                       | 直接粘贴 URL    |

      ```json theme={null}

            "command": "npx",
            "args": ["-y", "mcp-remote", "https://mcp.exa.ai/mcp"]
      ```

<div id="authentication">
  ## 身份验证
</div>

Exa MCP 支持三种身份验证模式：

| 模式      | 适用场景                          | 设置方式                                                             |
| ------- | ----------------------------- | ---------------------------------------------------------------- |
| 免密钥     | 无需登录或 API key 即可免费使用 (有速率限制)  | 连接到 `https://mcp.exa.ai/mcp`                                     |
| OAuth   | 交互式客户端、应用市场安装、生产环境使用          | 连接到 `https://mcp.exa.ai/mcp?login`，在浏览器中登录 Exa。用量计入你的 Exa 团队。    |
| API key | 不支持 MCP OAuth 的客户端            | 连接到 `https://mcp.exa.ai/mcp`，并将 `x-api-key` header 设置为你的 API key |

<div id="sign-in-with-oauth">
  ### 使用 OAuth 登录
</div>

ChatGPT、Claude 以及其他通过应用市场安装的客户端会在需要时提示你登录。在任何支持 MCP OAuth 的客户端中，你都可以连接以下地址来发起相同的流程：

```text theme={null}
https://mcp.exa.ai/mcp?login
```

你的客户端会自动发现 Exa 的授权服务器，打开浏览器登录页面，并管理访问权限。

<div id="use-an-api-key">
  ### 使用 API key
</div>

<Card title="获取你的 Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  在控制台中创建一个 key。新账户可获赠免费额度。

```text theme={null}
x-api-key: YOUR_EXA_API_KEY
```

<div id="available-tools">
  ## 可用工具
</div>

| 工具                        | 可用性                    | 用途                             |
| ------------------------- | ---------------------- | ------------------------------ |
| `web_search_exa`          | 默认启用                   | 搜索网页并返回相关且可直接使用的内容             |
| `web_fetch_exa`           | 默认启用                   | 从一个或多个已知 URL 读取整洁的正文内容         |
| `web_search_advanced_exa` | 选择启用后可用                | 使用高级筛选条件和控制项配置网页搜索             |
| `agent_run`               | 使用 OAuth 或 API key 时可用 | 运行多步骤研究、列表构建、Enrichment 及结构化输出 |

使用 `tools` URL 参数来选择客户端可见的工具。例如，启用全部工具：

```text theme={null}
https://mcp.exa.ai/mcp?tools=web_search_exa,web_fetch_exa,web_search_advanced_exa,agent_run
```

<Tip>
  显式指定 `tools` 列表会覆盖默认配置，因此需要列出所有希望启用的工具，包括网页搜索 (web search) 和抓取 (fetch) 。
</Tip>

<div id="exa-agent">
  ## Exa Agent
</div>

对于一次 search 无法完成的研究任务，请使用 [Exa Agent](/zh/docs/agent/quickstart)——例如构建列表、按 criteria 逐一核对每个项目，或返回结构化结果。

Agent 运行按用量计费，因此 `agent_run` 需要 OAuth 或 API key。以下 URL 会启动 OAuth，并在默认工具之外添加 Agent：

```text theme={null}
https://mcp.exa.ai/mcp?login&tools=web_search_exa,web_fetch_exa,agent_run
```

如果你使用 API key，请省略 `login`，并按照[身份验证](#authentication)中的说明添加该 key。

<Steps>
  <Step title="描述你的需求">
    用自然语言提出研究请求。你的助手会带上 `query` 调用 `agent_run`，Exa Agent 会自行判断该 search 什么、阅读来源，并对照请求核查所得结果。

    只有当你的应用需要以统一的 JSON 格式获取结果时，才让 Agent 使用 `outputSchema`。你可以在系统提示中把它提供给助手，也可以让助手为你生成一个。
  </Step>

  <Step title="获取结果">
    研究完成后，工具调用会把完整的研究成果交给你的助手：

    * 书面结论
    * 支撑这些结论的来源
    * 若你提供了 `outputSchema`，则包含经过校验的 JSON
    * 用量与费用

    你的助手会基于这份成果撰写回复，因此请告诉它你希望如何处理这些输出。你可以让它总结结论、进行对比、保存到文件，或是做任何其他事情。
  </Step>

  <Step title="需要更多时间时继续">
    超出单次 MCP 调用时长的研究不会失败：工具会返回 `status: "running"` 和一个 `id`，运行则继续在 Exa 上进行。你的助手只需把该 `id` 作为 `runId` 再次调用 `agent_run`，即可接着跟进同一次运行。
  </Step>
</Steps>

<Accordion title="可选控制项" icon="sliders-horizontal">
  | 字段                | 用途                                                     |
  | ----------------- | ------------------------------------------------------ |
  | `systemPrompt`    | 为 Agent 提供研究或判定结果的额外指引                                 |
  | `outputSchema`    | 以特定的 JSON 格式返回答案                                       |
  | `input.data`      | 丰富你已有的行数据或实体                                           |
  | `input.exclusion` | 跳过你已知晓的结果                                              |
  | `dataSources`     | 最多添加五个 [Exa Connect](/zh/docs/agent/connect/overview) 提供方 |
  | `previousRunId`   | 在已完成的研究之上发起新请求                                         |
  | `effort`          | 决定 Agent 投入多少研究量                                       |
</Accordion>

<Tip>
  使用 `runId` 继续等待进行中的任务；使用 `previousRunId` 基于已完成的任务提出新的后续请求。
</Tip>

关于输出 schema 写法、effort 模式、数据源和定价，请参阅 [Exa Agent 指南](/zh/docs/agent/quickstart)。

<div id="advanced-search">
  ## 高级搜索
</div>

当请求需要明确的类别或域名过滤、日期范围、文本约束、地理定向、查询扩展、摘要、highlights、时效性控制或子页面抓取时，请使用 `web_search_advanced_exa`。普通搜索则继续使用 `web_search_exa`，它暴露给模型的工具面更小，所需配置也更少。

Advanced Search 无需身份验证，不过已认证的连接会占用你自己的套餐额度和速率限制。可通过以下方式将其与默认工具一同启用：

```text theme={null}
https://mcp.exa.ai/mcp?tools=web_search_exa,web_fetch_exa,web_search_advanced_exa
```

MCP 工具将常用的 [Search API](/zh/docs/reference/search) 参数以便于工具调用的字段形式暴露出来，例如 `includeDomains`、`startPublishedDate`、`enableHighlights` 和 `maxAgeHours`。确切的字段名称请查阅客户端中的工具 schema。

<div id="troubleshooting">
  ## 故障排查
</div>

<AccordionGroup>
  <Accordion title="速率限制错误（429）">
    当前连接使用的是 Exa 的免费速率限制。请通过 OAuth 登录或添加你自己的 API key，然后重新连接，使请求按你所在团队的套餐和限制计算。

    <Card title="获取你的 Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      在控制台中创建一个 key。新账户可获得免费额度。
    </Card>
  </Accordion>

  <Accordion title="Agent 缺失或提示需要身份验证">
    `agent_run` 默认未启用，且无法使用免费速率限制。请将其添加到 `tools` URL 参数中，然后使用 `?login` 连接或配置 API key。完整 URL 请参见 [Exa Agent](#exa-agent)。
  </Accordion>

  <Accordion title="OAuth 登录页面无法打开">
    请确认你的客户端支持 MCP OAuth，并连接到 `https://mcp.exa.ai/mcp?login`。修改 URL 后请重启客户端。如果客户端无法完成 MCP OAuth，请改用 API key。
  </Accordion>

  <Accordion title="工具未显示">
    显式指定 `tools` 参数会覆盖默认工具列表。请检查 URL 中是否包含你需要的每个工具，然后重启 MCP 客户端以重新获取工具列表。
  </Accordion>

  <Accordion title="Claude desktop 无法连接">
    使用内置连接器：选择 **+** (或 **Add connectors**) → **Connectors** 标签页 → 搜索 **Exa** → 选择 **+**。
  </Accordion>

  <Accordion title="找不到配置文件">
    常见配置文件位置：

    * Cursor：`~/.cursor/mcp.json`
    * fx：`~/.fx/mcp.json`
    * VS Code：`.vscode/mcp.json` (位于项目根目录)
    * Claude desktop (macOS) ：`~/Library/Application Support/Claude/claude_desktop_config.json`
    * Claude desktop (Windows) ：`%APPDATA%\Claude\claude_desktop_config.json`
  </Accordion>
</AccordionGroup>
