<div id="production-checklist">
  ## 生产环境检查清单
</div>

* 为 Agent 提供明确的 `query`，写清任务单元以及期望的来源质量。
* 对于已知记录，使用 `input.data`，不要把数据行直接写进提示词。
* 对于不应再次返回的记录，使用 `input.exclusion`。
* 只要下游代码要消费结果，就加上 `outputSchema`。
* 需要可预期的范围和成本时，为数组设置 `maxItems`。
* 保存返回的运行 `id`，以便后续轮询、重放事件、查看成本或从该次运行继续。
