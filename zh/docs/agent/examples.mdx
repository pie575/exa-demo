<div id="production-checklist">
  ## Production 检查清单
</div>

* 为 agent 提供明确的 `query`，写清工作单元以及期望的来源质量。
* 已知记录请用 `input.data` 传入，不要把数据行直接写进 prompt。
* 不希望再次返回的记录，用 `input.exclusion` 排除。
* 只要下游代码要消费结果，就加上 `outputSchema`。
* 需要可预测的范围和费用时，在数组上设置 `maxItems`。
* 保存返回的运行 `id`，以便后续轮询、重放事件、查看费用，或从该次运行继续。
