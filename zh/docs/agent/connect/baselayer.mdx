[Baselayer](https://baselayer.com) 是一个“了解你的企业” (KYB) 平台，可依据权威注册与风险数据验证美国实体。它能根据名称和地址匹配企业，并返回完整档案：高管、各州注册信息、实体结构以及验证状态。

通过 [Exa Connect](/zh/docs/agent/connect/overview) 将 `baselayer` 接入 [Exa Agent](/zh/docs/agent/quickstart) 运行，agent 便会在进行 Exa 网页搜索的同时查询 Baselayer。

<div id="use-it-for">
  ## 适用场景
</div>

* KYB 客户准入以及供应商/客户验证。
* 对企业高管、注册信息和实体结构开展尽职调查。
* 企业风险筛查与监控名单命中检测。

<div id="provider-id">
  ## Provider ID
</div>

在 `dataSources` 中使用此值：

```text theme={null}
baselayer
```

<div id="pricing">
  ## 定价
</div>

Baselayer 按订单计费，费率取决于操作及其参数：

| 操作                        | 价格                                          |
| ------------------------- | ------------------------------------------- |
| 企业搜索                      | `$1.00 / search`                            |
| 企业详情 / 高管 / 注册信息 / 高管反向查询 | 免费 (读取此前搜索的结果)                              |
| 留置权搜索                     | `$2.00 / state searched`                    |
| 诉讼搜索                      | `$1.00 / category (litigation, bankruptcy)` |
| 监控名单筛查                    | `$0.10 – $0.25 / list requested`            |
| 行业分类                      | `$0.35 / call`                              |
| 网站分析                      | `$0.35 / call`                              |
| 网络足迹                      | `$0.15 – $0.35 / selected analysis`         |
| 国际企业搜索                    | `$4.00 / search`                            |

参数的选择会影响价格：覆盖两个州的留置权搜索费用为 $4.00，筛查全部六个受支持名单的监控名单筛查费用为 $1.35，网络足迹调用的费用则为所选各项分析的总和 (若未选择任何项，则按 Baselayer 的默认组合计费，即 NAICS 预测与网站分析) 。

          "properties": {

                  "type": "object",

                      "officers": {
                          "type": "array",
                          "items": {
                              "type": "object",

                                  "title": {"type": "string"},
                              },
                          },

                  },
              }
          },
      },
