[Financial Datasets](https://financialdatasets.ai) 为 AI agents 提供可直接供机器使用的
公司与市场数据。通过
[Exa Connect](/zh/docs/agent/connect/overview)，agent 可以获取
实时与历史价格、公司概况、财务报表 与
估值指标、财报、内部人士与机构持股、SEC 备案文件
及申报文件章节、公司新闻，并按 基本面指标
筛选美国市场。

将 `financial_datasets` 接入 [Exa Agent](/zh/docs/agent/quickstart) 运行，
agent 便会在进行 Exa 网页搜索的同时查询 Financial Datasets。

## 适用场景 {#use-it-for}

* 构建结构化的公司研究快照。
* 分析财务表现、估值与历史趋势。
* 阅读 SEC 备案文件，提取风险因素、MD&amp;A 等章节。
* 查看内部人士交易与机构持股情况。
* 按基本面指标筛选美国市场标的。
* 监控公司新闻与相关动态。

## 可用数据 {#data-available}

以下各数据集均在 `financial_datasets` 提供方下提供；agent 会自动选择适合当前任务的数据集：

| 数据集        | 返回内容                                                         |
| ---------- | ------------------------------------------------------------ |
| 实益所有权      | 来自 Schedule 13D/13G 的 5% 以上实益所有人，包括主动型和被动型持股。                |
| 公司概况       | 名称、板块、行业、交易所、所在地、SEC CIK、SIC 分类。                             |
| 公司新闻       | 某一股票代码的近期新闻文章。                                               |
| 财报         | 季度营收与每股收益，含同比变化及超预期/不及预期情况。                                  |
| 财务指标       | 市值、企业价值、市盈率、市净率、市销率、EV/EBITDA、PEG、利润率、ROE/ROA/ROIC、增长率、每股收益。 |
| 财务报表       | 来自 SEC 备案文件的利润表、资产负债表和现金流量表。                                 |
| 历史股价       | 指定日期区间内按日/周/月/年粒度的 OHLCV K 线数据。                              |
| 指数基金持仓     | 按权重列出的 ETF/指数基金成分股，或持有某一证券的基金。                               |
| 内部人士持股     | 来自 SEC 表格 3 和 5 的内部人士持股 (高管、董事、10% 股东持有的股份) 。                |
| 内部人士交易     | SEC 表格 4 内部人士交易 (姓名、角色、类型、股数、金额) 。                           |
| 机构持股       | 13F 机构持有人、持股数量及申报价值。                                         |
| 利率         | 当前及历史央行政策利率 (美联储、欧洲央行、日本央行等) 。                               |
| SEC 备案文件条目 | 特定 10-K/10-Q/8-K 条目的提取文本 (例如风险因素、MD&amp;A) 。                 |
| SEC 备案文件   | 备案元数据及 EDGAR 直达链接，可按表格类型筛选。                                  |
| 分部财务数据     | 按产品、业务分部和地域细分的营收、营业利润及其他报表项目。                                |
| 股价快照       | 当前实时价格、当日涨跌及报价时间。                                            |
| 股票筛选器      | 符合基本面筛选 criteria 的公司。                                        |

## 提供方 ID {#provider-id}

在 `dataSources` 中使用该值：

```text theme={null}
financial_datasets
```
