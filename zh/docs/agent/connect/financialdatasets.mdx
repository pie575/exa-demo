[Financial Datasets](https://financialdatasets.ai) 为 AI agent 提供机器可直接使用的
公司与市场数据。通过
[Exa Connect](/zh/docs/agent/connect/overview)，agent 可以获取
实时与历史价格、公司概况、财务报表与
估值指标、财报、内部人士与机构持股、SEC 文件
及其章节、公司新闻，还能按基本面指标
筛选美国市场。

在 [Exa Agent](/zh/docs/agent/quickstart) 运行中接入 `financial_datasets`，
agent 便会在 Exa 网页搜索之外同时查询 Financial Datasets。

<div id="use-it-for">
  ## 适用场景
</div>

* 构建结构化的公司研究快照。
* 分析财务表现、估值与历史趋势。
* 阅读 SEC 文件，提取风险因素、MD&amp;A 等章节内容。
* 查看内部人士交易与机构持股情况。
* 按基本面指标筛选美股市场。
* 监测公司新闻与相关动态。

<div id="data-available">
  ## 可用数据
</div>

以下每个数据集都可通过 `financial_datasets` provider 使用；agent 会自行选择最适合当前任务的数据集：

| 数据集      | 返回内容                                                         |
| -------- | ------------------------------------------------------------ |
| 受益所有权    | 来自 Schedule 13D/13G 的 5% 以上受益所有人，包括主动型和被动型持股。                |
| 公司概况     | 名称、板块、行业、交易所、所在地、SEC CIK、SIC 分类。                             |
| 公司新闻     | 某一股票代码的近期新闻文章。                                               |
| 财报       | 季度营收与每股收益，含同比变化及超预期/不及预期情况。                                  |
| 财务指标     | 市值、企业价值、市盈率、市净率、市销率、EV/EBITDA、PEG、利润率、ROE/ROA/ROIC、增长率、每股收益。 |
| 财务报表     | 来自 SEC 申报文件的利润表、资产负债表和现金流量表。                                 |
| 历史股价     | 指定日期区间内的 OHLCV K 线数据，支持日/周/月/年粒度。                            |
| 指数基金持仓   | 按权重列出的 ETF/指数基金成分股，或持有某一证券的基金。                               |
| 内部人士持股    | 来自 SEC Form 3 和 Form 5 的内部人士持股 (高管、董事、10% 股东所持股份) 。           |
| 内部人士交易    | SEC Form 4 内部人士交易 (姓名、职务、类型、股数、金额) 。                          |
| 机构持股     | 13F 机构持有人、持股数及申报价值。                                          |
| 利率       | 当前及历史的央行政策利率 (美联储、欧洲央行、日本央行等) 。                              |
| SEC 申报条目 | 特定 10-K/10-Q/8-K 条目的提取文本 (如风险因素、MD&amp;A) 。                  |
| SEC 文件 | 申报元数据和 EDGAR 直达链接，可按表格类型筛选。                                  |
| 分部财务数据   | 按产品、业务分部和地区拆分的营收、营业利润及其他项目。                                  |
| 股价快照     | 当前实时价格、当日涨跌及报价时间。                                            |
| 选股器      | 符合基本面筛选条件的公司。                                                |

<div id="provider-id">
  ## Provider ID
</div>

在 `dataSources` 中使用此值：

```text theme={null}
financial_datasets
```
