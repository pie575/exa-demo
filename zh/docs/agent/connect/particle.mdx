[Particle](https://particle.news) 的 Podcast Intelligence 索引了 100,000 多档节目，
并在节目播出后数分钟内完成全量转写、说话人分离与识别、打标签，以及元数据丰富，
让口语对话变得可搜索。每条结果都是一段带时间戳、标注说话人归属的会议记录片段。

通过 [Exa Connect](/zh/docs/agent/connect/overview) 将 `particle` 接入
[Exa Agent](/zh/docs/agent/quickstart) 运行，agent 便会在进行 Exa 网页搜索的同时查询 Particle。

<div id="use-it-for">
  ## 适用场景
</div>

* 寻找专家评论和可引用的精彩观点。
* 媒体与品牌监测。
* 叙事与情感倾向研究。
* 发现播客并及时追踪最新内容。

<div id="provider-id">
  ## 提供方 ID
</div>

在 `dataSources` 中使用此值：

```text theme={null}
particle
```

<div id="example">
  ## 示例
</div>

了解播客主持人对 AI 监管的看法。

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="What are prominent podcast hosts and guests saying about AI regulation in 2025?",
      data_sources=[{"provider": "particle"}],
      output_schema={
          "type": "object",
          "required": ["mentions"],
          "properties": {
              "mentions": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["podcast", "episode", "speaker", "quote", "stance"],
                      "properties": {
                          "podcast": {"type": "string"},
                          "episode": {"type": "string"},
                          "speaker": {"type": "string"},
                          "quote": {"type": "string"},
                          "stance": {"type": "string", "description": "pro-regulation, anti-regulation, or nuanced"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

