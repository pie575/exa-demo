---

[Particle](https://particle.news) 的 Podcast Intelligence 收录了 10 万多档节目，
并在节目播出后数分钟内完成全文转录、说话人分离与识别、内容标注及元数据补充，
让口头对话也能被检索。每条结果都是一段带时间戳、标注说话人的转录内容。

通过 [Exa Connect](/zh/docs/agent/connect/overview) 在 [Exa Agent](/zh/docs/agent/quickstart) 运行中附加
`particle`，Agent 就会在进行 Exa 网页搜索的同时查询 Particle。

<div id="use-it-for">
  ## 适用场景
</div>

* 查找专家评论和可引用的精彩言论。
* 媒体与品牌监测。
* 叙事与舆情研究。
* 发现播客并及时掌握最新内容。

<div id="provider-id">
  ## Provider ID
</div>

在 `dataSources` 中使用此值：

```text theme={null}
particle
```

<div id="example">
  ## 示例
</div>

查找播客主持人对 AI 监管的相关讨论。

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="What are prominent podcast hosts and guests saying about AI regulation in 2025?",
      data_sources=[{"provider": "particle"}],
      output_schema={
          "type": "object",
          "required": ["mentions"],
          "properties": {
              "mentions": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["podcast", "episode", "speaker", "quote", "stance"],
                      "properties": {
                          "podcast": {"type": "string"},
                          "episode": {"type": "string"},
                          "speaker": {"type": "string"},
                          "quote": {"type": "string"},
                          "stance": {"type": "string", "description": "pro-regulation, anti-regulation, or nuanced"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```
