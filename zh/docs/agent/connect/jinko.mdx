[Jinko](https://gojinko.com) 是一个旅行搜索平台，提供实时定价的航班和酒店搜索。你可以按航线和日期搜索实时航班报价，查询目的地或指定酒店的房型与费率，并探索从你的出发机场可抵达的目的地。

通过 [Exa Connect](/zh/docs/agent/connect/overview) 将 `jinko` 附加到 [Exa Agent](/zh/docs/agent/quickstart) 运行，agent 就会在 Exa 网页搜索的同时查询 Jinko。

## 适用场景 {#use-it-for}

* 搜索指定航线和日期的实时航班报价，包含票价、行李额和改签政策。
* 查找某个目的地带实时费率的酒店，或对特定酒店重新比价。
* 跨日期区间、舱位等级和预算范围，探索目的地与灵活日期方案。

## 提供方 ID {#provider-id}

在 `dataSources` 中使用此值：

```text theme={null}
jinko
```

## 示例 {#example}

查找 3 月份可从纽约抵达、往返票价低于 $400 的海滩目的地。

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="Find beach destinations reachable from New York for under $400 round-trip in March.",
      data_sources=[{"provider": "jinko"}],
      output_schema={
          "type": "object",
          "required": ["destinations"],
          "properties": {
              "destinations": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["city", "iataCode", "lowestFare"],
                      "properties": {
                          "city": {"type": "string"},
                          "iataCode": {"type": "string"},
                          "lowestFare": {"type": "number", "description": "round-trip fare in USD"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

