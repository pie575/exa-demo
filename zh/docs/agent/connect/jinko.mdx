[Jinko](https://gojinko.com) 是一个旅行搜索平台，提供带实时报价的航班与酒店搜索。你可以按航线和日期搜索实时航班报价，查询某个目的地或指定酒店的房型与价格，并探索从出发机场可直达的目的地。

通过 [Exa Connect](/zh/docs/agent/connect/overview) 将 `jinko` 附加到 [Exa Agent](/zh/docs/agent/quickstart) 的运行中，Agent 便会在进行 Exa 网页搜索的同时查询 Jinko。

<div id="use-it-for">
  ## 适用场景
</div>

* 按航线和日期搜索实时航班报价，包含票价、行李额和改签政策。
* 查找指定目的地的酒店及其实时房价，或对特定酒店重新比价。
* 在不同日期区间、舱位等级和预算范围内发掘目的地与灵活出行日期。

<div id="provider-id">
  ## 提供方 ID
</div>

在 `dataSources` 中使用此值：

```text theme={null}
jinko
```

<div id="example">
  ## 示例
</div>

查找三月份可从纽约出发抵达、往返票价低于 $400 的海滩目的地。

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="Find beach destinations reachable from New York for under $400 round-trip in March.",
      data_sources=[{"provider": "jinko"}],
      output_schema={
          "type": "object",
          "required": ["destinations"],
          "properties": {
              "destinations": {
                  "type": "array",
                  "maxItems": 10,
                  "items": {
                      "type": "object",
                      "required": ["city", "iataCode", "lowestFare"],
                      "properties": {
                          "city": {"type": "string"},
                          "iataCode": {"type": "string"},
                          "lowestFare": {"type": "number", "description": "round-trip fare in USD"},
                      },
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

  ```javascript JavaScript theme={null}
  import Exa from "exa-js";

  const exa = new Exa();
  const run = await exa.agent.runs.create({
    query: "Find beach destinations reachable from New York for under $400 round-trip in March.",
    dataSources: [{ provider: "jinko" }],
    outputSchema: {
      type: "object",
      required: ["destinations"],
      properties: {
        destinations: {
          type: "array",
          maxItems: 10,
          items: {
            type: "object",
            required: ["city", "iataCode", "lowestFare"],
            properties: {
              city: { type: "string" },
              iataCode: { type: "string" },
              lowestFare: { type: "number", description: "round-trip fare in USD" },
            },
          },
        },
      },
    },
  });
  ```
