Exa Connect 将优质数据合作伙伴接入 Exa Agent 的 loop。为某次运行接入一个提供方后，Exa Agent 会在进行网页搜索的同时查询该合作伙伴的数据库，再将结果整合为一个有据可依的结构化答案。

初次接触 agent 运行？建议先阅读 [Exa Agent 指南](/zh/docs/agent/quickstart)，再回来接入数据合作伙伴。

<Tip>
  Exa Agent 已经可以搜索完整的[数据索引](/zh/docs/search/data/overview)，即与 Search API 相同的新闻、代码、公司和人物来源。Exa Connect 则在此基础上再叠加优质合作伙伴数据库。
</Tip>

<Tip>
  更习惯使用 MCP？[Exa MCP](/zh/docs/get-started/exa-mcp#exa-agent) 中已提供 Exa Agent 和 [Exa Connect](/zh/docs/agent/connect/overview)。启用 `tools=agent_run`，即可在 Claude、Cursor 等 MCP 客户端中运行多步研究、列表构建、增强和结构化输出。
</Tip>

<div id="why-exa-connect">
  ## 为什么选择 Exa Connect
</div>

* **无需单独集成即可获取优质数据。** 无需签订合同，也无需对接 SDK，即可访问合作伙伴数据。你只需调用一个 Exa API。
* **底层对接由 Exa 负责。** 提供方认证、工具选择、重试和结果排序都由我们来管理。
* **由 Exa Agent 决定使用哪个来源。** 当你的 `outputSchema` 需要
  “来自 Similarweb 的月访问量”或“已验证的高管信息”时，Exa Agent 会调用
  对应的合作伙伴工具，而不是从网页中猜测。
* **一次运行即可同时使用索引与合作伙伴数据。** Connect 构建在 Exa 索引之上。
  Exa Agent 会在各来源最擅长的场景中使用它们，并为结果标注引用。

<div id="how-it-works">
  ## 工作原理
</div>

1. 在 [`POST /agent/runs`](/zh/docs/reference/agent-api/create-a-run) 的 `dataSources` 数组中**附加**一个或多个提供方。
2. Exa Agent 会根据你的 query 和 `outputSchema`，为每一步**选择合适的工具**：合作伙伴数据或 Exa 网页搜索。
3. 合作伙伴结果会与网页研究结果**融合**为结构化输出，并附上来源。

Fiber.ai 按积分计费，而不是按调用计费，因为它自身的收费会随调用内容而变：一次 search 收 2 积分，每返回一条 result 再加 1 积分；公司或人员查询按返回的候选项计费 (因此为消除同名歧义而调高公司查询的 `numResults` 会更贵) ；联系方式揭示则视你请求的是 work email、personal email 还是电话，收取 2 到 5 积分。你按 Fiber 针对每次调用上报的积分数付费；未匹配到结果的调用免费。参见 [Fiber.ai 定价](/zh/docs/agent/connect/fiber#pricing)。

Similarweb 按数据积分计费 (大致为每个指标 × 行 × 月消耗一个积分) ，因此单次调用的价格取决于其 `numResults`/`months`，每次调用 1 到 15 积分。你按 Similarweb 针对每次调用上报的积分数付费；未返回数据的调用免费。参见 [Similarweb 定价](/zh/docs/agent/connect/similarweb#pricing)。

Baselayer 按订单计费，费率取决于具体操作：KYB 企业搜索为 $1.00，UCC 留置权查询按检索的每个州收 $2.00，诉讼/破产案卷查询按每个类别收 $1.00，Watchlist 筛查按请求的每份名单收 $0.10–$0.25，行业分类与网站分析各 $0.35，网络存在分析为所选各项分析之和 (每项 $0.15–$0.35) ，国际企业搜索为 $4.00。对既往企业搜索的后续读取 (企业查询、高管信息、注册登记、高管反向查询) 免费。参见 [Baselayer 定价](/zh/docs/agent/connect/baselayer#pricing)。

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="Profile Anthropic: total funding and estimated monthly web traffic.",
      data_sources=[{"provider": "fiber"}, {"provider": "similarweb"}],
      output_schema={
          "type": "object",
          "required": ["company"],
          "properties": {
              "company": {
                  "type": "object",
                  "required": ["name", "totalFunding", "monthlyVisits"],
                  "properties": {
                      "name": {"type": "string"},
                      "totalFunding": {"type": "string", "description": "from Fiber.ai"},
                      "monthlyVisits": {"type": "number", "description": "from Similarweb"},
                  },
              }
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

<div id="combining-providers">
  ### 组合使用提供方
</div>

任务需要多少合作伙伴，就接入多少。Exa Agent 会在各个合作伙伴最擅长的环节调用它们，并将这些结果与网页搜索结果融合成一个结构化答案：

```json theme={null}
{
  "dataSources": [
    { "provider": "similarweb" },
    { "provider": "fiber" },
    { "provider": "harmonic" }
  ]
}
```

完整的操作演示,包括如何设计 query 和 `outputSchema` 以触发每一个合作伙伴,请参阅 [Combining providers](/zh/docs/agent/connect/combining-providers)。
