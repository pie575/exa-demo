Exa Connect 将优质数据合作伙伴接入 Exa Agent 的运行循环。只需为一次运行接入某个数据提供方，Exa Agent 就会在网页搜索的同时查询该合作伙伴的数据库，并将两者的结果整合为一个有据可依的结构化答案。

初次接触 agent 运行？建议先阅读 [Exa Agent 指南](/zh/docs/agent/quickstart)，再回来接入数据合作伙伴。

<Tip>
  Exa Agent 本身就会检索完整的[数据索引](/zh/docs/search/data/overview)，与 Search API 使用的新闻、代码、公司和人物数据源完全相同。Exa Connect 则在此基础上再叠加优质合作伙伴数据库。
</Tip>

<Tip>
  更习惯用 MCP？[Exa MCP](/zh/docs/get-started/exa-mcp#exa-agent) 中同样提供了 Exa Agent 和 [Exa Connect](/zh/docs/agent/connect/overview)。启用 `tools=agent_run`，即可在 Claude、Cursor 等 MCP 客户端中运行多步研究、列表构建、enrichment 和结构化输出。
</Tip>

<div id="why-exa-connect">
  ## 为什么选择 Exa Connect
</div>

* **无需单独集成即可获取优质数据。** 无需签署合同，也无需接入 SDK，即可访问合作伙伴数据。你只需调用一个 Exa API。
* **繁琐的对接工作交给 Exa。** 我们负责提供方认证、工具选择、重试和结果排序。
* **由 Exa Agent 选择数据源。** 当你的 `outputSchema` 要求
  “来自 Similarweb 的月访问量”或“已核实的高管信息”时，Exa Agent 会调用
  对应的合作伙伴工具，而不是从网页内容中臆测。
* **一次运行兼用索引与合作伙伴数据。** Connect 构建于 Exa 索引之上。
  Exa Agent 会扬各数据源之长，并为结果附上引用来源。

<div id="how-it-works">
  ## 工作原理
</div>

1. 在 [`POST /agent/runs`](/zh/docs/reference/agent-api/create-a-run) 的 `dataSources` 数组中**接入**一个或多个数据提供方。
2. Exa Agent 会根据你的查询和 `outputSchema`，为每一步**选择合适的工具**：合作伙伴数据或 Exa 网页搜索。
3. 合作伙伴数据会与网页研究结果**融合**为结构化输出，并附带来源信息。

| ---------------------------------------------------- | --------------------------------------------- |

| [Baselayer](/zh/docs/agent/connect/baselayer#pricing)   | `$0.10 – $4.00 / order (varies by operation)` |
| [Polymarket](/zh/docs/agent/connect/polymarket#pricing) | `Free`                                        |
| Affiliate.com                                        | `$0.015 / call`                               |
| Particle                                             | `$0.015 / call`                               |
| Financial Datasets                                   | `$0.01 / call`                                |
| Jinko                                                | `$0.005 / call`                               |

Fiber.ai 按额度 (credit) 计费，而非按调用次数计费，因为它自身的收费会随调用内容变化：一次搜索收取 2 个额度，每返回一条结果再加 1 个额度；公司或人员查询按返回的候选项计费 (因此为消除同名歧义而调高公司查询的 `numResults` 会更贵) ；获取联系方式为 2–5 个额度，具体取决于你请求的是工作邮箱、个人邮箱还是电话。系统会按 Fiber 为每次调用上报的额度数向你收费；未匹配到结果的调用免费。参见 [Fiber.ai 定价](/zh/docs/agent/connect/fiber#pricing)。

Similarweb 按数据额度计费 (大致为每个指标 × 每行 × 每月 1 个额度) ，因此单次调用的价格取决于其 `numResults`/`months`——每次调用 1 至 15 个额度。系统会按 Similarweb 为每次调用上报的额度数向你收费；未返回数据的调用免费。参见 [Similarweb 定价](/zh/docs/agent/connect/similarweb#pricing)。

Baselayer 按订单计费，费率取决于具体操作：KYB 企业搜索为 $1.00；UCC 留置权搜索按检索的州计费，每州 $2.00；诉讼/破产案卷搜索每个类别 $1.00；监控名单筛查按请求的名单计费，每份 $0.10–$0.25；行业分类与网站分析各 $0.35；网络足迹分析为所选各项分析的费用之和 (每项 $0.15–$0.35) ；国际企业搜索为 $4.00。对此前企业搜索结果的后续读取 (企业查询、高管、注册信息、高管反向查询) 免费。参见 [Baselayer 定价](/zh/docs/agent/connect/baselayer#pricing)。

  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query="Profile Anthropic: total funding and estimated monthly web traffic.",
      data_sources=[{"provider": "fiber"}, {"provider": "similarweb"}],
      output_schema={
          "type": "object",
          "required": ["company"],
          "properties": {
              "company": {
                  "type": "object",
                  "required": ["name", "totalFunding", "monthlyVisits"],
                  "properties": {
                      "name": {"type": "string"},

                  },
              }
          },
      },
  ```

<div id="combining-providers">
  ### 组合使用多个提供方
</div>

任务需要多少个合作伙伴，就可以接入多少个。Exa Agent 会在各家最擅长的环节调用对应的提供方，并将这些结果与网页搜索结果融合为一份结构化答案：

```json theme={null}
{
  "dataSources": [
    { "provider": "similarweb" },
    { "provider": "fiber" },
    { "provider": "harmonic" }
  ]
}
```

完整教程 (包括如何设计查询和 `outputSchema`，以确保每个合作伙伴都能被触发) 请参阅[组合数据提供方](/zh/docs/agent/connect/combining-providers)。
