[Polymarket](https://polymarket.com) 是一个预测市场平台，其市场价格反映了大众对现实世界事件结果的隐含概率。[Exa Connect](/zh/docs/agent/connect/overview) 提供对 Polymarket 公开市场数据的只读访问。

在 [Exa Agent](/zh/docs/agent/quickstart) 运行中附加 `polymarket`，agent 便会在 Exa 网页搜索之外同时查询 Polymarket。

## 适用场景 {#use-it-for}

* 查找某个主题的预测市场及当前的市场隐含赔率。
* 对比某一结果的隐含概率随时间的变化。
* 查看市场流动性、买卖盘深度以及持仓量最大的账户。
* 查看某位交易者的当前持仓和近期链上活动。

## 提供方 ID {#provider-id}

在 `dataSources` 中使用此值：

```text theme={null}
polymarket
```

## 定价 {#pricing}

Polymarket 的读取 API 无需认证且免费，因此调用 Polymarket 工具不产生任何费用：你只需按标准的 [Agent 运行定价](/zh/docs/agent/quickstart#pricing)付费。

## 可用数据 {#data-available}

| 数据      | 说明                              |
| ------- | ------------------------------- |
| 市场与事件   | 当前的预测市场和事件，含隐含概率价格、成交量和流动性。     |
| 价格历史    | 某一结果的隐含概率随时间的变化情况。              |
| 订单簿     | 某一市场结果的实时买卖盘深度与价差。              |
| 持仓者与交易者 | 某一市场的头部持仓者，以及某位交易者的当前持仓和近期链上活动。 |

## 示例 {#example}

获取美联储降息的市场隐含赔率，以及过去一个月内的变化趋势。

<CodeGroup>
  ```python Python theme={null}
  from exa_py import Exa

  exa = Exa()
  run = exa.agent.runs.create(
      query=(
          "What are the current market-implied odds of a Fed rate cut at the "
          "next FOMC meeting, and how have they moved over the past month?"
      ),
      data_sources=[{"provider": "polymarket"}],
      output_schema={
          "type": "object",
          "required": ["market", "currentProbability", "trend"],
          "properties": {
              "market": {"type": "string", "description": "the market question"},
              "currentProbability": {"type": "number", "description": "between 0 and 1"},
              "trend": {"type": "string", "description": "how the implied probability moved over the past month"},
          },
      },
  )
  run = exa.agent.runs.poll_until_finished(run.id)
  ```

