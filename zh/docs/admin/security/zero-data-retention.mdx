---
title: "零数据保留"
description: "Exa 各产品的零数据保留可用情况。"
---

零数据保留 (ZDR) 仅在 Enterprise plan 中提供，并按团队启用。详情请联系 [sales@exa.ai](mailto:sales@exa.ai)。

| 产品       | ZDR 可用情况 |
| -------- | -------- |
| Search   | 可用       |
| Contents | 可用       |
| Agent    | 可用       |
| Answer   | 暂不支持     |
| Websets  | 暂不支持     |
