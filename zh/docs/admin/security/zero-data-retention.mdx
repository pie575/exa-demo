零数据保留 (ZDR) 仅面向企业版方案提供，并可按团队启用。详情请联系 [sales@exa.ai](mailto:sales@exa.ai)。

| 产品       | ZDR 支持情况 |
| -------- | -------- |
| Search   | 支持       |
| Contents | 支持       |
| Agent    | 支持       |
| Answer   | 暂不支持     |
| Websets  | 暂不支持     |
