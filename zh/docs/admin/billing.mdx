<div id="billing-basics">
  ## 计费基础
</div>

请求会按 [价格](/zh/docs/admin/pricing) 中的费率或你的企业合同费率，从预付额度中扣除。团队所有者可在 [账单面板](https://dashboard.exa.ai/billing) 中充值额度；付款通过 Stripe 处理。

如果团队额度耗尽，请求将返回 `402 Payment Required`。达到所分配预算上限的 API 密钥 同样会返回 `402`。此时请充值额度，或请团队管理员调整该 API 密钥 的预算。参见 [错误码](/zh/docs/admin/error-codes)。

如需按 API 密钥 查看历史用量，请使用 [获取 API 密钥 用量](/zh/docs/reference/team-management/get-api-key-usage)。

<div id="rate-limits">
  ## 速率限制
</div>

速率限制以每秒查询数 (QPS) 衡量，按团队整体计算，涵盖团队的所有 API 密钥。你可以在 [API Keys](https://dashboard.exa.ai/api-keys) 页面为单个 key 设置更低的限制，但该 API 密钥 的流量仍会计入团队限制。

| 端点                                                         | 默认限制                 |
| ---------------------------------------------------------- | -------------------- |
| `/search`、`/answer`、`/chat/completions`                    | 10 QPS               |
| `type` 为 `deep-lite`、`deep` 或 `deep-reasoning` 的 `/search` | 5 QPS                |
| `/contents`                                                | 100 QPS              |
| `/agent/runs`、`/responses`                                 | 5 QPS，且最多 50 个进行中的运行 |
| `/websets/*`                                               | 20 QPS               |

部分端点共享速率限制额度。限制可能会调整，且因套餐而异；Websets 搜索还有基于套餐的并发限制，可通过 [Get Team Info](/zh/docs/websets/api/teams/get-team-info) 查看。

超出限制时，请求会返回 `429 Too Many Requests`。如果响应中包含 `Retry-After` header，请按其指定的时间等待，或使用指数退避重试。参见[错误码](/zh/docs/admin/error-codes)。

<div id="agent-limits">
  ### Agent 限制
</div>

Agent 限制分为两项独立的控制：同时进行的运行数量，以及启动新运行的速率。

* **并发数**：同一时间最多可有 50 个 Agent 运行处于进行中状态。该限制独立于账户的 QPS，提升 QPS 不会改变它。超出限制后再启动运行会返回 `429`，错误码为 `CONCURRENCY_LIMIT_REACHED`；请等待某个运行结束，或联系我们提高并发上限。
* **启动运行**：`POST /agent/runs` 会占用账户的 QPS，且每次启动运行计为两次请求。因此启动速率为 QPS 的一半：默认 10 QPS 的账户每秒可启动 5 个运行，25 QPS 则每秒可启动 12 个。
* **轮询**：用于查询运行状态、事件和运行列表的 `GET` 请求不计入 QPS，也不会阻塞调度，因此轮询运行中的 Agent 与启动新运行的速率互不影响。

<div id="25-qps-on-pay-as-you-go">
  ### 按量付费享 25 QPS
</div>

在任意 30 天周期内充值 $1,000 额度，您团队的速率限制将自动提升至 **25 QPS，有效期 90 天**。该门槛按购买的额度计算，而非消耗的额度；再次达标即可重置 90 天有效期。可在[账单面板](https://dashboard.exa.ai/billing)查看进度。

需要高于 25 QPS？[联系销售](https://exa.ai/contact/sales)。

<div id="auto-recharge">
  ## 自动充值
</div>

当余额降至你设定的阈值时，自动充值会自动购买额度。可在[账单面板](https://dashboard.exa.ai/billing)中进行配置。

| 设置       | 说明                                |
| -------- | --------------------------------- |
| **充值金额** | 每次触发自动充值时购买的额度，范围为 $5 至 $10,000。  |
| **充值阈值** | 触发充值的余额水平。                        |
| **每月上限** | 计费周期内自动充值消费的可选上限。设为 $0 或留空表示不设上限。 |

例如，充值金额为 $100、阈值为 $10、每月上限为 $500 时，余额每降至 $10 就会购买 $100，且该周期内自动购买总额最多为 $500。

如果即将发布产品或有其他高用量的工作负载，请提前充入足够的额度，并将自动充值金额设置得足够高，以免频繁产生小额扣款尝试。

<div id="receipts-and-invoices">
  ## 收据与发票
</div>

Exa 会通过 [billing@exa.ai](mailto:billing@exa.ai) 发送额度购买和自动充值的收据邮件。如有需要，请将该地址加入白名单。完整的发票历史记录可在 [账单面板](https://dashboard.exa.ai/billing) 中查看。

后付费发票结算仅面向企业版方案提供。
