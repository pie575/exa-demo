Exa 通过「团队」来管理账户用量和付费功能的访问权限：

创建账户后，你会自动归入一个「Personal」团队。你可以通过下图所示 Exa 控制台左上角的下拉菜单创建新团队，或在你已有的团队之间切换。团队数量不限，你可以随意创建。

<div id="inviting-people-to-your-team">
  ## 邀请成员加入团队
</div>

团队管理员可以在 团队 settings 中通过 Invite 功能添加成员。

<img src="/docs/images/admin/team-management/dashboard_invite.png" alt="在 团队 settings 中邀请成员" width="2954" height="1916" data-path="images/admin/team-management/dashboard_invite.png" />

成员被邀请后，其在团队管理菜单中的状态会显示为 &quot;Pending&quot;。

<img src="/docs/images/admin/team-management/dashboard_invite_pending.png" alt="成员列表中显示 Pending 邀请状态" width="2954" height="1916" data-path="images/admin/team-management/dashboard_invite_pending.png" />

对方会收到一封邀请其加入团队的邮件。

<img src="/docs/images/admin/team-management/dashboard_invite_email.png" alt="团队邀请邮件" width="1094" height="1082" data-path="images/admin/team-management/dashboard_invite_email.png" />

邀请被接受后，你会看到两位成员的状态均为 &quot;Accepted&quot;。所有团队成员共享各自团队所属 plan 的用量限制和功能。

<img src="/docs/images/admin/team-management/dashboard_invite_accepted.png" alt="团队成员列表显示 Accepted 状态" width="2954" height="1916" data-path="images/admin/team-management/dashboard_invite_accepted.png" />

<div id="team-management-api">
  ## Team Management API
</div>

使用 [Team Management API](/zh/docs/reference/team-management/create-api-key) 以编程方式创建和管理 API 密钥。

<Info>
  Team Management API 需按团队单独启用。它通过服务账号 API 密钥进行身份验证；为你的团队启用该功能后，即可在 [API 密钥页面](https://dashboard.exa.ai/api-keys)的 **Service keys** 标签页中创建此密钥。如需申请访问权限，请联系 [support@exa.ai](mailto:support@exa.ai)。
</Info>
