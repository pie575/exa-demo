## Search、Contents、Answer 和 Monitors {#search-contents-answer-and-monitors}

每个端点均按请求收取基础费用，其中包含最多 10 条结果。超出的结果以及 Exa 生成的页面摘要将另行计费。

| 端点          | 基础价格<br /> (含最多 10 条结果)  | 超出 10 条的每条结果 | AI 页面摘要     |
| ----------- | ------------------------ | ------------ | ----------- |
| `/search`   | $7 / 1k 次请求              | $1 / 1k 条结果  | $1 / 1k 个页面 |
| `/answer`   | $5 / 1k 次请求              | —            | —           |
| `/monitors` | $15 / 1k 次请求             | $1 / 1k 条结果  | $1 / 1k 个页面 |
| `/contents` | $1 / 1k 个页面，按内容类型计费      | —            | $1 / 1k 个页面 |

## Agent {#agent}

为 [Agent](/zh/docs/agent/quickstart) 设置固定的 `effort`，即可获得可预测的单次请求价格。`auto` 是默认的计量模式；beta 版的 `max` 也按计量方式计费，并采用相同的用量费率：

| Effort    | 价格          |
| --------- | ----------- |
| `minimal` | $0.012 / 请求 |
| `low`     | $0.025 / 请求 |
| `medium`  | $0.10 / 请求  |
| `high`    | $0.50 / 请求  |
| `xhigh`   | $1.00 / 请求  |

计量模式的运行按实际用量计费，且不超过各自的单次运行上限。`auto` 的默认上限为 $5；beta 版 `max` 的默认上限为 $20：

| 用量组成                | 价格            |
| ------------------- | ------------- |
| Agent Compute Units | $0.10 / ACU   |
| Search 工具调用         | $0.005 / 次搜索  |
| 邮箱联系方式增强            | $0.02 / 个邮箱   |
| 电话联系方式增强            | $0.07 / 个电话号码 |

### Connect 提供方 {#connect-providers}

使用 [Exa Connect](/zh/docs/agent/connect/overview) 数据源的运行，还会对每次提供方调用另行计费，例如

## 深度搜索 {#deep-search}

在 [`/search`](/zh/docs/search/deep-search) 中通过 `type` 设置。额外结果和 AI 页面摘要的费用与标准 Search 相同。

| 类型               | 基础价格<br /> (最多 10 条结果)  | 延迟      | 适用场景        |
| ---------------- | ----------------------- | ------- | ----------- |
| `deep-lite`      | $12 / 1k 次请求            | ~4 秒    | 轻量级综合       |
| `deep`           | $12 / 1k 次请求            | 4–15 秒  | 带结构化输出的多步推理 |
| `deep-reasoning` | $15 / 1k 次请求            | 12–40 秒 | 难度更高的研究任务   |

## 费用术语表 {#cost-glossary}

<AccordionGroup>
  <Accordion title="请求">
    对某个端点的一次 API 调用。价格按每 1,000 次请求标价，因此 $7 / 1k 的费率即每次调用 $0.007。
  </Accordion>

  <Accordion title="结果">
    响应中返回的一条搜索结果。基础价格已包含一次请求中的前 10 条结果；超出 10 条的部分每条按 $1 / 1k 结果计费。因此请求 `numResults: 20` 的费用为基础价格加上 10 条额外结果的费用。
  </Accordion>

  <Accordion title="页面与内容类型">
    页面指 Exa 为其返回内容的一个 URL。内容类型是该页面的一种呈现形式：`text`、`highlights` 或 `summary`。`/contents` 对每种内容类型分别计费，因此同一页面同时返回 `text` 和 `highlights` 时计为两次。
  </Accordion>

  <Accordion title="AI 页面摘要">
    由 Exa 生成的页面摘要，需在我们这一侧额外发起一次 LLM 调用。任何返回该摘要的端点均按 $1 / 1k 页面计费。
  </Accordion>

  <Accordion title="Agent Compute Unit（ACU）">
    一次 Agent 运行所消耗的模型计算单位，通过 `usage.agentComputeUnits` 上报。运行时间越长、`input.data` 越大、推理步骤越多，消耗的 ACU 就越多。
  </Accordion>

  <Accordion title="Effort">
    用于在费用、延迟与彻底程度之间取得平衡的 Agent 参数。`auto` 按消耗量计费 (ACU 加工具调用) ，默认上限为 $5；beta 版 `max` 采用相同的用量费率，默认上限为 $20。固定 effort 则按每次请求收取固定价格。参见 [Agent effort 模式](/zh/docs/agent/quickstart#effort)。
  </Accordion>

  <Accordion title="联系方式增强">
    一种 Agent 查找操作，可返回个人或公司的电子邮箱地址或电话号码。除该次运行的其他费用外，按找到的每条联系方式另行计费。
  </Accordion>

  <Accordion title="积分">
    账户中的预付美元余额。用量按上述费率扣减积分。
  </Accordion>
</AccordionGroup>
