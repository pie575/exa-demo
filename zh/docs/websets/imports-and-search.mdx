如果你已经有一份 URL 列表(公司、人物、产品等),可以将它们**导入**到 Webset 中。根据 Webset 的设置方式,导入的项目可以被丰富、依据 criteria 进行评估,或与网络发现的结果相结合。

本指南会逐一介绍每种配置,并提供可直接复制粘贴的 API 调用示例。只需将 `$EXA_API_KEY` 替换为你的 API 密钥即可。

<div id="our-example-5-it-consulting-suppliers">
  ## 我们的示例：5 家 IT 咨询供应商
</div>

在本指南中，我们将始终以同一份包含 5 家公司的列表作为导入数据：

| 公司           | URL                              | 备注                 |
| ------------ | -------------------------------- | ------------------ |
| Accenture    | `https://www.accenture.com`      | 全球性 IT 咨询公司，总部在美国  |
| Infosys      | `https://www.infosys.com`        | IT 服务，在美国业务规模大     |
| Wipro        | `https://www.wipro.com`          | IT 服务，在美国设有办公室     |
| EPAM Systems | `https://www.epam.com`           | 软件工程，在美国上市         |
| Persol Group | `https://www.persol-group.co.jp` | 人力资源公司，聚焦日本，美国业务极少 |

选择这几家公司，是因为其中 4 家都明显符合典型的 IT 咨询 criteria (在美国设有办公室、提供 IT 服务) 。**Persol Group** 是个例外：它是一家日本人力资源公司，在美国几乎没有业务，因此应当无法通过与美国相关的 criteria。

下文示例使用的 criteria 如下：

1. “该公司在美国设有办公室”
2. “该公司提供 IT 咨询或人员外包服务”

<div id="config-1-import-only-enrich-without-filtering">
  ## Config 1：Import Only —— 只增强，不过滤
</div>

<Note>
  **在线示例：** [在控制台中查看此 webset](https://websets.exa.ai/websets/webset_01kmnrshyh3bdart13q1ehdtdj)
</Note>

**适用场景：** 你已有一份 URL 列表，只想对其进行增强。不评分、不过滤 —— 所有项目都会保留。

<div id="api-calls">
  ### API 调用
</div>

```bash theme={null}
# 第 1 步：用你的供应商 URL 创建一个 CSV 导入
curl -s -X POST "https://api.exa.ai/websets/v0/imports" \
  -H "Authorization: Bearer $EXA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "format": "csv",
    "count": 5,
    "size": 128,
    "entity": { "type": "company" },
    "title": "IT Consulting Suppliers"
  }'
# 响应中包含 `uploadUrl` 和导入的 `id`

# 第 2 步：将 CSV 上传到第 1 步返回的预签名 URL
curl -X PUT "<UPLOAD_URL>" \
  -H "Content-Type: text/csv" \
  --data-binary @suppliers.csv
# suppliers.csv 的内容为：url\nhttps://www.accenture.com\nhttps://www.infosys.com\n...

# 第 3 步：创建一个使用该导入的 Webset（仅做增强，不使用 search/criteria）
# 创建 Webset 时会自动安排处理该导入。
curl -s -X POST "https://api.exa.ai/websets/v0/websets" \
  -H "Authorization: Bearer $EXA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "import": [
      { "source": "import", "id": "<IMPORT_ID>" }
    ],
    "enrichments": [
      { "description": "What services does this company provide?", "format": "text" },
      { "description": "Number of employees", "format": "number" }
    ]
  }'
```

<div id="what-we-see-in-the-live-webset">
  ### 在实时 Webset 中看到的结果
</div>

全部 **5 个项目**都出现在 Webset 中。由于没有设置 criteria，不会进行任何过滤。

| Supplier     | 在 Webset 中？ | Source   | Evaluations | Enrichments | 原因？                  |
| ------------ | ----------- | -------- | ----------- | ----------- | -------------------- |
| Accenture    | **是**       | `import` | 0           | 2           | 已导入，没有可供评估的 criteria |
| Infosys      | **是**       | `import` | 0           | 2           | 已导入，没有可供评估的 criteria |
| Wipro        | **是**       | `import` | 0           | 2           | 已导入，没有可供评估的 criteria |
| EPAM Systems | **是**       | `import` | 0           | 2           | 已导入，没有可供评估的 criteria |
| Persol Group | **是**       | `import` | 0           | 2           | 已导入，没有可供评估的 criteria |

每个项目的 `source` 均为 `"import"`，且 `evaluations` 为 `[]`。这 5 个项目全部被保留并完成增强，无论它们能否通过任何 criteria，因为此 config 中根本没有 criteria。

<Note>
  Persol Group 的 URL (`persol-group.co.jp`) 在实体数据中解析成了“PERSOL Vietnam Japan Desk”，系统依然会导入并对其进行增强，只是解析到了一个区域子公司页面。
</Note>

<div id="config-4-scoped-search-web-discovery-score-your-list-and-find-new-matches">
  ## Config 4：限定 scope 的 Search + 网络发现 —— 既为你的列表打分，又发现新的匹配项
</div>

<Note>
  **在线示例：** [在控制台中查看此 webset](https://websets.exa.ai/websets/webset_01kmpbj5wjcsh1yqn2cfhx2v7h)
</Note>

**适用场景：** 你有一份供应商列表，希望按 criteria 对其打分，同时还想从网络上发现符合相同 criteria 的其他公司。这需要两步：先用限定 scope 的 Search 创建一个 webset，再在同一个 webset 中添加一次常规的网页搜索。

<div id="api-calls-3">
  ### API 调用
</div>

<CodeGroup>
  ```python Python theme={null}
  import os
  import requests

  # 按 Config 1 中的方式创建 CSV 导入并上传，然后在此处使用其 ID。
  headers = {"Authorization": f"Bearer {os.environ['EXA_API_KEY']}"}
  webset_response = requests.post(
      "https://api.exa.ai/websets/v0/websets",
      headers=headers,
      json={
          "search": {
              "query": "IT consulting and staff augmentation companies",
              "entity": {"type": "company"},
              "criteria": [
                  {"description": "The company has an office in the United States"},
                  {
                      "description": "The company provides IT consulting or staff augmentation services"
                  },
              ],
              "count": 25,
              "scope": [
                  {"source": "import", "id": "<IMPORT_ID>"},
              ],
          },
          "enrichments": [
              {
                  "description": "What services does this company provide?",
                  "format": "text",
              },
              {"description": "Number of employees", "format": "number"},
          ],
      },
  )
  webset_response.raise_for_status()
  webset_id = webset_response.json()["id"]

  search_response = requests.post(
      f"https://api.exa.ai/websets/v0/websets/{webset_id}/searches",
      headers=headers,
      json={
          "query": "IT consulting and staff augmentation companies",
          "entity": {"type": "company"},
          "criteria": [
              {"description": "The company has an office in the United States"},
              {
                  "description": "The company provides IT consulting or staff augmentation services"
              },
          ],
          "count": 25,
          "behavior": "append",
      },
  )
  search_response.raise_for_status()
  ```

限定 scope 的 Search 会依据 criteria 评估你导入的列表 (剔除 Persol Group) ，追加的网页搜索则另外发现了 25 家公司。最终得到一个 webset，其中既有你已打分的导入项，也有新的网页发现结果。

<Note>
  网页搜索使用了 `"behavior": "append"`，因此结果会追加到已有结果之后，而不是替换它们。如果网页搜索发现的公司已存在于限定 scope 的 Search 结果中 (例如 Accenture) ，系统会自动处理重复项。
</Note>

<div id="quick-reference">
  ## 快速参考
</div>

| 配置                              | 作用                  | 保留所有项目？          | 项目会被打分？           |
| ------------------------------- | ------------------- | ---------------- | ----------------- |
| **1. Import Only**              | 丰富你的列表              | 是 -- 全部保留        | 否                 |
| **2. Search Only**              | 从网络中发现新的匹配项         | 不适用 (无导入)        | 是 -- 仅返回通过的项目     |
| **3. 限定 scope 的 Search**        | 依据 criteria 为你的列表打分 | 否 -- 未通过的会被丢弃    | 是                 |
| **4. 限定 scope 的 Search + 网络发现** | 为你的列表打分 + 发现新的匹配项   | 否 -- 未通过的导入项会被丢弃 | 是 -- 导入项和发现项都会被打分 |

  ## 我该使用哪种 Config？

* **“我只想增强我的列表，不需要过滤”** —— Config 1

* **“给我的列表打分，并剔除不匹配的”** —— Config 3
* **“给我的列表打分，同时再找出匹配的新公司”** —— Config 4
