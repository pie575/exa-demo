<br />

## 概述 {#overview}

Exclude Results 功能可确保你在创建新 search 时不会出现重复的 result。通过基于以往的 Websets 或上传的 CSV file 指定要排除的 URL，你可以专注于发现全新、独特的 result，对已有数据形成补充。

<br />

## 工作原理 {#how-it-works}

<img src="/docs/images/websets/exclude-flow.png" alt="创建 Webset 时的排除结果选项" width="1466" height="857" data-path="images/websets/exclude-flow.png" />

1. 开始创建一个新的 Webset
2. 在侧边栏的 criteria 下方，点击 “Exclude”
3. 从以往的 Websets 中选择，或上传包含待排除 URL 的 CSV 文件。你可以同时选择多个来源进行排除。
4. 启动 search，结果中将只包含未命中 exclusions 的新内容

可排除的结果数量上限取决于你的 plan。

<br />

## 何时使用 exclusions {#when-to-use-exclusions}

* 查找尚未录入 CRM 的潜在客户
* 用更精细的 criteria 跟进此前的 search
* 排除你已知的 result
