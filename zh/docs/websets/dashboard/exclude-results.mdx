---
title: "排除结果"
description: "排除以往 Websets 或 CSV 文件中的 URL，避免新的 search 出现重复结果。"
---

<br />

<div id="overview">
  ## 概览
</div>

Exclude Results 功能可确保你在创建新的 search 时不会出现重复结果。通过指定要排除的 URL (来自以往的 Websets 或上传的 CSV 文件) ，你可以专注于发现全新、独特的结果，为现有数据提供补充。

<br />

<div id="how-it-works">
  ## 工作原理
</div>

<img src="/docs/images/websets/exclude-flow.png" alt="创建 Webset 时的排除结果选项" width="1466" height="857" data-path="images/websets/exclude-flow.png" />

1. 开始创建一个新的 Webset
2. 在侧边栏的 criteria 下方，点击 &quot;Exclude&quot;
3. 从过往的 Websets 中选择，或上传包含待排除 URL 的 CSV 文件。你可以同时选择多个排除来源。
4. 启动 search，结果中将只包含未被排除的新条目

可排除的结果数量上限取决于你的套餐。

<br />

<div id="when-to-use-exclusions">
  ## 何时使用排除功能
</div>

* 查找 CRM 中尚不存在的潜在客户
* 用更精细的 search 对以往的搜索进行跟进
* 排除你已知的结果
