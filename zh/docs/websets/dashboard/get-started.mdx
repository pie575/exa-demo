## 2. 开始使用 {#2-get-started}

Websets 用起来非常简单。

<img src="/docs/images/websets/websets-landing.png" alt="Websets 首页" width="2870" height="1726" data-path="images/websets/websets-landing.png" />

1. 用自然语言描述你想要的内容，想写得多复杂都可以！

<img src="/docs/images/websets/websets-preview.png" alt="展示已生成 criteria 的 Webset 预览" width="2870" height="1726" data-path="images/websets/websets-preview.png" />

2. 确认 criteria 和数据类别无误。

3. 确认需要的 result 数量，然后启动 search。

<br />

## 3. Webset 内部原理 {#3-inside-your-webset}

简而言之，Websets 会执行以下操作：

1. 拆解你的需求

2. 找出可能满足需求的数据

3. 借助 AI agent 并查找多方平行来源，验证所有 criteria

4. 根据你向我们的 agent 提供的反馈调整搜索

<Info>
  如果你对初始结果不满意，可在“Edit criteria”中或聊天界面内优化 criteria。
</Info>

<br />

## 4. 与 Webset 交互 {#4-interacting-with-your-webset}

Webset 完成后，你就可以与其中的各个部分进行交互了！

点击某个结果可以查看：

<img src="/docs/images/websets/websets-result.png" alt="Webset 结果详情，包含 AI 摘要、匹配的 criteria 和来源" width="2870" height="1734" data-path="images/websets/websets-result.png" />

1. AI 生成的摘要

2. 它满足了哪些 criteria 从而被纳入 Webset

3. 支撑该匹配判断的来源 (可在此处点击查看这些来源)

你可以手动删除结果，在导出前整理好 Webset。

<br />

## 5. 添加更多结果 criteria 和自定义列 {#5-add-more-result-criteria-and-custom-columns}

<img src="/docs/images/websets/add-enrichment.png" alt="添加增强列" width="2870" height="1734" data-path="images/websets/add-enrichment.png" />

1. **添加增强：** 你可以创建自定义增强列，获取任何你想要的信息，比如联系方式 (邮箱和电话号码) 、营收、员工人数、情感分析、论文摘要等。需要填写：

* 列名 (例如 &quot;Revenue&quot;) 

* 列类型 (例如 &quot;Number&quot;) 

* 供 Websets 查找数据的说明 (例如 &quot;查找该公司的年度营收&quot;)

* 或者点击 &quot;fill in for me&quot;，由我们的 agent 自动生成说明

<br />

## 6. 分享并导出你的 Webset {#6-share-and-export-your-webset}

1. 点击导出，将 Webset 下载为 CSV 文件。

2. 点击分享，获取 Webset 的分享链接。

<br />

## 7. 搜索历史 {#7-search-history}

点击左上角的 sidebar 图标，左侧面板会显示完整的历史记录，包含过往的所有 Websets。
