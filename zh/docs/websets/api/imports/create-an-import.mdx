description: "创建一个新的导入，将你的数据上传到 Websets。导入可用于：


  - **增强**：借助我们的 AI 增强引擎，为你的数据补充更多信息

  - **Search**：通过 Websets 的 agent 式搜索，用自然语言筛选条件查询你的数据

  - **排除**：避免重复或已知的结果出现在 search 结果中


  导入创建完成后，你可以在 `uploadValidUntil` 之前（默认 1 小时）将数据上传到返回的 `uploadUrl`。"
