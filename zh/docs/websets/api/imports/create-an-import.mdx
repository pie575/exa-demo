description: "创建一个新的 import，将你的数据上传到 Websets。import 可用于：


  - **Enrich（增强）**：借助我们的 AI 驱动 enrichment 引擎，为你的数据补充更多信息

  - **Search（搜索）**：使用 Websets 的智能体式 search，通过自然语言筛选条件查询你的数据

  - **Exclude（排除）**：避免重复或已知的结果出现在搜索结果中


  import 创建后，你可以在 `uploadValidUntil`（默认 1 小时）之前将数据上传至返回的 `uploadUrl`。"
