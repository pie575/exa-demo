description: "创建新的 `Monitor`，持续为你的 Websets 补充最新数据。


  Monitor 会按你设定的 schedule 自动运行，无需人工干预即可让 Websets 始终保持最新：


  - **发现新内容**：执行 `search` 操作，找出符合你 criteria 的新项目

  - **更新已有内容**：执行 `refresh` 操作，更新项目的页面内容和增强

  - **自动化调度**：配置 `cron` 表达式和 `timezone`，精确控制运行时间"
