在 Claude Code 中安装 Exa，或将其连接到 Claude Web、Desktop 和 Cowork，让 Claude 能够获取网络上的最新信息。Claude 可以用自然语言搜索、阅读真正重要的页面，并在工作过程中参考这些来源。

<div id="install-exa">
  ## 安装 Exa
</div>

  <Tabs>

        </Step>
      </Steps>
    </Tab>

    <Tab title="Claude Code CLI" icon="/docs/images/mcp-clients/claude-code.svg" width="16" height="16" data-path="images/mcp-clients/claude-code.svg">

          你也可以在 Claude Code 中输入 `/plugin`，搜索 **Exa** 并安装。
        </Step>

        <Step title="启动新会话">
          新开一个 Claude Code 会话以加载插件，然后提出需要联网的问题。

这两种方式都无需编辑 MCP 配置文件即可使用 Exa。

<div id="work-with-whats-on-the-web-right-now">
  ## 用上网络上的最新内容
</div>

在 Claude Code 中，Exa 可以在你操作代码仓库的同时搜索最新的文档、issue、更新日志和实际案例。同一套集成也能为 Claude Web、Desktop 和 Cowork 提供最新的新闻、研究、公司信息、产品详情，以及其他尚未进入上下文的信息来源。

```text theme={null}
我们目前用的是 Tailwind v3。请用 Exa 找到并阅读官方的 Tailwind v4
升级指南，然后将本项目迁移到 v4。
```

Claude Code 可以利用检索到的内容在你的代码库中进行修改。在其他 Claude 客户端中，它同样可以在回答、artifacts 和 Cowork 任务中使用这些来源。

只要答案依赖于最新或特定的网络来源，这一模式都同样适用：

* “找到该依赖项的最新发布说明，并总结其中的破坏性变更。”
* “搜索关于推理时扩展的近期一手研究，并比较这些方法。”
* “阅读 Stripe 当前的 webhook 文档，并说明推荐的重试行为。”
* “找到这些产品的官方定价页面，并比较它们的入门级方案。”

<div id="search-read-and-research">
  ## 搜索、阅读与研究
</div>

Exa 集成为 Claude 提供了搜索和阅读网页的工具，Claude 可以在较长的研究任务中组合使用这些工具。

<Columns cols={3}>
  <Card title="搜索" icon="search">
    用自然语言搜索，直接获取相关的页面内容，而不只是一串链接。
  </Card>

  <Card title="阅读" icon="file-text">
    阅读你指定的页面，包括文档、研究资料、更新日志、issue 和文章。
  </Card>

  <Card title="研究" icon="compass">
    执行多次搜索，查阅有价值的页面，并将这些依据整合为带来源的回答。
  </Card>
</Columns>

<div id="research-without-leaving-claude">
  ## 无需离开 Claude 即可完成研究
</div>

直接说出你想要的结果，并告诉 Claude 你看重哪类信息源：

```text theme={null}
对比主流开源向量数据库的托管服务、许可方式和定价。
请使用最新的一手资料并注明出处。
```

在整个对话过程中，Claude 都可以调用 Exa 来查找并阅读完成任务所需的资料来源。适用于技术调研、竞品分析、市场摸底、公司调研，或任何答案散落在网络各处的问题。

<div id="use-exa-in-cowork">
  ## 在 Cowork 中使用 Exa
</div>

同一个连接器在 Cowork 中也可以使用。把需要外部信息的任务交给 Claude，它就能一边处理你的文件和其他已连接的工具，一边搜索或阅读网页。

```text theme={null}
审阅这份竞品简报，用 Exa 对照各厂商的最新页面核实其中每一条定价说法，
并在文档中补充引用来源。
```

<div id="prefer-mcp-directly">
  ## 更想直接使用 MCP？
</div>

如果你想手动配置 Claude，或者使用其他 MCP 客户端，可以直接连接到 Exa 托管的 MCP 服务器：

```bash theme={null}
claude mcp add --transport http exa https://mcp.exa.ai/mcp
```

有关其他客户端、配置选项和可用工具，请参阅 [Exa MCP](/zh/docs/get-started/exa-mcp)。
