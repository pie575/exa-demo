<div id="what-is-x402">
  ## 什么是 x402？
</div>

[x402](https://x402.org) 是一种基于 HTTP `402 Payment Required` 状态码的开放支付标准。它让客户端能够使用 Base 或 Solana 上的 USDC 稳定币按请求付费调用 API，无需账户、API key 或订阅。

Exa 在两个端点上支持 x402：**`/search`** 和 **`/contents`**。当请求中不带 API key 或支付 header 时，Exa 会返回 `402` 以及一个 `PAYMENT-REQUIRED` header，其中包含定价详情和支持的支付网络。客户端对一笔 USDC 支付进行签名，带上 `PAYMENT-SIGNATURE` header 重新发起请求，待链上结算确认后即可获得结果。

这非常适合需要在无预置凭据的情况下自主为网页搜索付费的 **AI agent**。

<Info>
  x402 与 API key 访问相互独立。如果请求中包含 `x-api-key` 或 `Authorization: Bearer` header，则会走常规的 API key 计费流程，完全绕过 x402。
</Info>

<div id="supported-endpoints">
  ## 支持的端点
</div>

| 端点          | 方法   | 描述                                                                           |
| ----------- | ---- | ---------------------------------------------------------------------------- |
| `/search`   | POST | 网页搜索，支持所有搜索类型 (`instant`、`auto`、`fast`、`deep`、`deep-lite`、`deep-reasoning`)  |
| `/contents` | POST | 按 URL 或文档 ID 检索内容                                                            |

其余所有端点均**不**支持通过 x402 调用。

<div id="step-1-discovery">
  ### 第 1 步：发现
</div>

向受支持的端点发送请求，且不携带 API key 或支付 header：

```bash theme={null}
curl -X POST "https://api.exa.ai/search" \
  -H "Content-Type: application/json" \
  -d '{"query": "best machine learning frameworks", "numResults": 5}'
```

你会收到一个 `402` 响应，其中包含经 base64 编码的 `PAYMENT-REQUIRED` header。解码后如下所示：

```json theme={null}
{
  "x402Version": 2,
  "resource": {
    "url": "https://api.exa.ai/search",
    "description": "Exa /search endpoint"
  },
  "accepts": [
    {
      "scheme": "exact",
      "network": "eip155:8453",
      "amount": "7000",
      "asset": "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
      "payTo": "0x...",
      "maxTimeoutSeconds": 60,
      "extra": { "name": "USD Coin", "version": "2" }
    },
    {
      "scheme": "exact",
      "network": "solana:5eykt4UsFv8P8NJdTREpY1vzqKqZKvdp",
      "amount": "7000",
      "asset": "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v",
      "payTo": "...",
      "maxTimeoutSeconds": 60,
      "extra": { "name": "USD Coin", "version": "2", "feePayer": "..." }
    }
  ]
}
```

`amount` 以 USDC 原子单位 (6 位小数) 表示，因此 `"7000"` = $0.007。
客户端可以使用其支持的任一已公布 `accepts` 条目进行支付。Solana 条目包含由 facilitator 提供的字段，例如 `extra.feePayer`；构造支付时请严格使用 `PAYMENT-REQUIRED` header 中的对应条目。

<div id="step-2-pay-and-retry">
  ### 步骤 2：支付并重试
</div>

用你的钱包对支付进行签名，然后重新发送请求，并附上 `PAYMENT-SIGNATURE` header，其值为经 base64 编码的支付 payload。x402 客户端 SDK 会自动完成这一过程。

<div id="step-3-settlement">
  ### 第 3 步：结算
</div>

Exa 会通过 facilitator 验证你的支付签名，然后在处理请求的**同时并行**发起链上结算。响应会一直保持挂起，直到结算确认完成。成功后，你将收到：

* HTTP `200` 及返回结果
* 一个 `PAYMENT-RESPONSE` header，其中包含结算回执 (base64 编码) ，内含链上交易哈希

如果结算失败，你会收到 `402`，并同时带有 `PAYMENT-RESPONSE` (错误详情) 和 `PAYMENT-REQUIRED` (以便你重试) 。

<div id="pricing">
  ## 定价
</div>

x402 采用与 API key 计费相同的打包定价。价格会根据你的请求参数预先计算得出，而非依据实际返回的结果。

<div id="search-search">
  ### Search (`/search`)
</div>

| 搜索类型                    | 基础价格 (最多 10 条结果)  | 超出 10 条的每条结果   |
| ----------------------- | ----------------- | -------------- |
| `instant`、`auto`、`fast` | $0.007 / 次请求      | 不适用 (上限 10 条)  |
| `deep-lite`             | $0.012 / 次请求      | 不适用 (上限 10 条)  |
| `deep`                  | $0.012 / 次请求      | 不适用 (上限 10 条)  |
| `deep-reasoning`        | $0.015 / 次请求      | 不适用 (上限 10 条)  |

启用 `contents.summary` 需**每条结果额外收费 $0.001**。

<Warning>
  x402 请求的结果数最多为 **10 条**。如果请求超过 10 条，`numResults` 会被静默限制为 10，计费也按 10 条结果计算。
</Warning>

<div id="contents-contents">
  ### Contents (`/contents`)
</div>

每种内容类型均按页面/URL 计费：

| 内容类型         | 每页价格   |
| ------------ | ------ |
| `text`       | $0.001 |
| `highlights` | $0.001 |
| `summary`    | $0.001 |

如果你未请求任何内容类型 (即未指定 `text`、`highlights` 或 `summary`) ，则默认启用 `text`。

<div id="examples">
  ### 示例
</div>

| 请求                                       | 价格     | USDC 原子单位 |
| ---------------------------------------- | ------ | --------- |
| `/search`，10 条结果，`type: "auto"`          | $0.007 | 7000      |
| `/search`，5 条结果，`type: "fast"`           | $0.007 | 7000      |
| `/search`，3 条结果 + summary，`type: "auto"` | $0.010 | 10000     |
| `/search`，10 条结果，`type: "deep-lite"`     | $0.012 | 12000     |
| `/search`，10 条结果，`type: "deep"`          | $0.012 | 12000     |
| `/contents`，2 个 URL，`text: true`         | $0.002 | 2000      |
| `/contents`，1 个 URL，`text` + `summary`   | $0.002 | 2000      |

<div id="make-a-paid-search-request">
  ### 发起付费搜索请求
</div>

<CodeGroup>
  ```typescript JavaScript theme={null}
  import { wrapFetchWithPayment } from "@x402/fetch";
  import { x402Client, x402HTTPClient } from "@x402/core/client";
  import { ExactEvmScheme } from "@x402/evm/exact/client";
  // 若需支持 Solana，还需导入：
  // import { ExactSvmScheme } from "@x402/svm/exact/client";
  import { privateKeyToAccount } from "viem/accounts";

  const signer = privateKeyToAccount(process.env.WALLET_PRIVATE_KEY as `0x${string}`);
  const client = new x402Client();
  client.register("eip155:*", new ExactEvmScheme(signer));
  // 如果希望客户端使用 Solana 的 accept 条目
  // （例如 `solana:5eykt4UsFv8P8NJdTREpY1vzqKqZKvdp`），请一并注册 Solana 签名器：
  // client.register("solana:*", new ExactSvmScheme(svmSigner));
  const fetchWithPayment = wrapFetchWithPayment(fetch, client);

  const response = await fetchWithPayment("https://api.exa.ai/search", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      query: "best machine learning frameworks",
      numResults: 5,
    }),
  });

  const data = await response.json();
  console.log(data.results);

  // 查看结算回执
  const httpClient = new x402HTTPClient(client);
  const receipt = httpClient.getPaymentSettleResponse(
    (name) => response.headers.get(name)
  );
  console.log("Transaction:", receipt?.transaction);
  ```

  ```python Python theme={null}
  import os
  import requests
  from eth_account import Account
  from x402 import x402ClientSync
  from x402.http.clients import wrapRequestsWithPayment
  from x402.mechanisms.evm.exact import register_exact_evm_client
  from x402.mechanisms.evm.signers import EthAccountSigner

  account = Account.from_key(os.environ["WALLET_PRIVATE_KEY"])
  client = x402ClientSync()
  register_exact_evm_client(
      client,
      EthAccountSigner(account),
      networks="eip155:*",
  )
  session = wrapRequestsWithPayment(requests.Session(), client)

  response = session.post("https://api.exa.ai/search", json={
      "query": "best machine learning frameworks",
      "numResults": 5,
  })

  data = response.json()
  for result in data["results"]:
      print(result["url"], result["title"])
  print("Payment response:", response.headers.get("PAYMENT-RESPONSE"))
  ```

  ```bash cURL theme={null}
  # 第 1 步：发现阶段，获取定价信息
  curl -s -o /dev/null -w "%{http_code}" -D - \
    -X POST "https://api.exa.ai/search" \
    -H "Content-Type: application/json" \
    -d '{"query": "best machine learning frameworks", "numResults": 5}'
  # 返回 402，并在 PAYMENT-REQUIRED 头中携带 base64 编码的定价信息

  # 第 2 步：用钱包对支付进行签名（建议借助 SDK 完成）
  # 第 3 步：带上支付签名重新发起请求
  curl -X POST "https://api.exa.ai/search" \
    -H "Content-Type: application/json" \
    -H "PAYMENT-SIGNATURE: <base64-encoded-payment>" \
    -d '{"query": "best machine learning frameworks", "numResults": 5}'
  # 返回 200，包含结果以及 PAYMENT-RESPONSE 头（结算回执）
  ```
</CodeGroup>

<Info>
  使用 cURL 需要手动完成支付签名。生产环境请使用 JavaScript 或 Python SDK，它们会自动处理完整的 402 &gt; 签名 &gt; 重试流程。
</Info>

<div id="discovery-mode-no-wallet-needed">
  ### 探测模式 (无需钱包)
</div>

无需钱包，发送未经认证的请求即可探测定价：

<CodeGroup>
  ```typescript JavaScript theme={null}
  const res = await fetch("https://api.exa.ai/search", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ query: "test query", numResults: 3 }),
  });

  // res.status === 402
  const paymentRequired = JSON.parse(
    atob(res.headers.get("PAYMENT-REQUIRED")!)
  );
  console.log(
    paymentRequired.accepts.map(({ network, amount }) => ({
      network,
      amount,
    }))
  );
  ```

  ```python Python theme={null}
  import base64, json, requests

  res = requests.post("https://api.exa.ai/search", json={
      "query": "test query",
      "numResults": 3,
  })

  # res.status_code == 402
  pricing = json.loads(base64.b64decode(res.headers["PAYMENT-REQUIRED"]))
  print([(accept["network"], accept["amount"]) for accept in pricing["accepts"]])
  ```

  ```bash cURL theme={null}
  curl -s -D - -X POST "https://api.exa.ai/search" \
    -H "Content-Type: application/json" \
    -d '{"query": "test query", "numResults": 3}'
  # 在 402 响应中查找 PAYMENT-REQUIRED 响应头
  # 解码：echo "<header-value>" | base64 -d
  ```
</CodeGroup>

<div id="payment-networks">
  ## 支付网络
</div>

Exa 会在 `accepts` 数组中列出当前支持的所有网络。请选择与你的钱包和已注册的 x402 客户端方案相匹配的条目。

| 网络                  | 标识符                                       | 代币   | 资产地址                                           |
| ------------------- | ----------------------------------------- | ---- | ---------------------------------------------- |
| Base (Ethereum L2)  | `eip155:8453`                             | USDC | `0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`   |
| Solana 主网           | `solana:5eykt4UsFv8P8NJdTREpY1vzqKqZKvdp` | USDC | `EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v` |

两者均使用 6 位小数精度的 USDC (`1000000` = $1.00) ，并通过 x402 facilitator 在链上完成结算。

<div id="rate-limits">
  ## 速率限制
</div>

x402 有自己的速率限制，与 API key 的限制相互独立：

| 限制               | 阈值       | 时间窗口 |
| ---------------- | -------- | ---- |
| 未付费的探测请求 (按 IP)  | 5 次请求    | 60 秒 |
| 付费请求 (按钱包)       | 10 次请求/秒 | 1 秒  |

同一 IP 在 60 秒内发起 5 次未认证的 `402` 探测请求后，后续请求将返回 `429 Too Many Requests`。成功完成一次付费请求会使该计数器减一。

按钱包计算的 QPS 限制适用于同一钱包地址发出的所有付费请求。

<div id="headers-reference">
  ## Header 参考
</div>

<div id="request-headers">
  ### 请求头
</div>

| Header              | 说明                              |
| ------------------- | ------------------------------- |
| `PAYMENT-SIGNATURE` | Base64 编码的支付 payload (x402 v2)  |
| `payment-signature` | 别名 (同样接受)                       |
| `x-payment`         | 旧版别名 (兼容 v1)                    |

<div id="response-headers">
  ### 响应 header
</div>

| Header             | 出现时机                    | 说明                                        |
| ------------------ | ----------------------- | ----------------------------------------- |
| `PAYMENT-REQUIRED` | `402` 响应                | Base64 编码的 `PaymentRequired` 对象，包含定价与支付说明 |
| `PAYMENT-RESPONSE` | `200` 或 `402` (支付尝试之后)  | Base64 编码的结算结果，包含交易哈希或错误信息                |

<div id="error-codes">
  ## 错误码
</div>

| 状态码   | 标签                         | 描述                                        |
| ----- | -------------------------- | ----------------------------------------- |
| `402` | `X402_PAYMENT_REQUIRED`    | 未提供支付信息，`PAYMENT-REQUIRED` header 中包含定价信息 |
| `402` | `X402_VERIFICATION_FAILED` | 支付签名未通过 facilitator 验证                    |
| `400` | `X402_INVALID_SIGNATURE`   | 支付签名格式错误或无法解析                             |
| `429` | `X402_TOO_MANY_UNPAID`     | 来自该 IP 的未支付探测请求过多                         |
| `429` | `X402_WALLET_RATE_LIMITED` | 钱包请求速率超过每秒 10 次                           |
| `500` | `X402_INTERNAL_ERROR`      | 生成支付要求时发生服务端错误                            |

<div id="faq">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="可以同时使用 x402 和 API key 吗？">
    如果请求中包含 `x-api-key` header 或 `Authorization: Bearer` 令牌，则优先走 API key 流程，x402 会被跳过。两者不会叠加，每个请求只能二选一。
  </Accordion>

  <Accordion title="如果请求已处理但结算失败会怎样？">
    响应会被拦截。你会收到 `402`，其中同时包含 `PAYMENT-RESPONSE` (内含错误信息) 和 `PAYMENT-REQUIRED` (便于客户端重试) 。在结算成功之前不会返回任何结果。
  </Accordion>

  <Accordion title="为什么 numResults 上限是 10？">
    x402 请求的每次 search 最多返回 10 条结果。如需更多结果，请使用付费套餐下的 API key 流程。
  </Accordion>

  <Accordion title="支持哪些钱包？">
    任何能在 Base 上签署 EIP-712 类型化数据的 EVM 兼容钱包，或 x402 SVM 客户端所支持的、适用于 `solana:5eykt4UsFv8P8NJdTREpY1vzqKqZKvdp` 的 Solana 钱包。x402 SDK 支持 `viem`、`ethers`、Coinbase Wallet 签名器以及 Solana SVM 签名器。对于基于 EVM 的 AI 智能体，[Coinbase Agentic Wallets](https://docs.cdp.coinbase.com/agent-kit/core-concepts/wallet-management) 提供 TEE 隔离的密钥管理，让你的智能体无需直接接触原始私钥。
  </Accordion>
</AccordionGroup>
