使用 `ai` 包中的 `gateway.tools.exaSearch()`，通过 [Vercel AI Gateway](https://vercel.com/docs/ai-gateway) 调用 Exa 网页搜索。你无需 Exa API 密钥，Vercel 会通过 AI Gateway 为这些请求计费。完整参考请查看 Vercel 的[网页搜索文档](https://vercel.com/docs/ai-gateway/models-and-providers/web-search)。

## 安装 {#install}

安装 AI SDK 5 或更高版本：

```bash install.sh theme={null}
npm install ai
```

## 身份验证 {#authentication}

<Info>
  AI Gateway 需要 API 密钥或 OIDC token。在 Vercel 控制台的 **AI Gateway &gt; API Keys** 中创建一个 `AI_GATEWAY_API_KEY`，然后将其添加到你的环境变量中。
</Info>

```bash .env theme={null}
AI_GATEWAY_API_KEY=your-api-key-here
```

当你在 Vercel 上部署应用时，可以改用自动提供的 `VERCEL_OIDC_TOKEN`。参见 Vercel 的[认证与 BYOK 文档](https://vercel.com/docs/ai-gateway/authentication-and-byok)。

## 快速开始 {#quick-start}

你可以在任何受支持的模型上使用 Exa search：

```typescript quickstart.ts theme={null}
import { gateway, generateText, stepCountIs } from 'ai';

const { text } = await generateText({
  model: 'openai/gpt-5.6-sol',
  prompt: 'What are the latest developments in AI this week?',
  tools: {
    exa_search: gateway.tools.exaSearch(),
  },
  stopWhen: stepCountIs(3),
});

console.log(text);
```

## 流式传输 {#streaming}

使用 `streamText` 在生成的文本和 search 工具事件到达时实时处理它们：

```typescript stream.ts theme={null}
import { gateway, streamText } from 'ai';

const result = streamText({
  model: 'openai/gpt-5.6-sol',
  prompt: 'What are the latest developments in AI this week?',
  tools: {
    exa_search: gateway.tools.exaSearch(),
  },
});

for await (const part of result.fullStream) {
  if (part.type === 'text-delta') {
    process.stdout.write(part.text);
  } else if (part.type === 'tool-call') {
    console.log('Tool call:', part.toolName);
  } else if (part.type === 'tool-result') {
    console.log('Search results received');
  }
}
```

在 Next.js 路由处理器中，使用 `return result.toUIMessageStreamResponse()` 将流返回给客户端。

## 配置 {#configuration}

向 `gateway.tools.exaSearch()` 传入 options 即可调整搜索行为：

```typescript configuration.ts theme={null}
tools: {
  exa_search: gateway.tools.exaSearch({
    type: 'fast',
    numResults: 5,
    category: 'news',
    includeDomains: ['reuters.com', 'bbc.com', 'nytimes.com'],
    contents: {
      highlights: true,
      maxAgeHours: 24,
    },
  }),
},
```

可用的选项包括：

| 选项                                                     | 说明                                    |
| ------------------------------------------------------ | ------------------------------------- |
| `type`                                                 | 搜索模式：`auto` (默认) 、`fast` 或 `instant`。 |
| `numResults`                                           | 返回结果的数量，范围为 1 到 100，默认为 10。           |
| `category`                                             | 内容类别。                                 |
| `includeDomains` / `excludeDomains`                    | 包含或排除特定域名。                            |
| `startPublishedDate` / `endPublishedDate`              | 按发布日期筛选结果。                            |
| `userLocation`                                         | 两位字母的 ISO 国家/地区代码，用于位置感知搜索。           |
| `contents.text`                                        | 返回提取的页面文本。                            |
| `contents.highlights`                                  | 返回页面中的相关 highlights。                  |
| `contents.maxAgeHours`                                 | 设置缓存内容的最长有效期。                         |
| `contents.livecrawlTimeout`                            | 设置实时抓取的超时时间。                          |
| `contents.subpages` / `contents.subpageTarget`         | 抓取子页面，并可指定目标子页面。                      |
| `contents.extras.links` / `contents.extras.imageLinks` | 返回结果中的链接或图片链接。                        |

完整的 parameters 列表及其行为，请参阅 Vercel 的 [Exa web search 参考文档](https://vercel.com/docs/ai-gateway/models-and-providers/web-search)。

## Vercel eve agent {#vercel-eve-agents}

使用 [eve](https://eve.dev) 构建的 agent 自带 `web_search` 工具，AI Gateway 模型默认通过 Exa 运行该工具，无需任何配置或 Exa API 密钥。若要显式指定提供方，可在 `agent/tools/web_search.ts` 中导出：

```typescript agent/tools/web_search.ts theme={null}
import { webSearch } from 'eve/tools';

export default webSearch({ provider: 'exa' });
```

通过直接提供方 (而非 AI Gateway) 调用的模型会保留其原生网页搜索功能。完整的工具集请参阅 eve 的 [harness 文档](https://eve.dev/docs/concepts/default-harness#built-in-tools)。

## 定价 {#pricing}

<Tip>
  在 AI Gateway 和 eve 上，Exa 网页搜索 **在 8 月 31 日前免费**，你现在就可以零成本用它来构建应用。
</Tip>

此后，Vercel 会按其 [网页搜索 文档](https://vercel.com/docs/ai-gateway/models-and-providers/web-search)中的费率，对通过 AI Gateway 发出的请求计费。

<Note>
  该 integration 目前支持 Exa 的标准搜索模式和内容提取控制。deep 综合模式和生成式摘要尚未开放。
</Note>
