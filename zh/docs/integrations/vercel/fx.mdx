[fx](https://fx.sh) 是 Vercel Labs 推出的原生编码智能体和命令行工具，同时也是一个 MCP 客户端。添加 Exa 托管的 MCP server，即可为它提供实时网页搜索和页面读取能力。

## 安装 {#installation}

<Steps>
  <Step title="安装 fx">
    ```bash theme={null}
    curl -fsSL https://fx.sh/setup.sh | bash
    ```

    然后使用 `fx login` 登录。有关提供方选项，请参阅 [fx 文档](https://fx.sh/docs)。
  </Step>

  <Step title="添加 Exa">
    运行 `fx` 启动，然后在交互式 shell 中添加 Exa MCP server：

    ```text theme={null}
    /mcp add --transport http exa https://mcp.exa.ai/mcp
    ```

    fx 会将该 server 保存到 `~/.fx/mcp.json` 并重新加载 MCP。
  </Step>

  <Step title="验证连接">
    ```text theme={null}
    /mcp list
    ```
  </Step>
</Steps>

## 手动配置 {#configure-by-hand}

fx 仅从 `~/.fx/mcp.json` 中读取 MCP server，因此你也可以直接在该文件中添加 Exa：

```json ~/.fx/mcp.json theme={null}
{
  "mcp": {
    "exa": {
      "type": "http",
      "url": "https://mcp.exa.ai/mcp"
    }
  }
}
```

运行 `/mcp reload` 即可应用更改，无需重启 fx。

免费 plan 足以应对日常轻量使用。若要放宽速率限制，请创建 API 密钥并将其添加到配置中：

<Card title="获取你的 Exa API 密钥" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  在控制台中创建密钥。新账户可获得免费积分。
</Card>

```json ~/.fx/mcp.json theme={null}
{
  "mcp": {
    "exa": {
      "type": "http",
      "url": "https://mcp.exa.ai/mcp",
      "header_env": {
        "x-api-key": "EXA_API_KEY"
      }
    }
  }
}
```

`header_env` 将 header 名称映射到环境变量，这样密钥就不会出现在配置文件中。

## 工具发现 {#tool-discovery}

fx 采用惰性方式发现 MCP tools：只有当某一轮对话需要时，server 的 tools 才会进入模型的上下文，因此在不涉及联网搜索的轮次中，接入 Exa 不会带来任何开销。
