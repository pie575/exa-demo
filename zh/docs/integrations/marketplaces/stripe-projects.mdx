借助 [Stripe Projects](https://projects.dev)，你和你的编码智能体可以直接在终端中开通第三方服务，无需打开控制台，也无需复制粘贴密钥。一条命令即可创建 Exa 账户，并将 API key 同步到你的项目中。

<div id="prerequisites">
  ## 前置条件
</div>

安装 Stripe CLI 和 Projects 插件：

```bash theme={null}
brew install stripe/stripe-cli/stripe && stripe plugin install projects
```

有关其他平台及完整的 CLI 配置方法，请参阅 [Stripe Projects](https://projects.dev)。

<div id="get-started">
  ## 开始使用
</div>

在你的项目目录中，初始化项目、添加 Exa 并拉取凭据：

```bash theme={null}
stripe projects init
stripe projects add exa/api
stripe projects env --pull
```

你的 `.env` 中现在已包含 `EXA_API_KEY`。[Exa SDK](/zh/docs/sdks/quickstart) 和[快速开始](/zh/docs/search/quickstart)会自动读取该变量，因此你的代码无需任何改动即可运行。

<Info>
  该密钥是在你自己的 Exa 账户中创建的。你可以随时在 [Exa Dashboard](https://dashboard.exa.ai) 中管理用量、密钥和账单。
</Info>

<div id="link-an-existing-exa-team">
  ## 关联已有的 Exa 团队
</div>

已有 Exa 账户？请先关联账户，这样 API key 才会在你现有的团队下创建：

```bash theme={null}
stripe projects link exa
stripe projects add exa/api
```

`stripe projects link` 会打开 Exa，供你完成身份验证并将团队与 Stripe 账户关联。之后可随时使用 `stripe projects open exa` 打开已关联的 Exa Dashboard。

<div id="provision-from-your-coding-agent">
  ## 通过编码智能体完成配置
</div>

`stripe projects init` 会在你的项目中写入一个 Stripe Projects [Agent Skill](https://projects.dev)，这样你就可以让 agent (Claude Code、Cursor、Codex 等) 代你执行整个流程：

```text theme={null}
使用 Stripe Projects 添加 Exa 并接入 API key。
```
