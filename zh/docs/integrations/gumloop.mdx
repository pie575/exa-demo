[Gumloop](https://www.gumloop.com/) 内置了 Exa 的 MCP 集成。将其添加到 agent 或 Agent Node 中，即可在工作流内搜索网页、提取页面内容、查找相关来源，并生成带引用出处的答案。

<div id="add-exa-to-a-gumloop-agent">
  ## 将 Exa 添加到 Gumloop agent
</div>

<Steps>
  <Step title="打开 agent">
    打开 agent 的配置，然后依次选择 **Add tools** → **Connect an app with MCP**。
  </Step>

  <Step title="连接 Exa">
    搜索 **Exa**，选择该集成并完成认证流程。
  </Step>

  <Step title="选择工具">
    打开已连接的 Exa 集成，只启用 agent 需要的工具。这样工具选择更加清晰，也能避免 agent 调用无关的操作。
  </Step>

  <Step title="测试连接">
    向 agent 提问：

    ```text theme={null}
    Find five recent articles about AI regulation and summarize the key changes with source links.
    ```

    查看本次运行记录，确认 agent 确实调用了 Exa 并返回了带来源引用的结果。
  </Step>
</Steps>

<div id="available-tools">
  ## 可用工具
</div>

| 工具                       | 用途                   |
| ------------------------ | -------------------- |
| **Search**               | 使用神经搜索或关键词搜索查找相关页面。  |
| **Get Contents**         | 从已知 URL 提取全文、摘要和元数据。 |
| **Find Similar**         | 查找与来源 URL 相关的页面。      |
| **Answer**               | 生成有据可依、带引用来源的答案。     |
| **Create Research Task** | 启动耗时较长的研究任务。         |
| **Get Research Task**    | 获取研究任务的状态和结果。        |

对于对话式 Agent，建议先启用 Search、Get Contents 和 Answer，其余工具仅在工作流确有需要时再添加。

<div id="use-exa-in-a-workflow">
  ## 在工作流中使用 Exa
</div>

<div id="agent-node">
  ### Agent Node
</div>

在确定性的 Gumloop 流程中添加 **Agent Node**，并将 Exa 接入为它的工具之一。该节点可以自行决定是执行 search、抓取完整页面，还是串联多次 Exa 调用，然后再将输出传递给工作流的下一步。

它非常适合以下场景：

* 为 CRM 或表格中的数据行补充最新的网页信息
* 监控新闻，并将带来源的 summary 发送到 Slack 或邮箱
* 在将记录转入销售工作流之前先调研公司信息
* 对比产品并将结果写入文档

<div id="reusable-custom-mcp-node">
  ### 可复用的自定义 MCP 节点
</div>

如果只是一个需要反复执行的操作，可以创建一个专用节点：

1. 打开节点库，找到 Exa。
2. 选择 **Create a node with AI**。
3. 描述单个操作，例如 `Search for funding announcements from the past seven days`。
4. 测试生成的节点，确认其输入和输出，然后保存。

当任务需要动态规划或调用多个工具时，使用 Agent Node；当同一个 Exa 操作需要对每个项目稳定一致地执行时，使用自定义 MCP 节点。

<div id="prompt-patterns">
  ## 提示词模式
</div>

<AccordionGroup>
  <Accordion title="搜索并总结">
    ```text theme={null}
    搜索本周发布的关于 [主题] 的官方公告。
    为每条结果返回日期、发布方、摘要和来源 URL。
    ```
  </Accordion>

  <Accordion title="补充公司信息">
    ```text theme={null}
    根据给定的公司名称和域名，查找其产品介绍、
    最新融资公告，以及两条近期新闻来源。
    ```
  </Accordion>

  <Accordion title="读取已知页面">
    ```text theme={null}
    获取该 URL 的完整内容，并以 JSON 形式提取定价层级。
    ```
  </Accordion>
</AccordionGroup>

<div id="troubleshooting">
  ## 故障排查
</div>

<AccordionGroup>
  <Accordion title="Agent 无法使用 Exa">
    重新打开 agent 的 MCP 工具，确认 Exa 已连接，并启用所需的工具。集成虽已连接，其中的单个工具仍可能处于禁用状态。
  </Accordion>

  <Accordion title="Agent 选择了错误的操作">
    在请求中明确说明它应执行 search、读取已知 URL、查找相似页面，还是基于来源作答。同时禁用该工作流中 agent 用不到的 Exa 工具。
  </Accordion>

  <Accordion title="工作流需要可预测的单次调用">
    将通用的 agent 步骤替换为输入和任务均已固定的自定义 Exa MCP 节点。
  </Accordion>
</AccordionGroup>
