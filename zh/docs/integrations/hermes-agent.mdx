[Hermes Agent](https://github.com/NousResearch/hermes-agent) 内置 Exa，作为其模型可调用的 `web_search` 和 `web_extract` 工具的原生后端。你可以将 Exa 同时用于这两项能力，也可以将其与 Hermes 支持的其他网页提供方搭配使用。

<div id="connect-your-exa-account">
  ## 连接你的 Exa 账户
</div>

<Steps>
  <Step title="获取 Exa API 密钥">
    <Card title="获取你的 Exa API 密钥" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      在控制台中创建密钥。新账户会赠送免费积分。
    </Card>
  </Step>

  <Step title="在 Hermes 中选择 Exa">
    运行工具设置向导：

    ```bash theme={null}
    hermes tools
    ```

    打开 **Web Search &amp; Extract**，选择 Exa，然后选择通过 API 密钥认证的选项。出现提示时，输入你的 Exa API 密钥。Hermes 会将 secret 保存在 `~/.hermes/.env`，将提供方选择保存在 `~/.hermes/config.yaml`。
  </Step>

  <Step title="测试网页访问">
    启动 Hermes，让它执行一次搜索，然后读取其中一条结果：

    ```text theme={null}
    Search the web for the latest Exa product updates, then read the most relevant result.
    ```

    Hermes 应当调用 `web_search`，并在需要获取页面内容时接着调用 `web_extract`。
  </Step>
</Steps>

<div id="configure-manually">
  ## 手动配置
</div>

将你的密钥添加到 Hermes 环境文件中：

```bash ~/.hermes/.env theme={null}
EXA_API_KEY=your-exa-api-key
```

然后为两项网页能力都选择 Exa：

```yaml ~/.hermes/config.yaml theme={null}
web:
  search_backend: "exa"
  extract_backend: "exa"
```

你也可以改用共享的回退方案：

```yaml ~/.hermes/config.yaml theme={null}
web:
  backend: "exa"
```

各项能力的单独设置优先级高于 `web.backend`。这样在组合多个提供方时，你可以仅将 Exa 用于搜索，或仅用于提取。

<div id="tools-hermes-gets">
  ## Hermes 可用的 tools
</div>

| 工具            | Exa 行为                                    |
| ------------- | ----------------------------------------- |
| `web_search`  | 使用 Exa 执行 search，返回排序后的页面，包含标题、URL 和文本片段。 |
| `web_extract` | 通过 Exa Contents 从一个或多个 URL 获取可读内容。        |

Hermes 会将提取到的长页面截断至其配置的字符预算，并将完整文本存储到磁盘上。可通过 `web.extract_char_limit` 修改默认值，也可以让 agent 为单次调用请求更大的 `char_limit`。

<Note>
  无需 API 密钥，Hermes 也可通过其免密钥的免费提供方池使用 Exa。该池有速率限制，并可能在多个提供方之间轮换。如果你需要请求稳定地使用自己的 Exa 账户，请配置 `EXA_API_KEY` 并选择以 API 密钥认证的 Exa 选项。
</Note>

<div id="troubleshooting">
  ## 故障排查
</div>

<AccordionGroup>
  <Accordion title="Hermes 未选择 Exa">
    运行 `hermes tools` 并显式选择 Exa。如果你手动修改配置文件，请检查 `web.search_backend`、`web.extract_backend` 或 `web.backend` 是否已设置为 `exa`。
  </Accordion>

  <Accordion title="Hermes 提示缺少 EXA_API_KEY">
    将密钥添加到 `~/.hermes/.env`，然后重启 Hermes，使其重新加载环境变量。
  </Accordion>

  <Accordion title="搜索可用，但提取使用了其他提供方">
    Hermes 可以分别配置搜索和提取。请将 `web.search_backend` 和 `web.extract_backend` 都设置为 `exa`。
  </Accordion>
</AccordionGroup>
