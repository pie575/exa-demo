TinyHumans 推出的 [OpenHuman](https://tinyhumans.gitbook.io/openhuman) 是一款桌面 AI 助手，内置原生网页搜索工具，智能体可自行调用。Exa 正是该工具背后的搜索提供方。

| 方式               | 配置             | 运行位置                                         |
| ---------------- | -------------- | -------------------------------------------- |
| **OpenHuman Managed** | 无需配置           | OpenHuman 的后端，由 Exa 提供支持。无需 API key。         |
| **Exa 提供方**      | 粘贴 Exa API key | 你的本地设备，使用你自己的 Exa 账户直连 `https://api.exa.ai`。 |

<div id="openhuman-managed">
  ## OpenHuman Managed
</div>

托管 search 为默认方式。在引导流程中选择 **Simple**，智能体即可立即联网搜索。

<Frame caption="在引导流程中选择 Simple，即可使用由 Exa 驱动的托管 search">
  <img src="/docs/images/integrations/openhuman/onboarding-runtime-choice.png" alt="OpenHuman 引导流程询问如何运行 OpenHuman，已选中 Simple 选项" style={{width: "700px", height: "auto", margin: "0 auto"}} width="1180" height="700" data-path="images/integrations/openhuman/onboarding-runtime-choice.png" />
</Frame>

<Tip>
  **托管模式是获取 Exa 结果最快的方式。** 无需创建、存储或轮换 key，本机上不留任何凭据，search 费用直接计入你的 OpenHuman 订阅。
</Tip>

<div id="exa-provider">
  ## Exa provider
</div>

直接配置 Exa，即可使用你自己的 Exa 账户运行 search，并为 智能体 提供 Exa 的 search 和页面 contents 工具。

<div id="get-your-exa-api-key">
  ### 获取你的 Exa API key
</div>

<Card title="获取你的 Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  在控制台中创建一个 key。新账户会获得免费额度。
</Card>

<div id="add-exa-in-openhuman">
  ### 在 OpenHuman 中添加 Exa
</div>

1. 打开 **Connections**，然后在 **API keys** 下选择 **Search engine**。

  <img src="/docs/images/integrations/openhuman/connections-search.png" alt="OpenHuman 的 Connections 页面，在 API keys 下选中了 Search engine，搜索引擎列表中显示 OpenHuman Managed 处于启用状态" style={{width: "800px", height: "auto", margin: "0 auto"}} width="1180" height="820" data-path="images/integrations/openhuman/connections-search.png" />

2. 选择 **Exa**。

<Frame caption="已选择 Exa，等待填入密钥">

<div id="configuration">
  ### 配置
</div>

该面板会将配置写入 OpenHuman 的 `config.toml`。你也可以直接在该文件或环境变量中设置相同的值：

<Tabs>
  <Tab title="config.toml">
    ```toml config.toml theme={null}
    [search]
    engine = "exa"        # 必填
    max_results = 5       # 可选，1-20
    timeout_secs = 15     # 可选

    [search.exa]
    api_key = "your-exa-api-key"   # 必填
    ```
  </Tab>

  <Tab title="环境变量">
    ```bash theme={null}
    OPENHUMAN_SEARCH_ENGINE=exa
    EXA_API_KEY=your-exa-api-key
    ```

    <Note>
      `EXA_API_KEY` 和 `OPENHUMAN_EXA_API_KEY` 都会覆盖 `search.exa.api_key`。若两者同时设置，则以 `OPENHUMAN_EXA_API_KEY` 为准。
    </Note>
  </Tab>
</Tabs>

<div id="tools-the-agent-gets">
  ### 智能体获得的工具
</div>

| 工具                 | 返回内容                             |
| ------------------ | -------------------------------- |
| `web_search_tool`  | 网页搜索结果，由 Exa 提供。                 |
| `exa_search`       | 排序后的页面，包含标题、URL、发布日期以及可选的正文文本。   |
| `exa_get_contents` | 指定 URL 的完整内容，可选返回摘要或 highlights。 |

智能体会在每次调用时设置 Exa 的[搜索参数](/zh/docs/search/quickstart)，因此只需用简单的自然语言指令即可控制搜索模式、域名、日期和类别。

<div id="troubleshooting">
  ## 故障排查
</div>

<AccordionGroup>
  <Accordion title="Exa 搜索不可用：未配置 API key">
    OpenHuman 在 **Search engine** 面板、`EXA_API_KEY` 与 `OPENHUMAN_EXA_API_KEY` 环境变量以及 `search.exa.api_key` 中均未找到 key。请任选其一进行配置；如果你是在 OpenHuman 运行期间修改了 `config.toml`，请重启 OpenHuman。
  </Accordion>

  <Accordion title="Exa 拒绝了所配置的 API key（HTTP 401）">
    该 key 无效或已被吊销。请在 [Exa 控制台](https://dashboard.exa.ai/api-keys)中核对，然后点击 **Clear** 清除已存储的 key,并保存正确的 key。注意不要粘贴进多余的空白字符。
  </Accordion>

  <Accordion title="Exa 返回了非 2xx 状态码">
    `429` 表示触发速率限制或配额耗尽：请在[控制台](https://dashboard.exa.ai)中查看用量。若为 `5xx`,请先重试,再参阅[错误码](/zh/docs/admin/error-codes)。
  </Accordion>

  <Accordion title="引擎列表中没有 OpenHuman Managed">
    纯本地会话无法使用托管 search。请改用你自己的 key 配置 Exa 提供方。
  </Accordion>
</AccordionGroup>
