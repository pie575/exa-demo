TinyHumans 推出的 [OpenHuman](https://tinyhumans.gitbook.io/openhuman) 是一款桌面 AI 助手，内置网页搜索工具，agent 会自行调用该工具。Exa 就是该工具背后的搜索提供方。

| 方式                    | 配置            | 运行位置                                       |
| --------------------- | ------------- | ------------------------------------------ |
| **OpenHuman Managed** | 无需配置          | OpenHuman 的后端，由 Exa 提供支持。无需 API 密钥。        |
| **Exa 提供方**           | 粘贴 Exa API 密钥 | 你的本机，使用你自己的 Exa 账户直连 `https://api.exa.ai`。 |

## OpenHuman Managed {#openhuman-managed}

托管 search 是默认方式。在引导流程中选择 **Simple**，agent 即可立即搜索网络。

<Frame caption="在引导流程中选择 Simple，即可使用由 Exa 驱动的托管 search">
  <img src="/docs/images/integrations/openhuman/onboarding-runtime-choice.png" alt="OpenHuman onboarding asking how to run OpenHuman, with the Simple option selected" style={{width: "700px", height: "auto", margin: "0 auto"}} width="1180" height="700" data-path="images/integrations/openhuman/onboarding-runtime-choice.png" />
</Frame>

<Tip>
  **托管方式是获取 Exa 结果的最快途径。** 无需创建、存储或轮换密钥，本机上也不存放任何凭据，search 费用直接计入你的 OpenHuman 订阅。
</Tip>

## Exa 提供方 {#exa-provider}

直接配置 Exa，即可在你自己的 Exa 账户下运行 search，并为 agent 提供 Exa 的 search 与页面内容工具。

### 获取你的 Exa API 密钥 {#get-your-exa-api-key}

<Card title="获取你的 Exa API 密钥" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
  在控制台中创建密钥。新账户可获赠免费积分。
</Card>

### 在 OpenHuman 中添加 Exa {#add-exa-in-openhuman}

1. 打开 **Connections**，然后在 **API keys** 下选择 **Search engine**。

### 配置 {#configuration}

该面板会写入 OpenHuman 的 `config.toml`。你也可以直接在该文件或环境变量中设置相同的值：

<Tabs>
  <Tab title="config.toml">
    ```toml config.toml theme={null}
    [search]
    engine = "exa"        # 必填
    max_results = 5       # 可选，1-20
    timeout_secs = 15     # 可选

    [search.exa]
    api_key = "your-exa-api-key"   # 必填
    ```
  </Tab>

  <Tab title="环境变量">
    ```bash theme={null}
    OPENHUMAN_SEARCH_ENGINE=exa
    EXA_API_KEY=your-exa-api-key
    ```

    <Note>
      `EXA_API_KEY` 和 `OPENHUMAN_EXA_API_KEY` 都会覆盖 `search.exa.api_key`。两者同时设置时，以 `OPENHUMAN_EXA_API_KEY` 为准。
    </Note>
  </Tab>
</Tabs>

### agent 可用的 tools {#tools-the-agent-gets}

| 工具                 | 返回内容                               |
| ------------------ | ---------------------------------- |
| `web_search_tool`  | 网页搜索，由 Exa 提供。                     |
| `exa_search`       | 经过排序的页面，包含标题、URL、发布日期以及可选的正文。      |
| `exa_get_contents` | 指定 URL 的完整页面内容，可选返回摘要或 highlights。 |

agent 会为每次调用设置 Exa 的[搜索参数](/zh/docs/search/quickstart)，因此只需用简单的指令就能控制搜索模式、域名、日期和类别。

## 故障排查 {#troubleshooting}

<AccordionGroup>
  <Accordion title="Exa search 不可用：未配置 API 密钥">
    OpenHuman 在 **Search engine** 面板、`EXA_API_KEY` 和 `OPENHUMAN_EXA_API_KEY` 变量以及 `search.exa.api_key` 中均未找到密钥。请在其中任意一处设置；如果你是在 OpenHuman 运行期间修改了 `config.toml`，请重启 OpenHuman。
  </Accordion>

  <Accordion title="Exa 拒绝了已配置的 API 密钥（HTTP 401）">
    该密钥无效或已被吊销。请在 [Exa 控制台](https://dashboard.exa.ai/api-keys)中核对密钥，然后**清除**已存储的密钥并保存正确的密钥。注意不要带入粘贴时混入的空白字符。
  </Accordion>

  <Accordion title="Exa 返回了非 2xx 状态">
    `429` 表示触发速率限制或配额耗尽：请在[控制台](https://dashboard.exa.ai)中查看用量。若为 `5xx`，请先重试，再参阅[错误码](/zh/docs/admin/error-codes)。
  </Accordion>

  <Accordion title="引擎列表中没有 OpenHuman Managed">
    纯本地会话无法使用托管 search。请使用你自己的密钥配置 Exa 提供方。
  </Accordion>
</AccordionGroup>
