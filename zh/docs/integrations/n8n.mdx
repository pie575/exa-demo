官方 [Exa node for n8n](https://github.com/exa-labs/n8n-integration) 可为可视化工作流添加网页搜索、内容提取、有据可循的答案以及 Exa Agent 运行等能力。你既可以把它当作普通的工作流步骤使用，也可以将其作为工具连接到 n8n 的 AI Agent。

<div id="install-the-exa-node">
  ## 安装 Exa node
</div>

包名为 `n8n-nodes-exa-official`。

<Steps>
  <Step title="添加社区 node">
    在 n8n 的 node picker 中搜索 **Exa**。如果你的 instance 上没有该 node，可由 instance 所有者参照 n8n 的[社区 node 安装指南](https://docs.n8n.io/integrations/community-nodes/installation/)安装 `n8n-nodes-exa-official`。

    该 node 要求 n8n 1.60 及以上版本，Node.js 20.15 及以上版本。
  </Step>

  <Step title="创建 Exa API 密钥">
    <Card title="获取你的 Exa API 密钥" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      在控制台中创建密钥。新账户可获得免费积分。
    </Card>
  </Step>

  <Step title="添加 Exa 凭据">
    在 n8n 中添加 **Exa API** 凭据并粘贴你的密钥。在每个需要使用该账户的 Exa node 上选择该凭据。
  </Step>
</Steps>

<div id="run-a-search">
  ## 运行一次搜索
</div>

1. 为工作流添加一个触发器。
2. 添加 **Exa** node。
3. 选择 **Search**。
4. 输入 query 并选择搜索类型。
5. 选择响应格式：
   * **Results**：返回排序后的页面
   * **Text**：返回综合生成的答案
   * **Structured**：返回符合你的 schema 的 JSON
6. 运行该 node，并将其输出传递给工作流的下一步。

Search 还可以返回每条 result 的正文、highlights、摘要、链接和图片。域名过滤、发布日期、分类、`maxAgeHours` 以及子页面抓取等功能可在该 node 的可选 fields 中配置。

<div id="available-resources">
  ## 可用资源
</div>

| 资源           | 操作                                                                                |
| ------------ | --------------------------------------------------------------------------------- |
| **Search**   | 使用 `auto`、`instant`、`fast`、`deep-lite`、`deep` 或 `deep-reasoning` 搜索网络，可选综合与结构化输出。 |
| **Contents** | 针对一组 URL 获取清洗后的文本、highlights、摘要、链接和图片。                                            |
| **Answer**   | 生成带引用来源、有据可循的答案，并可选结构化输出。                                                         |
| **Agent**    | 创建、查看、列出、流式获取、轮询和取消多步骤的 Agent 运行。                                                 |

<div id="use-exa-with-an-n8n-ai-agent">
  ## 在 n8n AI agent 中使用 Exa
</div>

通过工具输入，将 Exa node 连接到 **AI Agent** node。需要由模型提供的 parameters 可以使用 n8n 的 `$fromAI()` 表达式：

```javascript theme={null}
{{ $fromAI("query", "What should Exa search for?", "string") }}
```

Search 和 Answer 很适合用作 grounding 工具。如果任务需要多步骤研究、列表构建、结构化增强或高级 [Exa Connect](/zh/docs/agent/connect/overview) 数据，请使用 Agent 资源。

<div id="wait-for-an-agent-run">
  ## 等待 Agent 运行
</div>

创建 Agent 运行时，**Wait for Completion** 支持：

* **Stream**：保持一个服务器发送事件连接处于打开状态，直到运行结束
* **Poll**：按固定间隔检查运行状态

对于耗时较长或异步的工作流，请关闭 **Wait for Completion**，保存返回的运行 `id`，稍后再使用 **Get Run** 获取结果。n8n 步骤结束后，该运行仍会在 Exa 上继续执行。

<div id="troubleshooting">
  ## 故障排查
</div>

<AccordionGroup>
  <Accordion title="node picker 中找不到 Exa node">
    请让 instance 所有者安装已验证的社区包 `n8n-nodes-exa-official`。社区 node 能否使用，取决于你的 n8n instance 采用的托管方式。
  </Accordion>

  <Accordion title="Exa 凭据被拒绝">
    确认所选凭据中包含一个来自 [Exa 控制台](https://dashboard.exa.ai/api-keys) 的有效密钥，且该密钥还有可用积分。
  </Accordion>

  <Accordion title="Agent 工作流超时">
    关闭 **Wait for Completion**，保存返回的运行 `id`，之后在后续步骤中通过 **Get Run** 获取结果。
  </Accordion>
</AccordionGroup>
