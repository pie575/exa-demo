***

LlamaIndex 是一个基于结构化数据构建 LLM 应用的框架。在本指南中，我们将使用 Exa 的 LlamaIndex integration 来：

1. 将 Exa 的 Search and Retrieve Highlight Tool 指定为 LlamaIndex retriever
2. 搭建一个在生成响应时使用该工具的 OpenAI Agent

***

## 开始使用 {#get-started}

<Steps>
  <Step title="前置条件与安装">
    安装 llama-index、llama-index core 和 llama-index-tools-exa 库。OpenAI 相关依赖已包含在核心库中，无需单独指定。

    ```Python Python theme={null}
    pip install llama-index llama-index-core llama-index-tools-exa
    ```

    同时请确保已正确初始化 API 密钥。下面的代码使用 `EXA_API_KEY` 作为对应的环境变量名。

    <Card title="获取你的 Exa API 密钥" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      在控制台中创建密钥。新账户会赠送免费积分。
    </Card>
  </Step>

  <Step title="实例化 Exa 工具">
    导入对应的 Exa integration 库，并实例化 LlamaIndex 的 `ExaToolSpec`。

    ```Python Python theme={null}
    from llama_index.tools.exa import ExaToolSpec
    import os

    exa_tool = ExaToolSpec(
        api_key=os.environ["EXA_API_KEY"],
    )
    ```
  </Step>

  <Step title="选择要使用的 Exa 方法">
    在本示例中，我们只需将 [search&#95;and&#95;retrieve&#95;highlights](https://docs.llamaindex.ai/en/stable/api_reference/tools/exa/) 方法传给 agent，因此用 LlamaIndex 的 `.to_tool_list` 方法来指定。同时还传入 `current_date`，这是一个简单的工具函数，让 agent 知道当前日期。

    ```Python Python theme={null}
    print('Tools that are provide by Exa LlamaIndex integration:')
    print('\n'.join(map(str, (exa_tool.spec_functions))))

    search_and_retrieve_highlights_tool = exa_tool.to_tool_list(
        spec_functions=["search_and_retrieve_highlights", "current_date"]
    )
    ```
  </Step>

  <Step title="设置 OpenAI agent 并发起由 Exa 驱动的请求">
    设置 [OpenAIAgent](https://docs.llamaindex.ai/en/stable/examples/agent/Chatbot%5FSEC/)，并传入上面筛选出的工具集。

    ```Python Python theme={null}
    from llama_index.agent.openai import OpenAIAgent

    agent = OpenAIAgent.from_tools(
        search_and_retrieve_highlights_tool,
        verbose=True,
    )
    ```

    随后即可使用 chat 方法与 agent 交互。

    ```Python Python theme={null}
    agent.chat(
        "Can you summarize the news from the last month related to the US stock market?"
    )
    ```

    agent 会调用分配给它的 Exa tools，再根据结果作答。具体输出会因 query 以及 Exa 返回页面的发布日期而有所不同。
  </Step>
</Steps>
