[OpenClaw](https://openclaw.ai/) 支持将 Exa 作为原生 `web_search` 提供方。选定后，每个 OpenClaw 智能体都可通过内置网页工具使用 Exa 的搜索模式、日期筛选和内容提取功能。

<div id="set-up-exa">
  ## 配置 Exa
</div>

<Steps>
  <Step title="安装 Exa 插件">
    ```bash theme={null}
    openclaw plugins install @openclaw/exa-plugin
    openclaw gateway restart
    ```
  </Step>

  <Step title="获取 Exa API key">
    <Card title="获取你的 Exa API key" icon="key" horizontal href="https://dashboard.exa.ai/api-keys">
      在控制台中创建一个 key。新账户可获得免费额度。
    </Card>
  </Step>

  <Step title="保存 key">
    若采用网关方式安装，请将 key 添加到 `~/.openclaw/.env`：

    ```bash ~/.openclaw/.env theme={null}
    EXA_API_KEY=your-exa-api-key
    ```

    修改网关的环境变量后，请重启网关。
  </Step>

  <Step title="选择 Exa 作为网页搜索提供方">
    运行：

    ```bash theme={null}
    openclaw configure --section web
    ```

    选择 **Exa** 作为网页搜索提供方。OpenClaw 会将该选择保存在配置中，并从 `EXA_API_KEY` 读取凭据。
  </Step>
</Steps>

<div id="configure-manually">
  ## 手动配置
</div>

你可以在 OpenClaw 的 JSON5 配置中直接选择 Exa：

```json5 theme={null}
{
  tools: {
    web: {
      search: {
        provider: "exa",
      },
    },
  },
}
```

如需将 key 存储在配置中而非网关环境中：

```json5 theme={null}
{
  plugins: {
    entries: {
      exa: {
        config: {
          webSearch: {
            apiKey: "exa-...",
          },
        },
      },
    },
  },
}
```

<Note>
  建议使用 `EXA_API_KEY` 或 OpenClaw SecretRef，不要将 API key 直接写入配置文件并提交。
</Note>

<div id="what-agents-can-request">
  ## agent 可以请求什么
</div>

OpenClaw 通过 `web_search` 暴露 Exa 能力。

| 参数                           | 用途                                                                           |
| ---------------------------- | ---------------------------------------------------------------------------- |
| `query`                      | 网页搜索查询词。                                                                     |
| `count`                      | 结果数量，最多 100 条，并受所选 search 类型上限的限制。                                           |
| `type`                       | Exa 搜索模式，包括 `auto`、`neural`、`fast`、`instant`、`deep` 和 `deep-reasoning`。 |
| `freshness`                  | 将结果限定在最近一天、一周、一个月或一年内。                                                       |
| `date_after` / `date_before` | 以 `YYYY-MM-DD` 为边界限定结果范围。                                                    |
| `contents`                   | 随每条结果返回全文、highlights 或摘要。                                                    |

若省略 `contents`，OpenClaw 默认请求 highlights。当 agent 需要完整页面或摘要时，可以指定其他内容形式：

```javascript theme={null}
await web_search({
  query: "transformer architecture explained",
  type: "neural",
  contents: {
    text: { maxCharacters: 5000 },
    highlights: { numSentences: 3 },
    summary: true,
  },
});
```

OpenClaw 默认将网页搜索结果缓存 15 分钟。可修改 `tools.web.search.cacheTtlMinutes`；如果每次请求都必须获取最新结果，可将其设为 `0`。

<div id="troubleshooting">
  ## 故障排查
</div>

<AccordionGroup>
  <Accordion title="OpenClaw 中没有出现 Exa 提供方">
    安装 `@openclaw/exa-plugin`，重启网关，然后重新运行 `openclaw configure --section web`。
  </Accordion>

  <Accordion title="OpenClaw 提示缺少 Exa key">
    请确认网关进程 (而不只是你的交互式 shell) 能读取到 `EXA_API_KEY`。若采用网关方式安装，请将其写入 `~/.openclaw/.env` 并重启网关。
  </Accordion>

  <Accordion title="搜索结果不够新">
    OpenClaw 会独立于 Exa 缓存结果。请调低 `tools.web.search.cacheTtlMinutes` 或将其设为 `0`，并在请求页面内容时使用 Exa 的内容新鲜度选项。
  </Accordion>
</AccordionGroup>
