只需安装一次 Exa 插件，即可让 Codex 和 ChatGPT 通过 Exa 访问实时网络内容。搜索最新信息、阅读关键来源、开展更深入的研究，全程无需离开当前对话或编码会话。

## 安装 Exa {#install-exa}

<Steps>
  <Step title="打开插件">
    访问 [chatgpt.com/plugins/exa](https://chatgpt.com/plugins/exa?open_in_app)，该链接会在 OpenAI 的插件目录中打开 **Exa**，ChatGPT 和 Codex 共用这一目录。
  </Step>

  <Step title="安装插件">
    点击加号按钮进行安装。出现提示时登录 Exa，可以在安装过程中登录，也可以在 Codex 或 ChatGPT 首次调用它时登录。

    <Frame caption="在 Codex 中打开 Plugins、添加 Exa 并授权访问">
      <img src="/docs/images/integrations/chatgpt-codex/install-codex.gif" alt="在 Codex 中打开 Plugins、查看 Exa 插件并授权访问" style={{width: "100%", height: "auto"}} width="1100" height="825" data-path="images/integrations/chatgpt-codex/install-codex.gif" />
    </Frame>
  </Step>

  <Step title="开启新会话">
    skill 只会在安装完成后新启动的聊天和 CLI 会话中加载，因此请新开一个会话，并提出需要联网的请求。
  </Step>
</Steps>

到此即可。该插件已同时包含 Exa 的 MCP integration 和 skill，无需再单独配置 MCP 或 skill。

## 基于网络上此刻的最新内容进行开发 {#build-with-whats-on-the-web-right-now}

你用来开发的库、API 和工具每天都在变化。安装 Exa 后，Codex 可以在工作过程中搜索最新的文档、issues、变更日志和实际使用示例。

在你的代码仓库中：

```text theme={null}
我们目前用的是 Tailwind v3。搜索 Tailwind v4 升级指南并阅读，
然后把这个项目迁移到 v4。
```

Codex 可以通过 Exa 搜索、阅读相关来源，并根据查到的内容直接在你的代码库中完成修改。

只要答案可能在你的代码仓库之外，这种方式同样适用：

* “在动手修复之前，先到 `tokio-tungstenite` 的 issues 和变更日志里搜一下这个错误。”
* “找一些 Rust 中 Postgres advisory locks 的真实示例，并推荐适合这个工作线程池的模式。”
* “阅读最新的 Stripe webhook 文档，并据此检查我们的实现。”
* “搜索这个依赖的最新迁移指南，然后完成升级。”

## 搜索、阅读与研究 {#search-read-and-research}

Exa 插件为 Codex 和 ChatGPT 提供了三种使用网络的方式。

## 无需离开 ChatGPT 即可开展研究 {#research-without-leaving-chatgpt}

Exa 同样支持在 ChatGPT 中使用。当提问需要最新信息时，可直接在对话中用 Exa 搜索并研究网络内容。

```text theme={null}
对比主流开源向量数据库的托管服务、许可方式和定价。
请使用最新的一手资料，并注明出处。
```

ChatGPT 不再局限于上下文中已有的信息，还能借助 Exa 查找并阅读完成任务所需的信息来源。

无论是竞品研究、技术研究、市场图谱、公司研究，还是其他任何答案散落在网络各处的场景，都可以用它来完成。

## MCP + skills 协同工作 {#mcp-skills-together}

该插件在底层整合了 Exa agent 技术栈的两个部分。

[Exa MCP](/zh/docs/get-started/exa-mcp) 为 Codex 和 ChatGPT 提供访问 Exa 的工具，是 agent 与 Exa 搜索和研究能力之间的桥梁。

[Exa skills](/zh/docs/get-started/agent-skills/overview) 则为 agent 提供额外指令，指导它在实用工作流中运用这些能力，包括网络研究和 [Exa Agent](/zh/docs/agent/quickstart)。

安装插件后，两者都无需单独配置。

## 更想直接使用 MCP？ {#prefer-mcp-directly}

插件是在 Codex 和 ChatGPT 中使用 Exa 的推荐方式。如果你要手动配置 Codex，或者使用其他 MCP 客户端，也可以直接连接到 Exa 托管的 MCP server：

```bash theme={null}
codex mcp add exa --url https://mcp.exa.ai/mcp
```

有关其他客户端、配置选项和可用 tools，请参阅 [Exa MCP](/zh/docs/get-started/exa-mcp)。
