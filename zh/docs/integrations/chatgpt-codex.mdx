只需安装一次 Exa 插件，即可让 Codex 和 ChatGPT 通过 Exa 实时访问网络。无需离开当前对话或编码会话，就能搜索最新信息、阅读重要来源并开展更深入的研究。

<div id="install-exa">
  ## 安装 Exa
</div>

<Steps>
  <Step title="打开插件">
    访问 [chatgpt.com/plugins/exa](https://chatgpt.com/plugins/exa?open_in_app)，该链接会在 OpenAI 的插件目录中打开 **Exa**，ChatGPT 与 Codex 共用这一目录。
  </Step>

  <Step title="安装插件">
    点击加号按钮即可安装。出现提示时登录 Exa，可以在安装过程中登录，也可以等到 Codex 或 ChatGPT 首次调用它时再登录。

    <Frame caption="在 Codex 中打开 Plugins、添加 Exa 并授权访问">
      <img src="/docs/images/integrations/chatgpt-codex/install-codex.gif" alt="在 Codex 中打开 Plugins、查看 Exa 插件并授权访问" style={{width: "100%", height: "auto"}} width="1100" height="825" data-path="images/integrations/chatgpt-codex/install-codex.gif" />
    </Frame>
  </Step>

  <Step title="开启新会话">
    技能只在安装完成后新建的聊天和 CLI 会话中加载，因此请新开一个会话，并提出需要联网的请求。
  </Step>
</Steps>

这样就完成了。该插件已同时包含 Exa 的 MCP 集成和技能，无需再单独配置 MCP 或技能。

<div id="build-with-whats-on-the-web-right-now">
  ## 用网络上最新的内容来开发
</div>

你所依赖的库、API 和工具每天都在变。装上 Exa 后，Codex 可以一边工作，一边搜索最新的文档、issue、更新日志和真实用例。

在你的代码仓库中：

```text theme={null}
我们目前用的是 Tailwind v3。搜索并阅读 Tailwind v4 升级指南，
然后把这个项目迁移到 v4。
```

Codex 可以用 Exa 搜索、阅读相关来源，并根据查到的信息在你的代码库中完成修改。

只要答案可能在你的仓库之外，这套做法同样适用：

* “在动手修复之前，先搜索 `tokio-tungstenite` 的 issue 和更新日志，找找这个错误。”
* “找几个 Rust 中使用 Postgres 咨询锁的真实示例，并推荐适合这个工作线程池的模式。”
* “阅读最新的 Stripe webhook 文档，并对照检查我们的实现。”
* “搜索这个依赖项的最新迁移指南，然后完成升级。”

<div id="search-read-and-research">
  ## 搜索、阅读与研究
</div>

Exa 插件为 Codex 和 ChatGPT 提供了三种利用网络信息的方式。

<Columns cols={3}>
  <Card title="搜索" icon="search">
    用自然语言搜索，直接拿到最匹配页面的内容，而不是一串链接。
  </Card>

  <Card title="阅读" icon="file-text">
    读取你指定的页面，无论是文档、更新日志、issue 还是博客文章。
  </Card>

  <Card title="研究" icon="compass">
    深入处理需要多次搜索才能解答的问题，并给出带引用来源的答案。
  </Card>
</Columns>

<div id="research-without-leaving-chatgpt">
  ## 无需离开 ChatGPT 即可开展研究
</div>

Exa 同样支持在 ChatGPT 中使用。提出需要最新信息的问题，直接在对话中用 Exa 搜索和研究网络内容。

```text theme={null}
比较主流开源向量数据库的托管服务、许可协议和定价。
请使用最新的一手资料并注明出处。
```

ChatGPT 不再只能依赖上下文中已有的信息，而是可以借助 Exa 查找并阅读完成任务所需的资料来源。

可用于竞品调研、技术调研、市场版图梳理、公司调研，或任何答案散落在网络各处的场景。

<div id="mcp-skills-together">
  ## MCP + 技能，协同工作
</div>

在底层，该插件整合了 Exa 智能体技术栈中的两个部分。

[Exa MCP](/zh/docs/get-started/exa-mcp) 为 Codex 和 ChatGPT 提供访问 Exa 的工具，是智能体与 Exa 搜索和研究能力之间的桥梁。

[Exa 技能](/zh/docs/get-started/agent-skills/overview) 则为智能体提供额外指令，指导它在实用的工作流中运用这些能力，包括网络研究和 [Exa Agent](/zh/docs/agent/quickstart)。

安装插件后，两者都无需单独配置。

<div id="prefer-mcp-directly">
  ## 更想直接使用 MCP？
</div>

在 Codex 和 ChatGPT 中使用 Exa，推荐通过插件的方式。如果你想手动配置 Codex，或者使用其他 MCP 客户端，也可以直接连接 Exa 托管的 MCP 服务器：

```bash theme={null}
codex mcp add exa --url https://mcp.exa.ai/mcp
```

有关其他客户端、配置选项和可用工具，请参阅 [Exa MCP](/zh/docs/get-started/exa-mcp)。
